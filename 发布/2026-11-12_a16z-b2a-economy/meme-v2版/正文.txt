a16z 合伙人 Olivia Moore 11 月 11 日发了一篇长文《Welcome to the B2A Economy》，第一句是：互联网的主要用户已经不是人了，是 AI agent。企业卖东西的对象，正在从人（B2C）变成替人办事的 agent（B2A）。

前阵子我报名一个 Hackathon，是 Grok bot 定期翻我的 Outlook、自己填表提交的。报名表那一头，来填表的已经不是人。

文章里的几组数：
1. Shopify 一季度来自 AI 的流量涨了 8 倍，AI 搜索带来的订单涨了近 13 倍
2. GitHub 四成以上的代码合并请求，第一稿由 agent 写，半年前是 17%
3. Vercel 由 agent 触发的部署一年涨了 28 倍

B2A 的四类机会：agent 本身 / 只有 agent 才能催生的新产品 / 为 agent 优化的老公司 / agent 基础设施（支付、风控、身份、通讯）

让产品和内容被 agent 找到，自查三道门：
① 读得懂：信息结构化，商品和内容能被直接抓取
② 用得了：有插件、接口或 MCP，agent 不用在网页上点来点去
③ 付得了：注册和支付不会被风控当成机器人拦掉

国内平台更倾向自己做自己的 agent，所以国内做产品还要多问一句：被谁家的 agent 找到。

你做的产品，A 已经能让 agent 直接用，还是 B 还在防着它？评论区打 A 或 B。
