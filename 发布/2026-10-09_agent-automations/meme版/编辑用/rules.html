Anthropic 给定时 agent 定的六条规矩

claude.dev 博客《Building effective agent automations》，Lance Martin、CJ Avilla，2026-10-08。参考实现在 claude-quickstarts 仓库 managed-agents/daily-brief
1每个源记一个书签不读「过去 24 小时」。跑完把最新一条的时间戳写进文件，下次从那接着读。跑晚不漏，跑早不重
2读不到不等于没事MCP 挂了、token 过期，任务照跑但看不到那个源。书签不动，简报末尾写一行「PR 这次没读到」
3发之前每条再核一遍读完到发出去之间世界在变。没了就删，变了就改，查不到就删。拿不准的一律不发
4Slack 回 ok 才算发了先查今天发过没有；回了 ok 才算；之后才更新账本和书签。不确定就标「maybe posted」
5偏好每次重读，agent 只读偏好写进提示词会一直按旧规矩跑。放在它改不了的文件里，读不到就停下说一声
6只读的地方只给只读，每次跑有花费上限token 只读、网络白名单。上限先设正常一次的 3 到 5 倍，撞到是暂停不是报错
agent 本身只做一件事：判断哪几条你今天会动手，发出去。「12 个 PR 待审」不算一条。大多数日子只有几条，有时候一条没有。
