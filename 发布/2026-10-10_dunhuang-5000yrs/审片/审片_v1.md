# 审片 v1：敦煌风·上下五千年（成片_v1.mp4）

审片人：独立审片（未参与制作）。日期 2026-10-10。
看法：每秒 1 帧全片 + 每朝 6 个关键时刻（全景 / 快推前 / 快推 / 快推后 / 拉回 / 横移）+ 跳变点逐帧 + 国旗、飞天、驼队、龟甲原尺寸放大；音频用 ebur128 / astats / silencedetect。帧在 scratchpad/审片帧/。

## 总评
画风统一、物都画得具体，四库四色、活字反字、《论语》《梦溪笔谈》原文顺序这些细节做对了，可以发；但 15 朝用的是同一个模板（左上题签 + 中间一个物 + 第 3 小节一帧硬推 + 竖边框切到下一格），三分钟看下来像一串翻页的格子，不像一条长卷。飞天、莫高窟崖壁、九层楼这三个跟敦煌关系最大的画面，反而是全片最弱的。

## 打分：6.5 / 10
- 物认不认得出：7.5（16 个里 12 个一眼懂，飞天 / 崖壁 / 九层楼 / 造纸偏弱）
- 画风统一：8
- 运动和镜头：5（快推是一帧跳切，15 次一模一样）
- 节奏：5.5
- 史实：7.5（无硬伤，几处可挑）
- 收尾：5

## 问题清单（按严重程度）

### 严重
1. **15 朝同一个模板，翻页 PPT 感**（全片，每 10.9 秒一次）
   - 看到：每朝都是「竖边框 + 左上竖题签 + 画面正中一个物 + 第 3 小节第一拍突然放大 + 拉回 + 横移进下一个边框」。朝与朝之间有一根绿色竖框条（如 16.05s、37.87s、59.69s、114.24s），观众看到的是一格一格的画板在平移，而不是一条连着的长卷；底色还在赭黄 / 土红 / 深蓝之间换，强化了「下一页」感。
   - 建议：去掉朝与朝之间的竖框条，让相邻两朝的景在交界处互相长进去（长城的山连到驼队的山、宝船的浪连到书架下的地、高铁的桥接进月面）；快推的位置和方式至少分 3 种（有的推、有的摇、有的物自己走到镜头前）；题签不要每次都钉在左上同一个点。

2. **「快推」是一帧硬跳，不是推**（10.90→10.97s、21.8s、32.7s、43.6s、54.5s … 每朝第 3 小节第一拍）
   - 看到：scene 检测在每个第 3 小节第一拍都有一个单帧跳变（43.67s 的长城最明显），画面直接放大 1.2 倍、上下花边框直接被裁掉，没有中间帧。连续 15 次后像卡顿。
   - 建议：用 6–10 帧的 ease-out 推上去，落点仍卡拍；或者只保留几朝的跳切，其余改慢推。

3. **结尾太短、太小、不像莫高窟**（169.1–180s）
   - 看到：
     - 174.57s 一刀切到无边框的近景，丝带「钻进窟口」这个动作没有发生，丝带是绕进了一座塔的身上（171–174s）；
     - 「九层楼」画成了一座逐层收分、独立的楼阁式塔（红白柱 + 绿檐），真九层楼是贴崖而建的窟檐建筑，顶是攒尖、立面几乎等宽，跟画的不是一种东西；
     - 窟口里「前面走过的每一朝」只有约 40px 的小图标，手机上完全认不出是哪朝；
     - 题记「上下五千年 敦煌莫高窟」177.4s 才淡入，满屏只停约 2.3 秒，最后 1 秒音乐骤降（−29 dB）就结束了；题签还压在右侧两列窟口图标上，丝带头也被题签挡住（179.5s）。
   - 建议：尾声给到 8–10 秒，前 3 秒让丝带真的钻进一个窟口；九层楼按 96 窟窟檐的立面画（贴在崖面上、九层檐、顶层攒尖）；拉远前先在 3–4 个窟口上停一下（彩陶、飞天、天安门、嫦娥），让观众认出「前面那些都在这里」；题记放大到画面高度 1/3 以上、居中或放在空的天空区，至少停 4 秒再收。

4. **飞天粗糙，出戏**（81.5–92.4s，89.0s 放大最清楚）
   - 看到：头是一个黑圆盘（背面发髻）上压着一朵粉花，身体是一截红色胶囊，后面拖一条绿色叶片状裙摆，远看像蝗虫 / 螳螂；左下两块浅色手脚像骨头。这是全片唯一一个大人物，又是敦煌最出名的形象，现在是最弱的一张。
   - 建议：照莫高窟 320 窟 / 321 窟唐代飞天的姿态重画：身体呈 S 形横飞、上身裸露带璎珞、双手可见、长裙包脚、飘带绕臂两三圈；不画五官可以，但要有脸的轮廓和侧向。琵琶反弹更好认。

### 中等
5. **莫高开窟一段画面空**（70.9–81.8s）
   - 看到：三危山是三个红色三角，崖壁是一块画着横线的方板，71.91s 时整块方板只有一个窟口，像一张白纸；横移进来那几秒没有东西在动。「山头放出金光」后的金色小铃铛形状读不出是什么。
   - 建议：崖壁做成有凹凸的砂岩立面（上宽下窄、带层理和栈道），开凿过程加一个凿子 / 火光；三危山做成锯齿峰，金光用放射状光束 + 千佛小坐像的剪影。

6. **造纸一段不好认、空**（60.0–70.9s）
   - 看到：一个棕色大槽 + 一根横棍 + 几张白纸条，61.0s 右半屏完全空。没有手、没有竹帘的帘纹特写，晾的纸像便签。
   - 建议：快推时给竹帘一个近景（帘纹 + 纸浆从帘缝滴下），墙上晾的纸贴在墙上（焙纸）而不是夹在绳上；右侧空区放一捆竹 / 一堆树皮麻头，交代原料。

7. **太空两段大面积空屏**（136.4–147.3s、158.2–169.1s）
   - 看到：深蓝底 + 一颗小卫星 + 一条丝带，137–147 秒约 10 秒里画面 80% 是空的；快推的「从地平线后转出来」几乎看不出。深蓝大底也是全片唯一脱离壁画土色的段落。
   - 建议：深蓝改成敦煌青金石蓝的壁画天空并保留地仗颗粒，用卷云纹 / 星宿图填天；卫星加《东方红》的乐谱 / 电波纹（已有弧线可加强）；地球画大一点占画面下 1/3。

8. **题签和字被切、被挡**
   - 看到：快推时左上题签被裁一半（22.36s「殷商甲骨」、66.0s「蔡伦造纸」、98.73s「毕昇活字」只剩半个「年」）；飘落的小花压在题签字上（75.41s「开」、119.05s「库」、157.87s「娥」、92.42s「年」）。
   - 建议：快推时题签单独一层不跟着放大，或推的中心避开左上；花瓣粒子层放到题签下面。

9. **剥落斑块挡住主体**（54.5–58.6s 驼队快推、11.45s 等）
   - 看到：做旧的白色剥落斑块在丝带头、天空主体上方，55.0s 丝带头整个钻进剥落块里看不见。
   - 建议：剥落层避开每朝主体和丝带头的路径，或改为只在画面边缘。

10. **快推的事件有几朝太弱**
    - 张骞（54.5s）：说好的「节上牦牛尾在风里甩」几乎看不到，画面就是丝带往天上飞；
    - 郑和（109.1s）：「船头劈开浪头」只有船头一小撮白泡；丝带在桅杆上方飘，没挂成旗；
    - 毕昇（98.17s）：纸直接一刀出现在字盘上，没有「压下去再揭起」；
    - 编钟（32.7s）：没有木槌，是丝带头去敲钟。
    - 建议：这四朝的第 3 小节要有一个大动作，占画面 1/3 以上。

11. **蚕有点 Q 版**（0–5.5s）
    - 看到：白色圆球串 + 一个大眼睛，像表情包里的毛毛虫；开头第一个镜头就有点卡通。
    - 建议：去掉眼睛，用铁线描画出体节和细腿，颜色偏米黄。

### 轻微 / 史实
12. **秦长城画成了明长城**（38.2–49.1s）：砖砌、带垛口和砖楼，镜头表还写「砖一块块垒上」。秦长城主要是夯土和石块。可改成夯土墙 + 版筑木板，或者把题签改成不强调「秦」。
13. **四库全书 1772 年**：1772 年是乾隆下诏征书，四库馆 1773 年开馆。写「1773 年」或「乾隆年间」更稳。（经绿、史红、子蓝、集灰的四色是对的。）
14. **毕昇 1040 年**：《梦溪笔谈》写的是「庆历中」（1041–1048）。建议写「约 1045 年」或「北宋庆历年间」。
15. **张骞「西行」但驼队朝右（东）走**（49.1–60s）：长卷时间轴向右可以理解，但懂行的会挑。可以让驼队朝左走、丝带从右往左搭上驼背；另外张骞出使是外交不是运丝绸，驼背上的货物不必强调丝绸。
16. **郑和宝船 5 桅**：记载多为 9 桅，画 5 桅不算错，但「宝船」可以多画几根。
17. **国旗也加了裂纹做旧**（132.6–136s）：星的位置和朝向画对了，但国旗上叠裂纹和剥落质感，在小红书可能被挑「不尊重」。建议国旗那一层不叠做旧纹理。
18. **《论语》竹简最后一枚是孤零零的「不」**（33–37s）：句子在「不亦乐乎」中间断开。减一枚简停在「来」，或补全「不亦乐乎」。
19. **字盘架和四库书架长得一样**（92.7–103.6s 右侧红格架 vs 114.5–125.5s）：两朝挨得近，同一种红格子重复。字盘架可改成转轮排字盘（王祯式）或木格浅盘。

### 节奏
- 拖：莫高开窟横移进来那 5 秒（70.9–76s）、东方红一号整段（136–147s）、嫦娥五号全景（158–163s）都是物不动、画面空。
- 太快：尾声只有 10.9 秒，其中有效题记 2.3 秒；九层楼满壁窟口这个「全片回收」画面没给够时间。
- 整体：15 朝等长 × 10.9 秒，没有快慢变化，无口播时三分钟偏长。建议给 3–4 个重点朝（开窟、开元飞天、1949、嫦娥）各多一小节，其余压到 3 小节，尾声补到 4 小节以上。

### 音频
- 整体响度 −14.9 LUFS，真峰值 −1.2 dBFS，没有削波、没有静音段，作为手机平台的响度合适。
- 响度范围只有 3.0 LU，逐秒 RMS 从头到尾都在 −15 到 −21 dB 之间波动，没有起落：开头第一秒就是满音量（没有淡入），近现代段和古代段听起来一样大，尾声没有收的空间，最后 1 秒直接掉到 −29 dB 结束。
- 建议：开头 1–2 秒淡入；1949 / 嫦娥起来一点；尾声前留一小节降下来，题记出现时再给一个长音收尾，留 1.5 秒余音。音色没法评价。

## 做得好的地方
- 画风统一：土红 / 赭黄地仗、矿物色平涂、深色勾线、上下卷草和三角幡花边全片一致，没有蓝紫渐变、没有给物加脸（除了蚕的眼睛），没有一镜一画风的拼贴。
- 每一朝都有一个具体的物，不是空背景配文字：彩陶盆上的鱼跳出来钻进丝带（11.1s）、龟甲裂纹炸开（22–26s）、编钟受敲泛波纹、书架按经史子集四色一格格填满（115–124s）、丝带顺旗杆升起变成国旗（131–133s）、嫦娥上升器带火起飞（164s），这几个动作都好懂。
- 细节做对了，经得起懂行的人看：活字在字盘里是反字、印出来是正字，内容是《梦溪笔谈》「庆历中，有布衣毕昇，又为活板……」原文，竖排右起顺序正确；竹简是「学而时习之，不亦说乎，有朋自远方来」右起排列；四库四色经绿史红子蓝集灰正确；国旗五星位置和小星朝向正确；骆驼是双峰驼；张骞手里有节。
- 一匹丝带贯穿全片，没有断开，横移时跨过两朝的交界线是连着的，作为线索成立。
- 题签用竖排加〇的汉字年份，跟壁画题记一致。
- 人物按设定不画五官，驼队里的行人虽然简单但不出戏。
