Anthropic 官方放出的一段对谈：Claude Code 团队的三位工程师（Thariq、Sid、Robert），聊他们自己现在怎么用 Claude Code。

一年里的三个转变：
① 不盯过程，只给目标。Sid 七八成的工作在 Slack 里的 Claude Tag 上完成，不再看每一次工具调用
② 功能是临时的。早期模型五件事只做三件，团队加了待办清单；一年后这个功能不需要了。底层模型每两个月一变
③ 人只看大局。审代码不再挑小毛病，人只盯接口怎么设计、边界划在哪

模型每两个月换一次，你搭的流程迟早要拆。能留下来的，只有你给它的那个目标。
