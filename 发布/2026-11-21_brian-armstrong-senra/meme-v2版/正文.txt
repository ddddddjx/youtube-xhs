最近反复看的 AI 播客，第一期是 Coinbase 联合创始人兼 CEO Brian Armstrong 上 David Senra 的 60 分钟对谈。主持人问十年后全球交易有多少是 agent 跟 agent 之间完成的，他答：99.999%。

我挑了五件跟我自己对得上的：
1. 给 agent 的不再是提示词，是一块责任田：它带着子 agent 去做，回来问你「先做 1、2、3，同意吗」
2. 7 到 8 个主 agent + 一个幕僚长 agent，加一个「待决收件箱」：按 1 / 2 / 3、语音口述，像清邮箱一样清决策
3. Coinbase Brain：每个团队、每个代码仓库一个「脑」，每晚把会议纪要、事故复盘、代码评审提炼进去
4. agent 已经相当于大厂 5、6 级员工，但不完全像人：潜艇不像鱼
5. agent 理财四层：以后每个人口袋里一个私人银行家

我的 agent 工作流跟他很像，最大的体会是：agent 交回来的应该是一个决定，不是一篇作文。放手越久，出了问题回溯越长，所以 agent 开得越多，检查点越要设得密。

想看原片：agent 工作流在 17 到 30 分钟，Coinbase Brain 在 20 分钟，理财四层在 53 分钟。

你现在同时开着几个 agent？交回来的是决定，还是作文？
