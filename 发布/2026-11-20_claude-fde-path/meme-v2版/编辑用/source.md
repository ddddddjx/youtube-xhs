Forward Deployed Engineer
Learning path
Claude Forward Deployed Engineer path
Take a customer from a first use case to a working pilot, on site.
Self-paced
about 9.5 hours
What you can do at the end
Write a pilot plan for a customer use case: the baseline you’ll measure against, the success measures you agree on before building, the part of the use case you’ll ship first, and how you’ll bring on the first wave of users.
Before you start
You build software and you have worked directly with client teams. This path shares nine courses with the Claude Developer path, so if you’ve completed that path, two courses remain, about 100 minutes in all.
Time and format
About 9.5 hours in all. Take the courses in order or one at a time.
