这个号每天读一篇海外 AI 一手内容，每篇留一段能直接用的东西，想每天顺手看一篇，点个关注就行。

给 Claude Code 的指示写得再明确，做出来还是会偏。这周 Claude Code 团队的 Thariq 发了个 skill，把 plan 做成网页，4500 多人收藏。我顺手把 Claude Code、Codex、Kimi Code、Qoder、Cursor 的 plan 模式查了一遍，进法都是 Shift+Tab 或 /plan，差别在方案长什么样、它会不会先问你。

他做进网页的那几样，不装插件也能直接打进提示词，任何一家的 plan 模式都适用：
方案里先列出需要我拍板的问题，别替我默认。
列出这次要动哪些文件，哪些明确不动。
需求用一句大白话写，不写技术词。
界面用项目里已有的组件，不要新画。
方案控制在我一分钟能看完的长度。

想装插件，两行，在终端里跑：
claude plugin marketplace add anthropics/claude-plugins-community
claude plugin install html-plan@claude-community
装完用 /html-plan 加一句描述来调，要本机有 Node.js。
