原通义灵码		/plan 开关只读探索、出方案、你确认。常和 Goal 搭配：plan 里定方案，退出后 /goal set 让它自己跑完
CursorShift+Tab，复杂任务它会主动建议先问你几个澄清问题，再查代码、写方案；方案是 markdown，你在对话或文件里改，点 build 才动手。方案默认存用户目录，可存进仓库
共同点：都是只读、先出方案、你批了才改代码。差别在方案长什么样（一段文字、一个文件、一块界面）和它会不会先问你问题（Cursor、Kimi 会，Claude Code 默认不会，Thariq 的 html-plan 把问题标红摆在目录里）。
