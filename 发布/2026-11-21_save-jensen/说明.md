# 小工具：拯救黄仁勋（像素小游戏 · 平行宇宙 · 纯属虚构）

用户 11-21 要的像素小游戏：剧情是「平行宇宙里黄仁勋被董事会解聘，玩家把他带回英伟达」。用户先提过加「出轨」背景，没做（真人私生活，名誉风险，审核必拦）；「被解聘」是公司剧情，按「平行宇宙 · 纯属虚构 · 与英伟达公司及黄仁勋本人无关」的前提做，开头和成绩卡都写了。没用英伟达 Logo，像素形象自己画。

## 玩法
三关跑酷，点屏幕跳、可二段跳。你（黄外套）在前，老黄跟在后面复刻你的跳跃。
- 第一关 台北夜市：小吃摊 / 机车 / 灯笼柱；臭豆腐、粉丝两次「拉走老黄」
- 第二关 湾区街头：路锥 / 狗仔 / 汽车；猎头、狗仔两次
- 第三关 英伟达总部：文件堆 / 保安 / 纸箱；董事一次 + 终点「董事会投票」：联名信越多，需要连点的次数越少（8 到 20 次）
- 「拉走老黄」时世界慢放，3.6 秒内连点够数就拉回来（+2 封联名信），失败扣一颗心；每关 3 颗心，失败从本关重来、联名信保留
- 结局：老黄穿皮衣回到舞台，大屏「欢迎回来，老黄」
- 称号按联名信收集率：临时救火员 / 员工代表 / 董事会克星 / 老黄的贴身心腹
