# 小工具：你在 AI 第几层（10 题测试）

接 10-14 Karpathy 漏斗稿（`发布/2026-10-14_karpathy-capability-funnel/`）。10 道题，每题 0–3 分，满分 30，按分数分到 Karpathy 的四层。

## 文件
- `小工具/index.html`、`小工具/app.js`：源码（脚本外置、不联网、语法 ES2017 / Chrome 61 已用 espree 校验）
- `小工具.zip`：打包好的产物
- `图标.png`：1024×1024，1:1
- `编辑用/预览/`：手机尺寸截图和四层结果卡

## 分层
| 分数 | 结果 | 往下一层的一件事 |
|---|---|---|
| 0–8 | 第 1 层：还没真正用起来（60 亿人） | 下一封邮件 / 周报先让 AI 写初稿 |
| 9–17 | 第 2 层：把 AI 当好一点的搜索（10–20 亿） | 别再问问题，把最花时间的整件活交出去 |
| 18–25 | 第 3 层：0.2%，用 agent 干活（2000 万） | 一个每天自动产出的定时任务 + 自检标准 |
| 26–30 | 第 4 层门口（5000 人） | 给 agent 产出建验收，解决人的审查速度 |

真正的第 4 层是实验室内部用未发布模型的人，问卷测不出来，所以最高档叫「第 4 层门口」。

## 用到的平台能力（都先判断方法是否存在，在普通浏览器里也能跑完测试）
- 存相册 `saveImageToPhotosAlbum`（9.42+），先 `writeTempFile` 落临时文件
- 发笔记晒结果 `postNote`：标题「测了一下，我在AI第N层」+ 结果卡
- 带结果去评论区 `interactionOpenApi`（9.49+）
- 关注作者 `followAuthor` / `getFollowStatus`（9.51+）
- 上次结果 `setStorage`（9.46+，低版本降级 localStorage）
- 点选项轻振 `vibrateShort`（9.50+）
- 没用 AI 接口，不需要申请内测白名单

## 上传（电脑端，创作服务中心 → Builder Hub → 小工具 → 新建）
- 名称（≤14）：`你在AI第几层`
- Slogan（≤14）：`10道题，测你在AI第几层`
