Claude Code 里，给 agent 的话分两种

Addy Osmani《Your Coding Agents Made You a Manager》
请求：模型可以不听
  • 提示词
  • CLAUDE.md 里的规矩
  • skill
大多数事放这里。它看着真实代码，比你事先写的规则更清楚这条适不适用
强制：一定执行
  • hook（比如类型检查不过就不让结束）
  • deny 规则（比如不许改生成的代码）
  • 托管设置
只放「必须永远 / 绝不」的那两三条
他的两条判断：加粗了还不听的请求，改成 hook；表达偏好的 hook，删掉。全大写、「别偷懒」「再想想」，新模型已经不需要了
