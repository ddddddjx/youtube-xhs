这周我常用的那个AI输入法，第一次把免费周额度用完了。它倒没直接停掉，而是给我降速，我对着电脑说一大段提示词，字要等好久才慢慢冒出来。

我用它很久了，其实一分钱都没充过。但这次我也没去充，周六自己做了一个，真正动手的时间加起来大概两个半小时。晚上十一点多，我在备忘录里按住键盘右边那个键说了一句话，松开，屏幕上就出现了这一行。

被降速的那个叫 Typeless，在华人圈挺流行。你张嘴说话，它就替你打字，而且打出来的是收拾过的字。这个赛道里融资最多的一家，今年 8 月刚拿到新一轮，估值 20 亿美元。

那天中午，我在 Claude Code 里开了个新对话，第一句问的是，能不能找个逆向工程的项目，把 Typeless 拆开照着做。

它劝我别逆向，说有法律风险，也没这个必要，用开源的组件拼起来就够了。我回了句「好的」，十几分钟以后，第一版代码就已经提交了。

下午我去忙别的事，晚上十点半回来接着弄：先建了个仓库，再把环境装好，最后填上 DeepSeek 的 key。做出来的东西，流程大概是下面这样。

![SayType 的四步](flow.png)

前两步谁都做得到，手机自带的听写也能把声音变成字。

值钱的是第三步。你说话的时候会带「嗯」「那个」，会说到一半改口，Typeless 卖的就是把这些口语收拾成你本来想写的那段话。我这版是让 DeepSeek 来做这一步的，识别交给一个开源的模型，就跑在自己电脑上，一句话几乎是松手就认完了。

翻车当然也有。第一句话打出来之后，App 紧接着就崩了，菜单栏上的图标直接消失。我在对话里跟它说：「我说完第一次话后，就找不到它了。」

Claude 去翻了崩溃报告，定位到是识别完以后，在后台线程里刷新了菜单栏，红框里那一行就是。

![崩溃报告里的调用栈](crash_box.png)

修完这个，重装的时候又碰上识别服务注册失败，只好再修一次。还有一个问题到现在也没完全解决：我戴着 AirPods 说中文人名，它常常会认错，最后只能加一个个人词库，让 DeepSeek 照着词库去纠正。

成本这块，我自己都有点意外。整个项目只用掉了 Claude Code 本周额度的 8%。DeepSeek 我充了 2 美元，听说能用很久，到现在一共花了不到 1 美分。

![DeepSeek 后台](deepseek_box.png)

你要是也每天对着 AI 说一大段话，大概就能明白这东西为什么值钱。打字跟不上脑子的时候，替你把话理顺的那个软件，就是你一天里打开次数最多的那一个。

![三本账](compare.png)

当然，我手里这个离能卖还差一大截。签名和公证要弄，设置界面得做，钱怎么收也还没想，iPhone 的键盘还不让用麦克风，每一样都比那个晚上难。但是产品的形态是一样的，按住说话，松开就是整理好的字。

所以我在认真想下一步，去找投资人，把它往海外做。Typeless 和 Wispr 主打的是英文，国内也有大厂在做免费的听写，我想先去东南亚试试。如果你在做投资，或者在东南亚做产品，想聊聊的话，可以私信我。

做完这个以后，我就再也没打开过 Typeless 了。
