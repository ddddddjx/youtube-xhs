agent 有没有网络效应？a16z 的 Andrew Chen 今天发了一篇长文，专门聊这件事。他写过一本讲网络效应的书，这篇收藏 700 多。

他的结论是 agent 天生没有网络效应，更像邮件客户端，你用 Gmail 我用 Outlook，照样互相发。但他觉得接下来会有一场边界之争：通用 agent 会把文档、交易、介绍、活动都拉回自己家托管，每成功一次，就把别人的网络效应变成自己的。

我手机上 Claude、Codex、Grok 三个换着用，现在换起来没成本。等它们开始替我托管别人会点开的东西，就不一定了。

原文在 X 上搜 Andrew Chen「Do agents have network effects」就能找到，后半篇那段「边界之争」值得读原文。你现在主力用哪个 agent？如果明天让你换一个，最舍不得的是它记住的东西，还是它帮你做过、发给别人的东西？
