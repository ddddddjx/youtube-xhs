非常推荐大家读一读 Andrew Chen 今天在 X 上发的这篇长文，题目就一句话：agent 有没有网络效应。做 agent 产品的，或者每天在几个 AI 之间换着用的人，看完会对「以后用谁家的」多一层想法。

他是 a16z 的合伙人，之前在 Uber 管过乘客增长，写过一本专讲网络效应的书《The Cold Start Problem》。这篇发出来没多久，收藏 700 多。

背景是最近冒出来一批面向普通人的通用 agent，Muse、Town、Instinct、Grokbot，底子是 OpenClaw、Hermes 这类开源 agent，外面包了一层更安全、更好上手的壳。

大厂迟早也会下场，那几千家做旅行、购物、家庭这些垂直 agent 的创业公司，就得想清楚自己还有没有位置。

他先把反方的理由讲得很完整。这些 agent 用起来是一个人的事，虽然长得像聊天软件，但和 WhatsApp、电话网那种人越多越好用的东西不一样，更像邮件客户端：你用 Superhuman，同事用 Outlook，朋友用 Gmail，邮件照样互相发。

底下的大模型可以换，记忆和上下文也就是一堆文本文件，AI 搬起家来又特别快。

这点我挺有体感，手机首屏放着 Claude、Codex、Grok 三个，哪个顺手用哪个，换起来几乎没有成本。

所以他换了个问法：先别把网络效应当成一个模糊的词，拆到拉新、留存、变现三个指标上，看 agent 要做哪些功能才能真的长出网络效应。他还特意补了一句，这里说的「用户更多」，指的是人和人之间连得更密，规模大不算。

我从里面挑三点和大家聊聊。

1、新年聚会的那个群，可能就是 agent 拉新的地方

以前的产品拉新，靠用户自己发邀请、分享内容、在评论里 @ 人。到了 agent 这里，拉新的动作可以由 agent 来发起。

他举的例子很家常。agent 问你一句「要不要我帮你张罗一下新年的家庭聚会」，然后拉一个群，把兄弟姐妹、岳父岳母、爸妈都放进去，再做一个小网页让大家报名回复。

工作里也一样，你刚做完一份 PPT，agent 问要不要约个会给团队讲讲，顺手把会前文档和会议记录都挂在它托管的小网页上。

这套东西要跑起来，agent 得能读你的通讯录，知道哪件事该拉哪些人，还得能用邮件、消息把人够到。难的是分寸，他自己举了个反例：没人想收到「Andrew 想下周约你吃午饭」，后面紧跟一句「注册这个 agent 才能回复」。

更值得注意的是内容这条路。Google Slides、Figma、Notion 都是靠一个分享出去的链接长大的。

比如你跟 agent 聊装修，它最后给你做了一块类似 Pinterest 的灵感板。照他的推演，一个调好的 agent 会把这块板子挂在自己家，而不会去建一个真的 Pinterest 板；预算表也做成自己的小程序，不去开 Google Sheet，因为挂在自己家才帮 agent 传播。

他料到读者会觉得这听上去像骚扰，但他认为可以做得有分寸。留存高的 agent，有很多次机会把你的朋友慢慢拉过来。第一次邀请你没理，后来朋友分享来的网页正好用得上，你为了留个评论注册了，再后来别的功能也用上了。

2、约饭用不着同一个 agent，找人就需要了

留存这块，他问得很直接：别人都用同一个 agent，你的 agent 会不会更好用？

约会议、组饭局这类事，答案是不太会。agent 之间发邮件、看日历，就算各家不一样，也能商量明白。

但有几类事，大家用同一个 agent 会好很多。比如「旧金山有哪 10 个人值得见一见」，靠 agent 之间一个个问，凑不出最优解。

再比如「找一个没在公开看机会、但愿意为一家快速增长的公司跳槽的工程 VP」，这里面混着公开和私密的信息，被问的那一方 agent 要是觉得对方不可信，可能会说谎。

还有「接下来 5 分钟订一家朋友和他们带的人都满意的晚餐，过敏、时间、位置都算上」。

这几件事要的是信任、身份、发现和一份共享的上下文。他的推演是，某一家可以建一层只给自己 agent 用的网络，你在里面贡献的数据越多，你的 agent 就越好用。

接着他又给了一层反驳：也可能冒出一批专门给 agent 用的服务，比如一个任何 agent 都能来卖东西的新一代 eBay，身份和信誉放在那一层。他觉得两种都会发生，最后的样子更像分散，很难一家通吃。

3、agent 帮你做的东西挂在谁家，决定了以后换不换得动

文章最后，他的结论是 agent 天生没有网络效应。模型更好、体验更好、接入更多、分发更强，都能做出很大的公司，但这些算不上网络效应。

他预测接下来会有一场边界之争，每个大的通用 agent 都会想把有价值的网络功能拉进自己的墙里：文档自己托管，不去建 Google Doc；交易自己完成，不把你送去 Amazon；介绍自己来做，不去搜 LinkedIn；活动自己办，不用 Partiful。

每成功一次，就把别人的网络效应变成了自己的。老牌网络和新的创业公司正好相反，会想办法对所有 agent 开放，让哪一家都搬不走。

所以他觉得更值得问的，是网络效应会长在哪里。如果长在开放协议和专门的网络里，会有成千上万个 agent 在智能、个性、体验、价格上竞争，垂直 agent 也活得下去。

如果少数几家通用 agent 把身份、关系、私密上下文、信誉都攒在自己手里，换 agent 就意味着把自己的人脉一起丢下。

回到手机上那三个 AI，现在换来换去没成本，是因为它们还没替我托管过任何别人会点开的东西。他说接下来几年看这件事怎么演变会很好玩，这点我也同意。
