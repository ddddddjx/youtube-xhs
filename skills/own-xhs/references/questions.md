# 写稿前先问（own-xhs 版）

读完素材发给用户的那段话，照这个模板，150 字摘要 + 三问，不多问。

```
摘要（30 秒）：
这是 <谁> 写的 / 讲的 <什么>。核心判断：<一句>。支撑它的：<事实 1>；<事实 2>；<事实 3>。最可争论的一句原话：「<原句>」。

三个问题，答完我再写：
1. 日程：这周或者最近，你哪天干了什么跟这件事沾边的事？要日期、地点、结果，给三条。见客户、出差、带家人、配 agent、改需求都算；假设的也行，标一句「假设」。
2. 判断：你对这件事自己的三到五句话，不用整理，语音转文字直接发，半截话也要。
3. 两年后：你觉得两年后这件事会怎样，一句。
```

回答原样存成 `编辑用/输入.md`，不改字、不删语气词：

```
# 输入（用户原话，不改）

## 判断
- <一行一条，用户原话>

## 日程
- <一行一条，带日期 / 地点；假设的开头写「假设我」>

## 原话
- <用户回答里值得原样进稿的句子，尤其是半截的、重复的、「不知道」的>
```

判断不到 3 条或日程不到 3 条：回一句「还差 N 条判断 / 日程，补了我走 own 模式；不补就按转述写」。
