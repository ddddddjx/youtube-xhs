# 写稿前先问（own-xhs 版）

读完素材发给用户的那段话，照这个模板，150 字摘要 + 三问，不多问。

```
摘要（30 秒）：
这是 <谁> 写的 / 讲的 <什么>。核心判断：<一句>。支撑它的：<事实 1>；<事实 2>；<事实 3>。最可争论的一句原话：「<原句>」。

三个问题，答完我再写：
1. 日程：这周或者最近，你哪天干了什么跟这件事沾边的事？要日期、地点、结果，给三条。见客户、出差、带家人、配 agent、改需求都算；假设的也行，标一句「假设」。
2. 判断：你对这件事自己的几句话，不用整理，语音转文字直接发，半截话也要（进稿只留 1 到 2 条，10-14 起）。
3. 两年后：你觉得两年后这件事会怎样，一句。
4. 立场（10-18 起）：这篇回到你哪条长期立场？A 「AI 取代的是不做判断的人」/ B 「活要整个交给 AI 才算用上，短板是我」/ C 「稳定听话比惊艳值钱，选模型看活不看榜」/ D 「角色边界在消失，人留在回路里拍板」。选一个字母，或者说一条新的。
```

第 4 问的答案写进 draft.md 的 `stance_line`；用户说的新立场先进 `账号/档案.md` 观点库，再决定要不要加进长期立场那张表（四条以内，多了就不叫持续）。

回答原样存成 `编辑用/输入.md`，不改字、不删语气词：

```
# 输入（用户原话，不改）

## 判断
- <一行一条，用户原话>

## 日程
- <一行一条，带日期 / 地点；假设的开头写「假设我」>

## 原话
- <用户回答里值得原样进稿的句子，尤其是半截的、重复的、「不知道」的>

## 立场
- <A / B / C / D，或用户新说的一条>
```

判断一条没有或日程不到 3 条：回一句「还差 N 条判断 / 日程，补了我走 own 模式；不补就按转述写」。
