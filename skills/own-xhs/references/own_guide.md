## 1. 骨架：他那篇的 66 段是怎么排的

| 位置 | 他写的 | 来源 | own 模式对应 |
|---|---|---|---|
| 第 1 段 | 「连续看了 Instinct 创始人 Noah Shinn 和分析师 Ben Thompson 对 Personal Agent 的讨论，还是想写一些我的理解。」 | 素材 + 意图 | 这是他的起法之一，不固定；也可以从用户的一条日程或最大的判断起，素材放第二段。Noah 和 Ben 点一下再没出现 |
| 第 2 到 5 段 | 「AI 行业的风向变化实在太快了。」→ ChatBot 到 Personal Agent 一年多 → Muse 火了讨论重点变了 → 「好像，应用的时代应该真的来了。真的来了。当然……现在不敢下结论。」 | 他最大的判断 + 正在想的句子 | 用户判断里最大的一句 + 用户原话里的半截话 |
| 第 6 到 8 段 | 「很多人会抨击说炒作」→「是的，它更像是组合……所以也不能叫炒作」→「所有的创新本质都是 Mix。我写几点自己的理解。」 | 替读者反驳 + 收拢 | 可选，用户回答里有反驳就用 |

| 二、 | 判断句「Token 消耗再次跃迁」→ ChatGPT、o1、Coding Agent 三个节点 → 第四个 → 「AI 的工作时间，开始和人的在线时间脱钩。」 | 判断 + 已知清单里加一个 + 一句感叹 | 没日程也行，但全篇至少 3 个编号下有 |
| 三、 | 判断句「隐私靠技术解决」→ 元素组合 → 数据越敏感 → Meta Secure VM / Confidential VM → 「这个思路我觉得是可行的。总之就是……」 | 判断 + 行业当下的名词 + 原话式收尾 | 名词从用户工作里、这周新闻里拿 |
| 四、 | 判断句「Agent Network 水到渠成」→ **比如我想约一个朋友，周三没空，给我两个时间，其中一个我在出差** → 两个 Agent 自己协调 → 「会长出新一代微信一样的产品」 | 判断 + 日程 + 押注 | 押注不限 |
| 五、 | 判断句「下一代互联网总入口」→ JTBD → **我刚刚还在折腾 10 月 6 日的海底捞订餐，家人过生日** → 海底捞会出 Agent → 有人会说屏蔽怎么办 → **比如我要去上海出差** → 「谁掌握了用户的意图，谁就拿到了最上游的入口。」 | 判断 + 两个日程 + 反驳 + 结尾一句有分量的话 | 结尾停在用户「两年后」那句 |

读完这张表能看出：**五个编号句全是他的，五个场景全是他的日程，原文一个字没引。** 这就是 own 模式。

## 2. 五种段落，各写成什么样

1. **判断句**（编号句）：一句话，主语是行业里的东西，不是文章。「Personal Agent 很可能会成为下一代互联网的总入口。」用户给的是半句就补成一句，用词不换。
2. **日程段**：「假设我今天上午十点要去拜访一个客户。」「我刚刚还在折腾 10 月 6 日的海底捞订餐。」时间在前，事在后，一段只讲一件事，下一段才讲 Agent 会怎么做。用户给的日程照时间地点写，不加他没说的细节。
3. **展开段**：两三句，「因为」「所以」「比如」接着往下，解释判断为什么成立。这是 Claude 唯一大段写的地方，用的名词要是用户工作里的或者这周行业里的，不是原文里的。
4. **正在想的句子**：「好像，应用的时代应该真的来了。真的来了。」「现在不敢下结论。」「这个思路我觉得是可行的。总之就是……」只用用户原话，没有就不写。Claude 写出来的「正在想」一眼假。
5. **一句感叹**：「Personal Agent 开始有眼力见了。」「AI 的工作时间，开始和人的在线时间脱钩。」放在一段具体场景后面，单独成段。前一段抽象就不许。

## 3. 和 meme-xhs 规则的取舍

| meme-xhs 的规则 | own 模式 | 为什么 |
|---|---|---|
| 「假设我」最多 1 个、默认不写 | 不限 | 小盖 3 个，全是他的日程。限的是 Claude 编的，不是用户给的 |
| 押注最多 1 处 | 不限 | 小盖 4 处。判断对着世界下本来就是押注 |
| 「我觉得」最多 4 处 | 不限 | 小盖 7 处。限的是每段表态却没有场景 |
| 结尾不写对仗金句 | 不查 | 「谁掌握了用户的意图，谁就拿到了最上游的入口」就是对仗。前面有海底捞和上海出差，这句是人说的 |
| 结构词孤段 ✗ | 不查 | 「我写几点自己的理解。」「举个很简单的例子。」他都有。前后是场景就不是路标 |
| 首屏要时间锚、数字、反差 | 不查 | 他首屏三样都没有，第一句是信源 |
| 信源压成半句放第二段以后 | 反过来：第一句就是信源 | 点一下就走，之后不再提 |
| 访谈默认 retell，主语是「他」 | 不用 | 同一种素材的另一条路：用户有判断就走这条 |
| 1300 到 2200 字 | 1800 到 3500 | 五个判断各带场景，短不了 |
| 李录四条（不露生产过程、不直译、不打分、有钩子） | 照旧 ✗ | 这四条是用户的要求，和输入无关 |
| 标题公式、两张图、图下正文顺序 | 照旧 | 点击率和关注率的数据撑着 |
| 不预告、不导流、不极限词 | 照旧 | 平台和账号边界。小盖的「后面还想单独写一篇」我们不学 |

## 4. 交付前自己念一遍的四个问题
