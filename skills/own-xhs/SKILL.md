# own-xhs：meme-xhs 的加强输入版

**一句话**：这个 skill 就是 meme-xhs，只改一处：问用户要更多（判断、日程、原话），然后把拿到的东西放进稿子。文体选择、写法、检查、出图、标题、正文、交付，全部照 `../meme-xhs/SKILL.md` 和它的 `references/writing_guide.md` 走，这里不重复写。

为什么要它（10-08，对照小盖 Personal Agent 稿，`对标/小盖/口吻拆解.md` 第四批）：小盖的 24 条做法早就学进 meme-xhs 了，照着写还是被认出是 AI，因为规则管的是输出，他那篇的活人感来自输入：判断是他的，场景是他的日程，想到一半的话也是他的。这三样只能从用户那里拿。

## 文件

- `$O` = 本目录：`references/questions.md`（三问模板和 输入.md 格式）、`references/own_guide.md`（用户的东西怎么放进各文体 + 小盖那篇逐段拆）、`scripts/own_check.py`（先量输入进没进稿子，再跑 meme_check 全套，用户原话命中的警告自动放行）。
- `$M` = 同级 `meme-xhs`：SKILL.md、writing_guide、render_meme.py、box.py、render_illus.py、avatar.png 全部照用。
- `$Y` = 同级 `youtube-xhs`：check_paste.py、post_log.py。
- 输出目录：`发布/<YYYY-MM-DD>_<英文短标题>/meme版/`（和 meme-xhs 同一个目录名，读者和仓库都不分；`编辑用/` 里多一个 `输入.md`）。

## 和 meme-xhs 的差异（只有这四条）

### 1. 写稿前先问：三问，要具体东西（替代 meme-xhs 的 1.5 步）

读完素材，先发 150 字摘要（谁写的、核心判断一句、两三个事实、最可争论的一句原话），然后按 `references/questions.md` 问三样：

1. **日程**：这周或最近哪天干了什么跟这事沾边的，日期、地点、结果，三条。假设式的也行，标「假设」。
2. **判断**：你自己的三到五句话，不用整理，语音转文字直接发，半截话也要。
3. **两年后**：你觉得两年后会怎样，一句。

回答原样存 `编辑用/输入.md`（`## 判断` `## 日程` `## 原话` 三节，一行一条，不改字）。带日期的真日程进 `账号/经历库.md`（假设式标「假设」，不算经历），判断进 `账号/档案.md` 观点库。

判断不到 3 条或日程不到 3 条：告诉用户差几条；不补就回 meme-xhs 原流程（「你定」就按 meme-xhs 默认写）。

### 2. 文体照 meme-xhs 第 2 节选，多一种可选

七种文体（转述荐读、荐读、解读、观察、实测、活动见闻、热点快评）照旧按素材选，开头照 writing_guide 第 3 节，不固定任何一种起法。own 模式多一种 **自述判断**（front matter `genre: 自述`，小盖那种）：素材只是第一句引子，骨架是用户的判断当编号句，每个编号下放用户一条日程，原文里的人点一下不再出现，1800 到 3500 字。素材是分析文章或话题、而且用户给的判断本身能撑起骨架时用它；素材是本人讲自己真事的访谈照旧走转述荐读。哪种文体，在摘要那条消息里先说，用户不改就按它写。

### 3. 用户的东西怎么进稿子（`references/own_guide.md`）

不管哪种文体：
- 用户的判断进编号句或「我觉得」的位置，意思和用词不换；转述荐读里就是结尾和挑三点那几句「我」的话。
- 用户的日程进「假设我 / 比如我 / 那天我」的位置，带日期地点；转述荐读里替掉本来要用原文场景的那一两处。
- `## 原话` 里的句子原样放，含「不知道」「可能吧」「真的来了。真的来了。」，不润色。
- Claude 的活：排顺序、写接句、把半句补成整句。不替用户生成判断，不编场景。交付时指出哪几句是 Claude 接的。
- meme-xhs 里对 Claude 写的东西设的上限（假设我最多 1、我觉得最多 4、押注最多 1、结尾对仗、retell 里「我」最多 6），**用户给的句子不算在内**；Claude 自己写的仍然算。
- 李录四条、黑名单、标题公式、两张图、不预告不导流，照旧。

### 4. 检查

```bash
python3 $O/scripts/own_check.py "<输出目录>/meme版"
```

它先查输入：判断至少 3 条进稿且原文没说过、日程至少 3 条进稿且带日期地点、原话没被改写、连续 4 段抽象 ✗；再跑 meme_check 全套（标题、封面、节奏、黑名单、李录四条）；最后把 meme_check 里命中用户原话的「假设我 / 我觉得 / 押注 / 对仗 / 身份场景」警告改成 ✓ 放行，计数型的上限（推演 N 处、第一人称判断 N 处、预言 N 处、retell「我」N 次）只报数不扣。own_check 过了就不用再单独跑 meme_check；`ai_tone.py` 照跑，它报的上限同样对用户原话不算。

其余步骤（出图、标题三条、正文.txt、check_paste、post_log `--series meme`、每张图 SendUserFile、汇报）一字不差照 meme-xhs 第 5 到 8 步。汇报多一段：用了用户哪几条判断、哪几条日程、哪几句原话，哪几句是 Claude 接的。
