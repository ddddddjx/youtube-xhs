# 首图数据可视化 + 观点高亮（样本：崔璀优势星球 / Naval 3个选择）

## 首图（缩略图就要看懂）
- 超大黑标题：人名/来源 + 一个数字结论（「其实只有 3 个」）
- 标题下不是长文，是 **3 条编号观点卡**，每条 = 圆角色块标题 + 一张极简图
- 图只服务一句话：曲线对比、柱状「核心优势」、上升折线。线稿小人可有，不放真人照片
- 配色少：白底 + 一种主色（红/黄/青绿）做色条和图。信息流缩小后仍能数出 1/2/3
- 不要封面制作备注；数字本身就是钩子

## 内页「一整句」强化（不是散点加粗）
- 内页顶部重复本篇大标题，系列一眼认出
- **黄底高亮整句观点**（引用、结论、反常识），一页最多 1–2 处。高亮的是完整判断，不是单个词
- 编号小标题单独成行，加粗；下面才是展开故事
- 故事里给具体人、具体数字，再落到被高亮的那句结论
- 每条观点可扫：色块 → 图/高亮句 → 一句人话

## 落到我们的五图
- 01 若内容能拆成 2–3 点：用「编号色块 + 极简图」替代纯文字堆叠
- 02–05：结论句用整句高亮（黄底或红结论条），关键词加粗留在句内，不替代整句
- 图必须对应本页观点，不装饰
