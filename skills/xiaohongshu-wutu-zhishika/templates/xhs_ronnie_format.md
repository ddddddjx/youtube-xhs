# 罗尼先生图文格式（研报笔记轨）

蒸馏自账号「罗尼先生」样张（大摩 AI 三类瓶颈帖，约 11 页轮播）。
参考图：`samples/ronnie_refs/`

与现有「五图知识卡 / Dankoe」轨**并列**：适合研报、机构纪要、长逻辑链蒸馏；不默认替代 5 张短知识卡。

---

## 一句话 DNA

**纸质研报笔记感**：米白底 + 衬线体 + 藏青完整判断句 + 底部信源证据卡。信息密度高，像在读内部 memo，不是生活种草。

---

## 视觉规格

| 项 | 规则 |
|---|---|
| 画幅 | 竖图轮播（约 3:4）；页数可长（样张 11 页），一帖一事 |
| 底色 | 米白 / 浅奶油纸感（非纯白刺眼，非黄底高亮卡） |
| 主字色 | 正文纯黑 |
| 强调色 | 藏青 / 深蓝（约 `#2B4B7C`），只给**页标题 + 完整判断句** |
| 字体 | 全文衬线（宋体感 / Noto Serif CJK）；英文术语同衬线 |
| 页码 | 右上角小灰胶囊：`N/M` |
| 顶栏品牌 | 左上：圆形头像 + 账号名（可带认证标）+ 日期 `MM/DD`；截图外发也认得出主 |

配色极克制：米白 / 黑 / 藏青，最多再加一枚「信源标签」黄条。禁止红字卖点条、编号彩虹色块（那是崔璀轨）。

---

## 单页结构（从上到下）

1. **顶栏**：头像 · 名字 · 日期  
2. **页标题**：1–2 行藏青大衬线，一页只钉一个论点  
3. **正文**：2–4 段黑字短段；术语可中英混排（GPU、networking、Astra、Tech Bytes）  
4. **判断句（核心）**：1–2 句**完整观点**用藏青加粗放大，嵌在正文流里——不是零散加粗词，也不是黄底色条块  
5. **证据卡（可选，封面/关键页优先）**：底部圆角白卡 + 轻投影，放研报封面 / 图表 / 原文截图，当「信源证明」  
6. **分隔**：必要时细横线拆「优先级 / 为什么」等块

### 封面页额外

- **信源写进标题第一行，和结论同样的大字**（例：「Dan Koe 长文：／ 你不是没自律 ／ 是你其实不想去」「CMU 公开课：／ Skill 别让 AI 凭空写」）。封面一共三行：第一行信源，后两行判断
- 信源进标题后**就不要再挂左上角那个黄底小角标**，同一件事说两遍只会挤掉字号；角标留给栏目名 + 期数这类信息
- 中部或底部必有证据卡（报告表头 / 图表 / 原文配图）  
- 正文开篇点名：机构 + 日期 + 报告名  

### 内页

- 一页一个逻辑节点（算力网络极限 / Networking 血管 / Astra 改需求…）  
- 中段 1–2 句藏青完整判断做扫描锚点  
- 可无证据卡；有则继续「截图即证明」

---

## 文案（图下 caption）

```
标题：新闻句，与封面判断同向（例：AI钱开始换方向，大摩押注三类瓶颈）

正文：
- 第 1 句：机构 + 日期 + 报告名（大摩 9/7 Tech Bytes）
- 2–4 句：拆成可带走的结论（三类瓶颈 / 谁受益 / 需求端变化）
- 保留英文硬术语，少 emoji，无「带走清单」制作套话

标签：密标签块，宽+窄混搭
例：#AI #大模型 #金融投资 #howto投资 #人工智能 #IPO #财经
```

标题可搜（机构名 / 瓶颈 / 投资方向）；正文可点（钱在换方向）；图内可带走（完整判断句 + 证据卡）。

---

## 内容策略

| 维度 | 做法 |
|---|---|
| 信源 | 机构研报 / 内部纪要优先；开篇写死名字+日期 |
| 密度 | 敢密；靠留白边距 + 短段 + 藏青句破墙，不靠大图装饰 |
| 语气 | 分析师口吻，可争论结论，不鸡汤 |
| 长度 | 可 8–12 页长链；若并入本流水线默认交付，仍可压成 5 页精华版，但版式规则不变 |

---

## 反模式

- 用无衬线大字封面冒充本轨  
- 高亮只加粗两三个词，不成句  
- 去掉证据卡却自称「内部纪要」  
- 封面红字「带走清单」或制作备注  
- 把崔璀编号彩虹块叠进米白衬线页  

## 出图检查

- [ ] 米白底 + 衬线 + 藏青只给标题/完整判断  
- [ ] 顶栏品牌 + 右上页码  
- [ ] 封面有信源证据卡  
- [ ] caption：机构日期开篇 + 密标签  
- [ ] 未混入 Dankoe 红字条 / 崔璀色块首图
