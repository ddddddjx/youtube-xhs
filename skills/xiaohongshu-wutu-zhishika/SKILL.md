# 小红书五图知识卡格式

把英文圈 AI/产品相关内容做成 **竖图轮播 + 可粘贴文案**。

本包为可移植完整版：Skill 正文 + 依赖模板 + 样张。细则见 `templates/`，样张见 `samples/`。

## 风格轨（先定轨再出图）

**默认轨：五图知识卡（Dankoe）**
- 可信开篇 @dotey → `templates/dotey_voice.md`
- 兴趣转化「这很盒里」→ `templates/xhs_heili_engagement.md`
- 首图可视化 + 整句高亮 → `templates/xhs_visual_highlight.md`
- 黄金样张：`samples/dankoe_v4_no_cta/`
- 规格：1080×1440；默认 **5 张**无 CTA 末页；系列 **AI产品精读**

**并列轨：罗尼研报笔记**（使用者或内容主编点名「罗尼 / 研报笔记 / 机构纪要」时用）
- 细则 → `templates/xhs_ronnie_format.md`
- 样张 → `samples/ronnie_refs/`
- DNA：米白纸感 + **全文衬线** + **藏青完整判断句** + 底部**信源证据卡**；页数可长（样张约 11 页），一页一论点
- 勿与 Dankoe 红字卖点条、崔璀编号彩虹色块混用

## 默认轨文风
- **dotey**：强钩子 → 权威来源 → 关键术语 → 硬数字；短段对比
- **盒里**：可争论标题、一手信源、人物剧爆点；结尾可评论问题
- **高亮**：强化的是**一整句观点**（黄底或色条），不是零散加粗几个词。一页 1–2 句。编号小标题单独成行
- 封面红字只写术语/数字/结果，禁「带走清单」

## 默认轨首图 UI
能拆成 2–3 点时：超大标题（来源+数字结论）+ 编号色块 + 极简图（曲线/柱/折线，不放真人）。缩略图要能数出 1/2/3。配色少。

## 罗尼轨要点（摘要）
- 顶栏：头像+账号名+日期；右上 `N/M`
- 封面标题第一行写信源（「Dan Koe 长文：」「CMU 公开课：」），和结论用同样的大字；写进标题就别再加左上角小角标
- 页标题藏青大衬线 → 黑字短段 → 嵌 1–2 句藏青完整判断 → 可选圆角投影证据卡（研报/图表截图）
- caption：新闻句标题；正文机构+日期+报告名开篇；密标签；保留英文硬术语

## 视频来源 → 关键帧证据卡（新增）
来源是 YouTube 视频（讲座 / 访谈 / 发布会）时，按 `templates/video_keyframes.md` 执行：
1. yt-dlp 下载视频 + 英文字幕 → 读字幕提炼观点（用自己的话写，不逐字翻译）
2. `scripts/extract_keyframes.py` 抽候选帧 → 看 `contact_N.jpg` 挑 PPT / 图表帧（3–4 张）
3. `scripts/grab_frame.sh` 抽原分辨率帧（动画页往后挪几秒，可 crop 幕布）
4. 写 `cards.json` → `scripts/render_cards.py` 出图 → 必看 `overview.jpg` 检查
5. 写 `标题.txt` + `正文.txt`（含视频出处 + 截图版权说明）——纯文本，可原样粘贴进小红书，不带任何 Markdown 符号或占位提示

有证据卡时默认走**罗尼研报笔记轨**（当前 `render_cards.py` 实现的就是这一轨）。

**使用者账号**：`assets/account.json`（Krypto说AI）+ `assets/avatar.png`。出图时把 `avatar.png` 复制到 cards.json 同目录，`account` 填 `{"name": "Krypto说AI", "avatar_image": "avatar.png", "date": "MM/DD"}`，日期用出图当天。

## 共用交付
直接发图+文案；不打 zip 给运营；不登录个人社交账号自动发帖。
- 标题出 3 版（数字型 / 冲突型 / 人物型）写进 `标题备选.txt`，推荐的那条写进 `标题.txt`；每条带一个会被搜的关键词。封面同样出 3 版（`covers.json` → `封面备选/`）
- 正文里要有一段明确立场（先问使用者站哪边），倒数第二段一句话预告下一期；封面角标写「栏目名｜第 N 期」
- 出处只写「来源：频道名 / 作者 · 标题」，**文案和卡片上都不放站外链接**，不出现「油管」「翻墙」「VPN」「微信」等词；交付前跑 youtube-xhs 的 `check_paste.py`（会拦链接和导流用语，极限词 / 投资用语给 ⚠）
关键词：AI/AI产品/大模型/Agent + 来源术语。时间窗优先近 2 周。勿默认「一人公司」。日期以原文 permalink 页面显示为准。

## 反模式
封面与昨天撞同一句；开篇藏权威；高亮只描单词；纯装饰图；制作套话；过期帖；未定轨就混用罗尼衬线与 Dankoe 红字/崔璀色块

## Krypto说AI 账号覆盖规则（2026-09-22 复盘，优先于上面的轨）

- **封面 = 一句 8–14 字大字**（`title`，只能是问句或「不是 X，是 Y」反差句，**不能是答案**）+ 左上眉标「海外精读 #N · 信源名」（`tag`）+ **一张大图**（`evidence`：人物大图，或有冲突感的画面；课件截图不算大图）。导语、信源角标、图表、小字、正文摘要全部下沉到第 2 页「信源页」。首图是认知劫持不是信息传递
- 09-24 复盘：4 张「标题 + 4–6 行摘要 + 小截图」的封面点击率 4.9–8.2%，唯一放了大图的 12.3%。缩略图里摘要就是一块灰：要么有大图（图为主），要么没有任何图（下面的「字为主」），一半字一半截图的封面不要交付
- 三版封面（A 认知冲突 / B 好奇缺口 / C 数字锚定）写在 `covers.json` 单独渲染到 `封面备选/`；把大字单独念一遍，是答案就重写
- **没有人物大图时用「字为主」封面**（09-24，dbs-content 封面维度：字为主 / 图为主要二选一，一半字一半截图在缩略图里两头都看不清）：`cover: true` 且不给 `evidence`，脚本会把大字放到 175px、留出上下空白（封面大字一律黑字）；大字断成 3 行、每行 ≤6 个汉字宽，关键 2–4 个字用 `==高亮==` 打黄底（账号统一的黄色）。藏青衬线留给内页。截图、导语一律不上封面
- **信源图：原文页首截图**（09-24 定的默认做法，钩子 + 信源在一张图里）：大字 3 行在上，下面放原文页面最顶部的截图——只要标题、副标题、作者、日期那一块，不要正文、导航栏、代码图。这块在缩略图里读作「官方 / 某某博客」，比课件截图可信，也比纯留白有东西看。抓法：`Google Chrome --headless=new --force-device-scale-factor=2 --window-size=1200,700 --screenshot=hero_raw.png <URL>`，再用 ffmpeg `crop` 到标题块（约 1240×640），存成 `编辑用/ev_hero.png`，caption 写「来源 · 作者 · 日期 · 阅读时长」。有人物大图时人物优先，人物和页首都没有才用纯留白
- 封面页只有三层：黄标签眉标（栏目 + 信源）→ 3 行黑色大字（问句 / 反差句）→ 页首截图或留白。头像行是脚本自带的，不再加别的
- 封面标题第一行不再写「Dan Koe 长文：」「CMU 公开课：」这种信源前缀（上面罗尼轨那条对本账号作废）：人名 / 机构进眉标 `tag` 和标签，大字留给问句
- **下一期预告只能抄 `yt2red/发布/排期.md` 同栏目的下一篇**，做完就更新排期表；没排就先排（09-25：此前 9 篇预告 0 兑现）
- **末页是名片卡**，不再是「无 CTA」：`title` 写「关注看下一期」，`blocks` 写一句定位「每周精读 2 篇海外 AI 课程 / 长文」+ 下一期预告标题 + 「评论区扣 1 领本期模板」。每期同一版式。不写「求关注」「点个赞」
- 倒数第 2 页「我的看法页」：一句可以被反对的判断 + 二选一问题，和 正文.txt 一致
- 术语在封面上最多 1 个且跟人话；人名 / 机构进眉标和标签
- 文案顺序、置顶评论、可领取物、五维自检都按 youtube-xhs 的「封面、标题、文案硬规则」
