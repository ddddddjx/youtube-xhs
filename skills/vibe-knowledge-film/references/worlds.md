# 三套外观的规格

可选的外观有三套：**A 鎏金**（电影感暗金，11-03 起的默认）、**B 寓言**、**C 夜曲**。
A 是《运气的形状》那一套，10 月曾停用；11-03 用户给的简报要"电影感、暗金色调——近黑背景、金色渐变标题、米白衬线中文、暗角、胶片颗粒、漂浮的金色尘埃、柔和光晕"，正是它，所以恢复成默认。

数值量自参考片，换算到 1920×1080；引擎里的默认值（`vk-kit.js` 的 `PAL`、`SUB`，`vk.js` 的 `BG`）就是这张表。竖屏 1080×1920 的版式在文末「竖屏」。
复刻对照图在 `examples/`。

## 选哪一套

| 你的题目 | 选 | 因为 |
|---|---|---|
| 没指定，或要电影感、暗金、"有文化底蕴" | A 鎏金 | 简报的默认；近黑底上金字和米白宋体，实物（骰子、金币、书页）压暗一档也好看 |
| 一个心理或行为机制，起点是动物实验或生活场景，终点是"你该怎么办" | B 寓言 | 需要角色和场景来讲故事，需要一把贯穿全片的"尺子" |
| 一个抽象概念（数学、逻辑、信息、物理），能拆成几个可以当场演的小实验 | C 夜曲 | 用大字、带刻度的仪器和画得像实物的东西来演，声音可以完全合成 |

一条片只用一套世界。A 和 B 共用片名卡和字幕习惯。

**简报里的风格词落到 A 的哪一处**：近黑背景 = `BG.gilt`（`warm` 1 暖棕 / 0 冷蓝黑）；金色渐变标题 = `K.headline` / `K.titleGilt`；米白衬线中文 = 字幕（宋体 Bold，`#E8E3D9`）；
暗角 = `vignette .62`；胶片颗粒 = `fr.look.grain`（默认 .05）；漂浮的金色尘埃 = `BG.gilt` 的 `dust`；柔和光晕 = 辉光 .34。

## 共用

- 画布 1920×1080（竖屏 1080×1920，见文末），30fps。左右各留 5%（96px），上下各留 4%。
- 中文：宋体用 Noto Serif SC（思源宋体，可变字重 200–900），黑体用 Noto Sans SC。
  西文：Cormorant Garamond（标题、数字，开等高数字）、Lora Italic（英文字幕）、JetBrains Mono（等宽小标）、Courier Prime（打字机）。
  参考片的确切字体认不出来，这几款是最接近的开源字体，复刻对照下来观感一致。
- 所有亮的东西有辉光（出帧时把内容层模糊后加回去）；全幅一层很淡的胶片颗粒；四角压暗。
- 字幕永远水平居中，一行，不换行，不加底板。

## B 寓言

**底** 每场一幅用代码画的扁平插画：大色块 + 少量细节 + 柔和渐变，不描边，不写实。
分三层画：远景（天、地平线、远处的草）、角色层、前景（画框边上的草叶），镜头推拉时三层移动量不同。
画面自带一圈暖色暗角。辉光只开 0.12。片名和"规则卡"的时候才回到暗场。

**场景配色**（参考片的五个地点）

| 场景 | 天 | 地 | 点缀 |
|---|---|---|---|
| 海滩（现在） | `#99ABB1` → 近地平线 `#E6DCC4` | 沙 `#DBC898` | 喙 `#DD612C`，假蛋 `#DDAE4A` + 红晕 |
| 海滩（20 世纪中叶） | 同上，做成老纪录片：泛黄 + 椭圆暗角 + 片门抖动（`K.sepia`），只作用在场景上，仪表和字幕保持原色 | | 标注用深棕 |
| 澳洲荒漠 | `#82AFD3` | 红土 `#9B4A26` | 草 `#B8B46A` |
| 夜里的书桌 | 窗外蓝紫光斑 | 桌面 `#2A160A` | 橙子、奶茶、手机屏 |
| 芦苇荡黄昏 | `#874952` → `#E8A070` | 芦苇杆近黑 | 大红嘴 `#E8402A` |
| 夜空 | `#0A0B12` | — | 手机屏的暖光 |

**色** 字幕暖白 `#FFFAEB`；规则句金 `#EEC672`；"超常"的一切是红 `#FC593F`（关键词、仪表红区、红晕、计数）。

**版式**

| 元素 | 位置 | 字 |
|---|---|---|
| 仪表「本能读数」 | 左上，约 45–390 × 35–240 的深色圆角面板 | 半圆表盘 0–150，刻度 50 / 100 / 150，100 以上红弧并标"超常"；指针；中间读数（过 100 变红）；面板下一行"对象：×××"黑体 28 |
| 场景说明 | 左上小字 | 年份黑体 Bold 36 金色 + 地点 28 灰 |
| 顶部结论行 | 居中 y≈65 | "1950 · 银鸥雏鸟会啄亲鸟嘴上的红点"，黑体 34，字距 0.12em |
| 对照计数 | 左右各一组，y≈185–300 | 标签 34 + 数字 90（真的 = 白，夸张的 = 红） |
| 引线标注 | 贴着东西 | 黑体 30–36 + 一根细线；打勾的写"棕色 ✓" |
| 卡片 | 居中，略微倾斜（−1°） | 米色纸 `#D4CABA`，横线，投影；标题用斜体学名 + 宋体；内容深棕 |
| 字幕 | 中线 y=966（89.4%） | 黑体 Bold 48，字距 0.07em，深色投影；逐字亮起（每字 0.16s，错开 0.07s） |

**角色** 一个主角从头到尾（参考片是一只蛎鹬）。形体用四五个色块拼成，动作只做必要的：走（两条腿交替）、低头、扑翅、卧下。
主角在开场出现、在片尾回来；中间的例子各有各的角色，但画法一致。

**片名卡** 和 A 是同一张（金字、放射线），母题图形换成本片的（一枚蛋形细线）。从场景进片名是"压暗"：0.55s 暗到底，金线从暗里浮出来。

**声音** 同 A。

## C 夜曲

星点和彗尾光点只是底和片名卡的装饰，参考片里它们只在片名那几秒当主角。正片的主体是认得出的东西：大字、数轴、波形，以及画得像实物的珠子、细胞、探测器。别拿光点和连线当讲解；需要有体积的实物时，把它画进 `fr.look.under`（不吃辉光），见 `examples/fold_C`。

**底** `#010104`，中央一团深蓝 `#0B1830`（透明度 0.62）；四百来颗细星点，轻微闪烁；暗角 0.5；辉光全开。
章与章之间整幅暗一下（约 1 秒）。片名处星点最密。

**色** 白 `#F8F9F8`（主体字）· 字幕 `#D9D9D8` · 英文 `#86898C` · 小标 `#879399` ·
金 `#F8D893` / 暗金 `#B09973` · 冰蓝 `#64E3F6` / `#94FDFF`（最亮）/ `#508FA6`（标签）· 玫红 `#E84B75` / `#CF3655` / `#A21224`（深）· 紫 `#8477D0`。

**版式**

| 元素 | 位置 | 字 |
|---|---|---|
| 章节标 | 左上 x=101，y=88 | 等宽 15 `03` + 宋体 22 一个字 + 等宽 13 大写英文（字距 5px），下面一条 250px 细线；整体只有三成亮度 |
| 主体大字 | 居中，中线 y≈437（40%） | 宋体 Light 92–104，字距 0.15–0.29em，淡淡的冷色辉光 |
| 人名年份行 | 居中 y≈128 | "库尔特·哥德尔 KURT GÖDEL · 1931"：宋体 26 + 西文大写 24（字距 6px） |
| 双语小标 | 贴着图 | "惊奇 SURPRISE"：宋体 20–22 + 西文大写 21–23，`#879399` |
| 公式 | 居中 | 西文斜体 80–100，白或金；下面跟一行双语小标说人话 |
| 字幕 | 中文中线 y=939（87%），英文 y=995（92%） | 宋体 Regular 41，字距 0.12em；英文 Lora Italic 29。整行 0.55s 淡入，英文晚 0.18s |

**母题** 一个光点：小白核 + 一圈色晕 + 一圈更大更淡的晕（半径比约 0.8 : 1.6 : 4.2），运动时拖一条 240px 的彗尾。
它沿细线走、沿环绕、在两个字之间弹；金色表示"值得注意"，冰蓝表示"平常"。线宽 1–1.3px，三到五成亮度。

**片名卡** 上一幕留下的光点滑到正中 → 一帧闪亮 → 一条横贯画面的细线（带小刻度）展开，两个光点相隔半个画面、沿线向右跑（约 3 秒绕一圈）→
几千个点从字的周围聚拢成片名（宋体 Light 178–190，字距 58–62px，约 2.8 秒）→ 副题（宋体 Medium 40，暗金，字距 20px）→ 英文等宽小字。
片名前后一共停 12–14 秒，这段没有字幕。

**每章的骨架** 暗一下 → 章节标换字 → 一记和弦 + 一帧闪亮（可选）→ 装置登场 → 小实验跑起来（字幕一句一句跟）→ 年份人名行 → 一句定义 → 暗一下。

**声音** 全部合成（`engine/audio.py`）：低频长音垫底；每章开头一记带泛音的和弦（衰减约 8 秒）；屏上每打一个字、每问一次、每弹一次都有一声；
提问处上滑音；说到噪声就铺噪声；全片一次"定理落地"：一帧闪亮 + 扩散的细环 + 2–3 秒彻底静音。整体很安静（约 −18 LUFS）。

## A 鎏金（电影感暗金，11-03 起默认）

**底** 近黑。暖：底 `#070401`、中央光池 `#271B10`、脚下暖光 `#4A2710`；冷：底 `#030306`、光池 `#10131C`。
古代和文艺复兴的站用暖，17 世纪以后用冷，结尾回暖——用 `fr.look.bgo.warm`（0–1）渐变。
四十来颗失焦的尘埃慢慢漂；暗角 0.62；辉光 0.34（实物不能发白，所以只开三成）。

**色** 象牙白 `#E8E3D9`（字幕、数字）· 金 `#DDBD74`（关键词）/ `#E7C477`（年份）/ `#F4E0B7`（高光）· 朱红 `#D9583C`（负面词、数值）/ `#C94027`（印）·
灰阶 `#C4BBB1`（地点人物）`#94908B`（拉丁小字）`#5D5D5F`（出处小字）。

**版式**

| 元素 | 位置 | 字 |
|---|---|---|
| 年份 | 左缘 x=110，中线 y=95 | Cormorant SemiBold 96，金色竖向渐变，微辉光；换站时逐位滚动 0.85s，左边的数位先停 |
| 年份下细线 | x=103 起，长 337，y=146 | 1.2px `#B89B63` 32% |
| 地点 · 人物 | x=103，y=183 | 宋体 Medium 27，字距 5.5px，`#C4BBB1` |
| 出处（右对齐到 x=1790） | y=66 / 117 / 162 | 斜体西文原题 31 `#A9A59C` /《中文名》宋体 Bold 30 `#C9B27A` / 作者·地点·年份 宋体 20 `#77756F`；下面一条细线；右侧朱印"文献"（竖排两字，42×54） |
| 主体 | y 12%–78% | 数字用 Cormorant 150–160；标签宋体 19–32；引文中文 72 |
| 字幕 | 中线 y=915（84.7%） | 宋体 Bold 54，字距 0.11em；重点句 74，全片最重的一句 94 |

**简报要求的常驻件**（11-03 加，三套外观都用）

| 元素 | 横屏 | 竖屏 | 怎么画 |
|---|---|---|---|
| 顶部钩子行 | 居中 y=70，宋体 Bold 38，字距 0.12em，下面一条金色细线 | y=8.5%（163），46 | `K.hookBar(fr, t, '为什么{合作}能赢？', { style: 'gilt' })`，第 0 帧满亮，全片都在 |
| 0–2 秒大字 | 居中 y=42%，宋体 Black 132，金色竖向渐变，可染红 | y=36%，120 | `K.headline(fr, t, '{!背叛}永远更划算？', { a1: 2.2 })`，`a0` 不设就是第 0 帧满亮 |
| "你猜？" | 同大字，或停住上一幕只加一行 | 同左 | `K.headline(fr, t, '你猜？', { a0: 秒, a1: 秒, size: 110 })` + `fr.sfx(秒, 'ping')` |
| 景深三层 | 背景 0.2 / 中景 0.6 / 前景 1.4 | 同左 | `K.depth(fr, t, d, () => …, { blur })`，前景可以虚一点 |

**字幕动效** 逐字由虚变实：每字模糊 9px → 0、透明 → 实，0.34s；字间错开 0.085s，整句封顶 0.95s；退场整句 0.38s 淡出并变虚。

**片名卡** 黑底（冷）。从中心放出五十多条细金线，极慢地转；一百来颗金屑闪。
拉丁文一行（Cormorant Light 30，字距 19px，`#94908B`）在片名上方 154px；
片名宋体 Black 188–196，字距 20–26px，竖向金渐变 `#F7E8C2 → #E2C07A → #C39A52 → #8E6A2F`，逐字由虚变实（每字 0.34s，错开 0.1s）；
片名下面是**母题图形**（luck 是一条由光点画出的钟形曲线 + 一条带刻度的基线）；再下面副题（宋体 Medium 34，字距 18px）。
进片名用闪白：0.3s 升到顶、0.4s 落回，颜色 `#EADDB9`，中心亮、四角略暗，闪的时候上一幕还透得出来。

**每一站的骨架** 年份滚到位 → 0.25s 后出处淡入 → 主体装置登场（0.6–1.2s）→ 第一句字幕 → 装置做事 → 第二、三句 → 全体 0.5s 淡出，下一站的年份接着滚。
古代序章没有年份栏，改用上下两条回纹边 + 背景一行极淡的拉丁文大字。

**声音** 现成配乐，画面卡乐句。参考片那首约 112 BPM：一句字幕两小节，章节是小节的整数倍，
配乐的"满编进入"对第一个年份，"抽空再进"对全片最大的揭晓。事件音只留少数几个（落地、盖章、闪）。


## 竖屏 1080×1920（11-03 加）

`new_film.py --portrait` 建的工程，`index.html` 里 `window.VK_SIZE = [1080, 1920]`，引擎的 `W`、`H` 跟着变，`render.py` 自动按画布大小截图。

| 区域 | 位置 | 放什么 |
|---|---|---|
| 顶部 0–6% | y < 115 | 什么都不放（手机状态栏、平台的返回键） |
| 顶部钩子行 | y≈8.5%（163） | `K.hookBar` |
| 主画面 | y 12%–66% | 主体、3D 物体、图表；主体宽度占画面 75% 以上 |
| 字幕 | 中线 y=72%（1382），两行时上下各让半行 | 一句 ≤ 14 个字；放不下用 `|` 手动断两行，或者自动缩字号（超过画面宽 90% 时） |
| 底部 78%–100% | y > 1500 | 不放字和关键画面（抖音 / 小红书的标题、头像、点赞按钮压在这里）；只放前景的虚光、地面 |

竖屏的镜头更多用上下运动（从上往下摇、物体从底下升起来），一屏只放一个主体；横屏的"左右并排比"改成上下叠两格。
