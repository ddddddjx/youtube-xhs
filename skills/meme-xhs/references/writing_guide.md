# meme-xhs 写作指南

把 MemeInformation 180 篇的写法压成一份能照着写的步骤。背景、统计和出处见同目录 `memeinformation_voice.md`；这份只讲怎么写。

默认对齐的是它的**成熟期**（2026-05 以后）：有具体身份的「我」，冷静的判断，结构工整。早期的荐读体保留，用在荐读稿上；情绪口语期的写法不用。

---

## 0. 两条硬约束（用户明确指示前不用）

1. **标题不以中文专名开头**：品牌、机构、人名（智谱、腾讯、斯坦福、黄仁勋……）不放标题开头。开头换成数字或读者处境，专名放后半句。**英文品牌名开头可以**（「MiniMax，开始像一门好生意了」「Claude 越用越贵？」）。原号也只有 22% 的标题以专名开头；我们 09-24 复盘里，人名或机构开头的点击率只有 4.9% 到 8.2%，数字开头的是 12.3%。
2. **不用「刚好」式品牌引入**：「刚好那天我随身带着 X」「刚好对得上」「正好提供了这样一个入口」。这是原号配合商业合作的话术，我们照用会像软广。主角的进场方式换成：先把问题讲透，主角在第 2 到 3 页作为解法出现；或者借第三方之口（榜单、原作者原话、论文数据）。

用户当次明确说了才能用，检查脚本对应加 `--allow-cn-brand-title`、`--allow-ganghao`。

## 1. 真实性：「我」只写真的事

原号的力量来自一个有具体身份的「我」：前员工、小股东、做产品的团队、去了现场的人。**这些身份我们没有，也不能编。**

能用的「我」：
- **读到、刷到、看完的人**：「刚刷到 X 的一篇长文」「看完这期播客」。这是真的，每篇都能用。
- **用 AI 干活的人**：只写这次真做过的操作，或者用户提供的真实记录和截图。
- **用户给过的真实经历**：用户在对话里说过的事（去过的活动、做过的项目、自己的处境），可以写，写之前确认一句。

不能写：没发生过的朋友饭局、群聊、同事对话、持股、「我们团队」、实测结果。meme_check 会把这类句子列出来，逐条确认是真的，否则删。

没有真实经历可写时，不硬凑「我」：用荐读体、解读体或观察体，叙述者就是「看完的人」。

## 2. 选文体

| 文体 | 什么时候用 | 篇幅 | 骨架 |
|---|---|---|---|
| **荐读** | 一篇论文、播客、访谈、报告、课程、长文（我们最常用） | 1300 到 2000 字 | 刷到或读到的那一刻 → 它说了什么（三点，每点一个例子）→ 很多人会怎么误读 → 落到读者身上（分人群给建议）→ 一句判断或给资料 |
| **解读** | 公司、财报、发布会、技术博客、一个新产品 | 1500 到 2200 字 | 普遍现象或疑问 → 旧范式或反例 → 主角登场 → 借一个现成框架拆 → 第三方数字 + 这说明什么 → 对照组 → 「过去问 X，以后问 Y」→ 对仗收尾 |
| **观察** | 一个趋势、一个现象、一个行业判断 | 1300 到 2000 字 | 立靶子「很多人觉得……」→ 反驳 → 三个证据（历史类比、数字、案例）→ 让步 → 判断 |
| **实测** | 只在有真实测试记录时 | 1500 到 2500 字 | 真实需求 → 立判断标准「我更关心的是……」→ 任务一（要求 → 截图 → 评价）→ 任务二加码 → 一处翻车 → 原理一句大白话 → 总判断 |
| **活动见闻** | 只在用户真去了的时候 | 1300 到 2000 字 | 现场细节 → 最打动我的一句原话 → 生活类比 → 拆三件事 → 反差 → 我的判断 → 回到开头场景 |
| **热点快评** | 刚发生的事，要快 | 500 到 1000 字 | 一句梗或情绪 → 事实 → 一个反常点 → 一句判断 |

有原文库时（`~/Downloads/MemeInformation_文字_精校版/`，早期稿在 `~/Downloads/MemeInformation_文字稿.zip`），写之前读 2 到 3 篇同文体的全文，感受节奏。对照篇目：
- 荐读：强烈推荐你去看MIT发表的这篇论文 / 强烈推荐去看数学家陶哲轩近期关于AI的访谈 / 强烈建议你们都来看看这份字节的AI编程手册
- 解读：AI行业出现了马嘉祺bug / MiniMax，开始像一门好生意了 / 第二个腾讯长出来了 / 风口浪尖上的智谱
- 观察：打字这件事，正在拖慢每一个打工人 / AI视频真正的门槛：听话 / 整个行业一直在用错误的方式评价机器人
- 实测：GLM 5.3 🆚 Kimi K3：一手后端深度实测 / 电脑忘在公司，豆包替我改完了PPT
- 活动：AI在戛纳做了件你没想到的事 / 逛完WAIC这家展台，我看懂了Agent
- 快评：谁特么说千里科技陈奇离职了？ / 获胜原因：放荡不羁爱All in

只学节奏和结构，不抄句子。

## 3. 开头（第 1 页就是封面）

原号没有封面卡。小红书信息流里的缩略图就是第 1 页的上半截：头像、账号名，加上头两三段正文。**所以前两段就是封面**，要能单独把人拉进来。

第一段：时间锚 + 「我」+ 一个具体动作或感受，40 字以内。原号 74% 的第一段带时间词。

九种起手，挑一种：
1. 个人近况、真实需求：「最近在整理自己常用的 AI 模型清单。」
2. 刷到、看到：「刚刷到 X 的一篇长文，看完愣了一会儿。」
3. 自嘲、先认旧偏见：「我一开始也以为这是蹭热度。」
4. 反差惊叹：「谁能想到，……居然……」
5. 一道题、一句指令当开头，让读者先答：「你一眼看过去，可能下意识就有答案了。」
6. 物件的三种状态：写下 → 搁置 → 删除，几句话讲完一次反转。
7. 格言或反事实起句（不带「我」）：「三年前，如果你告诉……」
8. 给阅读地图：「这篇我想把三件事讲清楚。」
9. 反问、第二人称：「你有没有遇到过这种情况：……」

**前 5 段之内给反差**：「但」「却」「其实」「没想到」「很多人第一反应会觉得……」。原号 64% 在前 5 段内转折。

## 4. 中段

**三点结构**：分三点（也可以四到五点）。每一点内部的顺序是：具体例子 → 这说明什么 → 放到读者自己的工作里。可以用「第一个是……」「01」领起，也可以不编号。

**论证工具箱**（每篇挑三四样，不要全用）：
- 数字后面立刻跟一句解读：「这说明……」「这组数字意味着什么？」「这是一个信号」。
- 大数字配参照物：「去年全年的 1.5 倍」。
- 把比率换成读者能算的账：「每赚 100 块，要亏掉多少」。
- 数字联立制造反常：单看 A 不稀奇，单看 B 也说得通，两件事同时发生才反常。
- 概念后面跟一个有画面的生活类比（「人名卡壳」「冷门住户」「抄写作业」）。
- 给事件重新起名、换一把尺子：「与其说是 X，不如把它看成 Y」，全文围着新名字讲。
- 一个意象从头用到尾（尺子、一杯奶茶、一座桥）。
- 「过去问 X，以后问 Y」「从 X 走向 Y」。这是原号最核心的判断句型。
- 让步式反驳：先把对方的逻辑讲完整（「要是只看这一点，我也会这么想」），再指出漏掉的那一环。
- 中段主动降温：自问「是不是已经解决了？」，自答「差得远」。
- 至少写一处局限、翻车或代价。
- 读信号成本：「敢把没彩排的原片放出来，本身就是信号」。
- 给读者一个带走的自检问题：「把特效拿掉，你还会担心这个人物吗？」

## 5. 翻页

原号是先写一篇长文，再按屏幕高度切页，所以 27% 的页断在半句，13% 的页停在一句钩子短句上。render_meme.py 也是逐行切页，会自然断在半句，并报出「页末」统计。

写的时候做两件事：
- 每 6 到 8 段放一句 20 字以内的钩子短段，单独一行：「修复思路也很朴素。」「但事情没这么简单。」「还有一点让我印象挺深。」「问题出在第三步。」
- 揭晓句写成一个长句，让它有机会跨页。

出图后看页末统计，低于 30% 就在列出的位置补钩子句。

## 6. 语言

**节奏**（原号成熟期基线）：
- 段落中位 33 字，四分位 22 到 49；
- 20 字以内的短段约 21%，超过 80 字的长段约 5%；
- 八成以上的段落只有一句话。

**常用词**（原号每千字的中位用量，别超太多，否则像模仿腔）：
| 词 | 每千字 | 用法 |
|---|---|---|
| 但 | 1.6 | 转折 |
| 真正 | 1.3 | 第一口头禅：真正的门槛、真正难的是、真正有价值的 |
| 过去 / 以前 | 1.0 | 新旧对照 |
| 其实 | 0.6 | 纠正预期 |
| 我觉得 / 我认为 | 约 0.5 | 判断署名，不装客观 |
| 当然 | 约 0.4 | 让步降温 |

其他：
- 单句成段的节拍词：「确实。」「这不奇怪。」「为什么呢？」
- 大白话翻译器：「说人话就是」「简单说」「你可以把它理解成」。
- 句型：「X 不难，难的是 Y」「A 决定 X，B 决定 Y」「谁能……谁就……」「不是 X，而是 Y」（全篇一两次）。
- 口语适度：「挺」「蛮」「还挺有意思的」。不用「笑鼠」「特么」「好家伙」这种重口语，除非是热点快评。
- 感叹号：正文最多一个。

## 7. 结尾

挑一种：
- 对仗判断：「能力决定能跑多快，安全决定敢跑多远。」
- 回扣标题原词：标题里的那个词在最后三段出现一次（原号至少 25 篇这么做）。
- 回到开头出现过的物件或场景。
- 主动降调，落到一件小事：「没有什么宏大的时刻，……这就够了。」
- 给读者一个起点：「可以先从一份会议纪要开始试。」
- 反事实：「如果当年……当然也可能……只不过……」

结尾前一句常先让步（「当然，……还很早」），再收。不总结、不展望、不预告下一期、不喊关注。

## 8. 标题

**顺序：正文写完再起标题。** 从正文里挑一句最狠的判断当候选，结尾最好回扣标题里的那个词。

句式（成熟期优先）：
| 句式 | 写法 | 原号例子 |
|---|---|---|
| 逗号两段式 | 前段场域，后段判断 | AI短剧，故事比画面更重要 |
| 判断压成一个口语词 | X 真正的门槛：Y | AI视频真正的门槛：听话 |
| 趋势拐点 | 正在……、开始……了、终于、变了 | 打字这件事，正在拖慢每一个打工人 |
| 反常识判断 | 不是 X / 比 X 更 Y / 其实只是 | 人工智能时代，靠谱比聪明更值钱 |
| 第一人称动作 | 我让 / 我拿来 / 我先问了 / 替我 | 买扫地机器人前，我先问了AI买手 |
| 问句 | 为什么、真能打吗、算谁的 | AI替你办事，出了问题算谁的？ |
| 看完体 | 看完 / 逛完 X，我…… | 看完蚂蚁开源的两个项目，我直接点了star |
| 荐读体 | 推荐你去看 X / 这个 X 太通透了 | 强烈推荐你去看MIT发表的这篇论文 |
| 第一人称顿悟 | 我终于理解 / 我发现 X 才是 Y | 我终于理解阿里为什么要做千问了 |
| 泛化主体 + 强动词 | 一个 X，掀翻 / 改写了 Y | 一个API，掀翻整个视频行业 |
| 冷知识前缀 | 冷知识：+ 反常识 | 冷知识：Prompt没跑完，钱先没了 |
| 省略号留口 | 判断说一半 | 内容生产的方式已经变了...... |
| 跨圈热梗 | 明星、MBTI、网络梗接技术 | Agent 时代，最吃香的可能是 ISTJ 型模型 |

原号还有不少标题以中文专名开头（「智谱，……」「腾讯是一家……」「知乎，……」）。**我们的标题开头不放中文专名**（见第 0 节），专名出现在句中没问题。改法举例：
- 「智谱，开始像一门好生意了」→「卖 API 的大模型，开始像一门好生意了」
- 「腾讯是一家很神奇的公司」→「很少第一个出发，却总能找到位置」

规则：
- 20 字以内（小红书上限），原号中位 18 字。
- 标题不能直接说出答案，要让人还想点开。
- 术语最多一个，并且跟着人话。
- 不用感叹号，不用情绪口语（笑鼠、炸裂、啊？？）。

`标题备选.txt` 写三行、三种不同句式；最强的那条写进 `标题.txt`，并说明理由。

## 9. 正文.txt（发布时贴在图下面的文字）

原号的图下文字不在语料里，这一段是我们自己的设计，和图片保持同一个口吻：
1. 前 2 到 3 段直接用长文的开头（场景 + 反差），可以略压缩；
2. 一句判断；
3. 空一行，3 到 6 个标签：2 个大流量（#AI #人工智能），其余是精准词，人名和机构放在标签里。

纯文本，不用 Markdown 符号，不放链接，300 字以内。交付前跑 youtube-xhs 的 `check_paste.py`。

## 10. 反面清单

- 编造身份、朋友、团队、实测结果。
- 「刚好」式品牌引入；中文专名开头的标题（用户明确指示除外）。
- 「零门槛」「不用学任何 prompt」「小白也能」这类广告话术。
- 形容词和口号多，缺具体结果，结论重复（原号最硬的几篇就是这样）。
- 标题里的场景在正文里没兑现。
- 每节都用金句收尾；「真正」「其实」密度过高，成了模仿腔。
- 预告下一期、喊关注、写「我的看法：」标签。
