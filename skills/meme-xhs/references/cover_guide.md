# 首页怎么做

信息流里只露出第 1 页。和原号一样，meme 版**不做单独的封面页**，第 1 页就是正文页：作者块 → 一行突出标题 → 一张素材图 → 前两段。

09-29 曾试过单独封面页（大字 + 自己画的扁平插画），09-30 用户看后的结论：太刻意，尤其是没有原素材图、靠画图撑的时候。所以恢复原版首页，钩子靠标题和素材图。

## 10-14 起的硬规则：人脸或 headline，二选一必有

两周七篇版式一样，差别只在首图有没有视觉锚点：人物照片（原文上 19.2%、Wang 19.6%）、大标题 + 截图（Karpathy 20.4%）、纯文字 + 一张卡（李录 18.4%、品味 15.9%）、三段纯文字（定时 agent 10.5%）。人物稿 `hero` 放人物照片，`hero_after: 1` 或 2；非人物稿必写 `headline`。首图前两段里要有那句判断，不能全是人物介绍（平台对李录稿的诊断）。10-05「首页默认不写 headline」撤回。

## 首页三样东西

| 层 | front matter | 写法 |
|---|---|---|
| 突出标题 | `headline` | 一到两行，20 字以内，加粗大字。和 标题.txt 可以是同一句，也可以是它的口语版：「它替你订的酒店，是谁出的价」「交给 AI 五天，只涨了 8 个粉」 |
| 素材图 | `hero` + `hero_after` | 原文截图、原文配图、论文图表、后台截图、新闻照。**只用素材里有的图，不用自己画的**。放在第 3 段之后（`hero_after` 可改），先铺垫再给图，图最高 480px。没有合适的素材图就不放；图和前三段讲的不是同一件事也不放 |
| 前两段 | 正文 | 时间锚 + 我 + 一个具体动作；第二段就给反差或数字 |

头像、账号名、发布时间由脚本带出。首页不放栏目名、期数、信源名。

## 素材图怎么挑

- 缩略图里认得出是什么：一张图表、一张人物照、一段被框出来的原话，都可以。
- 深色截图能用（它是素材），但优先挑亮的、主体大的。
- 长条形的截图（一行引语）撑不起首页，放到正文里去。
- 自己画的示意图（`illus/`）放正文页，不放首页。

## headline 和标题的分工

标题.txt 要带可搜的词和数字；headline 是读者点进来第一眼看到的那句，可以更口语、更短。两句不必刻意错开，但也不要一字不差地重复三遍（标题、headline、正文第一句）。

## 单独封面页（默认不用）

`cover` / `cover_kicker` / `cover_image` / `cover_alts` 还在脚本里，只在用户当次明确要求时用，并且 `cover_image` 只用原素材图。写法见 render_meme.py 的说明。


## 10-03 补：宋体和红框（对标小盖第二批）

- **字体**：保持黑体。小盖两篇是宋体，10-03 Uber 稿试排了宋体版，用户看后定回黑体。`font: serif` 开关还在 render_meme 里，只在用户当次明确要求时用。
- **红框**：证据截图上把关键的那一句框出来，图前面的正文先说结论（「但 Kimi 这次完全反其道而行。」），图只负责证明。用 `python3 $M/scripts/box.py 截图.png x1,y1,x2,y2 [x1,y1,x2,y2 …]` 画框，输出 `截图_box.png`；坐标用 Read 看图估，画完再 Read 一次确认框住了那句。

## 10-15 起：不做「原文里我划了线的 N 句」引言卡

用户 10-15 看 How to be more ambitious 稿首页后定：黄底高亮的英文引言卡一眼就是在转述别人的话，和 6.9「我是听众不是评委」冲突。原文截图（红框）可以，自己排版的引言卡不做；首页素材图换成总结 / 对照卡的缩版、原文截图或人物照。原文里的好句子直接写进正文，用「他的原话是」带出来。

## 10-15 起：每个讲招的小节配一张图，不让读者一页消化三个论点

用户 10-15 看 ambitious 稿第 3 到 7 页后定：信息密度大的页（一页里有两三个关键论点）读者消化不动，不是只有首页要图，**正文里每一节的核心招都要有一张可视化**，放在讲完原文例子的那一段后面、「我」的段落前面。图的内容只做原文那一节最精华的一个机制（阶梯、对比条、名词→动词→叫谁的链、提示词的四个问题），标题写「X 是什么：一句话」，副标题写「原文的例子，XX」，底部一句大白话。提示词这类领取物做成编号卡，不再整段引文排进正文。

出图用 `render_illus.py`，窗口高度给 600 再用 PIL 裁掉底部空白（固定高度会把底部那行截掉），宽 960；一张图 350 到 450 px 高，一页放得下一张图加两三段。

## 10-23 起：v3 版式（用户说「v3」就是它，对标 `对标/赛博老奶/`）

front matter 写 `style: v3`，render_meme 交给 `scripts/render_v3.js`（Playwright）出图，其他 front matter 照旧。首页四层，从上到下：

1. **大字块**：`headline` 用 `|` 分三行，每行 4 到 7 字，粉底、左上右下两条红竖线、96px 超粗黑体（`headline_size` 可改）。缩略图里只看得见这块，句式用「对一群人的祈使句 + 一个可核的事实」或「判断 + 反转」，不用「都给我」「‼️」这类训话语气。
2. **导语** `lead`：一句话，把最有分量的半句写成 `==半句==`，出红字红下划线。
3. **素材图** `hero`：人脸或原文截图，撑满宽度，最高 `hero_max`（默认 330），底下压红粗线。
4. **引用块** `cover_quote`（可选）：粉底红竖线，一句出处或一句原话。

正文页：顶栏照旧；段落里 `==句子==` 出红字下划线，**每页最多一处**；`> ` 开头的段落出粉底引用块（原话、报告名）；图片底下压红粗线；分页按实际高度量，段落按句跨页，不在红线句中间断；末页太薄自动缩一号字。末页名片卡同原版（`card`）。

写稿时注意：正文第一段别重复 `lead` 已经说过的话（首页导语 + 引用块已经把「谁在哪说了什么」交代了，正文从第二件事起）。10-23 a16z 稿是第一篇（`发布/2026-10-23_a16z-andreessen-gap/meme-v2版/v3版/`），点击率跟原版对照后再定要不要当默认。

云端跑：`npm root -g` 下要有 playwright，Chromium 在 `/opt/pw-browsers`（脚本自己找）。
