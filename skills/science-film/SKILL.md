# science-film：3D 微观科普短片

对标：《追光：3 分钟看懂 2026 诺贝尔生理学或医学奖》（`对标/追光_3D科普/`：拆解、参考帧、手写版提示词）。
用户 10-11 定的目标：**给一个主题，自己搜资料，做出同水平的视频；前 5 秒抓住人，保证完播率和转化率。**

## 终稿重写（用户 10-16 定，每篇必走）

时机：字幕稿和发布文案写完、渲染之前。把成品里所有给读者看的文字（正文、标题之外的图上文字、图下正文、字幕、口播稿）按下面这段要求重写一遍，用户原话照收：

> 请全面化身为顶级语言风格编辑、真人表达校准师与AI痕迹清除专家。在不改变原文事实、核心观点和重要信息的前提下，对全文进行深度重写。删除空洞开场、正确但没有信息量的废话、机械连接词、过度完整的排比、重复总结、虚假的情绪升华和教科书式表达。重新调整句子长短、停顿节奏、观点顺序和用词密度。加入符合语境的真实细节、自然转折和明确立场，允许存在克制的不完美。禁止堆砌网络热词、故意口语化、编造个人经历、增加原文没有的事实，以及把文章改成另一种模板化文风。

本账号里怎么执行：
- 「真实细节」只从事实清单里带来源的条目取（这个号没有「我」的经历），没有就不加，不编；账号说明见 `抖音大健康/账号.md`。
- 「明确立场」只用有出处的结论，不替研究下没下过的判断。
- 重写后再跑本 skill 原有的检查脚本，检查和这段冲突时以这段为准，脚本的 ⚠ 说明理由可以留（例：为凑虚词占比去加「呢」「其实」就是故意口语化）。
- 改前那版存成 `draft_v1.md`（或同名 `_v1` 文件），交付时一句话说清删了什么、补了哪几处原文细节。

## 文件

- `$K` = 本目录。
- `references/完播与转化.md`：前 5 秒、中段、结尾的规则（检查脚本照它查）。**写稿前读。**
- `references/研究方法.md`：怎么搜、搜什么、`facts.json` 格式。**研究前读。**
- `references/引擎API.md`：积木、HUD、镜头、渲染命令。**写画面代码前读。**
- `对标/追光_3D科普/拆解.md` 和 `参考帧/`：原片逐秒拆解和 30 多张参考图。第一次做、或者质感不对时，对着参考帧看。
- `engine/`：Three.js 引擎（`index.html`、`lib/core.js` 时间和镜头、`lib/prims.js` 3D 积木、`lib/hud.js` 信息层和字幕、`lib/post.js` 后期）；`engine/films/demo/` 是示范工程。
- `scripts/`：`timeline.py`（拍子 → 时间轴）、`check_script.py`（稿子检查）、`render.py`（逐帧渲染）、`sound.py`（配乐 + 音效 + 旁白混音）、`qa.py`（成片检查 + 封面候选）。
- 工程目录：`抖音大健康/发布/<YYYY-MM-DD>_<英文短题>/`（别的账号用就放它自己的发布目录）。里面：`发现链.md`、`facts.json`、`script.json`、`timeline.json`、`film.js`、`静帧/`、`qa/`、`画面.mp4`、`成片.mp4`、`发布文案.md`。成片太大不进 git，其余都提交。

## 默认值（用户没说就用这些，交付时注明）

- 画幅 9:16（1080×1920），中英双语字幕，片长 60–100 秒，30fps；用户说 B 站 / YouTube 就 16:9、2–3.5 分钟、只中文。
- 无旁白（字幕驱动，按每秒 4.6 个字排时间）。云端 TTS 被网络策略挡住（10-11 测过 edge-tts），用户给了录音就用 `timeline.py --narration` 对齐。
- 配乐代码合成（无版权问题）；用户给了可商用音乐就用 `sound.py --music`。

## 流程（⏸ = 停下来等用户确认；用户说「你定」就不停，交付时注明哪几处是默认）

1. **研究 ⏸**：读 `references/研究方法.md`。用 WebSearch / WebFetch 找现象、源头、3～5 个关键实验（竖屏只留 2～3 个）、汇总、一个人、母题；每个数字回一手出处核对。写 `facts.json` 和 `发现链.md`（一页纸），交给用户确认。
2. **钩子 ⏸**：按 `完播与转化.md` 的五种钩子，写 3 个前 5 秒的方案（每个：类型、头两句字幕、第一帧画面、第一个音效、许诺什么），推荐一个，让用户挑。
3. **稿子**：复制 `engine/films/demo/` 当工程模板，写 `script.json`：`hook`（type / promise / payoff）、`terms`、`target`，每一拍 `id`、`zh`、`en`（英文按母语重写，不直译）、`key`（点金色的词）、`visual`（画面里的物在做什么）、`facts`、`sfx`、`music`，以及 `turn` / `emotion` / `cta` 标记。结构照原片：冷开场（0–15 秒）→ 片名卡 → 发现链 → 汇总放大 → 兑现（主观视角 + 结果清单）→ 情绪高点 → 一句道理 → 人 → 问观众 → 片尾卡。
   然后 `python3 $K/scripts/timeline.py <工程>`，`python3 $K/scripts/check_script.py <工程>`，红灯清零。
4. **画面**：读 `references/引擎API.md`，写 `film.js`。一镜到底：转场全用镜头穿过物体（推进钻入 / 拉远露出），不硬切；讲到哪推到哪；只用三种质感（果冻、点云、玩具）；母题从头亮到尾。先出静帧：
   `cd $K/scripts && uv run --with playwright==1.56.0 python render.py <工程> --stills <每拍中间各一个时刻> --out <工程>/静帧/`
   拼成一张图自己先看（参考帧对比：亮度、景深、颜色分区、文字有没有压在一起），改到满意。
5. **10 秒小样 ⏸**：渲冷开场那 10 秒（`--to 10`），配上声音（第 7 步的 sound.py），给用户看质感和钩子。
6. **整片**（后台跑。10-11 云端实测：1080×1920 约 1.1 秒 / 帧，90 秒片 30fps ≈ 50 分钟；`--scale .5` 草稿约 0.3 秒 / 帧 ≈ 13 分钟。先出草稿过 qa，再出全分辨率）：
   `uv run --with playwright==1.56.0 python render.py <工程> --out <工程>/画面.mp4 --fps 30 --layout <工程>/layout.json`
7. **声音**：`python3 $K/scripts/sound.py <工程> --video <工程>/画面.mp4 --out <工程>/成片.mp4 [--narration 旁白.wav] [--music 音乐.mp3]`
8. **验收**：`python3 $K/scripts/qa.py <工程> --video <工程>/成片.mp4 --layout <工程>/layout.json`，红灯清零。再派一个没参与制作的 agent 只看成片和 `完播与转化.md`，按「第几秒想划走、为什么」挑问题，改完重跑 6～8。
9. **发布包**：写 `发布文案.md`：
   - 标题 3 个备选（数字 + 反差 + 可搜的词），抖音中文、TikTok 英文各一份；
   - 简介：第一行关注理由（系列名 + 更新节奏），一句钩子，3～5 个标签；
   - 置顶评论：结尾那个问题 + 一个自己的答案；
   - 封面：从 `qa/封面_*.jpg` 里挑，配 6～10 个字的大标题；
   - 发布前核对表：片中所有年份、人名、数字、期刊，各附 facts.json 里的链接。
   commit + push 到 main（成片不进 git，给用户下载）。

## 画面底线（每次交付前对一遍）

- 第一帧就有主角，不从黑场开始；第 1 秒有动作；前 5 秒有一次状态变化 + 音效。
- 不硬切；每拍至少一次画面变化；停住时环境层（颗粒、光柱）还在动。
- 被讲到的东西最亮，其他压暗、虚化；冷色（脑内、微观）和暖色（安全、日常、人）分区。
- 字幕和 HUD 不重叠、不出安全区（qa.py 查）；右下角「示意」常驻。
- 数字都有出处；健康医疗题材不说疗效承诺（check_script.py 查违禁词）。
- 人和动物用低细节圆润造型，不画血、不追写实。
