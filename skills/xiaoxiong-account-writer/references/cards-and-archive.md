# 卡片与归档规则

本文件管：正文定稿以后怎么交付、怎么做卡片、怎么归档、没做完怎么标。写作部分不依赖本文件中的任何工具。

## 一、顺序：先定文字，再排版

1. **文字定稿**：按 [writing-style.md](writing-style.md) 完成两遍检查。
2. **事实复核**：数字、条文、流程逐条对来源（[identity-and-facts.md](identity-and-facts.md) 第四节）。
3. **平台字段**：平台短标题、约 200 字总结、备选标题。
4. **卡片排版（可选）**：用户要卡片或项目规则要求时才做。
5. **排版修订**：只动段落边界、分页位置、标题与首段的绑定、对齐方式。
6. **需要改字时回到第 1 步**：排版暴露的问题如果要改文字（改句子、删内容），回到正文修改，改完重新做第 2 步，不在排版阶段直接改。
7. **交付**：按第四节写明状态。

起草阶段不为卡片行数切句子。段落要等到排版阶段，按实际渲染结果再调整。

## 二、卡片检查项按优先级处理

原规则把十几项版面检查都设成发布门槛，结果常常为了一行短字去改文字，或者为了填满页面去补话。新做法按下面的优先级处理，前一级没过不看后一级：

| 优先级 | 检查项 | 处理方式 |
|---|---|---|
| 1 硬性 | 文字被裁切、跨页截断、旧内容残留、平台字段出现在卡片上、账号信息错误 | 必须修复 |
| 2 硬性 | 普通段落超过 3 个视觉行 | 在句子边界拆段，不删内容 |
| 3 重要 | 首页大面积空白；标题折行后只剩几个字 | 移动整段、调整分页；标题问题记录给作者决定是否改标题 |
| 4 一般 | 段落最后一行很短（少于 6 个字或不到行宽 40%） | 先合并相邻同义句；需要改字才能解决的，最多改到不改变意思为止，否则保留并在交付里列出 |
| 5 一般 | 非末页填充率低于 90% | 移动整段；不加空行、不加填充句、不改字号行距 |

- 渲染修订最多 3 轮。3 轮后仍有第 3—5 级问题，交付正文和卡片，并列出剩余问题。
- 任何时候都不靠字间距、空行、填充句、换字号解决版面问题。
- 卡片的首页可以不加粗；实操类首页可以加粗答案（与写作规则一致）。私信邀请句不强制放在首页，按正文位置排版。

## 三、原项目依赖（外部，可选）

以下工具和文件属于原小红书项目，不随本 Skill 提供。存在时使用；不存在时按「降级」继续文字工作。

| 依赖 | 用途 | 缺少时 |
|---|---|---|
| IdeaCard 应用和 `card.sh` 包装脚本 | 从 Markdown 生成 440×587 卡片预览、审计版面、导出 PNG | 只交付 Markdown，状态标「未预览」 |
| `card-precheck.mjs` | 渲染前文字预检 | 用本 Skill 的 `scripts/check_draft.py` |
| `小熊先生/_近期发文索引.md` | 历史查重、记录栏目和题材类型 | 请作者提供最近 30 天标题；交付注明「未做历史查重」 |
| `自适应学习/账号学习状态.json` | 数据规律 | 用 [data-feedback.md](data-feedback.md) 第三节 |
| 后台导出表 | 数据复盘 | 不做数据结论 |
| 账号头像、配色 | 卡片外观 | 不影响文字交付 |

原项目的路径、端口和命令写在项目自己的 `AGENTS.md` 里，本 Skill 不写死任何机器上的绝对路径。

## 四、交付格式与状态

每篇正式稿交付一个 Markdown 文件，结构见 [../templates/delivery-template.md](../templates/delivery-template.md)：

1. `# 标题`
2. 正文
3. 分隔线后的平台字段：20 字内标题、约 200 字总结、备选标题
4. 来源清单（不进卡片）：正文每个事实的来源和日期
5. 状态行，从下面选一个：
   - `文字定稿，未预览`
   - `文字定稿，已预览，版面遗留问题：……`
   - `文字定稿，已预览，版面通过`
   - `已导出 PNG：路径`
   - `未完成：缺少……`（写明缺什么事实、缺谁的确认）

没有渲染环境时，不写「卡片已通过」。

## 五、归档

- 在原项目中：按项目 `AGENTS.md` 的目录和命名规则归档，更新发文索引；同名文件不覆盖；不永久删除旧文件。
- 不在原项目中：在用户指定位置保存，文件名用 `YYYY-MM-DD_栏目_主题.md`。
- 发文索引至少记录：日期、文件、状态、栏目、题材类型、主要任务、选题五项指纹、是否已发布。是否已发布要准确，未发布稿不进入效果统计。
