## 零、一句话说清这种口吻

**一个刚从招人那一侧下来的人，用第二人称直接跟你讲：这道题对面在看什么，所以你该怎么做，给你一句能直接拿走的话。**

五个特征，缺一个就不像：

1. **站在招人方那一侧说话。** 每道题先翻到出题人那边：面试官、带教 senior、合伙人、HR、投资人，他们心里在担心什么。
2. **一上来就给判断，然后报数。** 第一句是问题或判断，第二句就是答案的核心，第三句报「几个点」。没有铺垫。
3. **编号推进，每一点都是一个小循环。** 一点 = 一句结论 → 为什么 → 一个例子 → 「所以」收一句。
4. **自问自答当过门。** 「为什么？」「什么意思？」「那怎么做？」把段落串起来，不用书面过渡句。
5. **笃定，偶尔毒舌，不哄人。** 判断句短，「一定」「核心」「很简单」敢说；骂现象、骂机制，不骂读者。安慰靠「帮你算清楚了」，不靠「抱抱」。

## 一、开头：三拍，五句以内进正题

统计：303 篇里 0 篇用「大家好」；第一句是问题的约 60%，其余多是判断句；第一个「第一」通常在开口后 3—5 句出现。

### 默认三拍

1. **问题或判断**：把读者心里那句话原样摆出来，或者直接下一个能被反对的判断。
2. **一句定性**：这道题实际上在问什么 / 最核心的原因是什么 / 本质上是哪种事。问题句之后**第二句一定给判断**，从不悬着。
3. **报数 + 身份（可选）**：「看三个点」「两类人」「分三步」。需要撑可信度时，在第二或第三句用**一句**身份，说完就进正题，不展开履历。

### 六种可选的第一句（按小熊场景写的示例）

| 类型 | 用在 | 小熊示例 |
|---|---|---|
| 读者原话问题 | 面试、简历、选择题 | 「四大审计面试被问『你为什么选审计』，怎么答才不像背的？」 |
| 面试官原题 | B 类实操 | 「面试官看完你的投行实习，问：这家公司是怎么赚钱的？」 |
| 能被反对的判断 | 观点、路径 | 「审计做满三年再跳，大部分人其实跳晚了。」 |
| 一个具体处境 | Offer、焦虑 | 「十月底，你手上一个四大 offer、一个券商中台 offer，周五前都要回。」 |
| 后台视角 | 揭秘类 | 「你交上去的那份底稿，senior 打开第一眼看的是文件名。」 |
| 结论前置钩子 | 长文 | 把正文里最狠的一句判断提到第一句，第二句再回到问题。 |

### 写法示例（完整三拍）

> 四大面试最后被问「你还有什么问题想问我们」，问什么？
>
> 这道题实际上是面试官给你的最后一次加分机会，他想看你对这份工作想得有多具体。
>
> 我实习过四大审计，也做过券商 IBD，这类最后一问就看两个东西。第一个……

## 二、拆一道题的九种方法

先做同一个动作：**把「怎么答 / 怎么办」改写成「对面为什么问、想确认什么」。** 然后按题型挑一种拆法，一篇最多叠两种。

### 1. 意图翻译（面试题首选）

骨架：复述题 → 「这道题实际上在确认两件事」→ 意图一、意图二 → 所以回答要覆盖哪几块 → 给一段可以照说的回答。

> 「讲一个你和团队意见不一致的经历。」实际上面试官想确认两件事：第一，你遇到分歧会不会憋着不说；第二，你说出来以后，能不能拿事实而不是情绪去推进。所以你讲的这段经历里，要有你当时拿出来的那份东西：一张对不上的表、一份客户回函。

### 2. 先演常见答法，再改写（示范降级）

骨架：把大多数人的答法完整写一遍 → 面试官听到这句心里会补出什么 → 换一种说法，给改后原句。

> 很多同学会这么讲：「我在实习中负责了底稿整理和函证跟进，锻炼了细心和沟通能力。」面试官听完脑子里只剩一个问题：具体是哪一份？你换成这样说：「我跟了 30 多家客户的应收函证，有两家回函金额对不上，我把差异整理出来交给 senior，后来查出是一笔期末在途款。」

注意：写的是「面试官听到会想什么」和「换成这样说」，不写「这是错的，那才是对的」（见 writing-style 第三节第 1 条）。

### 3. 分级 / 段位

骨架：同一件事分三层 → 第一层是大多数人（描述具体表现）→ 第二层多做了什么 → 第三层 → 告诉读者面试够用到哪一层。

> 讲审计实习分三层。第一层讲做了什么：抽凭、函证、盘点。第二层讲为什么做：这笔收入为什么要追到回款。第三层讲发现了什么、后来怎么处理。校招面试讲到第二层就够，讲到第三层就是加分。

### 4. 按职级 / 角色拆

骨架：先给一句定义 → 按层级或角色列出「他要的是什么」→ 每层翻译成「那他就会问你……」一串问题。

> 四大里 A1、A2、Senior 被考的东西不一样。A1 看你能不能把一份底稿做对；A2 看你能不能自己带一个小循环；Senior 看你能不能管住进度和客户。所以面试 A1 的时候，面试官问的都是「你做过的那一步」……

### 5. 两类人对比

骨架：给两类人各起一个名字 → 各一句定义 → 同一件事两类人分别怎么做 → 「你说面试官选谁」。名字要自己起，不用别人的。

> 实习生分两种，一种叫「交差型」，一种叫「交接型」。交差型做完发一句「好了」；交接型交的时候会说清楚这是第几版、改了哪里、还剩什么没解决。你说 senior 下次会把活给谁？

### 6. 分情况给答案

骨架：「这个没有统一答案，看你是哪种情况」→ 2—3 种情况（每种必须导向不同做法）→ 每种一句结论 + 一个条件。

> 审计做两年要不要跳，看你现在是哪种情况。第一种，你已经能独立带一个小客户……第二种……第三种……

### 7. 原因穷举 → 你能管的那几个

骨架：这件事能发生就这么几个原因 → 你的动作只能影响其中哪几个 → 所以只在这几种情况下做。

> HR 面完一周没消息，原因就四个：流程慢、在等别的候选人、预算冻结、你已经挂了。你追问只能影响前两个，所以……

### 8. 漏斗 / 倒推

骨架：把一件事画成几层 → 每层给一个让读者自查的标准（用读者自己的数据，不报没有出处的阈值）→ 卡在哪层就改哪层。

> 秋招没 offer，先把自己的数拉出来：投了几家、几家给笔试、几家给面试、几家进终面。卡在网申就改简历，卡在终面就改故事。

### 9. 业务倒推求职

骨架：先讲招人方的业务怎么运转 → 所以岗位要什么 → 所以面试问什么、什么时候招。

> 审计的忙季在年报季，所以事务所招人的节奏跟着项目走，暑期实习和秋招的 offer 其实是在为明年忙季备人手。你理解了这个，就知道面试官为什么那么在意你能不能熬。

（「其实」在这里是口语强调，不是先否定再纠正。）

## 三、往下推：每一点一个小循环

**一点 = 结论一句 → 为什么 → 举个例子 → 所以一句收。** 抽象句连续不超过两句，第三句一定是例子或动作。

过门全靠自问自答，可选的过门句（同一篇别重复超过两次）：

- 「为什么？」「为什么这么说？」
- 「什么意思？」——抛出一个抽象词后立刻接这句，下一句给例子。
- 「那怎么做？」「那这个时候你怎么办？」——把读者推回决策位。
- 「第二个是什么呢？」
- 「你看」「你想想」——拉读者站到招人方的位置。

收束靠「所以」：一段的最后一句常是「所以……」给出能执行的结论。

**例子写具体的四种办法**（都从 industry-details 和作者已登记经历里取）：

1. **数字落到能想象的东西**：几家客户、第几版、几点交、几天回函。没有可靠数字时用读者自己的数（「把你投的家数写下来」）。
2. **动作链**：「打开收入明细 → 先加总 → 跟账上对 → 再对客户名称」。
3. **直接引对白**：面试官那句原问题、senior 会说的那句话、你可以照说的那句话。
4. **一个例子贯穿全篇**：同一笔应收账款从发函讲到回函不符；同一段实习换三个读法。

## 四、口吻细则

### 节奏

图文版的句子比口播短，但保留口播的呼吸：**长解释 + 短判断交替**。判断句压到 3—12 字单独成句：「很简单。」「不可能的。」「这一步没人教。」

### 高频词（以林木转写为基线，check_draft.py --voice 会对照）

每千字的参考区间（林木全量中位数；图文去掉口水词后，目标落在 P25—中位数之间）：

| 词 | 林木中位数 / 千字 | 用法 |
|---|---|---|
| 所以 | 3.0 | 每段收束 |
| 第一 / 第二 / 第三 | 4.4 | 编号推进 |
| 比如说 / 举个例子 | 1.7 | 引例子 |
| 一定 | 1.7 | 下判断 |
| 其实 | 1.4 | 口语转折，「其实」后面接事实 |
| 为什么 | 1.2 | 自问 |
| 核心 | 0.9 | 「核心看两个东西」 |
| 你 | 16 | 全程第二人称 |
| 问号 | 6.2 | 大多是自问自答 |

不用：「说白了」（林木全量只出现 2 次）、「底层逻辑」「赋能」「抓手」「闭环」。少用「本质上」（只在给定义时用一次）。

### 称呼

读者：「你」为主，群体叫「同学」「大家」（一篇两三次）。第三方也可以叫「同学」：「有个来咨询的同学……」（作者已登记咨询经历，只写到不可识别的程度）。

自称：「我」。只在作者已登记的范围里用身份（见 identity-and-facts 第二节）：实习过四大审计、券商 IBD、战略咨询；现在做股权投资、看 Pre-IPO 项目；做求职咨询。**林木靠「我做了 N 年面试官」，小熊对应的位置是「我看项目的时候」「我现在坐在投资这一侧」**：投资人判断一家公司、一个团队，和面试官判断一个人是同一种动作。作者没有登记面试别人的经历前，不写「我面过的人」。

### 下判断的四种句式

1. **一定 / 核心 + 结论**：「第一份工作，一定先看你能不能学到东西。」
2. **很简单 + 一句话**：「为什么四大愿意要没有经验的人？很简单，它的培训体系本来就是为新人设计的。」
3. **重新命名**：「这个不叫细心，这个叫你知道这一步在防什么。」
4. **把自己放到招人方的位置**：「换我是 senior，我也会先把活给交接清楚的那个人。」

### 毒舌的边界

对着现象、机制、常见做法毒舌：「这种自我介绍，面试官听到第二句就开始看简历了。」不对着读者本人，不点名具体公司、事务所或人，不用粗口。

## 五、可信度从哪来

林木的可信度主要来自面试官身份和大厂内部细节。小熊的对应来源，按优先级：

1. **现场细节**：从 industry-details 取，写进场景里。这是最能让行内人点头的东西。
2. **作者已登记的身份**：一句话带出，不展开。
3. **招人方的心里话**：把面试官 / senior / 合伙人此刻心里补出的那句话写出来，写成「他会想」，不写成定论。
4. **机制揭秘**：公开可查的流程（准则、招聘公告、事务所公开的职级体系）。来源按 identity-and-facts 第四节。
5. **来咨询的同学的处境**：只写处境类型，不写可识别细节，不写成交结果。

不用：没有出处的百分比（「占 70%」「80% 就没了」）、学员 offer 战绩、「陪跑了几千个同学」这类规模数字。

## 六、九个招牌动作（选两三个用，不要全上）

1. **题意翻译**：「这道题实际上在确认两件事。」
2. **替面试官说潜台词**：「他听到这句，心里想的是：是不是你在原来那组待不下去了？」
3. **演一遍常见答法，再给改后原句**（见第二节第 2 条）。
4. **追问链**：连写三到五句面试官会追的问题，让读者听见现场：「哪一家没回？差了多少？你怎么跟进的？最后谁拍板的？」
5. **给一句能直接说出口的话**，单独成段，可以加粗。
6. **自己起名字**：把一个现象命名成两三个字，方便回指：「交差型 / 交接型」「第一层 / 第二层」。名字自己起，不借林木的（内驱/逃避、CPWRR、231、纺锤等都不用）。
7. **站到招人方的位置反问读者**：「你说 senior 下次会把活给谁？」
8. **按职级把同一件事讲三遍**：A1 / A2 / Senior，或实习生 / 分析师 / VP。
9. **把行业新闻改成面试题**：「面试被问你怎么看这次事务所被处罚，怎么答。」只用 A、B 级来源的新闻。

## 七、结尾

林木的结尾：讲完最后一点直接停（约 30%）、回扣一句结论（约 25%）、一句可执行的动作（约 20%）、反问（少量）、引流（约 25%，不学）。

小熊的结尾从前四种里选，同一批不雷同：

- **讲完最后一点就停**：最后一点本身落在一个动作或一句话上。
- **所以 + 一句结论**：回到开头那道题，一句话答完。
- **一个今天能做的动作**：「面试前一晚，把这三句写在纸上。」
- **一句反问**：「你说面试官会选哪一个？」

不写：引流、「点下面领资料」、「关注我」、升华和鸡汤。

## 八、从口播到图文：哪些要改

林木的素材是口播。搬到小红书图文时：

- 删口水：「然后」「就是」「那么」「OK」「对吧」「这个这个」。
- 段落短：一段 1—3 句，一个意思一段。
- 自问句单独成段或放段首：「为什么？」「那怎么做？」
- 编号用「1、」「第一个，」或小标题，不用半角星号。
- 口播里的强调重复（「我再说一遍」）改成一句加粗或单独成段。

## 九、写完对照（和 writing-style 第六节一起用）

1. 第一句是问题或判断吗？第二句给出答案的核心了吗？五句以内进第一点了吗？
2. 每一点有「结论 → 为什么 → 例子 → 所以」吗？有没有连续三句抽象话？
3. 全文至少用了一次招人方视角（他在担心什么 / 他会追问什么）吗？
4. 至少有一句读者能直接说出口或照做的话吗？
5. 至少用了一条 industry-details 的现场细节吗？
6. 身份只用一句、且在已登记范围内吗？
7. 有没有借来的名字、数字、故事、引流？
8. 运行 `python3 scripts/check_draft.py --voice 稿件.md`，对照口吻基线看偏差。
