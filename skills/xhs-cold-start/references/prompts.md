# 七步提示词

来自原流程（文子，X 长文，2026-07-06）的提示词，改成 Claude Code 里直接用的版本。`{赛道}` 这类花括号从 `账号档案.md` 里取。这些是给你（Claude）自己执行的任务说明，不是让用户复制的东西。

## 拆爆款（第 2 步）

输入：`对标/` 里的 5 到 10 篇笔记（截图或文本）。

> 以下是 {赛道} 赛道的 N 篇低粉爆款笔记。逐篇列出：标题、作者粉丝数、赞藏数、发布时间。然后分析：
> 1. 标题的共同规律（句式、关键词、情绪点），每条规律标出符合的样本编号；
> 2. 开头前 3 句怎么写（共鸣 / 转折 / 方案各在哪一句）；
> 3. 正文结构是什么套路（清单、流程、对比、故事），每段放什么；
> 4. 有没有固定话术模板（收尾句、评论区引导、标签组合）；
> 5. 这批样本各自靠的是底层引擎的哪一项：信息差焦虑、高收藏形态、过来人信任、低门槛转化；
> 6. 基于以上，总结一套可复制的内容公式：标题公式、开头公式、正文公式、收尾公式。
>
> 只写抽象出来的结构和规律，不复述、不改写任何一篇样本的具体内容。

`爆款公式.md` 的格式：

```
# 爆款公式（{赛道}，样本 N 篇，{日期}）
## 样本
| # | 标题 | 粉丝 | 赞 | 藏 | 发布 | 形态 |
## 表面结构
标题 = …（样本 1、3、5）
开头 = …
正文 = …
收尾 = …
标签 = …
## 底层引擎
| 样本 | 信息差焦虑 | 高收藏形态 | 过来人信任 | 低门槛转化 |
## 可复制公式
## 自己账号验证过的规律
（第 7 步复盘后追加）
```

## 四轮访谈（第 3 步）

> 你是一个小红书 {赛道} 赛道的内容运营。你手上有这套公式：
> 低粉高赞 = 信息差焦虑选题 × 高收藏内容形态 × 过来人信任 × 低门槛转化
>
> 任务：通过 4 轮提问盘清用户的基础信息。
> 规则：每轮只问 2 到 3 个问题，等用户答完再问下一轮；问题要具体，不问废话；用户答得含糊，追问一句；每轮开始前说一句「这轮问的是 X，因为 X」。
>
> 第一轮 你是谁（收集过来人信任的素材）
> 1. 你的职业 / 专业背景？
> 2. 在这个领域多久了？日常高频用哪几个工具或方法？
> 3. 有没有「从踩坑到开窍」的真实故事？
>
> 第二轮 你服务谁（收集信息差焦虑的靶心）
> 4. 目标读者是谁？一句话，越窄越好。
> 5. 这群人最大的焦虑是什么？怕错过什么、怕不会什么？
> 6. 看完你的笔记，他们最想立刻能做到什么？
>
> 第三轮 你做什么（收集高收藏形态的弹药）
> 7. 想聚焦哪些场景？越窄越好。
> 8. 能给读者什么赠品？公式、资源包、口诀、模板。
> 9. 偏好哪种形态？清单盘点、流程教学、种草。
>
> 第四轮 你怎么做（收集差异化）
> 10. 有没有独家信息源？内测、英文一手、付费社群、深度用户。
> 11. 人设语气？过来人、极客、毒舌、温柔、搞笑。
> 12. 每周更新几篇？
>
> 收集完交付：定位卡、账号四件套、内容边界、10 个「信息差 × 场景」选题（每个含标题、形态、收藏驱动点）。

用户已经在 `账号档案.md` 里答过的问题跳过。

## 七类选题（第 4 步）

> 根据 `账号档案.md` 的定位和 `爆款公式.md` 的规律，按痛点型、数字型、对比型、稀缺型、共鸣型、资源型、反常识型七类找选题。每类先写公式，再给 5 个 {赛道} 选题。每个选题写：标题（套公式）、内容形态、收藏驱动点。标题不超过 20 字，不用极限词。

`选题库.md` 的格式：

```
# 选题库（{定位}）
## 痛点型：[常见困扰] + [转折质疑] + [方案预告]
| # | 标题 | 形态 | 收藏驱动点 | 状态 |
| P1 | … | 流程 | … | 待写 |
…（七类各一节，编号 P / N / C / S / R / Z / F 开头）
```

## 第一篇选哪个（第 5 步）

> 从 `选题库.md` 的「待写」里挑第一篇。新号第一篇的任务是让算法打上赛道标签、攒第一波收藏，所以优先资源型或数字型。给出：选哪条、为什么（标题里每个部分分别起什么作用）、发之前还差什么（养号天数、账号四件套是否齐）。

## 一周排期（第 7 步）

> 按每周 3 篇排 `排期.md`：写明每天做什么、发布时间、内容类型、选题编号、标题公式。

默认模板（用户有自己的习惯时按用户的来）：

```
| 周几 | 做什么 | 时间 | 类型 | 选题 |
| 一 | 养号：刷同赛道，点赞收藏 10 条以上 | | | |
| 二 | 发第 1 篇 | 12:00 | 资源型，拉收藏 | R? |
| 三 | 互动：回复评论，去同赛道大号评论区留言 | | | |
| 四 | 发第 2 篇 | 20:00 | 共鸣型，立人设 | Z? |
| 五 | 养号：刷评论区找选题 | | | |
| 六 | 发第 3 篇 | 10:00 | 痛点型，拉互动 | P? |
| 日 | 复盘：跑 weekly_review.py，定下周选题 | | | |

四周递进：
第 1 周 冷启动：资源 + 共鸣 → 跑标签，立人设
第 2 周 冷启动：数字 + 痛点 → 攒收藏，拉互动
第 3 周 成长：痛点 + 对比 → 稳互动，建专业
第 4 周 破圈：反常识 + 稀缺 → 拉分享，破圈层
```

发布时间是原流程的建议，不是平台数据。第 2 周起用复盘里「最佳时间」替换。
