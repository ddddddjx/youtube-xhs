# 账号冷启动与活人感调教（Claude Code 版）

原流程跑在腾讯 WorkBuddy 上，靠「工作区 + `.workbuddy/memory/`」记住账号。Claude Code 里对应的是 **Krypto说AI 的仓库 + 根目录 `CLAUDE.md`**：在仓库里启动 Claude Code 会自动加载它，它再指向档案、经历库、范本。你教会它一次，下次不用重复解释。

原文最值钱的四处调教都在 `references/voice_tuning.md`：范本模仿、立场先问、「我」只从经历库取、写完念一遍像不像真人。**写任何稿子前先读它。** 七步提示词在 `references/prompts.md`。

- `$S` = 本 SKILL.md 所在目录。
- `$Y` = 同级的 `youtube-xhs`（复用 `scripts/check_paste.py`、`scripts/post_log.py`）。
- `$X` = 同级的 `xiaohongshu-wutu-zhishika`（复用 `scripts/render_cards.py`）。
- 账号工作区 = 仓库根目录（有 `CLAUDE.md` 和 `账号/` 的那一级）。

## 0. 工作区

Krypto说AI 的工作区就是这个仓库，已经建好：`CLAUDE.md`（记忆入口）、`账号/档案.md`、`账号/经历库.md`、`账号/范本/`、`发布/`、`复盘/`。日志在 `~/Documents/Krypto说AI/log.csv`。

要给**另一个**账号起号时才用 `python3 $S/scripts/init_workspace.py "<账号名>"`，它生成：

```
<账号名>/
  CLAUDE.md          记忆入口：一句话定位、人设、红线、写稿规则，以及下面几份文件的路径
  账号档案.md         第 1、3 步的产出
  爆款公式.md         第 2 步的产出
  选题库.md           第 4 步的产出（七类 × 5）
  排期.md             第 7 步的一周排期
  对标/              放对标笔记：截图（png/jpg）或复制下来的 txt
  笔记/<日期>_<短标题>/  每篇笔记一个目录：标题.txt 正文.txt 置顶评论.txt，图文版另有卡片图
  复盘/              每周一份复盘
  发布日志.csv        post_log.py 的日志
```

**每一步做完，把结论写回对应文件，并同步更新 `CLAUDE.md` 的摘要部分**。这相当于原流程里的「请记住以下信息，写入记忆文件」。用户在对话里随口说的经历，问一句「这条写进经历库？」，同意就记进 `账号/经历库.md`。

## 1. 先想清楚怎么变现

变现方式倒推定位、内容方向和人设。先问用户（一次问完，最多 3 个问题）：
1. 打算靠哪条路赚钱：接商单 / 开店卖货 / 挂链接带货 / 导流私域 / 卖自己的课或服务？
2. 你手里已有的产品或能力是什么？
3. 你自己愿意长期写什么（兴趣决定能不能坚持）？

用户已经答过，或者 `账号/档案.md` 里已有，就不再问。结论写进 `账号/档案.md` 的「变现」一节。
判断标准：先定用哪种方式赚钱，再倒推账号怎么做。如果选的赛道和变现路径对不上（比如美食号想接高价商单），直接指出。

## 2. 找低粉爆款，拆骨架

Claude Code 不能登录小红书搜索，这一步分工：**用户找，你拆**。

让用户照这四步找 5 到 10 篇，截图或复制进 `对标/`：
1. 搜赛道核心词；
2. 切「最新」排序，不看「综合」；
3. 挑发布不久、赞藏明显高于同期的；
4. 优先作者粉丝少（几百到几千）的。大号的爆款有粉丝加持，不好复制。

每篇至少要有：标题、封面、正文开头、正文结构、话题标签、作者粉丝数、点赞收藏数、发布时间。截图直接 Read，文本直接读。

然后按 `references/prompts.md` 的「拆爆款」提示词分析，产出写进 `爆款公式.md`：
- 表面结构（人人能模仿）：标题句式、开头前 3 句、正文结构、收尾、标签；
- 底层引擎（低粉能爆的原因）：原流程给出的公式是 **低粉高赞 = 信息差焦虑选题 × 高收藏内容形态 × 过来人信任 × 低门槛转化**。拿样本逐项对照，写出这批样本各自靠的是哪一项，不要照抄公式；
- 一套可复制的内容公式，外加每条公式对应的样本编号。

**红线（和原文不同，必须遵守）**：只抽象出结构和规律，**不改写、不复述任何一篇对标笔记的具体内容**。原文把这一步叫「洗稿，但抄的是骨架」；小红书 2026-08-07《AI 治理规则公告》明确反对「传授使用 AI 洗稿、规避审核的起号方法」，社区规范也禁止抄袭搬运。用户要求「照着这篇改一版」时，拒绝改写，改为用公式和用户自己的素材从头写。

## 3. 四轮访谈，建账号档案

用 `references/prompts.md` 的「四轮访谈」：每轮只问 2 到 3 个问题，等用户答完再问下一轮；答得含糊就追问一句；每轮开头说一句「这轮问的是 X，因为 X」。

| 轮 | 问什么 | 收集的是 |
|---|---|---|
| 1 你是谁 | 职业背景、用 AI（或你的领域）多久、一次「从踩坑到开窍」的真实故事 | 过来人信任 |
| 2 你服务谁 | 目标读者一句话、他们最大的焦虑、看完最想立刻做到什么 | 信息差焦虑 |
| 3 你做什么 | 聚焦哪些场景、能给什么赠品（模板 / 清单 / 口诀）、偏好哪种形态 | 高收藏形态 |
| 4 你怎么做 | 独家信息源、人设语气、每周更新几篇 | 差异化 |

`账号/档案.md` 里已经预填了问题和已知答案，只问标「待答」的。收集完交付三样，写进 `账号/档案.md`：
1. **定位卡**：一句话定位 + 人设标签 3 个 + 目标用户画像 + 差异化；
2. **账号四件套**：名字（人格名 + 领域关键词）、简介（我是 / 帮谁解决什么 / 这里分享什么 / 希望你在这里得到什么）、头像建议、背景图建议；
3. **内容边界**：什么绝不发（例：不提具体收益数字、不引流微信、不发未验证的方法）。
4. **经历库**：访谈里出现的每一次「从踩坑到开窍」，按时间、场景、发生了什么、数字，记进 `账号/经历库.md`。这是稿子里「我」的唯一来源。

同时把一句话定位、人设标签、内容边界、语气写进 `CLAUDE.md`。档案可以随时改，边做边调。

## 4. 建选题库

用 `references/prompts.md` 的「七类选题」：痛点型、数字型、对比型、稀缺型、共鸣型、资源型、反常识型。每类先给公式，再给 5 个本赛道选题，共 35 个。写进 `选题库.md`，每条带：标题、内容形态（清单 / 流程 / 对比 / 故事）、收藏驱动点、状态（待写 / 已写 / 已发）。

七类公式（原流程的产出，填空用）：

| 类型 | 公式 |
|---|---|
| 痛点型 | [常见困扰] + [转折质疑] + [方案预告] |
| 数字型 | [数字] + [场景工具] + [价值承诺] + [行动号召] |
| 对比型 | [错误做法] vs [正确做法] + [差距结果] |
| 稀缺型 | [限定词] + [资源方法] + [紧迫感] |
| 共鸣型 | [群体身份] + [情绪共鸣] + [转折方法] |
| 资源型 | [资源类型] + [覆盖场景] + [收藏号召] |
| 反常识型 | [颠覆常识观点] + [为什么] + [正确做法] |

**标题不要自由发挥**，固定用公式填空，生成后念一遍，问一句「像不像真人说的话」。每个标题还要过 youtube-xhs 的标题铁律：不超过 20 字、前 8 字有数字或读者处境、不用英文开头。不用「最 / 第一 / 唯一 / 100%」等极限词。

## 5. 挑选题，写稿

写之前按 `references/voice_tuning.md` 的顺序加载：档案、经历库、一篇范本，再读素材。立场先问用户 3 个可争论的点。

1. 用户问「第一篇发什么」时，从选题库里挑一个，说明理由。新号第一篇的任务不是爆，是**让算法打上赛道标签 + 攒第一波收藏**，所以优先资源型或数字型。
2. 建目录 `笔记/<YYYY-MM-DD>_<英文短标题>/`，写：
   - `标题.txt`：一行；`标题备选.txt`：三行，三种类型；
   - `正文.txt`：纯文本，能直接粘贴，不用 Markdown。结构用 `爆款公式.md` 里的那套：开头 3 句（共鸣 → 转折 → 方案）→ 正文（流程教学：每段 = 步骤 + 作用 + 体感；或清单：序号 + 名称 + 一句话）→ 收尾（一句能收藏的话 + 一个二选一问题「你是 A 还是 B，评论区打 A 或 B」，check_paste 会查）→ 标签 8 到 10 个；
   - `置顶评论.txt`：一句随手回复的口吻。
3. 要做图文卡片时，按 `$X/SKILL.md` 写 `cards.json`，用 `python3 $X/scripts/render_cards.py <cards.json> <笔记目录>` 出图，Read 生成的 `overview.jpg` 看一遍。长文型笔记改用同级的 `article-to-xhs`。
4. 在 `选题库.md` 里把这条标成「已写」。

## 6. 加真人内容，查合规

```bash
python3 $S/scripts/ai_tone.py "<笔记目录>"
python3 $Y/scripts/check_paste.py "<笔记目录>"
```

- `ai_tone.py` 找 AI 腔：套话（首先 / 其次 / 总之 / 赋能 / 深受感动……）、排比过整齐、没有「我」、第一人称判断不到 3 处、没有任何具体时间地点数字、emoji 堆砌。每处给出改法。
- `check_paste.py` 查 Markdown 残留、站外链接、导流用语（微信 / 加我）、极限词（最 / 第一 / 唯一 / 100%）、标题长度和标题与封面是否重复。
- ✗ 全部改掉；⚠ 逐条看。

去 AI 腔的办法只有一个真正有效：**加用户自己的经历**。把「这本书让我深受感动」这种句子标出来，先去 `账号/经历库.md` 找；没有就问用户要一个具体场景（「我在高铁上一口气读完，差点坐过站」），不要自己编。用户没有给的经历，不替他虚构。

**和原文不同的地方**：原文的目标是「AI 味太重会被限流，所以要去掉」。平台的实际规则是**标识**，不是「藏起来」：小红书 2026-04-27 的 AI 治理主张要求 AI 生成内容如实标注，没标的由平台识别后统一加标；2026-08-07 的公告要求 AI 生成、润色的笔记主动披露。所以：
- 正文由 AI 起草、用户改过的，发布时提醒用户在发布页勾选 AI 内容声明（或按平台当时的入口标注）；
- 不教、不做「规避 AI 检测」「去水印」这类操作；
- 不代发、不自动登录、不做自动评论和自动私信。2026-03-10 起，全部笔记由 AI 托管代发的账号会被封禁。

## 7. 排期和每周复盘

**排期**：按 `references/prompts.md` 的「一周排期」写 `排期.md`。默认节奏每周 3 篇（1 篇资源型保收藏 + 1 篇共鸣或痛点拉互动 + 1 篇痛点或反常识拉分享），其余几天养号、回评论、刷评论区找选题。四周递进：第 1 周资源 + 共鸣（跑标签、立人设）→ 第 2 周数字 + 痛点 → 第 3 周痛点 + 对比 → 第 4 周反常识 + 稀缺。
新号先养 3 到 5 天：正常刷同赛道、点赞收藏、偶尔评论，再发第一篇。用户问「今天发什么」时，读 `排期.md` 和 `选题库.md` 回答。

**记录**：每发一篇，**发布当天**登记进工作区的日志（post_log 用登记当天的日期当发布日，复盘按它分周）：

```bash
python3 $Y/scripts/post_log.py add  --log "<工作区>/发布日志.csv" --dir "<笔记目录>" --topic <选题类型> --title-type <标题类型> --title "<标题>"
python3 $Y/scripts/post_log.py fill --log "<工作区>/发布日志.csv" --dir "<笔记目录>" --impr 曝光 --ctr 点击率 --likes 赞 --saves 收藏 --comments 评论 --shares 分享 --follows 涨粉
```

用户丢来后台截图时，Read 截图，把数字抄出来再 fill，抄完念一遍让用户确认。`--topic` 填七类之一（资源 / 共鸣 / 痛点 / 数字 / 对比 / 稀缺 / 反常识）。

**复盘**：每周一次。先问 `voice_tuning.md` 第 7 节的三个问题，答案进经历库；把本周最好的一篇复制进 `账号/范本/`。然后

```bash
python3 $S/scripts/weekly_review.py "<工作区>" [--week 2026-W40]
```

脚本按原流程的看板给每篇打诊断，并写出 `复盘/<周>.md`：

| 指标 | 好 | 及格 | 差 → 怎么改 |
|---|---|---|---|
| 点击率（点击 ÷ 曝光） | >10% | 5–10% | <5% 换标题 / 封面 |
| 收藏率（收藏 ÷ 点击） | >5% 形态对了 | 3–5% 赠品不够 | <3% 换清单体 |
| 互动率（赞 + 评 + 分享 ÷ 点击） | >3% 痛点准 | 1–3% 加过来人语气 | <1% 加提问引导 |

读完脚本输出，补上脚本写不了的部分：最好一篇好在哪（标题 / 时间 / 类型）、最差一篇差在哪、评论区里冒出的 3 个选题、下周 3 篇排什么。把这几条写进同一份复盘，把得出的规律追加到 `爆款公式.md` 末尾的「自己账号验证过的规律」，并更新 `排期.md`。攒够四周再下结论，一周的数据只看方向。
