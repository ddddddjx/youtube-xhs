# 分屏成片：下半屏补充知识卡

小红书上的长视频，读者点进来时不知道讲者是谁、这是什么课、术语指什么。分屏把这些补在画面里：
**上半屏原视频（黄底中英字幕），下半屏一张固定的知识卡**，整片 1080×1440。

知识卡是**静态的**，整条视频从头到尾不变——一眼能读完，不用暂停。

---

## 版式（render_panel.py 已实现，不用自己拼）

| 项 | 规则 |
|---|---|
| 尺寸 | 默认 1080×832，视频区 = 1440 − 知识卡高度 |
| 底色 | 米白 `#F7F2E8`，和图文版卡片同一套 |
| 字体 | 全文衬线；小标题与判断句藏青 `#2B4B7C` |
| 底部 | 一行灰字页脚：来源 + 字幕说明 |

下半屏**不放头像、不放账号名、不加装饰色条**：上半屏已经是别人的画面，再挂自己的头像和色块只会挤掉信息。识别度靠米白 + 衬线 + 藏青这套版式本身，和图文版是同一套。

字幕底色用账号黄 `#FFD93B`（`merge_subs.py` 生成的 `bilingual_box.ass`）：中文黑字在上、英文深灰在下，同一块黄底里两行，不会裂成两块。黄色只出现在字幕这一处。

---

## 内容（四块，按这个顺序）

1. **讲者**：姓名 + 机构职位 + 一句他凭什么讲这个（研究方向 / 做过的产品 / 代表作）
2. **背景**：这是什么课 / 什么节目、第几讲、什么时候的，一句话说清来路
3. **概念**：视频里反复出现、但国内读者不一定懂的那个术语，用两三句解释清楚（skill、上下文窗口、推理成本……）
4. **一条判断**：这期最值得带走的那句话，写成藏青判断句（`==这样写==`），前面用一两句数据或事实垫。和图文版的立场同一条，但话要换过，别照抄

**小标题只写内容本身，不写标签词。** 「我的思考」「总结」「核心要点」「划重点」「敲黑板」这类词一律不用——读者要的是那句话本身。
反例 → 正例：`我的思考` → `凭空写的 skill 会掉分`；`核心概念` → `什么是 skill`；`总结` → `代码写得越多，步数越少`

页脚固定写：`来源：频道名 · 视频标题｜字幕：YouTube 自动翻译（译自自动字幕），Krypto说AI 压制`

## 字数
正文总共 **220–320 字**，超了就删内容，不要改字号——`render_panel.py` 里文字超出会被裁掉，不会自动缩小。
出图后**必须 Read 一眼 panel.png**：最后一行碰到页脚线就是多了。

## 命令

```bash
python3 scripts/merge_subs.py en.srt zh.srt .        # 生成 bilingual_box.ass
python3 scripts/render_panel.py panel.json panel.png # 想改高度：再传两个参数，如 1080 760
bash scripts/compose_split.sh <工作目录> panel.png <输出.mp4>
```

`compose_split.sh` 默认用 `bilingual_box.ass`；想要老的半透明黑底字幕，第 4 个参数传 `bilingual.ass`。
只要原片带字幕、不要分屏时，仍然用 `burn.sh`。

## panel.json 示例

```json
{
  "title": "这门课、这位讲者，<br>和「skill」到底指什么",
  "blocks": [
    {"cols": [["讲者", "Daniel Fried，CMU 语言技术研究所教授，研究代码生成与能操作软件的 Agent"],
              ["课程", "CMU《AI Agents 2026》第 4 讲，公开课"]]},
    {"h": "什么是 skill"},
    {"p": "一个带 SKILL.md 的文件夹：开头写名字和一句描述，正文写这类活该怎么干。"},
    {"h": "凭空写的 skill 会掉分"},
    {"p": "课上引用的 SkillsBench 实测：人写的 skill 把通过率从 33.9% 拉到 50.5%，让模型凭空写反而下降。==skill 是经验的存档，不是说明书。=="}
  ],
  "footer": "来源：Graham Neubig · CMU AI Agents 2026: 4. Memory and Skills｜字幕：YouTube 自动翻译，Krypto说AI 压制"
}
```

## 反模式

- 小标题用「我的思考 / 总结 / 干货」这类标签词，一眼就是 AI 写的
- 下半屏挂自己的头像、账号名，或加彩色竖条装饰
- 下半屏写视频里已经说完的话（重复 = 浪费半个屏）
- 把时间轴放进下半屏：时间轴属于文案，读者要能点，图上点不了
- 字塞满到贴着页脚线
- 每期换配色：米白 + 衬线 + 藏青固定不变，主页才有识别度
