# 竖版成片：顶部信息框 + 原视频 + 底部字幕

小红书视频是竖着刷的，横屏原片直接发，上下两大块是黑的。竖版成片把这两块用起来：
**顶部告诉读者「这是谁、在讲什么、为什么要看」，中间放原视频（字幕压在画面底边），原视频下方放两行随段落切换的章节标题**，整片 1080×1920。

```
   0–110    留空（小红书的返回键、搜索键盖在这里）
 110–590    顶部信息框：主题 → 来路 → 标题钩子（大字两行，第二行强调色）→ 讲者卡
 590–1198   原视频，宽度铺满（16:9 时高 608）；中英字幕压在它的底边，居中，半透明深色底框
1234–1390   章节标题：第一行白（这段在讲什么）、第二行强调色（这段的结论），随 chapters.json 切换
1600–1920   留空（小红书的作者栏、标题、点赞栏盖在这里）
```

背景默认纯深色（`--bg solid`），章节标题才看得清；原片画面本身很暗、想要点层次时用 `--bg blur`。顶部信息框整条视频不变，章节标题跟着段落变。

**11-08 起这样排的依据**（`对标/Better_Living/拆解.md`）：对标号的画面是「一块完整的视频 + 下面两行章节标题」，静音刷到任何一秒，顶部说这是谁，中部说现在讲哪段，字幕说这句话是什么。我们原来把字幕放在画面下方、左对齐、不加底框，下面再空一大块灰，像「压了字幕的原片」。字体全部黑体（PingFang / Noto Sans），跟图文 10-03 定的规矩一致，不再用宋体。

## frame.json 四样东西

| 字段 | 写什么 | 限制 |
|---|---|---|
| `tag` | 栏目名，不带期数（「海外精读」「K老师讲AI」），同一栏目每期一样；没有栏目才写主题 | ≤10 字，强调色 |
| `source` | 来路：年份 · 节目 / 课程名 · 第几讲（「MIT 金融数学公开课 · 第24讲」「2026 · Silicon Valley Girl 访谈」） | 一行，≤24 字 |
| `title` | **标题钩子**，用 `<br>` 分两行；第二行自动用强调色，所以把结论放第二行 | 每行 ≤11 个汉字；超了脚本会缩字号，字一小就没冲击力，所以先压字数 |
| `speaker` | `name` 讲者姓名（中文圈有通用译名就用译名）+ `role` 机构职位一行 | role ≤22 字 |
| `credit` | 可省。讲者卡右侧小灰字，写「中文字幕：Krypto说AI」 | |
| `accent` | 可省。强调色，默认账号黄 `#FFD93B`；同一个系列固定一个色 | |

### 标题钩子怎么写
刷到的人只看得到这两行大字，它决定留不留下来。和视频版 `标题.txt` 同一个角度，但要更短更硬：

- **对读者说的一句话**（11-08 起首选，对标「先跳下去，自信会在半空中找到你」）：脱离视频也能单独成立、读者会想截图的一句，第二行是结论：`先跳下去<br>自信会在半空中找到你`。「Claude 负责做 / 你只负责留评论」这种得先知道 Claude 是什么的不算
- **否定 + 重定义**（前五篇里唯一过 10% 点击率的句式）：`你不是没自律<br>是目标太正常`
- **人物 + 断言**：`李飞飞：<br>十年后只有两种打工人`（第一行是谁，第二行是他最扎人的那句判断）
- **条件句**：`给期权定价<br>得先学会给随机性积分`（想要 A，得先 B）
- **反问**：`一个 Agent 不够用？<br>先学会给它们分工`

规则：
- 钩子必须是视频里真讲了的内容，数字、判断都要能在字幕里找到出处；不编讲者没说过的话
- 不用「震惊」「必看」「干货」这类词；不用感叹号
- 术语最多 1 个，且要跟一个人话后果（`Agent 越多越乱` 可以，`multi-agent harness` 不行）；两行加起来 ≤22 字
- 钩子和 `开头卡.txt` 第一句可以是同一个角度：前 3 秒大字卡说完，顶部钩子整片都在
- 讲者有名就把名字放进第一行（搜索流量），讲者没名气就把机构 / 课程名放进 `source`，钩子只写内容
- 一条视频拆成多段发时，每段单独写钩子，`tag` 和 `speaker` 不变

讲者不止一人（访谈、圆桌）：`speaker` 写被访的那位；主持人不写。
剪出来的片段里全程是另一个人在说话时，讲者卡换成正在说话的那位——卡上写李飞飞、画面里却是别人，读者会觉得被骗。

## 字幕（压在原片画面底边）

`compose_frame.py` 自己从 `en.srt + zh.srt` 生成 `_work/frame.ass`，不用 merge_subs.py 的 ass：

- 中英同一块半透明深色底框，居中，贴着原片下沿往上 22px
- 中文黑体粗体白字 52 号，一行约 16 个汉字，最多 2 行，再长自动缩到 44 号；英文 28 号浅灰跟在下面，最多 2 行
- 字幕块盖住画面四成以上就会被列出来：回去把 `zh.srt` 里那几句压短，再跑一遍
- 只要中文：加 `--zh-only`

## 章节标题（原片下方两行，随段落切换）

写 `_work/chapters.json`（也可以 `--chapters` 指定路径）：

```json
{"accent": "#FFD93B", "chapters": [
  {"start": 0,       "line1": "Adam 早期演讲",  "line2": "紧张得观众也能感觉到"},
  {"start": "0:41",  "line1": "哪些话值得听",    "line2": "要看对方在说什么"}
]}
```

- 按 `zh.srt` 把整条视频分成 **4 到 8 段**，每段 20 到 90 秒；`start` 是原片时间（秒或 mm:ss），每段到下一段开始为止；成片跳过片头时脚本会自动减掉偏移
- `line1` 白字 ≤12 字：这段在讲什么（「Adam 早期演讲」「三条投资准则」）；`line2` 强调色 ≤14 字：这段的结论或最扎人的一句（「紧张得观众也能感觉到」）。两行都是读者静音刷到也看得懂的话，不写「第一部分」「背景介绍」
- 章节文字和视频文案里的时间轴是同一份内容：`视频版/章节.txt` 每行 `mm:ss 第一行 · 第二行`，发布时用小红书的「章节」功能逐条填进去，正文.txt 里的时间轴就可以只留一句话
- 没有 chapters.json 脚本照样压片，但会提醒；长于 2 分钟的视频不接受没有章节的成片

## 命令

```bash
python3 scripts/render_frame.py frame.json frame.png
python3 scripts/compose_frame.py <工作目录> frame.png 预览.png --preview 65    # 先出一帧看版面，几秒钟
python3 scripts/compose_frame.py <工作目录> frame.png <输出.mp4>                # 18 分钟视频约 6 分钟；压片期间自动防止 Mac 睡眠
```

- `--preview` 挑一个有字幕、画面里有人或课件的秒数，再挑一个章节切换后的秒数各出一帧；**必须 Read 预览图**再压整片：标题有没有超两行、讲者卡有没有压到视频、字幕块有没有盖住讲者的脸、章节两行有没有超长
- `--start auto`（默认）：从第一句话前 0.1 秒开始，跳过片头动画 / 赞助商页——刷到的前 3 帧就得有人在说话，否则直接划走。定位方法：字幕第一条的开始时间 + `silencedetect` 找到真正开口的那一刻。`--start 0` 不跳，`--start 12.5` 手动指定。跳过前先看 `scan_edges.sh` 的 head.jpg：跳掉的那段里不能有版权声明
- `--bg solid`（默认）纯深色底；`--bg blur` 原片模糊压暗当背景（原片本身很暗、想要层次时用）
- 原片是 4:3 这类偏方的画面：视频区按 720 高缩放，两侧露出模糊背景，字幕区相应变矮
- 原片本身是竖屏：不套这个版式，用 `burn.sh` 直接压字幕

## 反模式

- 标题钩子写成视频原标题的直译
- 三行标题、或一行塞十五六个字，缩字号后和字幕一样大，顶部没有重点
- 顶部挂自己的头像、账号名（署名放 `credit` 小字就够了）
- `tag` 每期换一种颜色：同系列固定一个 `accent`
- 把知识点、时间轴塞进顶部：顶部只回答「谁、讲什么、为什么看」，段落内容放章节标题，细节放文案
- 章节标题写成目录体（「第一部分 背景」「总结」）：两行要是读者看了想继续听的话
- 标题钩子写成功能描述（「Claude 负责做」）：先过「脱离视频能不能单独成立」
