# 小红书视频笔记文案模板（配字幕视频发布）

**只在发布状态为「可发布」（CC BY / 自己的视频 / 已获授权）时写。**「仅供学习」时不写文案，只放一个 `仅供学习_勿上传.txt`。发布时不要勾选「原创」。

账号：Krypto说AI。目标：刷到的人 3 秒内知道「这是谁讲的、讲了什么硬结论」，看完愿意收藏。

## 交付格式（硬规则）

输出四个纯文本文件，使用者要能**原样复制粘贴**进小红书编辑器：

- `标题.txt`：只有一行，≤20 字；前 8 字放数字或读者处境，人名 / 机构放后半句，禁止 How to 和英文开头，不把答案写进标题，过 SKILL.md 的「标题铁律」
- `正文.txt`：正文 + 结尾话题标签
- `开头卡.txt`：2–3 行，每行 7–16 字，第一行 = 话题 + Hook + 可信度，做成视频前 3 秒的大字卡
- `置顶评论.txt`：一句话说明可领取物怎么拿

禁止出现任何 Markdown 或给作者看的提示：`#` 加空格的标题行、`**加粗**`、`- ` 列表、`> ` 引用、反引号、`==高亮==`、`---` 分隔线、`[文字](链接)`、「（在这里写…）」「草稿供参考」之类占位。
小节用 emoji 开头（⏱ 📌 💬），列表用 `1.` `2.` 或时间戳开头，段落之间空一行。
写完必须跑 `python3 <本 skill 目录>/scripts/check_paste.py <目录>`，全部 ✓ 才交付。

## 正文.txt 结构（下面是示意，实际文件里不要带尖括号说明）

```
第 1 行：海外精读 #N
第 2 行：谁 + 在哪 + 讲什么（机构 / 人名 / 课程或节目名）
第 3–4 行：一句话钩子——这期最反常识的结论，留悬念不给答案

第 5–7 行：2–3 句可以被反对的判断，不是总结：谁按这套做会失败 / 我不同意第几点 / 我试了之后怎样。不带「我的看法」「💬」这类标签，直接用叙事句写（「我照着做了一周，……」）。不写「下一期」，那是末页名片卡的事。

⏱ 时间轴
05:37 ｜ 小标题　一句话说明这一段讲了什么
……（8–12 条，覆盖全片；见下面「时间轴」一节）

📌 3 条要点
1. 一句硬结论 + 一个数字
2. ……
3. ……

互动问题固定二选一，和「我的看法」是同一件事：你是 A 还是 B，评论区打 A 或 B
本期模板整理好了，评论区扣 1 发你

来源：频道名 · 视频标题（X：作者名 @handle · X；不放链接，不写平台导流的话）
中英字幕：YouTube 自动翻译（译自官方英文字幕 / 自动字幕），Krypto说AI 压制（X 视频写：Whisper 转写 + Krypto说AI 翻译压制）

#AI #人工智能 #人名或机构 #核心术语 #中英字幕 ……（≤8 个：3 个大流量 + 3–5 个精准，# 后直接跟词，不加空格）
```

顺序为什么这样：dbs-content 的「表达效率」一条说不要用 99% 的篇幅包装 1% 的判断。前五篇的判断都埋在时间轴和要点之后，读者翻不到就走，个人主页流量只有 0.6–2.9%。判断、下一期、可领取物三样都在第一屏和最后一屏各出现一次，是转关注的三个入口。

## 时间轴（长视频文案里读者最常用的部分）

读者刷到一条一小时的视频，不会从头看。时间轴要让他直接跳到自己想看的那段：

- 每条写成 `12:30 ｜ 小标题　一句话说明`。小标题 4–10 字，说明一句话讲清这段解决什么问题，可以用问句（「为什么模型会产生幻觉？」）
- 8–12 条，**覆盖全片**，不是只挑开头几段；30 分钟以上的视频按每 5–8 分钟一条
- 第一条通常是 00:00，方便读者确认从哪开始
- 时间对着 `zh.srt` / `en.srt` 核，**不能编**；视频有章节（`meta.txt` 里有）时以章节为准，再把章节名改成自己的话
- 只写视频里真讲了的内容，不把自己的补充塞进时间轴（补充写在下半屏知识卡和「我的看法」里）

## 内容规则

- 时间轴必须对照字幕文件核对时间，不能编造
- 文案是自己的总结，原话引用最多 1–2 句并注明出处
- 数字以画面课件 / 图表为准；口头数字与课件冲突时用课件
- 标题带一个用户会搜的关键词（人名 / 机构 / 产品名），术语不当话题主体
- 不放任何站外链接，不出现「油管」「翻墙」「VPN」「微信」等词（check_paste.py 会拦）
- 不写「带走清单」「干货满满」这类套话；emoji 只用在小节开头
- 视频可能超过小红书上传时长限制时，在对话里提醒使用者（不写进文案）

## 成片格式

发布用的成片是 **1080×1920 竖版**（`compose_frame.py` 出的 `<短标题>_竖版.mp4`）：顶部主题 + 标题钩子 + 讲者卡，中间原视频，底部中英字幕。`标题.txt` 和顶部的标题钩子同一个角度，但不要一字不差——钩子更短更硬，标题带搜索关键词。成片最前面是 2–3 张 `开头卡.txt` 做成的大字卡（每张约 1.5 秒），再接原片第一句话。

## 封面（三版）

- `cover_A.png` 人物帧 + 大字（认知冲突句：「不是 X，是 Y」）、`cover_B.png` 课件帧做底 + 大字（好奇缺口句：「[人名]不会告诉你的…」「…的钱被谁赚走了」）、`cover_C.png` 纯色底 + 大字（数字句：「16 天不跑偏，只靠 3 个角色」）：写 `视频版/编辑用/covers.json`，用 `$X/scripts/render_cards.py` 出到 `视频版/封面备选/`
- 大字 8–14 字，字宽占画面 80% 以上，只能是问句或「不是 X，是 Y」，不能是答案；小字、图表、角标、导语、信源行都不上封面；术语最多 1 个且要跟人话；主语路人要看得懂（09-23 自律视频封面「你的自律，也只够起飞？」读不通，4.8%）
- 三版的句子不能只是同一句换措辞，要是三个不同的触发器；把人名 / 机构遮住再看一遍，还想点的才算过
- 三版都要 Read 检查在缩略图尺寸下能否一眼读出，交付时让用户投票
- 前 3 秒开头卡和封面大字可以是同一句
