# meme-v2 写作指南

只有当前规则。每条后面括号里是对标原句，出处在 `对标/蒸馏_2026-10-21_对标库全量.md`。变更理由见 `changelog.md`。

## 1. 「我」怎么出现

「我」只写真的事：读到 / 看完了这份素材（每篇成立）、这次真做的操作、经历库里的条目。不编朋友、饭局、群聊、团队、实测。

真人感不靠「我觉得」，靠三种「我」：
- **在场的「我」**：一件带时间地点的事，而且问的就是素材要回答的那个问题（小盖：「昨天下午，我参加了飞书的 AI 先锋未来人才大赛，现场几位不是 985 也不是 211 的学生同时拿到好几个 Offer」）。经历库里没有跟素材同一个问题的事，就不写在场，直接从素材起笔，硬凑的在场用户一眼看出来（10-20 LobsterAI 稿的教训）。
- **付过代价的「我」**：这件事让我丢了时间、钱、脸或信任（MemeInformation：「我错过了老东家智谱的股票」「真算错了，最后背锅的还是我」；经历库「代价」列）。一篇一处就够，放在最顺手的地方。
- **正在想的「我」**：一句没说完的话、一次改观（「之前一直当耳旁风，直到今天下午……」「现在不敢下结论」）。只有用户真改变过看法才写改观。

「假设我下周一带个实习生」这种推演场景可以写，带具体时间地点，不写成已发生的事，不进经历库。数量不限，每处必须贴着一个具体场景或数字；连着两个抽象推演就是在给论证搭架子。

不写：「我早就看明白了」「我研究 X 很多年」这类自称内行；「这条我站他」「这点我同意」「我的看法是」这类给发言加前缀；「读了三遍」「数了一遍」「素材里」「整理稿」这类生产过程。

## 2. 判断怎么下

`stance` 是一句原文没说过的判断，宾语是世界：一家公司、一个行业、一群人、未来（小盖：「我相信未来海底捞肯定会提供一个订餐的 Agent」；JackClark 稿：「你可以不相信奇点，但 Anthropic 已经在按这个前提重新配置资金和岗位了」）。「这条我认」「整篇我就认这一条」是给文章打分，读者把你当读书笔记。

`stance_line` 是它回到的长期立场（`账号/档案.md`）：A AI 取代不做判断的人 / B 活整个交给 AI 短板是我 / C 稳定听话比惊艳值钱 / D 角色边界消失人拍板。读者连看三篇要能说出这个号站什么。

判断要能出错。「AI 会改变一切」放哪都对，没信息；「一年内校招面试题会从讲 feature 全流程换成问你做过的 agent」能出错，是判断。

敢劝，敢对一群人说重话，对着现象不对着具体的人（小盖：「别再把大量时间花在考一些含金量不高的证书上了」）。毒舌的笑点靠事实错位，不加「哈哈」。

反对原文时只能反对原文真说过的话，`stance_quote` 逐字贴原句。原文站得住就往前推一步，不硬造对立。

## 3. 开头

第一页就是封面：headline、hero、头两三段正文。前两段要能单独把人拉进来。

**开头只做一件事**（10-21 用户看 Jack Clark v2 稿后定）。两种起法二选一：
- 先摆舞台：谁、在哪、讲了什么（「上周六，IMF 年会请 Anthropic 的联合创始人 Jack Clark 上台做了一场讲座。这个讲座系列办了六十多年，历来请的都是央行行长和财长，请做 AI 的人上去还是第一次。」），下一段把事讲完。
- 先把反转事件完整讲完（出题、打分、模型不认账、专家重算、最后只错一道），然后一句「讲这件事的是……」交代来源。

事讲完以后，直接进判断的论证，不单独放一句「我看完想的是……」当过渡（10-21 晚用户退回：「我看完这段，想的不是 AI 有多厉害，是我自己有多久没回去查过它交上来的东西了」是小学生倒装句，观点破碎；它是「第一句要有我的处境」+「不写我觉得」+「一句一段」三条规则叠出来的）。「我」的反应并进自己的经历那段，跟经历一起说。一件事不切成两半夹一段履历，不在首页把判断、点读者、读者直觉、我的经历四样叠在一起。开头三段最多 4 个锚点。

**判断只论证一次。** 一段完整的话，前提、推理、结论在一起（「专家这次能被改对，是因为他们先出了题，而且肯回去重查一遍。要是出题的人已经不会算了，AI 说你错了，你连从哪一步查起都不知道。所以 AI 越是能改专家的作业，人越得自己先算一遍」）。不在别处再用半句重复它，不给它贴标签（「这是我整场听下来最想说的一句」「我最想说的一件事是」都是给检查脚本看的，删）。让读者对上号的处境句可选，有就放在「你」那段，不放首页。不写「如果你……，这篇想讲清楚一件事」。

不做：先交代信源（「X 在推上写了篇长文，我看完觉得挺清楚」）；替读者预设情绪（「你第一反应多半是焦虑」）；提一件后文不展开的事当铺垫；「推荐看看」「先说他是谁」；连着两篇用同一种引入。

信源压成半句放第二段以后。人人都知道的常识不解释（「Anthropic 就是做 Claude 的公司」删）。

## 4. 中段

默认是评论员式连贯短文，不编号：判断 + 分量 → 关键数 → 放回整份材料 → 拆一个误解 → 自己的事当证据 → 读者该留意什么 → 问读者 + 自己的答案（`对标/未署名_JackClark奇点稿/`）。素材知识密集时用编号笔记体，每个编号句自己就是一个判断，下面跟一到三段支撑。

每节三步：**一个点 → 一个例子 → 一句大白话重述**（西元：「它只是一套记账方式。」→「CRM 里那五个阶段是给 CFO 看的……」→「它是财务视角的抽象，不是操作视角的地图。」）。重述句不算冗余，是读者记住的那句。

**读者的直觉先说出来，再用事实翻过来**（小盖：「我们很自然就会觉得，A 肯定比 B 更聪明，对吧？但真的放到真实机器人上，结果可能完全不同。」）。预设的是读者的推理，不是情绪。写稿前先问第 ⑦ 问直接产出这一段。

**一个读者已知的锚用到底**（小盖 Natura 稿 GPT-3 出现四次；X2Real 稿全篇是「考试」）。锚要是读者早就熟的东西，别人不深入人心的比喻（「夜校」）只引原话一次。自己不发明代称（「门票」「吐 token」）。

**专名和数字第一次出现，后面 20 字内跟半句人话**（玉伯：「Apple II，很多人小学机房里用的就是它」「12 磅约合 5.4 公斤，一个人拎得动」；Kai：「其实和 codex 差不多，只是是 deepseek 做的」）。专名首页出现一次，后面写「他」「这个模型」「那家公司」。一句话最多一个锚点。

**「你」的处境跟「我」的处境并列**（西元：「你知道数据不太对，留存在跌，但你告诉自己也许下一个版本会好一些」）。至少一段主语是「你」，写 `reader` 那个具体时刻。

**让步带事实，转折带新框架**（小盖：「当然，计算机专业的学生在技术原理上有自己的优势。但随着 Coding Agent 的普及，很多过去要专业程序员的事，普通学生也可以尝试了」）。「他可能是对的。但……」这种空让步不写。替读者问出的反驳（「有人会说，小模型不也能做吗？确实……真正难的是……」）要用。

**自己泼冷水要说出具体难点**（「采集视频和把视频变成机器人能用的训练数据，仍然是两回事」），不写「当然还有局限」。

回指一篇已发的稿子（小盖：「恰好前两天我也聊过 Anthropic 的那份就业报告」）。有可回指的就回指一次，正文.txt 里也带半句。只回指已发的。

跑题可以，拉回来时用一句路标（「说回正题」「先把这个讲完」）。路标后面紧跟事实。

## 5. 句子

**每句写到结果才停。** 「代码强」不是一句话，「代码这块它确实强，强在我把一个没写清楚的需求丢过去，它能猜到我要的是什么」才是。因果用「因为 / 所以 / 但 / 即使 / 这样一来 / 不然」写出来，不让读者自己补推理（小盖：「因为它知道我们的日历、邮件、位置，也了解我们的习惯。所以很多时候，我们甚至不需要告诉它现在该干什么，它自己就可以判断」）。

**一句话一个主语，逗号不连三个以上的独立分句。** 「讲这件事的是 Jack Clark，Anthropic 的联合创始人。上周六他在 IMF 年会上讲了一场，这个讲座办了六十多年，台上一直是央行行长和财长，这回是头一次请做 AI 的人上去」一句里主语换了四次（Jack → 讲座 → 台上 → 这回），读起来像口播转录。主语换了就换句号。「讲了一场」这种没宾语的动词、「这个讲座办了六十多年」这种会被读歪的指代，念一遍就能听出来。

动词和形容词用双字：认→认同、翻→翻译、对→核对、派→派活；传得挺广→传播得很广泛、不太信→不太相信、多半是慌→多半是焦虑。口语里本来就单字的不算（愣了一下、来挑刺、写代码）。

单句段只能是三种：「你」的处境、前一段具体场景的口头重述、一句没说完的话（「现在不敢下结论。」）。前一段是抽象话、这一段又是抽象话，就是 10-02 被认出 AI 的「规矩得先立在文字上」。

一段两三句、40 到 80 字，段落长短要参差。段首过渡（「换句话说」「这就是为什么」「但他说不是的」）后面紧跟事实。

感叹号和语气词一篇三四处，放在「我」看到一件具体事之后（「太颠覆了」「这是销售能力的体现啊」）。

不写对仗金句（「AI 能帮你拆账，不能替你去吵」）。不写英文直译的比喻（「不在一个坐标系」）。「真正」「其实」「当然」各不超过每千字 2 处，多了是模仿腔。

## 6. 结尾

三选一，都不是行业判断：
- **落到自己一件小事**（MemeInformation：「每个月花大几百块买的投研工具会员确实不太划算，该停一停了」）。
- **往下收一句评价**（小盖：「整体来说，还行还行。」）。
- **「以前……现在……」+ 两类读者各一句**（「以前我面校招生问的是你做过什么，现在问的是你让 agent 做过什么。还在找工作的同学，带一个自己搭的 agent 来面试；已经工作几年的人，回头数数手上的活有几件还停在干活那一层」）。以前和现在必须是用户真实的变化。

末段 40 字以内最好。不总结、不展望、不预告、不喊关注、不对仗、不用一句抽象俏皮话单独收尾。retell 稿结尾前一段 150 到 300 字是「我」的判断，然后照上面收。

**转述别人的话，主语轮着来，「他」每千字不超过 8 个。**（10-21 用户看 Ilya 稿后定：「他」用得太频繁。）轮换的办法：直接用名字（「Ilya 说」）、省略主语（「讲到这里停了一下」）、拿内容当主语（「建议只留了一条」「接下来才是正题」「答案只有一句话」）、用原话（「Ilya 原话是，连我自己都很挣扎」）。连着两句都以「他」开头就要改。

**用词口径是科技 AI 栏目主编写的文字，不是跟朋友聊天。**（10-21 用户看 Ilya 稿后定：「有人说三年就到」「拿自己的活去换」「我自己量出来的」「有没有长出来」一看就是 AI 写的，要让读者觉得是内容工作者写的。）具体三条：谓语用双字词，不用单字口语动词收尾（到→到来 / 实现，换→换取，量→测出，长→建立 / 形成，交→交出去 / 交付）；口语名词「活」换成工作 / 任务 / 项目（slogan 里的「活全交给 AI」是品牌语，正文不用）；不自问自答（「那该怎么办？他借了……」→「对于该怎么办，他借用了一句老话」），不用「不是 X，是 Y」当判断句，不用「直觉长出来」「拿活去换」这类自造的口语比喻。

**从字幕、转录、英文原文来的句子，不照字面转述。** 字幕是译出来的，直接搬进稿子就是翻译腔。念一遍，换成中文里本来的说法：「这话常有人说，这次是真的」→「这种话每一代人都听过，但这回不是套话」；「他只给一点」→「这回就不多给了」；「很多地方还得追赶」→「很多地方差得远」；「他引了一句话：」→「他借了一句老话：」；「看看今天最好的 AI 能做什么，直觉会越来越强」→「把今天最好的模型用上一阵子，你自己就会有感觉」。原话要引就整句引，标明是原话。

## 7. 转述荐读（`mode: retell`）

只限访谈、播客、人物稿，原文里那个人讲自己的真事。主语是「他」，每点用原文一个真场景讲透（五点的飞机、凌晨三点半打不到车），转述词不限，段内过渡带着读者走（「聊到这里，他顺带提起」）。保留他自己的分寸，不替他把话说满。「我」全篇 10 次以内，多出来的只许用在结尾前那段判断里。范本 `对标/华一说AI/peterdeng_文字稿.md`。开头可以多一种：主角当年的狼狈场景，第二段收成一句判断（玉伯）。

## 8. 标题

正文写完再起。三条备选三种句式：
- 可搜词在前 6 字：路人认识的人名、模型 / 工具名、场景词。人名就是 keyword 时可以开头。**人物稿的标题带上他的头衔或机构**（10-21 用户定，「有天然流量」）：「OpenAI联创Ilya：……」比「Ilya毕业演讲：……」多一个路人认识的名字；头衔用最短的那个（联创 / 前首席科学家 / 创始人），机构名放最前面当可搜词。
- 社会证明要是路人认识的名字（「红杉合伙人」是职位，14.9%；用名字的 18% 到 22.5%）。原文有收藏数、浏览数可以写。
- 至少一条「情绪 + 名字」（「强烈推荐看看Anthropic就业报告。」「想做AI产品的人，都去看Karpathy这期。」）或认知差句（「看来很多人没读懂LobsterAI报告。」）。
- 20 字以内（英文每字母算一字）。不用感叹号、极限词、「N 条规矩教你 X」教程腔。不以非 keyword 的中文专名开头。标题里的场景正文要兑现。

## 9. 图下正文.txt

第一段直接是内容，带主关键词，不写「这个号每天……」。两三段要点，可回指的旧稿加半句。领取物原样贴（提示词、清单、分工卡），读者长按能复制；没有领取物就留一个每个人都有自己答案的问题（TomCC：310 评论 vs 6）。最后 3 到 6 个标签：主关键词一个、大流量两个、精准词若干，人名和机构放标签里。纯文本，1000 字以内。

## 10. 反面清单（一眼认出 AI 的）

结构词孤段当 PPT 过渡页（「理由有两个。」「先说这份手册。」）；抽象接抽象的单句金句；空让步再转折；「一是……二是……」；对仗金句；自造代称；后台叙述；给发言加前缀；自称内行；硬凑的在场；铺垫后文不讲的事；拿别人的比喻当全文意象；先交代信源；替读者预设情绪；结尾行业判断 + 总结；每段开头一个新断言、没有连接词；专名堆成报表（「俄亥俄的 Prometheus 已经过了 1 GW，路易斯安那的 Hyperion 要做到 5 GW」）。
