# meme-v2：真人感从输入来

一份素材进来，交付一组 1080×1440 手机长文截图、三个标题备选、一段图下正文。版式、出图、首页、公众号分支全部复用 `skills/meme-xhs/`（下面记作 `$M`），本 skill 只换写法和检查。本目录记作 `$V`。

这份 SKILL 没有日期补丁。规则为什么是这样、哪天改的，在 `$V/references/changelog.md`；写法细节在 `$V/references/writing_guide.md`，写稿前读完。依据是 `对标/蒸馏_2026-10-21_对标库全量.md`：一个月里改输出 20 多次没有一条被数据证实，改输入 2 次跟着 2 个爆款。

## 一句话原则

读者读完要觉得这是一个对 AI 有顶尖理解的真人写的。做到这点靠三样：**「我」在场且付过代价、判断对着世界下、每句话写到结果才停。** 不靠黑名单。

**用词口径是科技 AI 栏目主编写的文字**（10-21 用户定；**11-08 收窄：只管用词，不管口吻**。反应词「坐不住 / 可太能共情了」、一两个 emoji、「说实话」这类毛边放开，不再当 AI 腔删；四篇爆款每篇都有）。真人感来自上面三样，不来自口语：「有人说三年就到」「拿自己的活去换」「我自己量出来的」「判断力有没有长出来」这种单字动词收尾、口语名词「活」、自造比喻，读者一眼认出是 AI。谓语用双字词，「活」写成工作 / 任务 / 项目，不自问自答，不用「不是 X，是 Y」当判断句。细则在 writing_guide §5。

**主编口径只管用词，不管叙事者；第一句让一个人站在一个具体时刻里**（10-29 定，10-30 用户要求抽象化：「不要每次都重复完全一模一样的」）。10-21 之后六篇 v2 稿第一句全是第三人称背景交代（「今年 6 月，多伦多大学授予……」「Doug Leone 在红杉干了 26 年」），新读者在缩略图前三行里只看到一条新闻。原则只有一条：**前三行里，读者要看到一个人、一个能画出来的时刻、一件不对劲的事。** 人可以是我、原文主角、身边的人；时刻要具体到有时间、地点或动作。不要三种：第三人称背景交代、新闻导语、「我这两天看了 / 读了 / 刷到 X，有一段让我愣住了」这种汇报自己消费了什么内容的句子（10-30 用户：「都词穷了」；10-30 Amodei 稿初稿就是这么写的）。**起法没有固定的一种**，writing_guide §3 列了七种（自己的一个场景、自己工作里的事、身边人的一个场景、一句原话、一个反常的事实、一次实测、主角的狼狈时刻），每篇挑最贴素材的那种，**跟上一篇不同**。第一段 60 字以内、锚点最多 2 个；人物履历、机构分量、一串数字从第二段起。治用词的病用双字词，不换讲故事的人。

## 用户认可的范本（写稿前先读一篇）

**11-03 Kotler 心流访谈稿**（`发布/2026-11-03_kotler-flow/meme-v2版/编辑用/draft.md`，8333 观看、725 赞，赞率 8.7% 全账号第一，10-18 之后唯一自然过千的图文）。学四样：身份比名字响（标题用「心流专家」不用 Kotler）；第一句是主角一个能画出来的时刻（卧床三年、冲浪、疼痛消失）加一件反直觉的事；题材是每个人的事（卡住、被打断）而不是 AI 圈的事；四个条件分条写，每条一个原文场景，「我」的事（agent 并行丢念头）对上素材最关键的机制（被打断）。

**10-30 Amodei 兄妹 × Isaacson 访谈稿**（`发布/2026-10-30_amodei-isaacson-builders/meme-v2版/编辑用/draft.md`，用户 10-30：「这次写得好多了」）。好在三处，对照初稿 `draft_v1_我看了开头_经历独立.md` 看：
1. **第一句是一个能画出来的时刻**：「三年前朋友婚礼的前一晚，我第一次让 GPT 帮忙写婚礼誓词，它写得比我自己好。」初稿是「这两天看完 Anthropic 创始人兄妹的一期访谈，有一段让我愣了很久」，是在汇报自己看了什么。
2. **「我」的事是全文的问题，不是插在中间的回忆**：开头两段提出「看见了，没有跟上」；中段 Dario「看见之后去做了」当对照，收在「看见的人里还要再分两种……婚礼那一晚，我属于后一种」；判断段落到「Dario 去做了更大的实验，朋友做出了 AI 产品，同一段时间里，我在观望」。三次，每次推进一步。初稿是「听到这里，我想起三年前……」一整段插在访谈复述后面。
3. **「我」对上的是素材里最关键的机制**：素材讲一成人看见、九成人耸肩，「我」的事把一成人再分成去做的和观望的，这一层是素材里有（Dario 力主放大、出来创业）但没人点破的。

用法：学结构，不抄句子。起法跟它不同，「我」的事换成那一篇素材让用户想到的事。

## 步骤

### 0. 加载记忆和对标
读 `CLAUDE.md` → `账号/档案.md`（长期立场 A / B / C / D、观点库）→ `账号/经历库.md`（含「代价」列）→ `对标/README.md` 按文体和题材挑一篇对标读 → `账号/范本/` 一篇自己的。然后才读素材，原样存 `编辑用/source.md`。

### 1. 写稿前先问（每篇必走）
先给 150 字摘要：谁写的、核心判断、两三个事实、最可争论的一句原话。然后只问素材引得出的问题，六个里挑 4 到 5 个：
① 这件事你工作里碰到过没有，哪天、什么场景、结果；② 原文哪句你不服、哪句你站；③ 读者带走哪种价值（信息 / 框架 / 情绪 / 行动）；④ 有两边时你站哪边；⑤ 你想留给读者的一句判断，回到 A / B / C / D 哪条；**⑥ 这件事你付过什么代价（时间、钱、脸、信任）。****⑦ 身边有没有人跟你争过这件事，他原话怎么说、在哪说的**（11-12 用户定，对标小盖蚂蚁灵波稿「昨晚在成都，和同学聊天，他说吹牛吹半天……我说，肯定不能这么讲」；有就当开头，没有就换别的起法，不编人）。
（原第 ⑦ 问「读者按直觉会怎么想」10-30 撤掉，用户原话：「不要预设读者的直觉，不要去约束别人的立场后再去反驳或者支持，并都不够有力。」稿子里也不写「很多人会觉得……但我的体会不一样」「你可能以为……」这种先替读者站好位置再推翻的段落。判断直接用事实和自己的事立住。）
回答原话进经历库（含代价列）和观点库。**问完就停，等回答再写，用户不在线也等；只有用户在这一篇里亲口说「你定」才按默认写**（10-23 用户定：「要固定问我」）。**「我」的经历不从经历库里自己挑旧事套进稿子**：第 ① 问先问这篇素材让他想到了自己哪件事，经历库只拿来核对他说的、补他没说全的时间地点数字；他这次说的新事优先于库里的旧事（10-23 用户定：「不要总是死板套用我历史的经验输入」）。

### 2. 定骨架
- 骨架是原文里的人讲自己真事（访谈、播客、人物稿）→ `mode: retell`，主语是「他」，每点一个原文真场景，结尾前一段「我」。
- 骨架是用户自己的事 → 自述，素材只是引子。
- 骨架是一份材料（报告、论文、文档）→ 观察，按「一件在场的事 → 材料里最反常的事实 → 自己的事当证据 → 我的态度」走。
- 刚发生的事 → 热点快评，500 到 1000 字。
篇幅 1000 到 1800 字。**3 到 5 个读者能停下来的点为默认**（编号，或「第一个条件 / 第二个条件」这种分条），每点 = 原文一个场景 + 我一件真事或一句「你」；千字不分点的连贯短文停用，只留给 500 字以内的热点快评（11-08 用户定，依据 `复盘/2026-11-07_数据复盘_四篇爆款的共同点和之后十四篇的差别.md`）。

**定骨架之前先过第 ① 关**（11-10 用户定，`账号/爆文方法论.md` 第六节「四关」）：小红书先推给粉丝，粉丝点了才推给路人；这个号的粉丝点的是「一个路人认识的人或身份 + 每个人自己的事」，AI 工具、agent 配置、行业框架稿从 10-11 起没有一篇出过粉丝池，按八条模板写也一样（Anthropic 记忆 60、Claude 官方 258）。动笔前写一句「李录和心流带来的读者为什么会点这篇」，写不出来就告诉用户这篇过不了第 ① 关，换角度或不在小红书图文里发，由用户定。front matter 标 `goal: 涨粉`（路人认识的人 40 分钟以上的长内容，至少三个半年后还成立的点）或 `goal: 流量`（消息、文件、报告、推文）。

**定骨架之前先过门票**（11-08，`账号/爆文方法论.md` 第五节前四条）：① 路人认识的名字 / 路人能认的身份 / 一个反常事实，必有其一；② 题材碰到「我自己怎么办」，行业框架稿停发；③ 标题是名字或身份 + 反差；④ 前两行一个人站在一个能画出来的时刻里。一条不过就换题或换门票，不往下写。

### 3. 写 draft.md
front matter：`title`、`mode`（可选）、`stance`（一句原文没说过的判断，宾语是世界不是文章）、`stance_line`（A / B / C / D）、`reader`（读者的一个具体时刻，不是职业）、`cost`（这篇用到的那次代价，一句话）、`goal`（涨粉 / 流量）、`keyword`、`keywords`、`headline`、`hero`、`location`、`account`。可选 `stance_quote`（反对原文时逐字贴原句）、`hero_after`、`extra_pages`。

正文按 writing_guide 写。骨架的四个位置：
1. **开头只做一件事**：第一句按上面「第一句让一个人站在一个具体时刻里」写，起法跟上一篇不同，然后要么摆舞台（谁在哪讲了什么），要么把那个反转事件完整讲完，再一句交代来源，直接进判断。一件事不切成两半夹一段履历，开场不叠开场。新闻导语（「北京时间今天凌晨三点，Anthropic 发布了」「昨天 OpenAI 发了一篇文章」）不当第一句。**判断只论证一次**：前提、推理、结论写在一段里，不拆成「我看完想的是…」+「因为…」+「这是我最想说的」三处半句；「我」的反应并进自己的经历那段。「我最想说的一件事是」这类标签不写。不替读者预设情绪，不铺垫后文不展开的事。
2. **中段**：每节「一个点 → 一个例子 → 一句大白话重述」。不预设读者的直觉再反驳或附和。一个熟悉的锚用到底。专名和数字第一次出现后面跟半句人话。「我」出现的地方是场景和代价，不是打分。
   **「我」的事是全文的问题或检验台，不是插在中间的一段回忆**（10-30 用户：「感觉非常独立于主线」，对标见 `对标/蒸馏_2026-10-30_个人经历怎么串进主线.md`）。它要跟素材里最关键的那个机制对上，通常出现两三次、每次推进一步（提问 → 对照 → 落地），衔接靠「同一件事」不靠「听到这里，我想起……」。检验：把「我」那段删掉，文章还成立，就是插进去的。
3. **「你」**：可选。写的话是 `reader` 那个时刻，放在中段跟「我」的处境并列，不放结尾当槽位。
4. **结尾**：对标库里只有五种（writing_guide §6：向上问一个问题 / 把问题交给读者 / 场景后一句判断 / 推荐原片带时间锚 / 回扣开头），挑一种，一段写完就停。「两类读者各一句」「以前现在」「做 X 的朋友」是我们自己发明的槽位，不用。不总结，不对仗。

句子：每句写到结果才停，因果用「因为 / 所以 / 但 / 即使 / 这样一来」写出来；**一句话一个主语，逗号不连三个以上的独立分句**（主语换了就换句号）；动词和形容词用双字；一个意思可以说两遍；让步要带事实；跑题拉回的路标（「说回正题」）可以用，PPT 过渡页（「理由有两个。」）不行。

图：**每一页至少一张**（用户 11-08 看 Addy 稿后定，第五次要求：「一页全是字阅读成本太高」）。原文素材优先（截图、人物照、原话卡，`$M/scripts/box.py` 画红框），没有再画只讲一个机制的可视化（云端用 Playwright 截 HTML）。放进 `编辑用/`，`![说明](文件名)` 插进正文；出图后看 overview，没图的页把图挪过去或补一张，末页用问题 + 一张图收。

### 4. 终稿念一遍
把标题、开头三段、每个单句段、最后一段念出来。像 PPT 过渡页的删，像评委打分的改成自己的事，一句话没说到结果的补完。不做整篇机械重写。

### 5. 检查
```bash
python3 $V/scripts/check.py "<输出目录>/meme版"
```
✗ 全改。⚠ 逐条看，能说出理由的留，交付时写理由。脚本只有 42 条（16 ✗、26 ⚠；meme_check 是 44 ✗、81 ⚠），查的是「说没说完、有没有人话、是不是在场」，不查虚词百分比。

### 6. 出图、标题、正文.txt
```bash
cp $M/assets/avatar.png "<输出目录>/meme版/编辑用/"
python3 $M/scripts/render_meme.py "<输出目录>/meme版/编辑用/draft.md" "<输出目录>/meme版"
```
首页按 `$M/references/cover_guide.md` 的原版：一行 `headline` + 两段正文 + `hero`（人脸或素材图，`hero_after: 2`），看起来是一张手机长文截图，不是海报。**v3 版式（`style: v3`，粉底三行大字块 + 导语 + 引用块）11-08 起停用**：三篇点击率 8.2% / 11.3%，账号其他首图 14 到 23%，脚本留着不删。首页也不用放大的图表或英文推文当 hero（MIT、OpenAI 面试官两篇）。超过 18 页删段落。Read `overview.jpg` 和 `01.png` 看首页认不认得出。

标题正文写完再起，三条备选三种句式，写进 `标题备选.txt`，最强的进 `标题.txt` 和 `title`：
- **名字或身份 + 一个反差**（「替查理芒格管钱的人，对AI的预言」「心流专家：越沮丧，越接近答案」），不用判断句和框架名；圈内名字换成路人能认的身份（Kotler → 心流专家，Wulfie Bain → OpenAI 招聘经理）；
- 可搜词在前 6 字（路人认识的人名 / 模型名 / 场景词），社会证明是路人认识的名字；
- 至少一条「情绪 + 名字」（「强烈推荐看看Anthropic就业报告。」）或认知差句（「看来很多人没读懂LobsterAI报告。」）；
- 20 字以内，不用感叹号和极限词，不以非 keyword 的中文专名开头。
- 荐读体只在名字本身就是钩子时当主标题（「Anthropic就业报告」23.4%，「斯坦福教授这期a16z访谈」13.1%）；否则主标题用「身份 + 反差」那条。标题或正文.txt 第一段带人物全名或书名，补搜索。
- **标题和首页是同一件事**（10-30 用户：「标题还缺点意思」；依据 `对标/MemeInformation/叙事与标题手册.md` §4.2 和本号点击率排名）：标题要么是全文的结论、结尾逐字回扣，要么就是正文第一段那件事，读者点进来第一眼看到的就是标题的下半句。本号点击率前列里，「听完李录讲卖出，我想起了卖飞的美光」20.1% 就是「名字 + 我」的对照句。人物稿优先试「名字 + 他做了什么 + 我」的对照（「Claude创始人看见就去做了，我没有」），比「名字：一个数字判断」（「Anthropic兄妹：90%的人看走眼」，判断跟首页的「我」对不上）更像一个人在说话。

`正文.txt`：第一段直接是内容（带主关键词），两三段要点，有可回指的旧稿加半句，领取物原样贴，最后 3 到 6 个标签。1000 字以内。跑 `skills/youtube-xhs/scripts/check_paste.py` 和 `post_log.py add --series meme-v2`。

公众号分支同 meme-xhs 7.5：`$M/scripts/render_wechat.py`。

## 不动的硬规则
- 不编经历、朋友、团队、实测；「我」只来自经历库和这次的真实操作。
- 不提收益、不用极限词、不引流站外、不预告下一期、不喊关注（名片卡那句除外）、不放「刚好」式品牌引入。
- 不写生产过程（「素材里」「整理稿」「读了三遍」）、不给自己的发言加前缀（「这条我站他」「我的看法是」）、不自称内行。
- 对仗金句不写（10-02 评论区认出 AI 的就是它）。
- 自称 AI builder，不是 PM；slogan 和名片卡 CTA 按 render_meme 默认。

## 改这份 skill 之前先读（10-21 晚用户定：v2 不能再犯）

10-21 Jack Clark 稿被退回两次，两次的病根一样：**用换一批槽位的方式去掉槽位**。第一次把「我最想说的一件事是」从句首挪到句尾（「这是我整场听下来最想说的一句」），第二次把「我的反应」写成了指南范例句，稿子里就出现了「我看完这段，想的不是 X，是 Y」这种为了交差的倒装。两句都不是文章需要的，是规则需要的。

以后往 v2 加任何规则、范例句、检查项之前，过三道门：
1. **它会不会在稿子里变成一个固定位置？** 连看三篇，同一个位置出现同一种句子，读者就认出模板。会，就不加，或者只写成「可以」，不写成「要有」。
2. **范例句不是必放句。** 指南里的例句用来说明写法，稿子里不照抄；一句话如果只是为了让检查脚本看到 stance、看到「我」、看到「你」才存在，删掉它，脚本改成不查这个。
3. **一个观点只论证一次。** 判断不拆成「反应一句 + 因为一段 + 标签一句」三处半句；前提、推理、结论写在一段里，写完就往下走。
4. **口语不等于真人感**（10-21 Ilya 稿第三次退回）。学小盖「像跟朋友聊」学成了单字动词、「活」、自造比喻，被用户认出是 AI。用词口径仍是科技栏目主编，检查脚本里「活」和单字动词收尾的 ⚠ 不撤。**11-08 收窄**：这道门只管用词，反应词和 emoji 是撤禁不是加规则，四篇爆款都有，放开。

改规则的记录写进 `references/changelog.md`，每条写清「撤 / 换 / 加」和它拦的是哪篇稿的哪句。输出规则只撤不加，加的那条必须是拦住本次被退回的句式。

## 四关（11-10 用户定）
出粉丝池 → 路人点进来 → 被继续推 → 关注，每关一个数，表和证据在 `账号/爆文方法论.md` 第六节。它管选题、交付和发布后的检验，不是写法规则：按八条模板写得再好，题材过不了第 ① 关也只有几十到几百观看。长访谈稿上一篇同类停留低于 40 秒时，这一篇多留两个原文场景，不靠加图撑页数。平台 AI 建议的鲜艳大字报封面不采纳（v3 试过 8% 到 11%）。

## 跟 meme-xhs 的 A/B
同一份素材两个 skill 各出一版，发哪版用户定；发了的那篇在 `账号/日志.csv` 的 series 栏标 `meme` 或 `meme-v2`。看的数是每千次观看涨粉（10-18 的尺子：从 0.7 到 2 回到 5 以上）和粉丝停留是否长于路人。

**10-29 结果**（`复盘/2026-10-29_数据复盘_v2七篇和v3三篇.md`）：v2 七篇（10-20 到 10-29）合计观看不到 1600，每篇涨粉 1，没有一篇进公域推荐；同期 meme-xhs 原版的就业报告 6 万观看 68 粉。四篇爆款全是 meme-xhs 原版。用户定：**下一篇起写法上回到「第一句是我在当下做的一件事」+ 原版首图**；v2 保留的是输入侧（先问代价和读者直觉、经历库代价列、不套旧事）和句子层（写到结果才停、专名后半句人话、双字词），主编口径的第三人称开头和 v3 版式停。

**11-07 结果**（`复盘/2026-11-07_数据复盘_四篇爆款的共同点和之后十四篇的差别.md`，用户 11-08 定）：v2 十二篇里只有心流稿过千（8333，赞率 8.7% 全账号第一），其余 200 上下；心流稿和兄妹稿同是 v2 retell，差在门票（心流专家 vs Anthropic 兄妹）、题材（每个人的卡住 vs AI 圈的看见）、第一句能不能画出来。结论：A/B 结束，输入侧保留，输出侧按 `账号/爆文方法论.md` 第五节八条；连贯短文默认、每页有图、v3 首图、主编口径管口吻四条撤。
