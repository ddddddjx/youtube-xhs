# meme-v2：真人感从输入来

一份素材进来，交付一组 1080×1440 手机长文截图、三个标题备选、一段图下正文。版式、出图、首页、公众号分支全部复用 `skills/meme-xhs/`（下面记作 `$M`），本 skill 只换写法和检查。本目录记作 `$V`。

这份 SKILL 没有日期补丁。规则为什么是这样、哪天改的，在 `$V/references/changelog.md`；写法细节在 `$V/references/writing_guide.md`，写稿前读完。依据是 `对标/蒸馏_2026-10-21_对标库全量.md`：一个月里改输出 20 多次没有一条被数据证实，改输入 2 次跟着 2 个爆款。

## 一句话原则

读者读完要觉得这是一个对 AI 有顶尖理解的真人写的。做到这点靠三样：**「我」在场且付过代价、判断对着世界下、每句话写到结果才停。** 不靠黑名单。

## 步骤

### 0. 加载记忆和对标
读 `CLAUDE.md` → `账号/档案.md`（长期立场 A / B / C / D、观点库）→ `账号/经历库.md`（含「代价」列）→ `对标/README.md` 按文体和题材挑一篇对标读 → `账号/范本/` 一篇自己的。然后才读素材，原样存 `编辑用/source.md`。

### 1. 写稿前先问（每篇必走）
先给 150 字摘要：谁写的、核心判断、两三个事实、最可争论的一句原话。然后只问素材引得出的问题，七个里挑 4 到 6 个：
① 这件事你工作里碰到过没有，哪天、什么场景、结果；② 原文哪句你不服、哪句你站；③ 读者带走哪种价值（信息 / 框架 / 情绪 / 行动）；④ 有两边时你站哪边；⑤ 你想留给读者的一句判断，回到 A / B / C / D 哪条；**⑥ 这件事你付过什么代价（时间、钱、脸、信任）；⑦ 读者按直觉会怎么想，你的体会哪里不一样。**
回答原话进经历库（含代价列）和观点库。用户说「你定」就按默认写，交付时标出哪些是默认。

### 2. 定骨架
- 骨架是原文里的人讲自己真事（访谈、播客、人物稿）→ `mode: retell`，主语是「他」，每点一个原文真场景，结尾前一段「我」。
- 骨架是用户自己的事 → 自述，素材只是引子。
- 骨架是一份材料（报告、论文、文档）→ 观察，按「一件在场的事 → 读者的直觉 → 用具体例子翻过来 → 我的态度」走。
- 刚发生的事 → 热点快评，500 到 1000 字。
篇幅 1300 到 2200 字，评论员式连贯短文为默认，编号笔记体只在素材知识密集时用。

### 3. 写 draft.md
front matter：`title`、`mode`（可选）、`stance`（一句原文没说过的判断，宾语是世界不是文章）、`stance_line`（A / B / C / D）、`reader`（读者的一个具体时刻，不是职业）、`cost`（这篇用到的那次代价，一句话）、`keyword`、`keywords`、`headline`、`hero`、`location`、`account`。可选 `stance_quote`（反对原文时逐字贴原句）、`hero_after`、`extra_pages`。

正文按 writing_guide 写。骨架的四个位置：
1. **开头只做一件事**：要么先摆舞台（谁在哪讲了什么），要么先把那个反转事件完整讲完，然后一句交代来源，直接进判断。一件事不切成两半夹一段履历，开场不叠开场。**判断只论证一次**：前提、推理、结论写在一段里，不拆成「我看完想的是…」+「因为…」+「这是我最想说的」三处半句；「我」的反应并进自己的经历那段。「我最想说的一件事是」这类标签不写。不替读者预设情绪，不铺垫后文不展开的事。
2. **中段**：每节「一个点 → 一个例子 → 一句大白话重述」。读者的直觉说出来再翻过来。一个熟悉的锚用到底。专名和数字第一次出现后面跟半句人话。「我」出现的地方是场景和代价，不是打分。
3. **「你」**：至少一段主语是「你」，写的是 `reader` 那个时刻。
4. **结尾**：三选一，落到自己一件小事 / 往下收一句评价 / 「以前……现在……」+ 两类读者各一句。不停在行业判断上，不总结，不对仗。

句子：每句写到结果才停，因果用「因为 / 所以 / 但 / 即使 / 这样一来」写出来；**一句话一个主语，逗号不连三个以上的独立分句**（主语换了就换句号）；动词和形容词用双字；一个意思可以说两遍；让步要带事实；跑题拉回的路标（「说回正题」）可以用，PPT 过渡页（「理由有两个。」）不行。

图：每篇至少两张，一张原文证据（`$M/scripts/box.py` 画红框），一张对照或总结（`$M/scripts/render_illus.py`）。信息密度大的节配一张只画一个机制的图。放进 `编辑用/`，`![说明](文件名)` 插进正文。

### 4. 终稿念一遍
把标题、开头三段、每个单句段、最后一段念出来。像 PPT 过渡页的删，像评委打分的改成自己的事，一句话没说到结果的补完。不做整篇机械重写。

### 5. 检查
```bash
python3 $V/scripts/check.py "<输出目录>/meme版"
```
✗ 全改。⚠ 逐条看，能说出理由的留，交付时写理由。脚本只有 42 条（16 ✗、26 ⚠；meme_check 是 44 ✗、81 ⚠），查的是「说没说完、有没有人话、是不是在场」，不查虚词百分比。

### 6. 出图、标题、正文.txt
```bash
cp $M/assets/avatar.png "<输出目录>/meme版/编辑用/"
python3 $M/scripts/render_meme.py "<输出目录>/meme版/编辑用/draft.md" "<输出目录>/meme版"
```
首页按 `$M/references/cover_guide.md`：`headline` + `hero`（人脸或素材图）。超过 18 页删段落。Read `overview.jpg` 和 `01.png` 看首页认不认得出。

标题正文写完再起，三条备选三种句式，写进 `标题备选.txt`，最强的进 `标题.txt` 和 `title`：
- 可搜词在前 6 字（路人认识的人名 / 模型名 / 场景词），社会证明是路人认识的名字；
- 至少一条「情绪 + 名字」（「强烈推荐看看Anthropic就业报告。」）或认知差句（「看来很多人没读懂LobsterAI报告。」）；
- 20 字以内，不用感叹号和极限词，不以非 keyword 的中文专名开头。

`正文.txt`：第一段直接是内容（带主关键词），两三段要点，有可回指的旧稿加半句，领取物原样贴，最后 3 到 6 个标签。1000 字以内。跑 `skills/youtube-xhs/scripts/check_paste.py` 和 `post_log.py add --series meme-v2`。

公众号分支同 meme-xhs 7.5：`$M/scripts/render_wechat.py`。

### 7. 交付
SendUserFile：`overview.jpg`、`01.png` 到 `NN.png`、`标题.txt`、`标题备选.txt`、`正文.txt`。汇报：骨架是谁；「我」用了经历库哪几条、代价是哪一次；stance 和 stance_line；哪些是默认；check 留下的 ⚠ 和理由；需要用户补的东西。按 `账号/爆文方法论.md` 发前清单逐条写过没过。不代发。

## 不动的硬规则
- 不编经历、朋友、团队、实测；「我」只来自经历库和这次的真实操作。
- 不提收益、不用极限词、不引流站外、不预告下一期、不喊关注（名片卡那句除外）、不放「刚好」式品牌引入。
- 不写生产过程（「素材里」「整理稿」「读了三遍」）、不给自己的发言加前缀（「这条我站他」「我的看法是」）、不自称内行。
- 对仗金句不写（10-02 评论区认出 AI 的就是它）。
- 自称 AI builder，不是 PM；slogan 和名片卡 CTA 按 render_meme 默认。

## 跟 meme-xhs 的 A/B
同一份素材两个 skill 各出一版，发哪版用户定；发了的那篇在 `账号/日志.csv` 的 series 栏标 `meme` 或 `meme-v2`。看的数是每千次观看涨粉（10-18 的尺子：从 0.7 到 2 回到 5 以上）和粉丝停留是否长于路人。3 篇之后再定 v2 留不留、哪条规则搬回 meme-xhs。
