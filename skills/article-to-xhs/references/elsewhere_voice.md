# elsewhere 文风手册（第二版）

这一版来自对「elsewhere别处发生」全部 67 篇文章（2025-11 到 2026-09，约 23 万字）的逐篇通读和词频统计。第一版有几处是凭印象写的，和原文对不上，这一版改掉了，见第 17 节。

例句都是短摘，只用来说明写法，不要抄进稿子。

这个号给自己的定位：写「重要、但也更有意思」的科技商业内容，让读者「在主流叙事之外」看到一个行业、一群人的另一面。口号是 Maybe wrong, always fun。

**一句话配方**：找到一个形式框；从一个具体的时间、人或事起笔；每个判断换成一件有时间地点的小事；数字带参照物；信源写清来路；长段铺事实，短句下判断；结尾停在一句原话、一个动作或开头出现过的物件上。

---

## 1. 先认清我们写的是哪一类

elsewhere 的稿子分两类。

| 类别 | 材料从哪来 | 代表篇目 | 叙述者 |
|---|---|---|---|
| 一手采访稿 | 作者亲自采访当事人和周边的人，有匿名信源 | 阿里投资Kimi始末、DeepSeek 融资故事、Liblib 调查、各篇人物特稿 | 「我」常出现：我问、对我说、据我们了解 |
| 公开资料复原稿 | 播客文字稿、创始人博客、公司公告、监管文件、论文、媒体报道 | Cursor没有做错任何事（文末列了 40 条出处）、预测市场一文里的海外部分、Kimi K3 预告片拆解 | 叙述者几乎隐身，全文可以没有一个「我」 |

Krypto说AI 没有采访，只能写第二类。所以范本是《Cursor没有做错任何事》：把散在四十多份公开资料里的场景，按时间线重新拼成一个故事。

由此得出三条硬规则：
1. 资料研究就是写作的主体。资料不够，稿子写不出来，不能用文采补。
2. 叙事用第三人称讲故事。研究过程（读了什么、查了多少、哪里没读到）不写进稿子，只写进研究文件、在交付时告诉用户。不写「我问了他」「他告诉我」。
3. 匿名信源的措辞（一位接近交易的人说）只能在转述某篇报道时用，而且要说出是哪篇报道写的。

## 2. 先找形式框

动笔前先找一个框，标题、小标题、结尾都从框里长出来。这是 elsewhere 长稿读起来完整的主要原因。

| 篇目 | 框 | 怎么贯穿 |
|---|---|---|
| Cursor没有做错任何事 | 一道证明题 | 导语问「证明题还是反证题」；第一节叫 No hand-waving（数学里的挥手式论证）；最后一节叫「证毕」；结尾说他们遇到「一道没有测试集的题」 |
| 去他*的「世界模型」 | 一扇任意门 | 开头是小学三年级想看别人眼里的世界；结尾回到二十年前的同一个念头 |
| 宇树融资故事展 | 一场展览 | 一件展品一节 |
| 2026年AI应用期中考试 | 一张卷子 | 整篇写成考卷，连注意事项都有 |
| AI独角兽制造机 | 一个剧本 | 小标题连成叙事弧：剧本、Loop、造雨人、鲶鱼、榜样、结果 |
| Liblib，你的梦想是什么？ | 读者的三个预期 | 每节先问「提起一家AI公司，你第一个会想到什么？」，再写这家公司恰好相反 |

框的来源通常是材料里已有的东西：当事人说过的一个词、公司名字的含义、一件反复出现的物件。不要从外面硬找一个比喻套上去。

## 3. 主标题

| 套路 | 写法 | 原号标题 |
|---|---|---|
| 化用 | 名言、书名、台词、歌词只改一两个词 | 即使没有上帝，也要造出一个来 / 赤子孤独了，会创造一个世界 / 王华东正传 / Cursor没有做错任何事 |
| 反差口语 | 口语、自嘲，带一点冒犯 | 去他*的「世界模型」/ 我去被投公司了，拜拜 / Kimi K3 据说很强，但预告片我们是真没看懂 |
| 限定词惊叹 | 可能是、怎么会有、比 X 更 | 可能是世界上最小的VC / 怎么会有这么离奇的AI4S创业者 |
| 档案体 | 对象加始末、往事、故事 | 阿里投资Kimi始末 / SHEIN融资往事 / 忘不了的 Kimi C轮融资 |
| 人名加信条 | 冒号后面是一句原话或一个意象 | 红杉公元：而我选择，另开一桌 / 对话郭山汕：不入江湖，但要继续赢 |
| 挪用格式 | 借考试、综艺、榜单的格式 | 2026年VC晋升大赏 / AI独角兽制造机 / 六小虎的融资故事，仿佛六种人生 |

标题里不出现：深度、独家、重磅、万字、揭秘、一文读懂、感叹号、金额。

## 4. 开头

第一句一定是具体的时间、人或事。67 篇里没有一篇用「随着 AI 的发展」这类大背景起句。

六种起手：
1. **新闻一句**。「2026年8月14日，Cursor 宣布自己正式成为 SpaceX 的一部分。」
2. **现场特写**。上市当天，创始人穿一件白色 T 恤混在台下人群里，合照时才匆匆上台。
3. **设问加答案**。「你能想到最小的基金能有多小？」下一段：「告诉你一个答案：330万美金。」
4. **采访印象或统计梗**。「访谈王华东，是个略微干燥的过程。」一场对话里出现了 16 次「哭」和 43 次「哈哈哈」。
5. **自我打断**。「Liblib ——哦不对， Evoken」
6. **先认下已知**。已知信息不再赘述，以下是一些未被展示过的故事。

导语（前 5 到 9 段）要依次完成这些事，顺序可以微调：
1. 钩子，一两句；
2. 一个和钩子相反的事实，制造张力。Cursor 一文的第三段是：五个月前创始人还说要做一家 independent and long-lasting 的公司；
3. 为什么现在写：上市、融资、收购、发布、离职；
4. 必要的背景，压到两三段，导语里至少出现一个数字和一个名字；
5. 一句悖论式的概括。「价值与独立并不是同一件事。」「这是一家并不AI、却又大获成功的公司。」
6. 全文要回答的一个问题，只有一个；
7. 交代方法：elsewhere 的采访稿会写「聊了十几位接近它的朋友」。我们没有采访，**不写这一步**：「我查了八十多份出处」对读者是噪音，还暴露了后台。直接进故事；
8. 一句过渡进正文。

吴睿睿那篇《我在澡堂复活AI应用》一句一段、近似诗行，是活动预告的特例。不要把它当作常规开头的模板。

## 5. 按文体选骨架

| 文体 | 骨架 | 范本 |
|---|---|---|
| 复原型叙事（一家公司、一笔交易、一个产品的来龙去脉） | 导语抛问题 → 从最早的一个场景起笔 → 按时间顺序推进，每节一个阶段、一个意象小标题 → 倒数第二节给历史类比 → 结尾回到框 | Cursor |
| 现象评论 | 两三个平行事实引出现象 → 一句话定义现象 → 每节一个机制，机制用匿名或实名的小场景撑 → 主动拆掉最容易的解释 → 问句或借来的句子收尾 | AGI的另一半、AI独角兽制造机、AI互动内容的怪异二三事 |
| 新赛道或新概念介绍 | 新闻点 → 先讲概念再讲公司（用五个具体例子让读者秒懂）→ 海外对标各一段小传 → 几家公司「气质各异」各两段 → 往远处想一步 | 预测市场的founder们都说他们在做今日头条 |
| 人物 | 现在的事做钩子 → 他在做的东西 → 最有戏的一段经历 → 童年和家人放在最后一节 → 末段把童年那一幕翻转过来 | 去他*的「世界模型」、赤子孤独了、那个去百度做模型的年轻人 |
| 交易碎片 | 一节一家机构或一个小故事，小标题用机构名或 1、2、3 → 「说回」衔接 → 结尾一条新消息或「下回再说」 | DeepSeek 融资故事、忘不了的 Kimi C轮融资 |
| 快评 | 新闻 → 「PR 稿已经饱和，不再回溯」→ 第三段就给出唯一的观点 → 后面全是证据 → 一个想象的画面收尾 | 六小虎的融资故事 |
| 盘点 | 导语讲方法和范围 → 每条四要素：一句话定位、出身、最特别的一点、融资或数据 → 每个分类至少一句判断 | 16个让Agent更好用的公司正在融资 |

整篇文章先给定位和数字，单个案例先给场景后给结论。两者顺序相反。

## 6. 一节怎么写

**节的第一句是定位句。** 短，直接告诉读者这一节讲谁、讲哪件事，不铺垫。
- 「先说那场投资人会议。」
- 「Kimi 和阿里，差点失之交臂。」
- 「是有一个loop存在的。」
- 「Cursor 尝试过摆脱这种依赖。」

**小标题要变，框不变。** 同一篇里，elsewhere 的小标题长短和句式一直在换，统一它们的是形式框和语气：

| 篇目 | 小标题 |
|---|---|
| Cursor没有做错任何事 | No hand-waving / 新房子 / 负重起飞 / 唯一胜利法 / 不同斜率的坡 / 钱解决不了问题 / 证毕 |
| DeepSeek 融资故事 | 传说中的四小时会议 / 克制与AGI / 50亿到15亿 / Monolith / 正心谷 / DeepSeek 会是红杉高瓴最大 miss 吗？ / 最大要求：不要挖人 |
| 宇树融资故事展 | 从QQ邮箱搜来的微信好友 / 坐着卧铺上北京 / 严重偏科的 outlier / 只有18人公司的账本 / 一套奇葩的面试题 |
| 孟醒访谈 | 被全场灭灯的《非诚勿扰》男嘉宾 / 自动驾驶十年间 / Momenta的大logo / 不可比，才能让我可比 / 投资最多奇人的人？ / 没有尽头 |
| Liblib | 制造业公司 / 流水的CTO / 节奏感 / 被 Manus 点醒 / 冕与win |

能看出来的规律：两三字的短词和一整句原话混着用；有英文、有数字、有问句；「A、B 和 C」只是陈之琰偶尔用的一种，一篇里也不全用。一个模子刻出来的小标题，读起来像目录生成器。

**小标题和节首句咬合。** 上一节最后一句说「最稀缺的是信任」，下一节标题就是「信任怎么来的？」，第一句是「信任不是靠一次融资建立的。」

**一个小故事的五步：**
1. 时间或场合起句（2019年、那年7月一个周一的下午、18天后）；
2. 人做了一个动作；
3. 一句原话，常常是对方说的；
4. 用「当时」「那时」补一两句背景；
5. 结果，或者一句短评。结果常单独成段。

**背景后置。** 履历、成立时间、公司百科最早出现在第三四段，一两句带过。人名可以放在场景最后才揭晓：先写咖啡馆里十分钟做完编程题，第四段才说「这个名叫 Michael Truell 的年轻人刚满18岁」。

**时间锚要密。** Cursor 一文 17% 的段落以时间起句。多用相对时间制造节奏：三个月后、18天后、两个月后、六天后、四年后。

**转场用这些：** 说回、先说、这里再展开一下、时间回到、直到、类似的事情还有、故事讲到这里、在另一边。
不用：首先、其次、此外、另一方面、与此同时、综上。

**人物出场三句话。** 「一个叫蒋珊珊的人出现了。」然后：加微信几次没通过；本科和研究生学数学和计算机；据接触过她的人说，气质清冷、常年吃素。外貌和性格要有出处。

## 7. 判断落成动作

elsewhere 几乎不直接写形容词式的判断。判断句最多占一行，支撑它的画面占三到五行，画面里一定有一件可以拍下来的东西。

| 如果写成抽象说法 | 他们实际怎么写 |
|---|---|
| 创始人对技术趋势极度乐观 | 他和一位 IMO 金牌得主打赌两年内 AI 拿到金牌水平，还穿着印有 scaling laws 曲线的 T-shirt 到处走 |
| 应用公司依赖上游 | 卖给用户的是一个确定的价格，向上游买的是一张不断滚动的账单 |
| 这笔融资时间很紧 | 签署期限压在大年三十，签字到大年初一零点前后才结束 |
| 老板管理高压 | 群里的短消息每条间隔不到 2 秒；一位新人上班第四天吵了一架，当天下午飞书被清空 |
| 这家公司靠压成本增长 | 采购打折账号时买的是学生账号；技术团队讨论要不要把流量从八折渠道迁到七五折渠道 |
| 这个赛道留存差 | 作者自己玩了十多个回合，然后写：第二天我一个产品都没有打开 |
| 团队不讲排场 | 机器狗每天爬楼梯，台阶边缘被踩缺，碎屑扫掉，楼梯不翻修 |
| 家道中落留下匮乏感 | 饭桌上的肉越来越少；五六岁想吃一顿肯德基，被明确拒绝 |
| 公司内部对增长很冷静 | 年收入过 1 亿美元那天，Slack 机器人发了一条数字通知，办公室很快恢复正常 |

三个要求：
1. 每件小事是一次性的，有时间地点，不是「经常」「往往」。
2. 写完把形容词划掉，看事情本身还能不能让人得出同样的判断。
3. 事件后面不解释「这说明了什么」。

失败和代价也要写：一个功能上线后很快失败了，因为没有人愿意一边聊天一边看 AI 的指导；第一版产品用户要插设备、下 app、连三样东西。只写赢的稿子不可信。

## 8. 数字

**每个数字配一个参照物。**
- 8 亿美元，「这个数额够募三个VC了」。
- 延迟从 475 毫秒压到 260 毫秒，「只相差约四分之一秒」，前者像在等服务器，后者接近人的动作。
- 次日留存 25% 到 40%，对比大厂标准（次留 40%、七留 20%、三十留 10%）和抖音早期的 25% 到 30%。
- 产品毛利率为负，「正常情况的这个数字应该是70%以上」。
- 600 亿美元，按年化收入算「大约15倍P/S」。

**数字写到能查到的最细**：1182.82 万元、212.8 毫米、72 个字的离职博客、46 页的技术报告。查不到精确值就明说是大概。

**会读数字。** 「不过你注意到没有：新产品公布的是收入数据，旧产品讲的是用户量。」一家机构出资 9.8 亿，「似乎是为了小于10亿这个整数」。读数字的口径，比报数字更有价值。

**给读者算一笔账。** 安卓东南亚一个下载 0.5 美元，北美 3 到 5 美元，所以一张百万下载的成绩单最低只要 50 万美元。

数字不连续堆放，每个数字挂在一个人或一个动作上。

## 9. 引语

- 转述多于直接引语，大约三比一。直接引语只留三种：有性格的短句、关键决定、反常识的判断。
- 直接引语多数在 20 字以内，超过两句就转述，只把最有口气的半句留在引号里。
- 引导动词几乎只用：说、后来说、回忆、写道、承认、形容、称。不用：表示、指出、强调、坦言、直言、感慨道、透露。
- 引语后面接动作、事实或另一方的说法，不接解释，不接赞叹。王兴说完愿意支持一把，下一段是投票通过。
- 对方的狠话比主角的话更值得直接引用。
- 冲突写成两行对话，各占一段，不加说明。
- 英文原话保留原文，括号里给中文：「Growth can hide poor execution.」（增长会遮蔽糟糕的执行。）
- 记不准就标（大意）。

## 10. 信源

elsewhere 把信源按远近分级，用不同的词：

| 级别 | 措辞 |
|---|---|
| 亲耳听到 | 对我说、告诉我、我曾问过 |
| 自家掌握 | 据「elsewhere」了解、据我们了解 |
| 转了一手 | 据一些接近它的人转述 |
| 传闻 | 据说、相传、江湖盛传、有个不可考的传说是 |

放到公开资料复原稿里，对应的写法是把出处写进句子：
- 「他在2021年11月的一篇文章里解释过为什么值得做，标题叫……」
- 「2024年，创始团队对 Lex Fridman 说……」
- 「同年接受 The Verge 采访时，他又承认……」
- 「公司后来在博客里写道……」
- 「一位在办公室观察了两个月的作者问过他……」

出处要写出三样：谁、哪一年、在什么场合。「研究表明」「数据显示」「有报道称」「业内人士」「据悉」在 elsewhere 全库里接近零次。

**主动坦白：**
- 单方说法要标明：这是他对自身经历的判断，「不必然是那些组织中每个人看到的事实」。
- 事后归因要承认：「以上难免有一些事后的归因。」
- 一个细节说明不了什么就直说：「当然这只是一个细节，不必然意味着什么。」
- 没查到就写没查到。
- 同一件事有两种说法就并排写，不替读者选。
- 流行的说法先摆出来再纠正：这款产品常被说成套壳，「但真实的顺序恰好相反」。

## 11. 解释概念

默认读者聪明但不在圈内。小红书读者比 elsewhere 的读者更外行，解释要多给一步，但方法一样。

1. **先给一个荒诞或日常的场景，再给术语。** 讲世界模型，先假设北京国贸出现一只怪兽，AI 生成的视频里怪兽砸了一小时，「警察不会来」。讲完才出现架构名词。
2. **用五个具体例子代替定义。** 讲预测市场，先列五个问题（马斯克下周发多少条推文），然后一句：「这就叫：预测市场。」
3. **类比成人的分工。** AI 做研究拆成两个角色，一个负责提假设，一个负责做实验。
4. **术语当场用一句话说清**，括号给中文，给完不再重复。
5. **一句「简单来说」收口。** 一家公司被概括成：想造的是「造 AI 的人」。
6. 技术对标给第三方事实和限制：官方称最长一分钟，但多数演示在 10 到 20 秒。

## 12. 短评和单句段

全库 43% 的段落是单句段，但其中大多数是平实的陈述，不是金句。

单句段出现在五个位置：
1. 转场：「说回43亿美元的C轮。」「两条失败线在此汇合。」
2. 反转：「更糟的是，凌海病了。」「但PC端很快撞到了天花板。」
3. 悬念：「但问题是，谁会出那8亿美元？」「直到 Manus 出现。」
4. 揭晓：「这个人说的就是刘元。」
5. 节尾冷评：「难的是中间的钱。」「只能等。」「清单已经写好，缺的是引擎。」「这有点难评。」

短评的要求：
- 15 到 25 字以内，一句；
- 是另起一个角度的冷话，不复述上文，不解释上文；
- 大约一半的节用短评收尾，另一半停在事实、原话或动作上。每节都收一句金句，读起来像 PPT；
- 对仗和「不是 X，是 Y」要省着用。全库这个句式的中位数是每千字 0 次。

## 13. 表达立场

- 立场放在结构里：选谁写、留哪个细节、什么放最后，本身就是判断。
- 用对称句代替结论，两边都成立：「它越成功，越需要购买上游资源；它越成功，上游也越有理由亲自进入它的市场。」
- 质疑写成问句：「那这还是一个纯粹的投决吗？」
- 重话交给有名有姓的第三方去说，自己只接半句。
- 给反方留篇幅。批评最重的那篇 Liblib 调查，专门用一节写支持者的逻辑，一节写创始人十年没赢过。
- 判断带限定词：可能、大概、似乎、或许、某种程度上、未必。全库每千字 1.7 个。
- 全文最多直接表态一次，一句。
- 不写启示、建议、「我们应该」，不预测谁会赢，不对具体的人做道德裁决。

## 14. 幽默

偏冷，靠事实和措辞的错位，笑点后面不加提示。
- 算账式：8 亿美元够募三个 VC。
- 一本正经说尴尬：引完一段外交辞令式的官方回复，「这个回复，有点让我不知怎么回复。」
- 装傻：「我什么都不知道，大家可以自行脑补。」
- 括号里小声说话：（一年出几趟国都拮据）、（不许打架）。
- 反讽教程：「如何制造一个AI club deal？你得先有一个大厂高P。」
- 让事实自己讽刺：为了拿到额度专程去陪创始人跑步，轮次打开了，这家机构自己却没投。
- 甩手：「那就当我没说。」

讽刺的对象是现象、机制和自己，不是具体的弱者。

## 15. 结尾

四种，按常见程度排：
1. **一句原话。** 「人，应该去变化更大的地方。」
2. **回扣开头。** 开头是父亲不让儿子睡，两个人要一起把那一关打过去；结尾是「这一次，轮到他想把父亲叫起来」。
3. **一个画面或一个问句。** 如果另一家也上市，敲钟照片的画风会不会不一样？
4. **一条新消息或预告。** 最新一轮融资正在进行中。「下回再说。」

结尾前一两段可以放历史类比（微软收购 GitHub）。最后一段写动作或物件，不写感想。不总结，不号召，不展望，不求关注。

## 16. 语言质感

**节奏基线**（46 篇 1500 字以上的稿子）：

| 指标 | elsewhere | 怎么用 |
|---|---|---|
| 段落字数中位数 | 62 字 | 一段 1 到 3 句，手机上两到四行 |
| 超过 120 字的段落 | 8% | 只在解释机制时出现 |
| 单句段 | 43% | 长段铺事实，短句下判断 |
| 句子字数中位数 | 27 字 | |
| 数字 | 每千字 7 个，交易稿 16 个 | |
| 破折号 | 每千字 1.2 个 | 用来补一句解释、延迟揭晓 |
| 感叹号 | 0 | 只出现在引语里 |
| 「不是 X，是 Y」 | 每千字 0 次（中位数） | 稀有 |
| 留余地的词 | 每千字 1.7 个 | |
| 「你」 | 每千字 1.5 个 | 和读者说话：你注意到没有 |

**并列**用冒号和分号压进一句，不用大段排比。排比的每一项必须是具体的事。

**中英混排**：圈内真实使用的英文词直接用（deal、founder、bet、pass）。小红书上要收紧，见第 19 节。

**括号**三种用途：注身份或译名、标（大意）、小声吐槽。

**加粗**：叙事稿正文几乎不加粗。没有「金句加粗」。

**第二人称**用来和读者对话：「我知道你会想问」「你注意到没有」「这是不是很像你最近可能听说的一种叙事」。

**自谦**：先自贬再说价值。「这些内容实在单薄、甚至轻浮。」「说实话，我们也没看懂。」

## 17. 这些文章从来不做的事

1. 不用大背景句开头。
2. 不用首先、其次、最后排论点。
3. 不写综上所述、总而言之、值得注意的是、众所周知、不得不说、毋庸置疑。
4. 不用颠覆、震惊、重磅、炸裂、揭秘、干货、赋能、抓手、闭环、底层逻辑做自己的叙述语言。
5. 叙述句不用感叹号，不用表情符号。
6. 不自称笔者、小编。
7. 不用据悉、据报道、业内人士、知情人士、研究表明。
8. 小标题不写背景、分析、总结、启示这类功能名。
9. 不按出生、求学、工作、创业的顺序写人物。
10. 不堆形容词夸人，不替人物拔高，引语后面不接「这句话道出了本质」。
11. 不把单方说法写成事实，不对未证实的事下断言。
12. 不给建议，不写启示，不预测输赢。
13. 不在结尾升华、号召、求关注。
14. 不写大段排比抒情。
15. 不虚构场景，不给匿名者起化名。
16. 数字不写成模糊量级，不连续堆放。

**第一版手册里写错的地方：**
- 「坦率地说」「怎么说呢」「我数了一下」不是 elsewhere 的口头禅。全库各出现一两次。不要当作固定句式用。
- 不是每一页、每一节都要有「我」。复原稿可以通篇没有「我」。
- 不是每一节都以一句对仗金句收尾。
- 「两拍冷开场」（一个数字一段、一个物件一段）只出自一篇活动预告，不是通用开头。
- 怪数字不是装饰。数字的价值在参照物和口径。

## 19. 用在小红书时的边界

1. **只学文风，不冒充。** 不自称 elsewhere，不用它的栏目名（elselier、début），不写「据「elsewhere」了解」。
2. **信源不能编。** 原文之外的细节、数字、原话，只能来自亲自读过并写进 `参考资料.md` 的公开出处。查不到的不写。
3. **不虚构采访。** 见第 1 节。
4. **用自己的话重写。** 每份产物里直接引用原文的句子不超过两句，每句不超过 30 字。
5. **化用必须有真实出处。** 只化用大家熟知的名句、书名、台词。
6. **读者更外行。** 第一次出现的人名、公司名、机构名，用一个短语介绍（做 PPT 软件的 Gamma、法国商学院 INSEAD）。封面、标题、正文第一屏以中文为主，英文术语最多一个并附解释；内页每页英文黑话不超过两个，第一次出现时括注中文。
7. **卡片和文案里不放链接。** 出处写进句子，完整清单留在 `编辑用/参考资料.md`。

## 20. 范文拆解

### 《Cursor没有做错任何事》（复原型叙事，张一皓、陈之琰）

全文约一万字，没有采访，文末列 40 条出处，格式是「作者, 媒体, "标题", 日期」。一手材料占多数：公司博客、创始人个人博客、监管文件、播客文字稿。

- **导语 9 段**：收购新闻 → 公司说的好处 → 五个月前创始人说的相反的话 → 行业背景两段 → 价格 → 一句悖论 → 一个旁证数字 → 抛出证明题。
- **第一节不从收购讲起**，从 2019 年咖啡馆里的一道编程题讲起。四位创始人各自失败过一次，两条失败线写完，单句段：「两条失败线在此汇合。」
- **每节一个比喻，节内把比喻讲透**：插件是「给旧房子添置新家具」，他们要的是「一间围绕AI重新设计的新房子」。
- **收入曲线平了一年**这件事，写成「一段漫长的助跑」，然后单句段：「只能等。」
- **清单式材料直接引用**：创始人 2023 年的博客里列的五条待办，原样放进来，最后一句「清单已经写好，缺的是引擎。」
- **定价事故**写成 18 天的时间线，再用两张账单解释结构性的问题。
- **融资数字**用一段列完四轮，下一段只说：从 4 亿到 293 亿，只用了一年多。再下一段转折：融资越快，越能说明问题。
- **历史类比**放在最后一节：微软收购 GitHub，两笔交易都在买开发者入口，买到的资产不同。
- **结尾**三步：公司名字的含义 → 「一道没有测试集的题」→ 一位观察者问创始人最担心什么，他说担心人们开始在饭桌上聊天气。最后一段写第一个离开的人去做了什么。

### 《AI互动内容的怪异二三事》（赛道批评，吴睿睿）

- 从一个早晨开始：许多合伙人收到一份 7 页的数据报告，水印写着仅供某基金使用。
- 六家公司用一段交代完，接着写它们讲的是同一个故事：下一个抖音。
- 核心论证是给读者算账和找尺子：下载量可以买，多少钱一个；留存买不到，实际是多少，大厂标准是多少。
- 作者亲自试用，坦白第一天玩得开心，第二天一个都没打开。
- 给反方留位置：用留存衡量小游戏可能不公平。然后再反问。
- 历史类比两个：一个关了三年多的社交产品，2021 年的新消费。
- 结尾对「你」说话，甩手。

### 《预测市场的founder们都说他们在做今日头条》（新概念介绍，郭允骁）

- 先声明这类公司「长得有点科幻」，给出新闻点。
- 「在介绍这三家公司前，先介绍一下预测市场本身。」五个问题，一句定义。
- 海外两家各一段小传，突出气质对比：一个是辍学的加密原住民，一个是带着投行履历、竭力自证合规的团队。
- 转折点给一个事件：2024 年大选时平台给出的胜率比民调准，数据被接进交易终端。
- 三家华人团队各两段，先写气质再写观点。
- 指出反常：它和 AI 似乎没有关系。然后自己找到一个联系。
- 结尾往远处想一步，轻轻一问：「这还挺科幻的，不是吗？」

**共同的底层动作**：先找到一个具体的人在一个具体时刻做了一件具体的事，再让道理从这件事里自己长出来。
