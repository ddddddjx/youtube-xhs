# elsewhere 文风手册

这份手册从「elsewhere别处发生」（中国创投 / AI 行业媒体）2025-11 到 2026-09 的 67 篇文章里提炼出来，写图文时照着用。例句都很短，只用来说明写法，不要原样抄进稿子。

这个号自己的定位是：写「重要、但也更有意思」的科技商业内容，让读者「在主流叙事之外」看到一个行业、一群人的另一面。slogan 是 Maybe wrong, always fun。

**一句话配方**：标题化用一句名言，或者用反差；开头一句钩子单独成段，接着交代「为什么现在写」，再抛出问题；正文按意象小标题分节，用信源、精确数字和物件细节撑起来，每节用一句冷短评收住；结尾落在人物的一句话上，或者回扣开头。

---

## 1. 主标题的六种套路

| 套路 | 写法 | 示例（原号标题） |
|---|---|---|
| 化用 | 化用名言、诗句、电影台词、鸡汤或经典书名，只改一两个词，嵌进新语境 | 即使没有上帝，也要造出一个来（伏尔泰）/ 赤子孤独了，会创造一个世界（沈从文）/ 去投资游戏吧，就像从没受过伤一样 / 王华东正传 / Cursor没有做错任何事 |
| 反差口语 | 口语、自嘲，带一点冒犯 | 去他*的「世界模型」/ 我去被投公司了，拜拜 / Kimi K3 据说很强，但预告片我们是真没看懂 |
| 限定词惊叹 | 用「可能是 / 怎么会有 / 比 X 更」加一个夸张判断 | 可能是世界上最小的VC / 怎么会有这么离奇的AI4S创业者 / 比 Amen Ring 更神的是它的创始人 |
| 档案体 | 对象加上「始末 / 往事 / 故事 / 故事展」，最多再加一个情绪词 | 阿里投资Kimi始末 / SHEIN融资往事 / 忘不了的 Kimi C轮融资 |
| 人名＋冒号＋信条 | 冒号后面写一句人生信条或一个意象，常常是对仗句 | 红杉公元：而我选择，另开一桌 / 对话郭山汕：不入江湖，但要继续赢 / 源码律动黄云刚：我的阿克苏 |
| 挪用格式 | 借综艺、考试、榜单、比喻的格式 | AI也有「创造101」/ 2026年VC晋升大赏 / AI独角兽制造机 / 六小虎的融资故事，仿佛六种人生 |

共同点：标题短，钩子是人名或公司名本身，不用「干货 / 教你 / 必看」。

## 2. 小标题（放到图文里就是每一页的页标题）

1. **意象短语、小说回目感**，4 到 10 个字，最常用。例如：绿皮火车，江湖儿女 / 五角场的眼泪 / 一边做噩梦，一边爬上青城山 / 所有的童话都有结局。
2. **「A、B 和 C」三项并列**，最后一项落在主题上。例如：国贸怪兽、警察和第二个世界 / 晨跑、10万投资和1000亿传说。
3. **两个字的词连成一串**，几页标题连起来读就是一条叙事弧。例如：剧本 → Loop → 造雨人 → 鲶鱼 → 榜样 → 结果；掀桌 → 献祭 → 造反 → 修行。
4. **人物原话**，越反差越好。例如：我一定说不出"我对AI有信仰"这种话 / 我真的没有秘密 / 真诚？Bullshit！
5. **对仗**。例如：十年苦熬，一年登仙 / 十年如一周，一周似十年 / 咸的玩笑，甜的玩笑。
6. **问句**。例如：谁的创业？/ 信任怎么来的？/ 三角会翻过来吗？
7. **交易稿按机构分节**，例如 IDG / 红杉 / 景林；或者直接用数字 1 / 2 / 3，读起来像「几个小故事」。

同一篇只用一种小标题套路，风格要统一。

## 3. 开头的动作

常用的起手方式：
- **新闻钩子，一句话冷静陈述**。例如：「2026年8月14日，Cursor 宣布自己正式成为 SpaceX 的一部分。」
- **现场特写**。例如：走进一间办公室，对方被同事叫醒，从地板上爬起来；接着写他的帽子和衣着。
- **自问自答或设问**。例如：「你能想到最小的基金能有多小？告诉你一个答案：330万美金。」
- **采访印象或统计梗**。例如：「访谈王华东，是个略微干燥的过程。」又如，一场对话里「出现了16次'哭'，但也有——43次'哈哈哈'」。
- **悖论式定调**。例如：「这是一个真实的投资人故事。但又真实到不像是一个投资人的故事。」
- **自我打断的俏皮**。例如：「Liblib ——哦不对，Evoken……」

前三到五段按顺序走完这几步：
1. 钩子，常常只有一句，单独成段；
2. 为什么现在写：上市、融资、收购、离职；
3. 先认下已知信息，再说明有新东西：「已知信息不再赘述，以下是一些未被展示过的故事」；
4. 抛出全文要回答的问题；
5. 用一句过渡进入正文：「以下是……的故事」。

## 4. 正文怎么展开

**按文体选骨架**：

| 文体 | 骨架 |
|---|---|
| 交易内幕 | 碎片化，一节讲一个小故事或一家机构；节与节之间用「说回……」「这里再展开一下」衔接；结尾放一条新消息，或者写「下回再说」 |
| 人物特稿 | 用现在的事件做钩子，倒叙成长经历（童年、父亲、低谷），把童年经历和他今天的方法论对上；结尾回扣开头的意象 |
| 访谈 | 提炼几个「小片段」，每段一个受访者原话做小标题；提问者有存在感，会追问、会吐槽 |
| 行业评论 | 现象 → 机制 → 后果 → 质疑；结论句加粗；可以分点写「一是……二是……三是……」 |
| 清单盘点 | 先写方法论，再写「以下排名不分先后」；每条一行俏皮标题，加一两句介绍，用「据说 / 号称」保持距离 |

**所有文体通用的手法**：
- **信源措辞**：「据……了解」「一位接近交易的人说」「有投资人评价」「江湖盛传」「有个不可考的传说是」。主动标明局限，比如「（大意，原话可能略有出入）」「这是他对自身经历的判断，不必然是事实」。同一件事可以并列不同立场的说法。
- **细节**：只选三类。一是精确数字，比如「2019年全年收入1182.82万元」；二是物件和动作，比如机器狗放进20寸行李箱、坐十几个小时卧铺进京；三是私下原话，比如「方便带个狗子过去吗？」。
- **短评**：不写成大段议论。事实写完，跟一句短评，单独成段收住这一节。例如：「难的是中间的钱。」「所有馈赠，都是被标好价的。」「这有点难评。」「缺木，然后加入了红杉。」
- **悬念句**也单独成段。例如：「但问题是，谁会出那8亿美元？」「直到 Manus 出现。」
- **历史类比**。例如：徐新当年给京东 1000 万美元，现在又劝 Kimi 多融钱。
- **节奏**：短段为主，长句和单句交替，多用破折号转场。

## 5. 结尾

- **人物的一句话**，最常见。例如：「人，应该去变化更大的地方。」「我不是真的想成功，我只是想更自由地失败。」
- **回扣开头，形成闭环**。例如：结尾时，当年被塞进行李箱的那只狗，和今天的明星机器人「是同一个型号」。
- **反问或冷幽默**。例如：「像极了VC，不是吗？」「好难过，这不是我想要的结果。」
- **抛出新消息或预告续篇**。例如：「据了解，它最新一轮融资正在进行中。」「下回再说。」

## 6. 语言质感

- **人称**：作者以「我」出场，会亲自试用产品，也会被受访者反问；团队用「我们」。
- **中英混杂但不装**：投资黑话直接用英文，比如 pass、bet、conviction、check size、outlier、vintage、fomo，英文两边留空格；第一次出现时括注中文，比如「hand-waving（挥手式论证）」。
- **幽默偏冷**：多是一句话的反转，或者挪用正经格式开玩笑；网络梗点到为止，比如「难评」「红温」「i人」「牛马」「整活」。
- **文学性**：常用沈从文、路遥、《天下无贼》、王尔德、禅宗、港乐做引子；比喻多来自牌桌、江湖、游戏、证明题。
- **温度**：对人温暖体恤，写孤独、眼泪、父亲；对现象克制地质疑，不吹捧，也不骂街。
- **价值观**：建设性，不搞破坏；关注人，不信社会达尔文；讲平衡，不选边站队。偏爱非共识、理想主义、「野心大 ego 小」的人，警惕 FOMO 和泡沫。

## 用在小红书图文时的边界（必须遵守）

1. **只学文风，不冒充**：不自称「elsewhere」，不用它的栏目名（elselier、début），不写「据「elsewhere」了解」。叙述者是账号本人，用「我」。
2. **信源不能编**：「一位接近交易的人说」这类措辞，只有原文里确实有这个信源时才能用，而且要说明是转述原文，比如「据原文作者的采访」「文中一位投资人说」。原文没有的细节、数字、原话，一律不写。
3. **用自己的话重写**：每份产物里直接引用原文的句子不超过两句。
4. **化用必须有真实出处**：只化用大家熟知的名句、书名、台词，不要编一句假名言。
5. **平台规则优先**：封面、标题、正文第一屏以中文为主，术语最多一个，且要附上人话解释；内页每页的英文黑话不超过两个，第一次出现时括注中文。卡片和文案里都不放链接。
