# 拆解：同一个素材，他们为什么比我们的 Jack Clark 稿抓人（2026-10-20）

对照的是我们的 `发布/2026-10-21_jack-clark-imf/`（10-19 版）。同一场讲座，两篇的骨架完全不同。

## 一、骨架对比

| | 他们 | 我们 |
|---|---|---|
| 一句话主线 | 你信不信奇点无所谓，Anthropic 已经按这个前提在调钱和岗位了 → 你的手艺会贬值 | AI 把专家的物理题答案改对了 → 人要留住判断 |
| 开头 | 判断 + 分量：「今年最容易被低估的信号」，第二段是原话「奇点已经开始了」 | 场景：50 道物理题，AI 说专家错了 |
| 场合（IMF） | 当成意义讲：AI 从极客话题变成央行和财长要管的宏观、国安议题 | 当成冷知识讲：讲座办了六十多年，头一回请做 AI 的人 |
| 奇点 | 先拆误解（不是机器有了意识），再用大白话讲：进步开始自己加速，人原来的预测和组织架构全失效 | 只给了一句定义，用户读完仍不懂 |
| 证据 | 不讲跑分，把公司的动作串起来：初级招聘 27%→9%、（股权基金）、向央行预警，结论是「不是嘴炮，是真金白银在对冲」 | 讲跑分：物理题 49/50、人类最后的考试 8%→67.7%、数学题 2%→94% |
| 跟读者的关系 | 「争论奇点存不存在没意义，你的熟练手艺贬值得太快」 | 「你每天交给 AI 的周报也是同一个结构」，偏弱 |
| 结尾 | 问读者「普通人该守住什么」+ 自己的答案：快速定方向、敢拍板、为结果负责 | 以前 / 现在 + 两类读者各一句 |

## 二、他们好在哪（值得学的四样）

1. **把「信不信」从读者手里拿走**：「你可以不信奇点，但他们已经按这个前提在花钱」。读者不需要懂奇点，也不需要同意，只要看到有人在用真金白银下注。这条直接解决了用户说的「事不关己」。
2. **用动作当证据，不用跑分当证据**。跑分只有技术圈的人有感觉；「新人只招 9%」每个打工人都有感觉。这个数我们自己 10-18 的就业报告稿刚用过，可以回指。
3. **场合讲成意义**。央行行长和财长坐在台下听 AI 公司讲课，这件事本身就说明 AI 已经是经济问题。我们写了场合，但没说它意味着什么。
4. **概念先拆误解再讲人话**。「很多人以为奇点是机器有了意识，其实……」。比我们直接下定义好懂得多。

另外，它的结尾答案（敢拍板、为结果负责）就是我们的长期立场 A，说明这个立场在别人稿里也是落点，我们可以说得更早、更具体。

## 三、不学的（跟账号规则冲突或站不住）

- 「最耐人寻味」「最容易被低估」：极限词，账号内容边界不用「最」。
- 「冷酷得吓人」「飞轮」「焊死在身上的底层护城河」「真金白银」：热词和套话，终稿重写里明确禁止堆热词。
- 「不是……而是……」：结尾那句是对仗，我们 10-06 起不写。
- 「拿出公司股权去设立基金应对未来的失业冲击」：我们的素材里没有，没核实过不能用。
- 「博主在推文里补的那句解读」：转述的是另一个人的推文，我们没有原推，不能照搬那句话当引语。
- 整篇几乎没有具体场景（物理题那种故事），全靠判断撑，读多了会像评论员。我们的物理题故事是他们没有的，要留着当证据，不当主线。

## 四、对这篇稿的改法（待用户定）

- 主线换成他们那条：信不信奇点不重要，做 AI 的公司已经按这个前提在调岗位，你的活会被重新定价。
- 开头第一句写判断加分量（不用「最」），第二句是 Jack 在台上的原话，第三句是场合的意义。
- 奇点用「先拆误解再讲人话」的写法，两三句讲清。
- 证据顺序：先公司的动作（初级占比 27%→9%，回指 10-18 就业报告稿），再物理题故事（压缩成一段，作为他们为什么敢这么信）。
- 结尾仍落在立场 A：守住定方向、拍板、对结果负责，配上经历库 #20 那条「以前 / 现在」。
- 标题跟着主线走，例：「新人只招9%，Anthropic在为什么下注」这类「数字 + 读者处境」。
