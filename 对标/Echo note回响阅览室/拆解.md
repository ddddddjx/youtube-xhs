四篇收藏都 ≥ 赞，是「存下来回头看」的稿。

## 一、每篇都是同一个骨架

1. **第一句：花了多久 + 我 + 听完了。** 「花了三个晚上，我把 Acquired 这期星巴克特辑听完了。」「熬了两个晚上看完 Nathan Barry 对 Chris Do 的这期深聊。」——代价换真诚，一句话交代「我是认真看完的人」。
2. **第二段：这个人是谁 + 一个反常识数字。** 星巴克「账上还常年躺着十几亿美元没被花掉的礼品卡余额」；Housel「书卖了数百万册、译成 50 多种语言」。
3. **第三段：一句加粗的「我」的改观。** 「三个多小时听下来，最让我改观的一件事是：**星巴克从来就不是一家咖啡公司，它做的是一门场景生意。**」「**这是我听过最不像『个人品牌课』的一期个人品牌课**」。全篇的论点在首页就亮出来，而且是以「我被改变了」的口吻。
4. **第四段：点名读者 + 承诺。** 「**如果你正在做内容、做个人品牌，发了很久却总觉得『没人记住我』，这篇会告诉你：问题可能不在你怎么发，而在你还没想清楚自己是谁。**」
5. **正文：4 到 6 个小标题，每个小标题是一个反常识判断**（「星巴克最早不卖咖啡，只卖咖啡豆」「把它做垮的不是对手，是那台让你不用排队的手机」「人买的不是功能，是身份」）。下面一个具体场景（米兰吧台、芝加哥早上八点地铁下车、加油站清洁工），场景后面跟一句**加粗**的判断。
6. **结尾：「我改了一个看法」+ 分人群带走。** 「以前我以为星巴克的成功是品牌和规模的成功，现在觉得它更像一场场景的胜利」；「如果你是创业者，带走扩张纪律；如果你已经在管一家公司，记住那句自我拆台的话」。

## 二、为什么像有个人观点（用户要的东西）

用户觉得我们的稿「像转述、没有个人 IP」，这个号的素材 100% 是别人的，却不显得是搬运。原因不是它有个人经历（它几乎没有），而是三处**编辑的声音**：

- **「我被改变了」的框**：首页「最让我改观的一件事」+ 结尾「我改了一个看法：以前……现在……」。读者读到的是一个人的认知变化，不是一份摘要。我们的 retell 稿一直缺这个框，结尾那段「我」常常是另起一个话题。
- **它替读者做了取舍和排序**：「这是全期最诚实的部分」「关于存钱，Housel 的说法是整期里最值钱的一句」「最后一条最实操」。打分对象是素材里的段落，不是给文章整体打分，读者感到「这个人听过、挑过」。
- **每节的加粗句是它自己的话**：原话用「他说 / 她的原话是」引出，加粗句（「产品可以复制，一家店的气质不能」「便利做到极致，体验就变成了取餐口」）是编者的提炼，读者分得清哪句是谁的。

## 三、标题和首图

- 小红书标题全是**荐读 + 情绪 / 读者痛点**，没有数字、没有人名：「想做品牌的人，都给我去看这篇！」「很少见到这么真诚的分享」「真心建议：存不下钱的都去听这期播客」。点赞最高的是带命令语气、点名一群人的那条。
- 首页大字是另一句：**「主题：反常识判断」**（「个人品牌：最该做的不是包装，而是搞清你是谁」）。标题负责情绪，大字负责信息，两句分工。我们这篇刚把标题改成「强烈推荐看看Anthropic就业报告。」、大字保留「Anthropic技术岗，新人只招9%了」，正好是同一种分工。
- 首图一律是**播客现场的人脸截图**，大字在图上方。

## 四、和我们现有规则的冲突（不照抄，待用户定）

| 它做的 | 我们的规则 | 看法 |
|---|---|---|
| 每节结尾一句加粗对仗金句（「产品可以复制，一家店的气质不能」「功能会让人比价，身份会让人不计价」） | 6.5 对仗金句：编号句 ✗、全篇 >2 处 ⚠ | 它的金句前面都有一个具体场景，是「场景 → 起名」，不是抽象接抽象。可以考虑：前一段是具体场景时，节尾一句加粗判断放行 |
| 「花了三个晚上听完」 | 10 反面清单「后台叙述」禁「读到第三遍」 | 它只在第一句用一次、讲的是投入不是过程，跟我们禁的「一条条对」不同 |
| 「这是全期最诚实的部分」「整期里最值钱的一句」 | 「我」是听众不是评委、不给文章打分 | 它打分的对象是素材里的某一段，帮读者排序，不是表态「我同意」 |
| 加粗 | render_meme 不支持行内加粗 | 要学就得改 render_meme（`**…**` 渲成 Semibold） |
| 末页卖订阅、「可在阅览室阅读全文」 | 不引流站外、暂不放售卖 | 不学 |
| 标题无可搜词 | 10-18 起可搜词前 6 字 | 它的标题情绪强、搜索弱；我们可以「标题情绪 + 大字带可搜词」两句分工 |

## 五、建议学的（用户点头再改 skill）

1. **「改观」框**：retell / 观察稿首页第三段写「最让我改观的一件事是：……」，结尾写「以前我以为……，现在觉得……」。这是把 stance 放进读者看得见的位置，比现在结尾一段「我」更像个人观点。改观的内容要来自写稿前先问的回答，不替用户编。
2. **小标题 = 反常识判断 + 节尾一句加粗提炼**：配套给 render_meme 加 `**加粗**`；meme_check 对「前一段是具体场景」的节尾加粗句不报对仗。
3. **首页第四段点名读者 + 承诺**：「如果你正在……，这篇能给你……」。我们现在 `reader:` 只要求某段主语是「你」，没要求首页就点名。
4. **结尾分人群带走**：两类读者各一句（正好对上我们两群读者：AI 技术类 / 个人成长类）。
5. **标题情绪荐读、首页大字放可搜词和反常识判断**，两句分工。

**10-18 晚用户定**：1、3、4 写进 skills（writing_guide 6.10）；第 5 条改成「标题 = 情绪 + 人名 / 模型名 / 信源」，不写只有情绪的；第 2 条加粗金句不学。
