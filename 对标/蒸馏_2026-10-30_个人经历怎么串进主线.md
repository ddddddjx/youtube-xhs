# 个人经历怎么串进主线（2026-10-30）

起因：用户看 Amodei 访谈稿初稿，「三年前结合 GPT 的那个故事，感觉非常独立于主线」。初稿的结构是「访谈讲完 → 听到这里，我想起三年前 → 判断」，「我」是插在中间的一段回忆，删掉它文章照样成立。

读了 6 篇：MemeInformation《我表妹要校招了》《电脑忘在公司，豆包替我改完了PPT》《我和朱啸虎对办公Agent的判断是一致的》，小盖《飞书应届生》《Personal Agent》《李录》。

## 他们怎么做的

| 稿 | 「我」是什么 | 出现几次、每次干什么 |
|---|---|---|
| MemeInformation 表妹校招 | **全文要回答的问题**：学弟拿着大厂和创业公司两个 offer 来问我 | 开头学弟提问 → 中段表妹也来问、我去帮她查阿里星 → 结尾我催她去线下活动。三次，问题 → 研究 → 行动，一步比一步往前 |
| MemeInformation 豆包 PPT | **检验台**：公司团建报名表，20 个人的饮食和交通 | 产品发布只占第一句，后面整篇是我拿自己的真任务去试，素材变成了我的实验 |
| MemeInformation 朱啸虎 | **先有的判断**：和做企业落地的朋友聊天，「我一直觉得办公 Agent 的壁垒是上下文」 | 朋友的话 → 朱啸虎采访当证据 →「这一点我和朱啸虎判断基本一致」→ 往前推一步。素材是来印证我的，不是我去附和素材 |
| 小盖 飞书应届生 | **每个论点的例子**：参加了大赛；十多年前自己校招看学校证书；亲戚家孩子问要不要考计算机二级 | 三件事分别塞进三个编号点里，各自证明那一点，不单独成段 |
| 小盖 Personal Agent | **每个抽象概念的落地画面**：上午十点拜访客户、约朋友见面来回对时间、刚刚在折腾海底捞订餐 | 概念讲一句，马上接一件自己的日程，读者靠这件事理解概念 |
| 小盖 李录 | 只有一个框：朋友推荐、跟硅谷那套不一样、「值得商榷」 | 「我」最轻的一篇，也是这几篇里互动最低的（49 赞） |

## 抽出来的规律

1. **「我」的事是全文的问题或检验台，不是插在中间的回忆。** 判断方法：把「我」那段删掉，文章还成不成立。成立，就是插进去的。表妹那篇删掉表妹就没有文章了；我们的初稿删掉誓词那段，访谈复述照样完整。
2. **「我」的事跟素材里最关键的那个机制对上。** 豆包那篇对的是「远程派活」，朱啸虎那篇对的是「上下文」。素材里讲什么，「我」的事就恰好是这件事在自己身上的样子，不是相关话题下的另一件事。
3. **出现两三次，每次推进一步，不重复同一件事。** 提问 → 查证 → 行动；判断 → 印证 → 往前推。同一个回忆讲两遍，读者会觉得在凑。
4. **衔接靠「同一件事」，不靠「我想起」。** 他们没有一篇用「听到这里，我想起……」「看到这里，我想到了自己……」。表妹是因为同一个问题出现，朱啸虎是因为同一个判断出现，Personal Agent 是因为同一个概念需要一个例子。

## 对 Amodei 稿意味着什么

用户的事是「三年前就看见了，但没有行动」。素材里最关键的机制是「一成人看见，九成人耸肩」。初稿只把用户放进了那一成，就停了。

可是素材里还有一层没用上：Dario 看见之后做了什么。他力主把规模继续做上去，后来和妹妹、另外五位联合创始人一起离开 OpenAI 创办了 Anthropic。**一成里还要再分两种：看见了去做的，看见了观望的。** 用户属于后一种，这正是他的代价。这样「我」的事就成了全文的问题（看见之后呢？），Dario 是对照，朋友转行是另一个对照，结尾的判断（拉开距离的是看见之后那几年）是答案。
