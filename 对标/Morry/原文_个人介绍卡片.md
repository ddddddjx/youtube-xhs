# 搭建个人视觉体系系列｜第4篇：个人介绍卡片

作者：Morry.AI (@Morry4AI)
来源：https://x.com/Morry4AI/status/2109525318017114220
发布时间：2026-10-12

---

很多用户第一次认识你，并不是先进入你的主页，而是先刷到了你的一篇文章。
如果内容足够好，他可能会一直读到最后。
这时候，在文章底部放一张「个人介绍卡片」，其实是一个非常自然的自我介绍机会：
告诉他你是谁、你长期分享什么，以及去哪里继续找到你。
所以「个人介绍卡片」真正解决的是：
内容 → 人
用户最开始可能只是因为：
“这篇 AI 教程不错。”
才认识你。
但是你真正希望发生的是：
“原来这个人一直在做 AI 教程。”
“他的其他内容可能也值得看。”
“我可以关注他。”
如果一篇内容让用户认识了你的观点，那么文章最后的个人介绍卡片，就是让用户进一步认识你这个人。
它很像一篇内容的「固定片尾」。
可以放在：
X Article / 公众号 / Newsletter / 博客文章底部
也可以用在：
小红书最后一页 / PDF / 电子书 / 报告 / PPT / 课程资料 / 个人网站
尤其是 PDF、图片这类很容易被二次转发的内容。
即使内容离开了原来的社交平台，一张固定的个人介绍卡片，也能继续告诉别人：
这是谁做的。
⸻
这是「搭建个人视觉体系」系列的第四篇。
 
前面三篇，我们已经完成了：
头像 → Banner → 个人配图规则

Banner 篇教程入口：
 
配图篇教程入口：
 
所以这一篇，我们不重新设计一套新的视觉风格。
而是直接使用前面已经做好的：
头像 + Banner + 个人配图规则
把它们组合成一个新的视觉资产：
个人介绍卡片
⸻
01｜确定你的卡片上放什么
个人介绍卡片和 Banner 有点像。
它不是简历，也不是信息越多越好。
对于大部分内容创作者来说，一张卡片只需要回答三个问题：
-你是谁？
-你长期分享什么？
-用户接下来去哪里找到你？
所以对于大部分内容创作者来说，可以先准备下面这些信息。
 
 
这里重点说一下「CTA/ 联系入口」
有一个原则：
一个场景，尽量只保留一个核心 CTA。
不要同时让用户：
关注 X、关注公众号、加微信、访问网站、订阅 Newsletter、发邮件……
入口越多，注意力反而越分散。
根据使用场景增减。
比如：
① X 文章
可以放：
Follow @Morry4AI
② 公众号文章
可以放：
关注公众号：Morry + 二维码
⸻
③ 小红书最后一页
可以放：
@ Morry + 一句简单的关注引导
⸻
④ PDF / 电子书 / 行业报告
因为内容可能脱离原平台传播，可以放：
X / Website / 公众号 / QR Code
⸻
⑤ 个人网站 / Portfolio
可以放：
X / Email / Newsletter / Website
⸻
按上方提到的格式，准备好卡片需要表达的信息，我们进入下一步。
⸻
02｜上传已有视觉资产，让 AI 直接给你 3 个方案
接下来开始真正设计。
但和第一篇制作头像时不同。
做到第四篇，我们已经拥有了一套可以直接复用的视觉资产。
所以这一次：
不要重新设计，直接继承。
把前面三篇最终确定的内容重新上传 / 提供给 AI：
① 来自「头像篇」：头像或IP角色
负责确定：
人物 / IP 形象
② 来自「Banner 篇」：Banner图片
负责让 AI 理解：
品牌色 / 人物使用方式 / 整体个人视觉气质
③ 来自「配图篇」：个人配图规则
负责确定：
颜色 / 字体 / Grid / 图形 / 圆角 / 线条 / 插画 / 整体视觉语言
④ 刚刚 STEP 01 整理好的：
个人信息
把这些内容全部交给 AI，然后使用下面这段 Prompt：
 
这样 AI 会直接给你：
方案 A / 方案 B / 方案 C
三个不同方向。
从里面选择一个最接近你想要的版本，然后直接在这个版本上继续调整。
例如：
头像再小一点，其他不变。
内容关键词太抢眼，降低一级信息层级。
CTA 放到右下角，其他版式保持不变。
留白再增加一些，不要增加新的装饰元素。
保留现在的设计，只把背景调整为我的品牌绿色。
这里也有一个很重要的 AI 做图习惯：
尽量局部修改，不要每次重新生成。
如果一个版本已经有 80% 是你满意的，就告诉 AI：
修改哪里，其他部分保持不变。
这样更容易逐渐得到一个稳定的最终版本。
 
03｜确定最终版本，保存你的「个人卡片母版」
不断调整以后，选择最终满意的版本。
调整到满意以后，最后检查四件事：
第一，Avatar 对不对？
必须使用前面已经确定的人物 / IP，而不是 AI 又生成了一个“差不多”的角色。
第二，信息层级对不对？
第一眼应该优先看到：
头像 / Name / Positioning
然后才是：
Content / CTA
第三，视觉统一吗？
把：
头像 / Banner / 内容配图 / 个人介绍卡片
放在一起。
应该明显能感觉到：
它们属于同一个人、同一套视觉体系。
第四，信息是不是太多？
如果卡片里已经出现：
多个平台 + 多个二维码 + 邮箱 + 微信 + 网站 + 一堆标签
继续删。
个人介绍卡片不是用来放下关于你的所有信息。
它只需要做到：
让刚刚看完内容的人记住你，并知道下一步去哪里。
确定最终版本以后，把它保存成：
个人介绍卡片母版。
 
⸻
以后每篇文章都可以直接复用，不需要重新设计。
换平台时，下面这几个部分可以不变：
头像 + 昵称 + Positioning + 一句话介绍
只需要根据场景调整：
尺寸 / CTA / 社交账号 / QR Code
无论做多少个版本，尽量不要随意改变：
头像 / 品牌色 / 字体 / 版式逻辑 / 图形语言 / 视觉气质
因为个人介绍卡片真正有价值的地方，就是：
重复出现。
第一次看到：
Morry + 头像 + 品牌绿色
用户可能没有太深的印象。
但第二次、第三次，又在不同内容的结尾看到同一套视觉元素，它们就会逐渐形成：
属于你的固定视觉符号。
⸻
到这里，我们已经完成了 4 块个人视觉体系
第一篇：头像
解决：
别人怎么记住你。
↓
第二篇：Banner
解决：
别人进入主页以后，怎么认识你。
↓
第三篇：个人配图规则
解决：
别人刷到你的内容以后，怎么认出你。
↓
第四篇：个人介绍卡片
解决：
别人看完你的内容以后，怎么进一步记住你、找到你。
⸻
而且你会发现：
做到这一篇，我们已经越来越少从零开始设计。
更多时候是在复用之前已经建立好的：
头像 + Banner + 个人配图规则
再根据新的使用场景进行组合。
这也是建立个人视觉体系真正的意义：
不是每做一个新东西，都重新找风格、重新写 Prompt、重新让 AI 设计。
而是随着视觉资产越来越完整，需要重新设计的东西越来越少，可以直接复用的东西越来越多。
最终，无论用户是：
看到你的头像 → 进入你的主页 → 刷到你的文章 → 读到内容最后
看到的始终都是：
同一个人，同一套视觉语言。
这才是一套真正可以长期使用的：
个人视觉体系。
⸻
这 4 块内容是内容创作者最应该优先设计使用的，之后也会补充一些其他视觉体系。
