# Morry.AI《搭建个人视觉体系系列｜第4篇：个人介绍卡片》拆解（10-13）

来源：X @Morry4AI，2026-10-12，用户 10-13 上传的 zip（md + 一份纯文字 PDF；原帖的示例图和 Prompt 截图都不在包里）。原文存同目录 `原文_个人介绍卡片.md`。只当参考，规则冻结期内不改 SKILL。

## 一、它在卖什么
不是在教「怎么做一张名片」，是在卖一个**系列**：个人视觉体系 = 头像 → Banner → 配图规则 → 个人介绍卡片（第 4 篇）。每篇解决漏斗里的一环：
| 篇 | 解决 |
|---|---|
| 头像 | 别人怎么记住你 |
| Banner | 进主页以后怎么认识你 |
| 配图规则 | 刷到内容以后怎么认出你 |
| 个人卡片 | 看完内容以后怎么记住你、找到你 |
系列本身就是关注理由：看了第 4 篇的人会回去找前 3 篇，也会等第 5 篇。

## 二、结构（教程体，标准三步）
1. **为什么**（约 25%）：先讲问题不讲方法。「用户先刷到文章，不是先进主页」→ 卡片解决的是「内容 → 人」。用三句用户内心独白把转化讲具体：「这篇 AI 教程不错」→「原来这个人一直在做 AI 教程」→「我可以关注他」。再列使用场景（X Article、公众号、小红书最后一页、PDF、PPT……），点出 PDF / 图片会脱离平台被转发，卡片替你署名。
2. **回指系列**：「前面三篇我们已经完成了……所以这一篇不重新设计，直接继承。」
3. **三步方法**，每步都是一个可执行动作：
   - 01 确定放什么：只回答三问（你是谁 / 长期分享什么 / 去哪找你）；一个场景只留一个 CTA；按 5 个场景给 CTA 写法。
   - 02 上传已有资产让 AI 出 A/B/C 三案：头像 + Banner + 配图规则 + 个人信息 + Prompt；之后只做局部修改（「头像再小一点，其他不变」），给了 5 句可抄的修改指令。
   - 03 定稿存母版：四项检查（Avatar 对不对 / 信息层级 / 视觉统一 / 信息是否太多），换平台只改尺寸、CTA、二维码，其余不动。
4. **收尾**：画出 4 篇的漏斗总图，再升一层意义：「视觉资产越完整，需要重新设计的越少」，最后预告「之后也会补充其他视觉体系」。

## 三、写法上的招
- **一行一句、箭头和斜杠代替长句**：「头像 → Banner → 个人配图规则」「X / Website / 公众号 / QR Code」。信息密度高，适合 X Article 和截图传播。
- **用户独白引号**把抽象的「转化」变成三个心理阶段。
- **原则 + 反例**：「不要同时让用户关注 X、关注公众号、加微信……入口越多，注意力越分散」。
- **可直接复制的东西**：Prompt（截图，包里没有）、5 句局部修改指令、四项检查清单。读者收藏的是这些。
- **AI 工作习惯顺手教**：「尽量局部修改，不要每次重新生成；80% 满意就说改哪里、其他不变」。这条比卡片本身更通用，是隐藏的第二个价值。
- **重复 = 资产**：「第一次看到 Morry + 头像 + 品牌绿色没印象，第二次、第三次……形成固定视觉符号」，给「为什么要固定母版」一个心理学理由。
- **它自己就是范例**：教「做个人卡片」的文章，文末自然就放着他的个人卡片，内容即证明。

## 四、为什么能起量（推断）
- 选题落在创作者自己的痛点（涨粉、被记住），受众就是会转发教程的人。
- 系列化：每篇都带前作入口，单篇流量能回流到整个系列。
- 动作极小：读完 10 分钟就能做出一张卡，完成感强。
- 和 AI 工具绑定但不炫技，重点在「复用资产」，不在模型多强。

## 五、对 Krypto说AI 能借的
1. **末页名片卡对照他的四项检查**：头像（爱因斯坦 IP）✓；层级：头像 / 名字 / 一句话，现在只有 CTA「关注我，看 AI builder 怎么把活交给 AI」，10-09 用户删了定位句，按 Morry 的三问还缺「长期分享什么」，可以待议；一个 CTA ✓；视觉统一：正文配图（结构图、对照表、引语卡）已经在用橙 #e8963a + 黄高亮，名片卡还是黄底头像 + 橙字，基本统一。
2. **把配图规则写成文件**：我们这两周做的 map / brief / quote 卡已经形成「白底、橙色强调、黄色高亮、圆角浅灰卡片、黑体」的语言，可以整理成一份「Krypto 配图规则」，以后每张图直接继承，不用每篇重新排。
3. **系列化选题**：「AI builder 怎么把活交给 AI」可以拆成固定系列（如：给 AI 写设计规范 / 写派活 brief / 配定时 agent……），每篇回指前作，比单篇解读更容易转化关注。Developing Taste 稿的「说得清的品味才能交给 AI」就可以是第 1 篇。
4. **「局部修改，其他不变」这句指令**可以进我们自己的提示词领取物。
5. **PDF 带署名**：我们给用户做的精读 PDF 末尾只有一行小字署名，可以加一张统一的名片卡页，PDF 被转发时也能找回账号（不放站外链接，只放小红书账号名）。
