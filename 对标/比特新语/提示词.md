# 反推提示词：比特新语「37 法则」那种效果（11-03）

可以直接贴给 `/vibe-knowledge-film`（按 11-03 的简报格式写的），换【】里的主题就能用。

```
请用"代码生成视频"的方式，为我做一支横屏知识短片，并直接交付 mp4。

主题：【37% 法则（最优停止）】。只讲透一个反常识的结论，用一个装置从头演到尾，不要做成大杂烩。
规格：【60】秒，1920×1080，30fps。没有旁白，没有底部字幕。

【画面风格】
- 底：近黑偏冷的炭蓝（#07090E 到中心 #141A26 的径向光池），很重的暗角，极淡的胶片颗粒，偶尔几粒尘埃。不要星空，不要暖棕。
- 字：每一句话就是画面顶部（纵向 15% 处）居中的一行中文粗宋体（思源宋体 Heavy，约 64px，字距 0.05em），米白 #EDEAE3 带一层柔光；
  关键词用橙金渐变（#FFD27A → #F08A3C → #E2512E）加辉光。逐字由模糊变清晰出现（每字约 0.06 秒），换句时整行淡出。一句一行，不超过 18 个字。
- 数字和大字：衬线体（Noto Serif / Didone 感），橙金渐变 + 强辉光，比如「37%」约 110px。
- 小标：等宽字体（JetBrains Mono），10–14px，大写、字距 0.3em，灰蓝 #7D8799，用于编号（No.11）、坐标刻度、计数器标题（SIMULATED LIVES）。
- 颜色只有三种含义：米白 = 叙述；冷蓝灰 = 过去 / 观察；橙金 = 规则、答案、高潮。

【装置：从头用到尾的同一个东西】
- 100 个选项 = 100 根发光细竖线，排在画面下半部的一条基线上，高度 = 这个选项的好坏（固定随机种子生成）。
- 「一个一个看」：竖线从左到右逐根长出来，当前那根最亮（白色 + 光晕），头上一行等宽小字 No.xx；看过的变暗成灰蓝。
- 「错过就不能回头」：左边看过的竖线碎成粒子飘散。
- 「什么时候该停？」：当前那根被一个细圆环圈住，其余压暗，画面停 1 秒。
- 「前 37%」：大号「37%」落下一根橙色竖线；左边罩一块深蓝半透明矩形 = 观察期；基线下两组小标签「观察期 · 只看，不选」（冷蓝）和「行动期 · 遇强则选」（金）。
- 「标尺」：观察期里最高的那根，向右拉出一条细金色水平线，左端小字「标尺」。
- 高潮：行动期里第一根超过标尺的竖线——整根变橙白，竖线带 RGB 色差，镜头光晕，三道同心细圆向外扩散，火星粒子四溅；
  旁边砸下巨大的「跳。」（金黄渐变、强辉光，句号画成空心圆），小字「No.61 · 真正的最好」。配一下重击。
- 转折：「可为什么，偏偏是 37%？」——前一幕整体压暗当背景，问句居中，37% 染金。
- 证明：「把这个游戏，重玩一百万遍。」——切到一张极简坐标图（细线轴，等宽刻度；y 轴「选中『最好那一个』的概率」0–50%，x 轴「观察期占比」0–100%），
  右上计数器 SIMULATED LIVES 从 0 滚到 1,000,000（千分位逗号）；散点像尘埃一样铺满再收拢成一条发光的金色曲线，曲线头上一个亮点在走；
  左右两端注释「看得太少 / 标尺太低」「看得太多 / 最好的已走」。数要真算：用代码模拟，曲线就是模拟结果。
- 收尾：「曲线的最高点，落在 36.8%。」——顶点亮一下，虚线落到横轴标 36.8%；最后一句落在人身上（例如「人生不是选秀，但你可以先看一会儿，再出手。」）。

【节奏】
- 0–2 秒：第一帧就有画面和那行字（比如「假设你要在 100 个选项里，挑出最好的那一个。」+ 第一根竖线已经亮着），不能黑屏。
- 每 10–15 秒一个转折或问句（什么时候该停？/ 可为什么偏偏是 37%？）。
- 镜头基本不动，留白大；每句话只改画面里的一处：长出来、碎掉、圈住、点亮、收拢。

【声音】
- 没有人声。配乐：氛围钢琴 + 轻电子，约 113 BPM，所有切点和揭晓对齐小节线；（没有配乐就用 Python 合成，同样的速度和气质）。
- 音效：每长出一根竖线一声极轻的嗒；问句处上滑音；「跳。」那一下重击 + 闪亮；计数器滚动时细碎的颗粒声；结尾配乐淡出。

【交付】
画面完全由时间 t 决定（window.draw(t)），Playwright 逐帧导出，9 帧拼图自查两轮再渲全片，ffmpeg 出 H.264 + AAC 的 mp4，附总览图和源码 zip。
```

## 套进 `/vibe-knowledge-film` 时的对应

- 外观：用 C 夜曲的底（`BG.night`，`tint` 调成炭蓝 `#141A26`、`stars: 0`），强调色换成橙金；不用底部字幕，把每句话写成 `K.hookBar` 风格的顶部大字（或者 `K.subs` 里给每句设 `y: 160`、`big: 1`）。
- 高潮四件套：`K.flash` + `K.ripple`（三道）+ 竖线手画 RGB 偏移 + 粒子；重击 `hit`。
- 计数器和曲线：照 engine.md「模拟要真算」那段，载入时把一百万次模拟算完存表，按 t 查表。
