先搞懂：这是什么？

DeepSeekHarness（简称DSH）是DeepSeek官方开源的AI编程助手框架。它就是一个本地运行的AI工作台，能让AI帮你读代码、改文件、跑命令、做项目。==其实和codex是差不多的，只是是deepseek做的。==

[图：官网首页 Everything is a plugin]

1️⃣ 前置准备：安装 Node.js

DSH 是基于 Node.js 运行的，第一步必须先装它。
版本要求
Node.js 22.19.0 以上，或者直接装 24.x 版本
版本太低会直接报错，一定要注意
Windows 安装步骤：
在 Node.js 官网
选择 Windows 的 .msi 安装包下载
双击安装包，一路点「下一步」，默认设置就行
装完后按 Win + R，输入 cmd 打开命令提示符
输入 node -v 回车，能看到版本号就说明装成功了
macOS 安装步骤：（同上，.pkg、终端 App、node -v）

[图：Node.js 下载按钮截图]

2️⃣ 一键启动

这是最简单的方法，不用下载源码，一行命令搞定。
第 1 步：打开终端 / 命令提示符
第 2 步：输入启动命令
复制下面这行命令，粘贴到终端里回车：
==npx @deepseek-ai/dsh web==
第 3 步：等待下载启动
第一次运行会自动下载 DSH 的文件，耐心等几十秒
期间如果问你是否确认安装，输入 y 回车就行
第 4 步：打开网页界面
⚠️ 注意：终端窗口不能关，一关服务就停了。想用的时候保持终端开着就行。

[图：DSH 界面]

4️⃣ 首次使用：配置 API Key
打开web后，第一步要填 API Key，不然 AI 没法工作。
第 1 步：获取 DeepSeek API Key（开放平台注册、左侧菜单 API keys、创建）
==Key 只会显示一次，赶紧复制保存好，别弄丢了！==
记得给账号充点钱，余额为 0 用不了
第 2 步：填入 DSH（Settings → Models → DeepSeek → 粘贴 → Save）

5️⃣ 正式开始用：三步上手
第 1 步：选择工作区 ==点击「Choose workspace」，选一个文件夹作为 AI 的工作目录。== 建议专门建一个空文件夹练手 / AI 只能操作这个文件夹里的文件，不会乱动你电脑上别的东西
第 2 步：选择运行模式 ==新手直接选「标准模式」就行，功能最全。== 标准 / PTC / 极简 / 创造四种各一句
第 3 步：开始对话 三句示例指令，「然后 AI 就会自动读文件、执行命令、写代码了。」
