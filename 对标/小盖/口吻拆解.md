## 他怎么写

**1. 标题是一句平常话，用句号结尾。** 「我已经蹬完了 5 亿……」「感觉 AI 可以……」「头一回这么深刻的理解了……」：第一人称的感受或者动作，没有逗号两段式，也没有反问。句号让标题读起来像在跟人说话，不像在做广告。

**2. 第一段直接讲事实和数字，不交代信源。** 「OpenCode 上最近有个叫 Space Bunny 的匿名模型特别火。截至我写这篇文章，它已经连续五天排到模型使用总榜的第一。」第二段马上接自己的动作和一个大数字：「我已经蹬完了将近 5 亿 Token」。没有「今天刷到」。

**3. 「我」是一个完整的人，不只是一个职业身份。** 喜欢银杏，每年秋天捡叶子夹在书里；是山西人，喜欢古建；给孩子做过电子画册；有一份心愿 TodoList，用语音输入法记灵感；中秋假期用手机远程遥控 Claude Code，「像钓鱼一样」。这些细节和 AI 没关系，正是它们让读者觉得屏幕那边有个人。

**4. 话里留着口语毛边。** 「不知道咯。」「反正免费」「这玩意」「咱也不说追平谁谁谁吧」「还行还行。」「可真是中国的上海啊」。比喻都来自日常生活：领鸡蛋（免费 Token）、结婚过日子（选模型）、钓鱼（远程跑 agent）、有人免费帮你干一个月的活（免费模型）。

**5. 判断说得随意，猜就直说是猜。** 「我感觉大概率还是国内模型」→ 用排除法推一遍 → 「不知道咯。」。局限也照直说：「中间肯定也会犯错」「有时候也会在一些简单的任务上过度思考」。

**6. 段落是两到四行的一小段，靠「比如 / 所以 / 毕竟 / 像」往下接。** 一段一般有两三句，读起来是一口气说下来的，几乎没有单句成段的金句，也没有刻意埋的钩子。页末断在哪里全看篇幅（RSI 那篇断在「……迭代与优化 / 的循环。」）。

**7. 结构跟着「我做了什么」走，不搭框架。** Space Bunny 那篇：它是什么 → 猜是谁家的 → 性能感受 → 第一个 Case → 第二个 Case → 我的习惯 → 第三个 Case → 整体评价。没有三点，没有方法论小结，也没有单独的「领取物」。

**8. 像在给人演示屏幕。** 「我截个图，大家看右上角的电话按钮」「大家可以仔细看一下风铃」「大家着重看下第一点」「大家可以查查」。图出现之前，先告诉读者该看图上哪里。

**9. 技术解释用「粗略地理解成」。** 「可以很粗略地理解成，大部分层只关注附近的信息，每 5 层再安排一层，从全部历史里筛选出最重要的信息。」先承认是简化，再讲人话。参数直接用「1、2、3、4」列出来。

**10. 结尾往下收。** 「整体来说，还行还行。」「我的话肯定有，因为这个 TodoList 已经攒了不少东西。」没有回扣金句，没有升华。

## 我们 10-03 那篇（Harness 稿）和他差在哪

| | 小盖 | 我们 |
|---|---|---|
| 标题 | 「我已经蹬完了 5 亿……。」一句平常话 | 「你的Harness配好了，检查器还会量错」，句式是搭出来的 |
| 第一段 | 事实 + 数字，然后是我做了什么 | 「今天我刷到 @beamnxw……」，先交代信源 |
| 我 | 爱好、家乡、孩子、假期在干什么 | 只有「读到的人」，外加一个检查脚本 |
| 段落 | 两到四行，句子之间有连接词 | 大量一句一段，「说人话就是」「最硬的一句在」这类搭桥句 |
| 比喻 | 领鸡蛋、结婚、钓鱼，生活里随手拿的 | 「一把新尺子」「长成检查器喜欢的形状」，是写出来的修辞 |

一句话：他像在跟朋友聊这几天干了什么，我们像在写一篇论证。读者说的「AI 味」，大半来自后者。

## 能学的（不违反账号规则）

1. 标题试一种平常话 + 句号的写法，和现有句式做 A/B：「头一回看懂 Agent harness 是什么。」「我的检查脚本全过了，评论区还是不买账。」
2. 第一段先讲事实和数字，信源放到第二、三段，一句话带过。
3. 一段写两三句，用比如、所以、毕竟往下接。单句成段一篇最多两三处。
4. 比喻只从日常生活里拿（买菜、带孩子、考试、上班通勤），不写「一把尺子」这类修辞。
5. 放图之前先告诉读者看哪里：「大家看这张表最后一行」。
6. 拿不准的直接说拿不准：「我猜……不知道对不对」。
7. 结尾可以往下收，一句评价就停，不一定要回扣。
8. 「我」要变成一个完整的人：需要用户补生活细节（爱好、城市、这周在干什么、家里人、手机上常开的 App），写进经历库。**这一条最关键，也是我们最缺的。**

## 不能学的

- 他的经历（5 亿 Token、山西人、孩子的电子画册、银杏）：用户没有，不借。
- 「强烈推荐」「最前沿 / 最激进」「比 90% 的导游都专业」：极限词，账号规则禁用。
- 软广痕迹（豆包「完全免费」那篇读起来像合作稿）：我们不放任何售卖信息。
- 他不放领取物；我们的提示词照样放，只是写得像随手递过去（「这段可以直接贴在派活的最后」），不单独搞成一节方法论；不写「我平时都这么用」，除非经历库里有。

# 第二批（10-03 补）：Jev 稿和 Kimi FDE 稿，活人感不靠生活细节也能成立

第一批拆出来的结论是「我要变成一个完整的人」，这条我们最缺。第二批两篇里几乎没有银杏、孩子、山西这些东西，「我」只做了三件事：上手跑了 case、看了访谈、越来越觉得。可它们照样不像 AI 写的。差别全在讲法上，下面每一条都是我们这周就能用的。

## 两篇的数据说明什么

| | Jev（知识编号稿） | Kimi FDE（站队稿） |
|---|---|---|
| 赞 / 藏 / 评 | 220 / 203 / 6 | 927 / 574 / 85 |
| 题 | 一个新模型的训练范式 | 开源 vs 闭源、Kimi vs OpenAI |
| 标题 | 平常话 + 句号，自我设定「言简意赅」 | 对比句 + 句号，「和 X 完全不一样」 |
| 第一句 | 意图：「想言简意赅再写写我对 Jev 的理解」 | 判断：「越来越觉得 OpenAI 和 Anthropic 很难垄断智能行业」 |

知识稿收藏和赞一样多，评论几乎没有；站队稿赞是四倍，评论是十四倍。**要曝光，题目得有两边可站；要收藏，正文得是能按编号查的知识。** 一篇稿最好两样都占：对比句当标题，编号知识当正文。

## 他这两篇怎么写（第一批没拆到的）

**11. 第一句直接是判断或意图，信源退到第二句之后。** Kimi 稿：「越来越觉得 OpenAI 和 Anthropic 很难垄断智能行业。」第二句才是事实加专名加数字：「前段时间，美国法律 AI 独角兽 Harvey 用 Kimi K3 训练出了自己的专有模型。」第三句推理：「因为如果一家垂类 AI 公司……那它就没必要……」。Jev 稿第一段就把反差放在段尾：「很多人觉得 Jev 就是之前我们熟悉的分类模型，其实根本不是这么回事。」首屏的顺序是：判断 → 事实 → 为什么 → 反差，没有「刷到一篇长文」。

**12. 知识稿的骨架是编号 1、2、3……9，每个编号开头那句自己就是一个判断。** 「1、如果只看训练范式，LLM 这几年真正的关键节点大概有三个。」「5、理解了这个训练逻辑，就会知道，Jev 根本不是小模型，也不是分类模型。」「7、Jev 和目前我们熟知的 LLM 模型是互补的关系。」编号下面再跟一到三小段支撑。读者可以只读九个编号句就拿走全部结论，这就是收藏的理由。这和我们黑名单里的「理由有两个。一是……二是……」不是一回事：他的编号后面跟的是完整的判断句，不是「原因一、原因二」的提纲。

**13. 先用读者已经知道的东西锚新东西。** 讲 RLCD 之前，先把预训练、RLHF、RLVR 三个已知节点各用一段讲一遍，再说「Jev 的逻辑是也许还有第三种后训练方向」。讲 Kimi 的 FDE 之前，先讲 Palantir 怎么做 FDE、OpenAI 和 Anthropic 怎么自建团队，再一句「但 Kimi 这次完全反其道而行」。新概念永远是已知清单上的「第 N+1 个」。

**14. 平行句式做对比。** 「RLHF 的北极星指标是 instruction following……RLVR 的北极星指标是 verifiable outcome……Jev 使用的训练方法叫 RLCD，它的目标是让模型输出经过校准的决策概率。」三段同一个句式，读者不用理解术语也看得出第三个和前两个不一样。「之前的软件主要是 Logic + Data，未来的软件会越来越接近 Logic + Data + Intelligence。」也是同一招。

**15. 概念的名字放在解释后面。** 先讲「输入不一定非得组织成人能读懂的 Prompt，输出也没必要再生成一段漂亮的自然语言……交给 if、switch、排序和阈值判断继续执行」，然后才是「所以 Jev 创始人一直强调一个词，Machine Native。」先讲完一串「云厂商提供算力……行业服务商负责落地……」，然后「这就是生态。」名字是收束，不是开头。读者先懂了事，再拿到词，词就记得住。

**16. 同一组例子从头用到尾。** Jev 稿的例子只有三个：邮件有多紧急、客户流失风险多高、工单该分到哪个部门。第 7 点用、第 8 点的伪代码用、第 9 点的 Choice / Noul / Score 还是用。Kimi 稿的例子也只有中软、亚信、AWS、Fireworks。例子少，读者才记得住。

**17. 换一群读者再讲一遍。** 「8、再解释一下 Jev 到底怎么用，程序员可能会更容易理解。」然后是四行伪代码：`urgency = AI.score(email)` / `if urgency > 0.8: notify_manager()`。前面七点是给看概念的人，第八点是给写代码的人，同一件事讲两遍，两群人都碰到了。我们的两群读者（AI 技术类男性、个人成长类女性）正好需要这一招：每篇一次「换个说法」。

**18. 替读者把反驳说出来，再用事实接住。** 「9、有人可能会说，这些事情用一个小模型不也能做吗？LLM 早就可以理解自然语言了。」「确实，单独做一次判断并不难。真正的挑战是，怎么把这种判断变成足够稳定、可校准、可验证的程序能力。」「大家应该都经历过，这种方式偶尔就会冒出一些很奇怪的判断。」这是让步再转折，但让步的那句带着事实（「单独做一次判断并不难」），反驳的是读者真会问的问题，不是在给自己的立场留后路。和 10-02 被骂的「他可能是对的。但今天我会……」区别就在这。

**19. 回指自己之前写过的稿子。** 「具体为什么不一样，前几篇文章我已经详细写了。」「想言简意赅再写写我对 Jev 的理解。」一个「再」字，读者就知道这个号在持续追这件事，这是关注理由，比「求关注」强。我们不预告下一期，但可以回指已经发出去的那篇。

**20. 截图上画红框，文字先说结论，图再证明。** 「但 Kimi 这次完全反其道而行。」下面是官宣截图，「Kimi 选择以开放合作的方式推进企业级落地」这一句框了红框。AWS 那张也是，「Moonshot AI 推出的 Kimi K3 已在 Amazon Bedrock」框出来。读者不用读整张图。

**21. 单句段他也用，但只有三种。** 带态度的判断：「这就是开源的优势。OpenAI 根本没办法这么玩。」说话人的动作：「我展开说下。」给刚讲完的一串事实起名：「这就是生态。」没有一句是飘着的金句（「规矩得先立在文字上。」那种）。Kimi 稿 1400 字里有七八处单句段，照样不像 AI，因为每一句都接着上文的具体内容。

**22. 毒舌对着公司和现象，用强否定词。** 「其实根本不是这么回事」「完全反其道而行」「OpenAI 根本没办法这么玩」「商业模式完全不一样」。不对着人，也不加「哈哈」。

**23. 结尾先降温再给一句温和的判断，或者停在功能说明上。** Kimi：「没有谁对谁错。我只是觉得，当模型足够强之后，也可以把开源当做一个商业优势。」Jev：最后一段讲 Score 可以拿来排序或者设阈值，讲完就停。两篇都没有回扣标题，没有升华。

**24. 字体是衬线（宋体），不是黑体。** 两篇的正文都是宋体，在信息流里一眼就是「一个人认真写的长文」，和满屏黑体大字的营销卡区分开。这是版式层面的活人感。

## 第二批能学的（写进 meme-xhs 写作指南）

1. 第一句是判断或意图，第二句是带专名和数字的事实，信源一句话带过。
2. 知识密集的素材用编号笔记体：每个编号开头一句判断，编号句连起来就是全文结论。
3. 新概念先放进读者已知的清单里当「第 N+1 个」，用平行句式对比，名字放在解释后面。
4. 一篇只用一组例子，从头用到尾。
5. 每篇一次「换一群读者再讲一遍」：程序员版给一段伪代码，非技术版给一个工作里的场景。
6. 读者会问的反驳替他问出来，让步句带事实，再接住。
7. 回指自己已经发过的稿子。
8. 证据截图画红框，图前面先说结论。
9. 单句段只用三种：带态度的判断、说话人的动作、给上文起名。
10. 标题备选三条里，素材有两边时至少一条写成对比句（「X 的路子，和 Y 完全不一样。」）。
11. 结尾先降温再一句温和判断，或者停在功能说明上。
12. 字体：宋体试过一次（10-03 Uber 稿），用户定回黑体，不再试。

## 第二批不能学的

- 「Jev 背后的公司 TypeSafe 提出来的一套新的训练方法」：他上手跑了项目，这句站得住；我们没跑过就不写「我上手做了很多 Case」。
- 「大家各美其美」「真的很厉害」：抒情句，账号语气是毒舌，不用。
- 他的 Kimi 稿读起来有合作稿的可能（官宣截图两张、「这就是生态」），我们写公司时立场只从自己工作里的体感出发，不替任何一家公司站台。

# 第三批（10-05 补）：Personal Agent 稿，对照我们的路线图稿 v2

用户 10-05 看了路线图稿 v2（已经按第二批规则改过口吻）说「文风还是很怪」，发来这篇让对照。这一轮的结论：**差距不在句式，在判断的对象、骨架的来源和场景的有无。** 第二批的规则治的是表层，这三样没动，怎么换口吻都像解读。

## 七条差距（每条都拿两边原句对照）

**25. 判断对着世界下，不对着文章下。** 小盖：「我相信未来海底捞肯定会提供一个订餐的 Agent」「App、SaaS、平台应该都会变成 Agent 背后的供应商」「谁掌握了用户的意图，谁就拿到了最上游的入口」。我们：「整篇我就认这一条」「这条我不同意」「文末那条雇佣标准我觉得比路线狠」。他押的是未来，我们打的是分。stance 的对象是文本，读者就把你当读书笔记。

**26. 每个抽象点下面都有一个带时间地点的生活场景，而且是「假设我」。** 「假设我今天上午十点要去拜访一个客户，九点半它检查路况」「我刚刚还在折腾 10 月 6 日的海底捞订餐，家人过生日」「我问他周三有没有时间，他说没空，给我两个时间，其中一个我在出差」「我要去上海出差，分别打开机票、酒店、打车」。这些不是要核实的经历，是日常推演，谁都不会去查。我们把「只写真事」做成了「不写场景」，「我」只剩一个 PM 头衔。假设式场景不违反真实性。

**27. 骨架是他自己的五个判断，不是原文的章节。** 他的五个小标题：会不会主动行动、Token 消耗再跃迁、隐私靠技术解决、Agent Network 水到渠成、下一代互联网总入口。没有一个是 Noah Shinn 或 Ben Thompson 的目录。我们的 1 到 7 就是 Month 1 到 Month 6。骨架跟着原文走，换什么口吻都是解读。

**30. 没有领取物、没有自测、没有 headline。** 他的结尾停在「谁掌握了用户的意图，谁就拿到了最上游的入口」。我们的「四个自测问题」和首页那行「2.6 万人收藏的 AI 工程师路线图」是营销号的两个标志。09-30 定的「产出占后半篇三分之一」直接带来了课程感。他这种号的关注来自「这人对行业有看法」。

**31. 名词来自行业当下，不来自原文。** Muse、Meta Secure VM、Confidential VM、OpenClaw、Instinct 三点前打电话、克里斯坦森 JTBD、字节腾讯阿里。我们是 CS50P、LlamaIndex、Chroma，全是那篇文章里的。读者判断「这人在不在行业里」靠的是他顺手提到的东西。

## 叙事：少点，多讲

他只讲 2 点，我们讲 4 点。字数差不多（他约 2300，我们约 2100），所以他每一点的篇幅是我们的两倍，差的全在**铺垫**：

1. **先把原文反对的那套叙事讲圆，再放原文那句。** 第一点「造神 IPO」他用了 7 段铺垫：OpenAI / Anthropic / xAI 都在讲 AGI → 回顾 ChatGPT 到 Agent → RSI 是什么 → ASI → 投资者为什么被吸引 → 想象空间多大 → 「投资者会觉得仍然是一笔划算的投资」，然后才是「但李录把这种叙事形容为一场造神的 IPO」。我们那篇第一点两段就把「半神」「认购神明上市的股票」放出来了。他的写法是：读者先被带进硅谷那边，觉得有道理，再被李录一句掀翻。金句延后，掀翻才有力。
2. **替读者问一句，再给原文的答案。** 「那你说，人类还愿意接受这样的东西存在吗？」→「李录的判断是，大概率不会。」我们的编号句是直接给结论。
3. **每一点自己往前推一步，只推一步。** 第二点原文讲 AI 有持续增量成本，他接的是：agent 越强，用户交给它的活越多，单次推理成本降了，总消耗也未必降。这句原文没有，是他自己的，而且只有这一句。我们那篇的「我」是贴自己的经历（每一步看一眼再放行、美国八年），不是顺着原文推论。两种都成立，他这种更像「有自己 insight」，正好是用户 10-12 对 retell 的批评。
4. **例子用自己手上的工具。** 讲增量成本，例子是 Codex 跑 agent 烧 token。名词来自他当下在用的东西，不来自原文。
5. **保留意见写成实质，不写成姿态。** 「当然，我觉得他这个判断也有值得商榷的地方。毕竟，人类能否真正阻止超级智能失控，现在谁也没有把握。但至少他提醒了我们，技术能力和社会接受程度，可能是两个完全不同的问题。」这是先让步再转折（我们 6.5 节禁），但让步句里有事实（谁也没把握），转折句里有一个新框架（能力和接受是两个问题），所以不空。禁的是「他可能是对的。但今天……」那种没内容的让步。
6. **结尾问句回扣开头的比喻。** 开头「造神的 IPO」，结尾「真的能撑起来神一样的估值吗？」。中间隔了 2000 字，一个词把两头扣上。
7. **开头是态度变化，不是推荐。** 「之前对李录了解不多，一直当耳旁风」→「今天下午看了」→「真的很受触动」。读者跟着一个人从不在意到被打动。我们的「趁放假看了」只有动作，没有变化。朋友推荐那句我们不能编，但「之前没当回事」这种低起点可以有，只要是真的。

## 他做了我们禁的（和第四批一样，列出来不照抄）

- 「先简单介绍一下李录。」「我先分享其中两个印象特别深刻的观点。」：路标句孤段，用户 10-07 点名不要「先说他是谁」。
- 「这个比喻很辛辣。」：单句评价段，前一段是加粗的编号句，不是具体场景。
- 「我们都知道」「可以回顾一下」「我们知道」开头的铺垫段，三处。我们的读者 10-02 把这类当 AI 腔。
- 「当然……毕竟……但至少……」两次，结构一样。
- 「确实，我感觉李录的这个提醒还是很重要的。」：给文章打分的句子，我们限一两句，他有三四句（很有见地、很辛辣、值得商榷、很重要）。
- 7 段铺垫一个观点，手机上是两页半没有新信息，翻页流失的风险他账号扛得住，我们扛不住。

## 一、为什么像一个聪明人在说话（7 条）

1. **第一句骂一群人，不讲产品。** 「我真的神烦那些一讨论人形机器人，就咧个嘴说这是泡沫的人。」骂的是一种现象（唱衰派），不是具体的谁。标题和首页 5 段没有一个产品名，读者先选了边（我也不觉得是泡沫 / 我就觉得是泡沫，进来吵），后面 2700 字都是给这一边递证据。「神烦」「咧个嘴」「鼠目寸光」三个带脸的词全在前两句，后面一个都没有，情绪只用在门口。
2. **一个锚用到底：GPT-3。** 首页「到了当年 GPT-3 的阶段」→ 第 4 页 GPT-3 和 Scaling Law 从头讲 → 第 11 页「零样本指令遵循，让我想起 GPT-3 当年的突破」→ 结尾「如果具身智能真的走到了自己的 GPT-3 时刻」。四次，每次多加一层意思。读者不懂具身智能没关系，GPT-3 他们知道，整篇是在用已知锚未知（我们第一批就学了，这篇是做得最彻底的一次）。
3. **跑题一段，再自己拉回来。** 「这里我想啰嗦一句。如果真对某个领域感兴趣，还是应该多和业内的人聊聊。……就像郭德纲讲过的段子……说回正题。」这段跟机器人没关系，按提纲写的稿不会有。真人说话才会跑题，跑题还暴露了他是什么样的人（跟业内的人聊、看不上为流量说话的外行）。我们的脚本把「说回正题。」判 ✗，判得对，但跑题本身是这篇最像人的地方。
4. **概念从零讲，不假设读者懂。** Scaling Law 用了 4 段：GPT-3 参数量 → 规模大了通用能力出来了 → 过去每个任务单训、GPT-3 给几个例子就行 → 「那么……这条路在机器人身上能不能走通？」。第一视角数据也是：过去要专业人员操控真机 → 现在戴带摄像头的眼镜 →「比如工人组装零件，或者普通人在家做饭、整理衣服」。讲完每个概念，读者都学到一样跟这家公司无关、明天能拿去跟人聊的东西。
5. **例子全是手边的东西。** 剪刀、螺丝刀、餐具、门把手；拧瓶盖、用剪刀、在手掌里调整物体位置；做饭、整理衣服。英文专名每千字只有 13 个，抽象的地方都换成了一样摸得到的东西。
6. **自己给自己泼冷水，四次，每次都有内容。** 「这些结果还局限在特定任务中」「采集视频和把视频变成机器人能用的训练数据，仍然是两回事」「人手的动作也得想办法映射到机器人身上」「还得看更充分的真机测试……现在远没到下定论的时候」。每一句都说出了一个具体的技术难点，不是「当然也有局限」这种姿态。这是全篇信任感最大的来源：吹的人不会自己指出难点。
7. **「我」的位置是看方法的人，不是看热闹的人。** 「最让我感兴趣的是两件事」「我觉得核心还是他们用到了第一视角的数据」「比起盯着今天的机器人还会摔跤、抓东西还会失败，我更关心研究者究竟找到了哪些有效的方法」。「我」一共 7 处，没有一处是「我用了」「我试了」（他也没法试），全是「我关注什么、我为什么关注」。这个位置同时站在唱衰派上面（你看的是摔跤，我看的是方法）和吹捧派上面（我自己说了没到下定论的时候）。

## 二、软广为什么不像软广（6 条）

1. **产品晚出场。** 产品名第一次出现在第 2 页最后一段，前面 11 段在骂人、讲周期、讲 GPT-3、跑题。读者点进来是为了「泡沫不泡沫」这个争论，不是为了一家公司。
2. **先放进一个品类，再说它哪里不一样。** 「现在做具身大模型的公司不少，硅谷有 Physical Intelligence、Generalist，国内有自变量、蚂蚁灵波等等。」先承认有对手，读者就默认作者是中立的。然后只挑两件事讲（Scaling Law、灵巧手），不说「最强」，说「最让我感兴趣」。倒数第三页还主动降一级：「这些能力单独拿出来，行业里已经有不少公司在做。」
3. **背书用别人的嘴。** 估值 40 亿、红杉 / 宁德 / 蚂蚁投资，前面挂「媒体报道」；百万小时、500 亿参数、47.7%、67.7% 前面挂「按照他们的介绍」「技术报告里」。他自己只说「相当大」「特别重要」，不给结论性形容。
4. **产品是例子，主语是行业。** 骨架是「具身智能会不会有自己的 GPT-3 时刻」，Natura-1 是这个问题的一份证据。把产品名删掉，这篇照样是一篇讲具身智能 Scaling Law 的科普；软广和科普的区别就在这里，他写的是后一种。
5. **每页一张对方的图，但图是证据，不是海报。** 泡茶、整理瓶罐、修车胎第一视角拼图、scaling 曲线、柱状图。没有 logo 大图、没有宣传语，全是技术报告里的截图，读者当成「他给我看原始材料」。
6. **唯一一句广告放最后，语气最轻。** 「话说我太喜欢 Natura-1 的技术报告了。大家有时间可以看看：」+ 链接。「话说」是聊天收尾的口头禅，「太喜欢」夸的是报告，不是产品；前面 2900 字攒下的信任，在这一句兑现。

## 三、他做了我们禁的（列出来，不照抄）

- 「说回正题。」「这里我想啰嗦一句。」路标孤段 / 路标句。
- 「最近跟不少业内的人聊天」：朋友 / 业内聊天场景，我们没有就不写。
- 外链（小红书站外链接），我们边界里写了不引流站外。
- 软广没有标注合作。我们以后接商单要按平台规则报备。
- 「当然……但至少……」结构用了 3 次（第 7、9、12 页），句式一样，读多了能看出模板。

## 四、对我们有用的（不改规则，写稿时用；改不改 SKILL 等用户定）

1. **10-14 的流畅度检查有盲区。** 这篇四项不过却像人，说明虚词 / 「你」只是一种活人感（西元那种聊天腔），小盖这种「讲课腔」靠的是跑题、概念从零讲、自己泼冷水、一个锚用到底。如果检查只奖励前一种，会把稿子都推向同一个腔调。待议：meme_check 的虚词和「你」两项对 `genre: 解读` 或讲概念的稿子降成提示，不当硬线。
2. **工具稿 / 产品稿的样板。** 我们的主线是「AI agent 怎么配」，一篇讲 Claude 或 Codex 某个新功能的稿子，可以照这个骨架：开头骂一种现象（比如「一说 agent 就说是玩具的人」）→ 用一个已知的锚（读者熟的工具或事件）→ 品类里还有谁 → 只挑一两件不一样的事，从零讲清原理 → 两三处具体的难点 → 结尾回到锚。我们比他多一样：我们能写「我这周真用它干了什么」，他这篇没有。
3. **商单样章。** CLAUDE.md 写了后续接商单，这篇就是「接了商单也不掉粉」的写法，存着当样章。
4. **泼冷水要说出具体难点。** 我们 10-13 Muse 稿 0 个顾虑；这篇 4 个，而且都是具体技术问题。以后解读稿至少留一处「这件事卡在哪」，用原文或常识里的真问题，不写「当然也有局限」。

# 第九批（10-18）：《强烈推荐大家看看 Anthropic这个就业报告。》（10/18，90 赞 83 藏 4 评）

同一份素材（Anthropic《How employment is changing at Anthropic》），我们的稿是 10-20 的《Anthropic技术岗，新人只招9%》。截图 9 张在 `截图/anthropic就业报告_1018/`。用户 10-18 让对比切入和口吻。

## 一、切入：他是「读报告的人 + 跟人打交道的人」，我们是「看数据的人 + 管 agent 的人」

| | 小盖 | 我们 |
|---|---|---|
| 首屏第一句 | 对信源下判断：「Anthropic 的技术博客，含金量真的很高……基本上都会打印出来仔细阅读」 | 用户处境：「今年我们几乎没招校招生」 |
| 首图 | 自己打印出来的中文译稿照片（物件，真人信号） | 重画的数据折线图 |
| 读者 | 第二页点名：「尤其是对正在找工作的朋友」 | `reader:` 刚工作两三年的上班族，正文里「你」两三处 |
| 素材用了多少 | 只用第一份报告，挑 4 个发现（初级岗、自主判断力、AI 工具经历、应届生），数字 6 个 | 两份报告都用，agent 工时、80% 等人、半周读产出、面试评语、75 vs 28、12% 失业率，数字十几个 |
| 骨架 | 5 个编号句，每个编号句自己是判断（「1、初级岗位的招聘，确实在明显减少。」） | 三节，没编号，节和节之间靠过渡句 |
| 价值 | 行动：在校生去做真实项目，面试拿作品讲 | 框架：干活 → 看活 → 拍板 |
| 结尾 | 「如果我是面试官，我会非常愿意和这样的应届生聊聊」 | 「AI 取代的，是不做判断的人」 |

## 二、他的「我」是一串跟人打交道的场景，我们的「我」是三句陈述

他每个编号下面都有一件带人物、带对话的事：
- 「从年初到现在，我陆续跟不同的实习生（非 985 高校）合作过……还真不如直接把事情交给 AI 完成」
- 「年前，我给客户推荐过一个候选人，结果面试没通过……客户老大叹了口气说：主要问题是他的主动性不够」，再追问一句、对方回答一段
- 「我亲戚家的孩子就是这情况，毕业一年了，现在还在家里待着」

我们的「我」：评估标准里写了一条考 agent 能力（陈述）、看板没人看漏了 bug（一件事，没有对话）、越头部越慌（观点）。用户恰好是校招面试官，比小盖「如果我是面试官」更硬，但我们只用了一句评估标准，没有一个候选人的场景。

## 三、口吻：他敢说重话、敢劝人，我们只下判断不劝

- 他有一处冒犯一群人的话：「很多二流学校的学生……还是在努力考研，以考研为荣。我真心觉得糊涂。」评论区会吵，曝光靠它（4 评不多，但这是两边可站的那句）。
- 他用了一串我们禁的：「强烈推荐」标题、「说实话」「我个人觉得」「总之」、「在我看来，主动性至少包括三个方面。首先……其次……最后」（三段排比）、信源放第一段并写出英文报告全名。这些在他那里不扣分，因为每段后面都跟着他自己的事。
- 宋体正文、打印纸照片，整体像读书笔记，跟「含金量很高、打印出来读」那句对上。

## 四、我们有、他没有的（差异化）

- agent 那一层：6 倍工时、80% 时间在等人、读产出要半周、带小孩那段比喻、给 Claude 团队写绩效评估。他完全没碰，只讲招聘。
- 第二份报告：75% vs 28% 和用户「越头部越慌」。
- 他 10/18 先发，我们 10-20 发，同一个 27%→9% 读者可能已经看过。

## 五、对这篇稿能做的（不改规则，等用户定）

1. **补一个面试场景**：问用户「今年面校招生，有没有哪一个让你印象深的，他怎么讲自己用 agent 的，你当时怎么判断的」，有对话最好。这是他三件事里我们唯一能对等拿出来、而且更硬的一件。
2. **标题避开撞车**：9% 他已经用过。候选「Anthropic员工手下的agent，干活时长是人的6倍」或用户那句「越用AI的人越慌」，把差异化的那层放到标题。
3. **结尾往行动挪半步**：用户是面试官，最后一段可以写「我面校招生想看到的是……」，前提是用户给内容，不替他编。

按 10-18 回看「输出规则只撤不加」：这批的结论是输入问题（缺人物场景），不是句式问题，不新增写作规则。

# 第十批（10-19）：两篇 10/19 的图文（用户 10-20 发来，截图在 `截图/2026-10-19_X2Real仿真评测/`（13 张）和 `截图/2026-10-19_AI创业者出海/`（只截了前 3 页））

| 篇 | 标题 | 数据（截图时） |
|---|---|---|
| A | 昨晚讨论人形机器人，简直吵得不可开交。 | 141 赞 44 藏 33 评 |
| B | 为什么我严肃建议 AI 创业者都先考虑出海。 | 493 赞 369 藏 15 评 |

两篇的素材都不是他自己的：A 是自变量机器人的 X2Real 论文，B 是一场闭门会上别人讲的。跟我们 LobsterAI 稿是同一种活（拿别人的东西写），但读起来都是「他」。

## 一、开头：一件他在场的事，不是信源

- A 第一句「昨天讨论人形机器人，简直吵得不可开交」，接着是朋友的说法（春晚跳舞整齐 → 最牛）和他自己的反驳（「但我不太认同。跳舞的动作可以提前编排……跑马拉松会更考验……」），吵完才引出「怎么横向比较机器人的真实能力」，第六段才出论文。论文是来回答一场争论的，不是开场。
- B 第一句「参加了一个 AI 硬件创业者的闭门交流会，真是长了不少见识」，第二句就是判断：信息靠 AI 很方便，但特有的经验得和真正的创业者交流。
- 对照我们：LobsterAI 稿 10-19 用户要求「直接从信源切入」，这是对的方向（不预设情绪），但小盖再往前一步：信源前面放一个他真在场的人和事。我们经历库里能当这个用的：朋友推荐 WorkBuddy 那次（#28），细节还没问。

## 二、讲概念：先让读者按直觉答错，再翻过来

- A：「假设两家公司，模型 A 仿真完成 90%，B 只完成 70%。我们很自然就会觉得，A 肯定比 B 更聪明，对吧？但真的把这两个模型放到真实机器人上，结果可能完全不同。」
- 他预设的是读者的**推理**（A 比 B 聪明），不是读者的**情绪**（你会焦虑）。这跟 10-19 用户定的「不替读者预设情绪」不冲突，可以学：把读者的直觉说出来，再用事实翻过来。
- 例子都是手边的物件：杯子摩擦力、抬高 10 厘米变 12 厘米、眼镜腿折叠、红苹果换红杯子。

## 三、一个人人熟悉的意象用到底

- A 全篇是「考试」：考试系统 → 考题设计 → 刷分 → 背几次就记住考题 → 考试系统本身也得进化 → 联想到大模型 benchmark 被刷到满分。「考试」读者天天在用，所以能撑一整篇；跟我们「夜校」相反（10-19 用户：不深入人心的概念别当意象）。
- B 的比喻是「小鱼塘和大鱼塘」，一句话、用一次。

## 四、数据给了，马上给分寸

- 「注意，这里说的是相关系数，并不意味着预测准确率达到 84%。简单理解，就是……」
- 反例单独讲：眼镜放木架，真机 70%、仿真 0%，「这说明，复杂的物理接触仍然很难准确模拟」。
- 结尾前「当然，X2Real 目前还有不少局限。比如柔性物体、液体……」，局限是具体的东西，在段内，不是孤段。

## 五、收藏为什么是 A 的 8 倍（B 369 藏）

- B 有**信息差**：Plaud 销售额 5 亿美元、ARR 1 亿；速卖通和天猫的 AI 硬件扶持计划（天使轮 + 品牌销售扶持）。读者存下来是为了以后用。「这也是我在交流会上了解到的信息差，分享给大家」直接点明。
- A 评论多（33）是因为开头那场争论读者也能站队（春晚跳舞 vs 马拉松）。
- 对我们：分工卡是我们的「信息差」，要放在正文里读者看得到的地方，不只放图下。

## 六、他做了我们禁的（列出来，不照抄）

- 加粗关键句（我们 render_meme 不支持加粗，`**` 会被去掉）。
- 「这不是锦上添花，是生死问题」对仗句、「我们很自然就会觉得……对吧？」反问。
- 「分享一些我的收获，希望对大家有帮助」这类过门句。
- 文末贴链接（我们不引流站外）。
- B 标题前 6 字没有专名（「为什么我严肃建议」），社会证明靠「严肃建议 + AI 创业者」这个人群词。

## 七、对 LobsterAI 稿能做的（等用户定）

1. 开头放一件在场的事：朋友推荐 WorkBuddy 的那次（谁、怎么说的、你当时怎么想），再接报告「七成人只用一个模型」。要用户补细节。
2. 「七成只用一个」那里学 A 的翻转：先说出读者的直觉（一个模型够强就够了吧？），再用自己五个工具翻过来。
3. 分工卡从图下正文挪一份进图上正文（现在只有一张图），或者把「为什么 / 翻过的车」那列写成段落。

## 补（10-20 用户又发来）：出海稿第 4 页 + 第三篇《看来很多人没看懂字节昨天的决定。》（10/14，1315 赞 374 藏 19 评，`截图/2026-10-14_字节Seed安全对齐/` 9 张）

出海稿第 4 页：「这事当然也不是做慈善」，给出速卖通的动机（今年前半年 AI 硬件销售额同比翻倍，宇树、Rokid 已在上面卖），「所以我理解他们的逻辑……大家一块双赢嘛」。信息差后面马上补「对方图什么」，读者才信。

字节 Seed 稿是三篇里赞最多的（1315），值得单独看：

1. **标题**：「看来很多人没看懂字节昨天的决定。」= 路人认识的名字（字节）+ 时间（昨天）+ 认知差（很多人没看懂）。没有数字，靠「我看懂了你们没看懂」拿点击。我们 10-18 的「情绪 + 名字」标题可以多一种：认知差句。
2. **第一句是他自己的情绪，不是读者的**：「我天，字节 Seed 真是带了个好头。」紧接一个带分寸的事实「我没记错的话，这是国内第一个单独建制的安全与对齐部门」。情绪归自己，跟 10-19 用户定的「不替读者预设情绪」正好对上。
3. **先立一个外部说法再修正**：X 上有人调侃中国研究员不聊 AI 安全、硅谷动不动为安全辞职，「虽然这个说法有点夸张，但确实形成了挺鲜明的对比」；再给路透数据（9 家公司 857 次发布，只有 3.6% 有公开安全评测），马上补分寸「当然，这不代表这些公司私下没有进行安全测试」。
4. **他自己的在场**：「上个月 Dreamforce……我当时就注意到」「前段时间，我也和几个朋友交流过这件事」。每一节都有一句他在场。
5. **具体的吓人例子撑「为什么重要」**：OpenAI 的 agent 突破沙箱入侵 Hugging Face、Claude 自己找漏洞执行命令、把模拟表格提交到真网站，「这些事情，研究人员都没有要求它去做」。
6. **又一次「读者直觉 → 翻过来」**：「可能很多人一听对齐这个词，会觉得不就是让模型听人类的话吗？这事有那么难吗？我跟大家讲，这事真的非常难。」
7. **结尾**：「说实话，我还挺佩服字节这次的投入和决心」+ 一个人人熟悉的类比（发展工业不能牺牲环境）收住。

对我们：三篇共同的骨架是「一件新闻 / 一份材料 → 他在场的一句 → 读者的直觉 → 用具体例子翻过来 → 他的态度」。我们 LobsterAI 稿缺的是「他在场的一句」和「读者的直觉」这两环。
