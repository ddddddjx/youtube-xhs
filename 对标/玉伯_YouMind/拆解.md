# 玉伯《乔布斯的讲故事天才》拆解：一篇 AI 写的视频转述，为什么 3.3 万浏览、收藏是赞的两倍

用户 10-15 发来，原文存 `乔布斯讲故事_原文.md`。来源：玉伯（Frank Wang，@lifesinger）10-14 发在 X 上的长文，末尾写着「本文由 YouMind 根据主人玉伯的喜好生成」，底稿是 YouTube 频道 The Art Of Storytelling 的视频《The Storytelling Genius Of Steve Jobs》。所以这篇是**AI 写的、转述一支视频**，跟我们 meme-xhs 的 retell 稿是同一种活，可以直接对照。

数据（发出约一天）：浏览 32868、赞 184、收藏 361、转发 36。**收藏是赞的 2 倍**，说明读者把它当成要回头翻的东西存，不是看完点个头。收藏从哪来，见第三节。

## 二、骨架：一条时间线 × 八个手法，两根绳拧在一起

这篇最值得学的是结构。表面是清单（八种讲故事手法），底下是一部按年份走的传记：

| 节 | 手法 | 年份和场景 | 一个摸得着的东西 | 反面 |
|---|---|---|---|---|
| 开头 | | 1978 地方电视台，开录前紧张到想吐 | 监视器里的自己 | |
| 1 | 类比 | 1980 对一小群人讲话 | 神鹫 vs 骑自行车的人 | 竞争对手夸参数 |
| 2 | 具象化 | 1981 ABC / Nightline | 12 磅，扔出窗外 | |
| 3 | 演示 | 跨年份（iPod、FaceTime、GarageBand） | John Mayer 当场弹吉他 | 霍姆斯 TED 演讲 |
| 4 | 亲近 | 一次台上回忆 | 「光是滑动那一下，你就把我拿下了」 | 扎克伯格元宇宙宣传片 |
| 5 | 框定 | 1984 Macintosh | 黑胶 → 磁带 → CD → iPod | 扎克伯格的时间线是编的 |
| 6 | 重新定义 | 1997 Macworld | 「世界上最大的教育公司是谁」 | |
| 7 | 灵魂 | 2005 斯坦福 | 书法课 | 扎克伯格缺这个 |
| 8 | 表演 | 2007 iPhone、2008 牛皮纸信封 | 「这不是三台设备，这是一台」 | 库克、录播发布会 |

几件事：
1. **清单给读者收藏的理由，时间线给读者读下去的理由。** 只按手法排，是一篇「8 个讲故事技巧」的干货帖，读到第三条就想划走；只按年份排，是一篇乔布斯小传，读完不知道带走什么。两根绳拧在一起，每一节读者都在等「下一个年份发生了什么」，同时又攒下一条能用的手法。读完正好从紧张到想吐的 1978 走到站上历史的 2007，人物有了弧线。
2. **每一节的格式一样，但读者感觉不到模板。** 小标题 = 中文手法名 +（英文）+ 冒号 + 一个例子。正文 = 年份地点 → 原话（中英双语）→ 为什么管用 → 有时接一个反面。之所以不像凑槽位，是因为每节的「摸得着的东西」都不一样，而且反面不是每节都有（8 节里 5 节有）。我们 10-06 说的「不按清单凑槽位」，这篇的做法是：格式固定，槽位可空。
3. **反面例子用到底。** 霍姆斯在第 3 节出场，扎克伯格在第 3、4、5、7 节反复出现，最后库克和新 CEO 收尾。同一个反面每次多扣一层：衬衫穿对了别的全错 → 站在豪宅里当先知 → 时间线是编的 → 缺灵魂。这就是小盖「一组例子用到底」，用在了反面上。读者记住的是「乔布斯 vs 模仿者」这个对照，八条手法挂在这个对照上就不散。
4. **文章自己在用它讲的手法。** 开头用具象化（紧张到想吐），12 磅后面补一句「约合 5.4 公斤，一个人拎得动」是给读者做具象化，结尾把苹果失去讲故事能力和创新乏力连起来是框定。没有一句点破，读者读的时候已经被这些手法讲服了。

## 三、收藏从哪来

1. **末尾「值得记住的」一张表**：八行，每行「手法（英文） + 一句话 + 一个例子」。正文 4000 多字读完，这张表是带走的东西。这就是我们说的领取物，但它不是另附的提示词，是正文的压缩版。
2. **「读完之后」三块**：原片两个时间戳（3:04 年轻乔布斯的局促、23:55 一指滑过屏幕的惊叹），视频里提到的两样，想继续看的两本书，每条后面一句为什么值得看。时间戳挑的是「要看画面才知道」的那两处，等于告诉读者原片哪两分钟值得点开。
3. **中英双语引文**：每句关键原话都附英文原句和出处。读者拿去做 PPT、发朋友圈、写演讲能直接用，这是收藏的另一个理由，也是可信度。

对我们：正文.txt 的领取物顺序（要点 → 领取物 → 标签）不变，但「要点」可以学这张表：每条一个名字 + 一句话 + 原文里的一个例子，而不是我们自己总结的抽象句。时间戳那块可以直接学，不违反「不引流站外」（不放链接，只写原片第几分钟）。

## 四、开头和结尾

**开头四段**：
- 第一段是一个**场景**，不是判断：1978 年地方电视台，「天哪，你看，我上电视了」，想吐。我们 10-14 定的「第一句判断或处境」，这里是**人物的处境**，而且是反神话的处境，读者点进来以为看封神，第一眼是一个紧张的年轻人。
- 第二段把场景变成判断：「后来被讲成神话的那个人，起点就是一间地方电视台，紧张到想吐。」
- 第三段是**新闻钩子 + 谁在讲**：乔布斯去世十五周年、库克离任、新 CEO 故事还没写；作者按时间顺序看完所有公开露面，归成八种。「结果连他自己都有点意外」是悬念，但全文没兑现（哪里意外没说），这是 AI 稿的一个漏洞。
- 第四段是**对你有什么用**：「学这些用不着为了当下一个科技大亨……手里这台手机最早只是乔布斯脑子里的一个故事。」把乔布斯拉回读者手里的一样东西。

**结尾**：停在一个对现在的判断（苹果讲故事的能力是不是随乔布斯一起没了，这和创新乏力的关系可能更深），然后自己泼冷水（乔布斯远非完人，神话大过了这个人；前文还有「作者承认可能有自己脑补的成分」）。跟 Natura 稿一样，吹的人自己说出边界，信任就上来了。

## 五、AI 痕迹（它的毛病，我们别学）

1. **「在作者看来 / 按作者的说法 / 在他看来」20 处**，密度在我们 3–6 的范围里，但用词只有四五种，读多了能听出是同一个开关。西元的「Jen说 / Mark的意思是」换着说，这篇不换。
2. **钩子不兑现**：「结果连他自己都有点意外」，后文没有意外。我们的开头三句如果埋了悬念，正文必须接住。
3. **图注是生图提示词**：「天上是移动效率排第一的神鹫，地上是骑上就能赢过它的自行车，车把上放着一台早期个人电脑。」三张图都是这种，像把 prompt 原样贴了出来。我们的图是原文截图和对照卡，不用学。
4. **偶尔的书面连接**：「魔力也正好说明他怎么对待这整场发布」「这一手道德上的重新框定很巧妙，也是那个敏感时刻非做不可的」，评委腔，我们 10-07 删过同类句子。
5. **软广位置**：最后一行「本文由 YouMind 根据主人玉伯的喜好生成」。YouMind 是玉伯自己的产品，整篇就是产品的样品，产品名只在最后出现一次。跟 Natura 稿同一个路数：产品晚出场，内容本身是证据。

## 六、能学的（不改规则，记在这里，10-21 复盘时再议）

1. **retell 稿的骨架可以是「时间线 × N 条手法」**。素材是一个人的一生 / 一系列公开露面时，按年份走，每节挂一条可带走的东西，末尾一张表收齐。比「他讲了三点」更能让人读完。
2. **一个贯穿的反面人物**，比每节各找一个反例好记。
3. **收藏型结尾**：正文.txt 的要点写成「名字 + 一句话 + 原文例子」的表；有原片就给两个时间戳，挑「要看画面才知道」的。
4. **中英双语原句**：关键原话附英文，跟每篇要一张原文证据图是同一件事，放正文里成本更低。
5. **钩子要兑现**：开头埋「意外」「反直觉」，正文要有一节专门交代。

## 七、如果拿这个题做一篇

选题过门槛：乔布斯是最「有来头的人」，两群读者都碰得到（技术男：iPhone 发布会；成长类：讲故事、表达力、斯坦福演讲）。但它不讲 AI，要接回主线得有一个 AI builder 的视角。按「不改写、不复述对标笔记」，做的话从原视频出发，不从这篇转述出发。

可能的接法（写稿前先问，用户定）：
- **扎克伯格那条线**：视频说元宇宙的时间线是编的。我们 10-13 刚发过 Zuck × Wang 播客，Meta 这回押超级智能先押了一千多亿。同一个人又讲了一条「下一步必然是 X」的时间线，这次是不是真的？可以回指已发稿。
- **AI 产品发布为什么越来越像录播**：苹果改录播、库克讲不了故事；AI 公司的发布会（演示翻车、只放 benchmark）跟乔布斯的「在台上真的跑起来」对照。
- **做 AI 产品的人怎么讲**：类比 / 具象化 / 演示，哪条你在工作里给老板或用户讲 agent 时真用过。

要问用户的：
1. 你给别人（老板、同事、朋友）讲 AI agent 能干什么时，用过哪个类比或演示，对方什么反应？（要时间、场景、结果）
2. 视频说扎克伯格的时间线是编的、乔布斯的是真的。你觉得今天 AI 圈谁在讲编出来的时间线？
3. 这篇你想让读者带走信息 / 框架 / 情绪 / 行动里的哪种？（默认：框架，八条手法那张表）
