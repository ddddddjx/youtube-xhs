## 一、这是哪一类视频

YouTube 上常见的「自我提升 edit / video essay」：**一条第一人称旁白 + 全程电影 / 动画 / 体育 / 网络 meme 片段混剪 + 逐词弹出的动态字幕 + 几处手绘图**。旁白是主体，画面不讲内容，只给情绪和比喻。

## 二、旁白（内容骨架）

只讲一个观点：**别同时修整个人生，找出让其他一切都更难的那一件事，先修它。**

| 段 | 时间 | 内容 |
|---|---|---|
| 钩子 | 0–8s | 第一句就给答案：「最简单的方法：找出让一切更难的那件事，别一次修整个人生」 |
| 共鸣 | 8–33s | 每年一月 /「winter arc」我们都列一堆要改的（赚钱、健身、睡眠、吃好…），撑几天，漏一次健身、熬一次夜、刷两小时手机就全塌 |
| 翻转 | 33–66s | 我们第一反应是骂自己懒、没自律，「但那是描述，不是解释」；有用的问题不是「我为什么这么懒」，是「我为什么一直这样」 |
| 机制 | 66–120s | 「你的生活一直在给你信息」：总累是信息、落后是信息、总食言也是信息；看起来五个问题其实是一个 → 睡眠例子 → 恶性循环例子（累→没法专注→拖延→落后→焦虑→更晚睡→更累）→ 睡眠影响精力、精力影响工作、工作影响压力、压力影响睡眠 |
| 区分 | 2:00–2:20 | 有的问题是孤立的（书读少了就多读），有的问题会蔓延到所有地方，只盯后者 |
| 行动 | 2:20–2:52 | 拿纸笔问自己两个问题：① 我一直在修、却总回来的是什么？② 如果现在只能解决一件，哪件对其他一切影响最大？例子：答应太多事、手机让你没法专注 10 分钟 |
| 优先级 | 3:00–3:30 | 「大多数人知道什么是优先级，只是想让每件事都是」；注意力有限，允许其他事暂时不完美——「先把该死的睡眠修好」→ 围绕它重建生活：让在乎的事更容易做、移掉挡路的、别等一次大爆发的动力 |
| 结尾 | 3:30–3:58 | 目标不是完美生活，「shit happens」；插一段影视原声（「我又会犯错吗？」「会的，但不是因为你是你」）；落点：理解自己的生活后，不必把每次挫折当成回到原点的证据 |

写法上值得学的：
1. **第一句就是答案**，后面 4 分钟都在解释为什么。
2. **一个比喻用到底**：「生活在给你信息」，每个例子都套这句「that's information」。
3. **先骂错对象再翻转**：描述 vs 解释，judging vs understanding。
4. **一个例子讲成闭环**：睡眠 → 精力 → 工作 → 压力 → 睡眠，屏幕上画成圈。
5. **给可以马上做的动作**：两个问题、纸笔，不给清单。
6. **口语和脏话**（fucked / damn / shit happens）当节奏点，中文版要换成本地口语，不直译。

## 三、画面怎么做的

- **剪辑节奏**：场景切换检测约 100 处 / 236 秒，平均 2.4 秒一切（快的地方 1 秒内），一句旁白配 1 到 3 个镜头，镜头内容是「情绪对位」而不是「内容图解」：说「你骂自己懒」配捂脸的人，说「你一直在补」配 Moneyball / 《黑暗骑士崛起》，说「看起来五个问题」配疲惫的脸。
- **素材来源**：电影（搏击俱乐部、点球成金、黑暗骑士崛起、香草天空、美国精神病人、爆裂鼓手、银翼杀手 2049、当幸福来敲门、心灵捕手、闪灵等）、动画（功夫熊猫、瑞克和莫蒂、疯狂原始人）、体育颁奖（C 罗、金球奖）、Kanye 颁奖礼、网络 webcam meme、新闻采访画面。**全部是别人的版权片段**。
- **字幕**：不是常规底部字幕，是**逐词 / 逐短语弹出的动态排版**：白色粗无衬线（Helvetica / Neue Haas 系），字在画面中间或贴着人物，单词一个一个出（「usually」「to」「where」「together」）；关键短语改成黄色斜体小字（「waste a couple hours scrolling」「why am I keep doing this?」），有时一行行叠出一段（红底白字的睡眠 → 精力 → 工作 → 压力链）。
- **纯色卡**：红底超大白字（「THING」「STOP」叠在人物身后）、黑底白字（「that's information.」）、米白底黑 / 红字（「so if you've identified」）——用来给关键句「停一下」。
- **手绘图**：黑底上用绿色马克笔画 1、2、3、4、5 五个框，再用蓝线连到红色「Core Problem」——全片最核心的那张图，就是「五个问题其实是一个」。还有白线勾的手握魔方、纸和笔（「2 questions」）这种极简动画。
- **调色**：大部分镜头压暗、偏冷或偏青绿，统一成一个 moody 色调，让不同来源的片段像一部片子。
- **声音**：旁白干净近讲、语速中等偏慢；底下垫氛围钢琴 / 环境乐，结尾混进一段影视原声对白当「证据」。整体响度约 −25.7 LUFS（偏轻，YouTube 原片）。

## 四、能不能拿到「一模一样的素材」做中文版

**做不了、也不建议做**，原因三条：

1. **素材全是版权影视片段**。这条视频本身是在 YouTube 合理使用的灰区里混剪，我们把同样几十段电影 / 动画 / 颁奖礼片段重新找来再发小红书，是直接搬运版权内容，平台会限流或下架，账号起号期扛不起。云端也下载不了 YouTube 视频流（10-19 已验证，403）。
2. **旁白是别人的原创稿**。逐句翻译配中文 = 搬运别人的作品，碰账号「不改写、不复述对标内容，只学结构」那条边界，也跟「博主像搬运工」的人设诊断（10-18）反着来。
3. **跟账号对不上**。这条是纯自我提升题，跟「AI builder」没有连接点，过不了爆文方法论第五节的门票（路人认识的名字 + 碰到我自己怎么办 + 跟 AI 有关）。

## 五、能做的：学它的形式，做我们自己的一条

学的东西：一句答案开头、一个比喻用到底、一张手绘「五个框连到一个核心问题」、两个问题当行动、逐词动态字幕、纯色卡给关键句停顿、统一压暗调色。

不学的：电影片段混剪（换成我们自己能用的画面）、脏话（换成中文口语）、纯自我提升题。

三种落法，待用户选：

- **A. 同题、自己的稿、自己的画面（推荐）**：主题换成跟 AI 有关的同一机制，例如「你以为要学十个 AI 工具，其实卡住你的只有一件事」，旁白用用户复刻音色（`/explainer-film` 那套 TTS），画面用代码画的动态字幕 + 手绘框图 + 纯色卡（`/vibe-knowledge-film` 引擎能出）+ 用户自己的录屏 / 生活素材；版权干净。
- **B. 纯排版版**：不用任何影视片段，整片只有黑底 / 红底 / 米白底的逐词动态字幕 + 手绘图 + 配乐（incompetech CC BY），像 kinetic typography。最快，风格最接近原片的「字」那一半。
- **C. 中文讲解原片**：拿原片做 `/explainer-film` 式解说（原片小窗 + 中文旁白讲它的观点 + 「我」的经历），出处写清。仍然带着原片里的影视片段，版权风险比 A / B 大，不推荐。

如果选 A 或 B，要用户先答：① 你自己有没有「以为有五个问题、其实是一个」的经历（AI 工作里或生活里都行）；② 横版还是竖版；③ 用不用你的复刻音色。
