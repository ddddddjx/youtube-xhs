# MemeInformation 叙事与标题手册（第二版）

来源：MemeInformation 小红书 180 篇图文笔记（2025-07 到 2026-09）。
- 78 篇（主要是 2026-05 以后）来自 711 张图的 OCR 加看图校对，原文在 `~/Downloads/MemeInformation_文字_精校版/`，逐篇拆解见 `逐篇拆解_aa.md` 到 `_ad.md`。
- 102 篇（主要是 2025-12 到 2026-04）来自 `~/Downloads/MemeInformation_文字稿.zip` 的 RapidOCR 文字稿，句末标点常缺，逐篇拆解见 `逐篇拆解_早期补充_aa.md` 到 `_ad.md`。
- 2026-09-30 起，178 篇 OCR 文字稿全文放在本目录 `文字稿/`（`<标题>_<笔记ID>.md`），不用再去 Downloads 找。写稿前读哪几篇见 `账号/范本/README.md`。
- 180 篇的标题、发布日期（从笔记 ID 的时间戳推出）、字数见 `180篇标题时间线.tsv`。

例句都是短摘，只用来说明写法，不要抄进稿子。

**没有的数据**：语料里没有点赞、收藏、点击率。早期 24 篇的截图页头带着「XX 阅读」，但那是作者截图那一刻的数字，不是最终表现，只能当旁证。所以这本手册只能说「他们常这么写」，不能说「这么写效果更好」。和我们自己复盘数据冲突的地方，以我们的数据为准（见第 13 节）。

**第一版改正的地方**：
- 第一版说「约一半标题以品牌开头」，不对。180 篇里带专名的标题约一半（92 篇），但专名放在开头的只有 22%（40 篇）。
- 第一版说「没有一篇用大背景起句」「开头三段八成有我」「几乎每篇都写一处翻车」，这些只适用于 2026-04 以后的成熟期。早期稿里格言起句、没有「我」、不写局限的都不少。
- 第一版说「全部不预告下一期」。早期有 1 篇写了「后面咱们再细聊」，并且真的发了续篇。

**一句话配方（成熟期）**：用一个「最近我……」的具体场景起笔；首页之内给反差；先把问题讲透，主角第 2 到 3 页出场；中段拆成三点，每点「例子 → 这说明什么 → 放到你的工作里」；主动写一处翻车或局限；每页最后一句逼人翻页；结尾用一句对仗判断，或者回扣标题原词。

## 1. 这个号是怎么长成现在这样的

这是第二版最重要的新增内容。第一版只看到了成熟期，以为这套配方是它一开始就有的。180 篇按时间排开，能看出四个阶段：

| 阶段 | 篇数 | 叙述者 | 标题长什么样 | 代表标题 |
|---|---|---|---|---|
| 荐读转述期（2025-12 到 2026-01） | 34 | 「刷到、看完的人」，转述论文、访谈、外媒、财报 | 荐读体、情绪日记句、网梗 | 强烈推荐你去看MIT发表的这篇论文 / 看到这个新闻，我心里突然咯噔一下 / 阿里千问这是拿了爽文主角的剧本 |
| 情绪口语期（2026-02 到 03） | 46 | 「我」开始有场景：凌晨的备忘录、咖啡馆里的朋友、群聊 | 情绪口语、比喻典故最多 | 装OpenClaw装得我心态崩了 / 可灵3.0像武当太极，Seedance2.0像华山快剑 / 马之千里者，骐骥也 |
| 大判断期（2026-04） | 25 | 行业评论者，有自己的判断框架 | 泛化主体 + 强动词，问句 | 一个API，掀翻整个视频行业 / 学术圈，快被AI埋了 / AI把短剧门槛打穿后，谁最先睡不着？ |
| 成熟实测期（2026-05 到 09） | 75 | 有具体身份的「我」：做产品的人、小股东、参会者 | 冷静的「X，Y」判断体，第一人称实测，省略号收尾 | AI短剧，故事比画面更重要 / 电脑忘在公司，豆包替我改完了PPT / MiniMax，开始像一门好生意了 |

标题特征按阶段统计（各阶段里带这个特征的标题占比）：

| 特征 | 荐读期 | 情绪期 | 判断期 | 成熟期 |
|---|---|---|---|---|
| 逗号两段式 | 44% | 71% | 64% | 64% |
| 情绪口语（炸裂、笑鼠、懵、崩、凉凉、救命） | 11% | 21% | 16% | 4% |
| 比喻、典故 | 5% | 13% | 8% | 4% |
| 大判断动词（掀翻、踹翻、洗牌、变天、埋了、打穿） | 0% | 8% | 32% | 2% |
| 问号 | 20% | 0% | 28% | 14% |
| 省略号 | 0% | 0% | 0% | 10% |
| 荐读体（推荐你去看） | 8% | 4% | 8% | 0% |

四个变化：
1. **从「我推荐你看 X」到「我遇到了 X」。** 叙述者从转述别人的人，变成先讲自己一件小事的人。「时间词 + 我 + 具体场景」起笔，是 2026 年 2 到 3 月才成为常态的。
2. **标题从情绪走向克制。** 情绪口语在 2 到 3 月最多，4 月换成了大判断动词，5 月以后两样都收了，变成冷静的逗号判断句。
3. **结构越来越工整。** 早期是快讯、日记体，很多不到 1000 字；4 月开始出现排除法、镜像编号、框架复核这类有设计的骨架；成熟期稳定在 9 页、1700 字左右。
4. **可信度手法后期才稳定。** 主动写局限、让步降温，早期只有三分之一的稿子有，成熟期成了标配。

早期截图里的阅读数大多只有 13 到 55。只有 4 篇过百：前员工写智谱的散文（132）、写印奇的人物特写（133）、阿里千问春节（418）、高德（600）。前两篇都是「有人」的稿子，但只有两个数据点，不能下结论。**能确定的只有一点：这个号也是从几十阅读起步的。**

## 2. 账号画像（成熟期 78 篇）

| 指标 | 数值 |
|---|---|
| 每篇页数 | 中位 9 页（3 到 18 页） |
| 每篇字数 | 中位约 1700 字；早期 102 篇中位约 1550 字 |
| 段落长度 | 中位 33 字；20 字以内的短段占 21%；超过 80 字的长段只占 5% |
| 首句带时间词（最近 / 昨天 / 这两天 / 刚刷到） | 约 6 到 7 成，全期都稳定 |
| 开头三段出现「我」 | 成熟期约 8 成，早期约 6 成 |
| 看得出商业合作痕迹 | 过半；早期一个月里千问就写了 5 篇 |

版式：手机备忘录截图式长文，白底黑字，一页 5 到 10 个短段，截图、表格直接嵌进正文。2026 年 2 到 3 月有一段时间每页页眉印着日期戳（「2026.03.14」）。全程没有封面大字卡，第一页就是正文。

**价值观主线**：「Demo 很聪明，一进真实业务就……」。稳定、听话、可交付、少返工，比惊艳更值钱。180 篇里有 30 多篇在讲这个母题，全期没变，是全号的人设。

## 3. 叙述者

成熟期几乎每篇都有「我」，而且「我」带着具体身份：

| 身份 | 例子 | 作用 |
|---|---|---|
| 前员工 + 持股人 | 「我错过了老东家智谱AI的股票」；早期那篇写智谱的散文，副题是「深圳看不到星星」 | 给财报解读一条情绪线 |
| 小股东 | 「作为MiniMax的小股东，听完这次财报电话会」 | 利益相关，反而显得坦诚 |
| 做产品的人、带团队的人、「做AI这一行快5年」 | 「最近我在做一个 ToB Agent 产品」 | 实测有真实任务 |
| 参会、逛展的人 | 「逛完 WAIC，手机相册塞满了 PPT」 | 现场感 |
| 普通用户、打工人 | 「电脑忘在公司」「凌晨1:47的备忘录」 | 读者代入最快 |
| 职场前辈 | 「我表妹要校招了」 | 给建议有立场 |
| 刷到、看完的人（早期主力） | 「刷到陶哲轩的访谈」「看完老黄的演讲」 | 荐读和转述，门槛最低，也最薄 |

**身份越具体，情绪线和可信度越强。** 身份最模糊的稿子（早期的纯转述、大会笔记、纯产品介绍）读起来最像通稿。

**朋友、群聊当消息源**：早中期约 12 篇用「医生朋友」「投资朋友」「群聊里有人说」起笔。有 2 篇写了「我当时没接话」，一个沉默动作，比直接下判断更有余味。

## 4. 标题

### 4.1 十四种句式

成熟期常用：

| 句式 | 写法 | 原号标题 |
|---|---|---|
| 逗号两段式 | 前段放场域或主体，后段放判断 | AI短剧，故事比画面更重要 / 京东，越过AI的山丘 |
| 趋势拐点 | 正在……、开始……了、变了、终于 | 打字这件事，正在拖慢每一个打工人 / 电影圈风向变了？ |
| 反常识判断 | 不是 X / 比 X 更 Y / 真正的门槛 / 其实只是 | AI视频真正的门槛：听话 / 企业需要的 AI，不是各种Claw |
| 第一人称动作 | 我让 / 我拿来 / 我先问了 / 替我 | 我让Kimi帮我埋伏下一个智谱 / 买扫地机器人前，我先问了AI买手 |
| 问句 | 为什么、真能打吗、拿什么、算谁的 | AI替你办事，出了问题算谁的？ |
| 看完体 | 看完 / 逛完 + X，+ 我的结论或动作 | 看完蚂蚁开源的两个项目，我直接点了star |
| 跨圈热梗 | 明星、MBTI、网络梗接技术内容 | AI行业出现了马嘉祺bug / 最吃香的可能是 ISTJ 型模型 |
| 栏目前缀 | 冷知识： | 冷知识：Prompt没跑完，钱先没了 |

早中期常用、成熟期少见：

| 句式 | 写法 | 原号标题 |
|---|---|---|
| **荐读体** | 强烈 / 超级 / 非常推荐你去看 + 一个权威对象；只表态，不给判断 | 强烈推荐你去看MIT发表的这篇论文 / 这个播客太通透了 / 强烈建议你们都来看看这份字节的AI编程手册 |
| 第一人称顿悟 | 我终于理解 / 我有一种直觉 / 我发现 X 才是 Y 的真正主角 | 我终于理解阿里为什么要做千问了 / 我发现ARR才是MiniMax电话会真正的主角 |
| 泛化主体 + 强动词 | 「一个API」「一个中国开源模型」「这届投资者」当主语，配掀翻、踹翻、洗牌 | 一个API，掀翻整个视频行业 / IPO逻辑，正在被中国AI公司踹翻 |
| 语气词、多问号 | 哇，/ 啊？/ 笑鼠，/ 有点子炸裂！ | 啊？？原来火山在车圈人脉这么广的吗？？？ / 笑鼠，这些AI竟然都不知道洗车要带车过去 |
| 比喻、典故、双关 | A 像 X，B 像 Y；古文双关公司名 | 可灵3.0像武当太极，Seedance2.0像华山快剑 / 马之千里者，骐骥也（双关「千里科技」） |
| 情绪日记句 | 不写对象、不写判断，只写一个情绪瞬间 | 看到这个新闻，我心里突然咯噔一下 / 今天，我看到一条新闻时有点小意外 |

还有几种零散但好用的：
- **先认错再转折**：「这波智谱确实菜了，但他们决定负责到底」。
- **替补句式**：「用不了claude cowork？阶跃直接顶上来了」「美团快手百度之后，MiniMax顶了上来」。
- **自造昵称当主语**：「阿里通云哥，突然站到台前」「这届投资者，可能正在被AI纯度带偏」。
- **括号副题做情绪钩子**：「我眼中的智谱AI（深圳看不到星星）」，副题和公司无关，把财经事件写成个人散文。
- **指示词开头**：这波、这届、这下、这就是……最可怕的地方。

标题中位 17 到 18 字，全期没变。感叹号只有 4 篇；省略号只在成熟期出现（10%）。

### 4.2 标题和正文的关系

- **标题是全文结论，结尾逐字回扣**：180 篇里至少 25 篇。
- **标题就是正文里的一句原话**，常常是第一句：至少 15 篇。写完正文，挑一句最狠的当标题。
- **标题把核心判断压成一个口语词**：「听话」「靠谱」「松弛」「含金量」「非共识」。
- **标题是诱饵，正文给第二层**：《AI大佬最近在集体焦虑什么？》表面在答「焦虑什么」，真正的判断是 Agent 成了新的信息入口。
- **反面**：至少 4 篇标题的场景在正文里没有兑现。有一篇标题写杨丽萍，正文一次没提；有一篇标题写「百万预算」，正文却说「过千万」。

### 4.3 专名放哪

- 180 篇里带专名（公司、产品、人名）的标题约一半（92 篇），**专名放在开头的只有 22%（40 篇）**。
- 标题带品牌时，品牌一般在第一段就出场；标题是判断句时，主角就延后到第 2 到 3 页。
- 商业主角经常不进标题。有的用泛化主体代替（「一个中国开源模型」），有的用「它」「他」代替（「股价跌82%，他却死活不裁员」），有的只写对手或旁人（「Meta为什么要花这么多钱买Manus？」写的其实是 Qwen）。

## 5. 开头

九种起手：

1. **个人近况、真实需求**（成熟期最多）。「最近刚好有一个活动页需求」「我这两天突然有点馋鲜肉月饼」。
2. **刷到、看到**（早期最多，约 25 篇）。「刚刷到」「刷群聊的时候」。叙述者是信息的接收者，比「我在做」被动。
3. **朋友、饭局、群聊**。「上周和一个医生朋友吃饭」。
4. **自嘲、糗事、先认旧偏见**。「我错过了……成为一个亿万富翁的机会」「我一开始也以为是蹭热度」。
5. **反差惊叹**。「谁能想到，AI视频赛道的天花板，居然被一个百人团队给刷新了」。
6. **把一个生活指令或一道题当开头**。「去接孩子，顺路买麦当劳，5点前到学校」；或者把测试题原文放在第一段，让读者先答（「你一眼看过去，可能下意识就有答案了」）。
7. **物件的三种状态**。备忘录里一条「写下 → 搁置 → 删除」，七句话讲完一次情绪反转。
8. **格言或反事实起句，不带「我」**（早期约 15 篇）。「春节最狠的套路，从来不是让你抢到红包」「三年前，如果你告诉汽车行业的人……」。
9. **给阅读地图**。「这篇我想把三条升级线讲清楚」，先告诉读者会拿到什么。

**第二步常常是反转**：「原本以为……没想到」「很多人第一反应会觉得……其实」。成熟期 78 篇里，转折词（但、却、其实、没想到、原来……）出现在前 3 段的占 44%，前 5 段 64%，首页（约前 8 段）77%。「很多人会觉得……」立靶子再反驳，在早期一组就有 14 篇。

## 6. 骨架

### 6.1 实测模板

个人真实需求 → 遇到这个产品 → 先说「我更关心的是……」立判断标准 → 任务一（任务要求 → 截图 → 评价，常先预判「这里容易翻车」）→ 任务二加码 → 小翻车一处 → 原理一句大白话 → 总判断 → 价格或免费信息 → 一句方法论收尾。

- 任务来自真实生活，不是 benchmark：团建报名表、活动页、挑扫地机。
- 提示词原文照贴，过程和前后对比全摊开。
- 标题里的场景要在正文里单独验证一次。
- 对比测试让主角赢，但承认对手某一项更好。
- **陷阱题**：专门问一个不存在的东西，看模型会不会硬答；或者用一道人人都懂、答案反直觉的常识题横评六个模型（「洗车要带车过去」）。
- **熟悉作品当测试标尺**：用《法证先锋》、金庸武侠、韩剧当风格测试的维度。

### 6.2 解读模板（公司、财报、技术博客）

普遍现象或疑问 → 旧范式或反例 → 主角登场 → 借一个现成框架拆 → 第三方数字 → 「这组数字意味着什么？」→ 对照组 → 「过去问 X，以后问 Y」→ 对仗收尾。

**借别人的框架当骨架**（高管的「两个腾讯」、投资人的「回到生意本身」），比自己造更有说服力。也可以**从标杆公司抽象出三条标准**（比如从 Anthropic 抽出三条），拿来检验国内公司，结尾「回到最初的框架」复核一遍。

### 6.3 活动模板

现场细节 → 最打动我的一句原话 → 生活类比 → 数据 → 拆三四件事 → 反差点 → 我的判断 → 回到开头的场景。

### 6.4 荐读模板（早期主力，对我们最有用）

论文、访谈、播客、报告、手册的荐读稿：
1. 标题只表态（强烈推荐你去看 X），或者给一个顿悟（我终于理解……）。
2. 第一句复述标题，或者写「刷到」的那一刻。
3. 用三个例子或三点讲清楚「它说了什么」。
4. 落到读者身上：分人群给建议（「如果你是普通用户……如果你是做产品的……」）。
5. 结尾给资料（「我问他们要了一份完整的手册，放在附件里」），或者给一个路径（「去镜像站翻翻」）。

早期荐读稿最大的问题是太薄：只转述，没有自己的场景，也没有局限。4 月那篇荐读（联合国 AI 奖）改成了「刷到一部 AI 纪录片，被打动」起笔，读起来明显更像故事。**荐读的形式可以留，但开头要换成一个场景。**

### 6.5 另外几种有设计的骨架（2026-04 以后出现）

- **排除法**：先写行业为什么不做这件事（三个理由），再逐个否定现有的三种解法，最后主角是唯一的例外。
- **难关清单**：每一节是一道行业公认的难关，加上主角怎么过。
- **痛点、解法镜像编号**：前半四个痛点，后半同编号的四个解法一一对应。
- **争议解读**：先大段放出反对的声音 → 当事方怎么回应 → 升维成行业问题 → 反问收尾。
- **时间线即证据**：把一家公司一个月里的动作按日期列出来，「你们自己感受」。
- **人物特写**：新闻 → 简历 → 早年 → 回到新闻 → 「这个人才是最大变量」。
- **套一种大众叙事类型**：把一张数据图写成爽文剧情：旧王者 → 转折 → 开挂 → 王座。
- **配角弧线**：同一个真人配角在开头、中段、结尾各出场一次，变化落在他身上。

### 6.6 三点结构

全期最常见的中段形态：分三点，也有四到五点。每点内部：**具体例子 → 这说明什么 → 放到读者自己的工作里**。

## 7. 翻页设计

统计成熟期 78 篇的 623 个页面交界：

| 页末是什么 | 次数 | 占比 |
|---|---|---|
| 断在半句，下一页接着写 | 169 | 27% |
| 一句 22 字以内的钩子短句 | 80 | 13% |
| 普通完整段落 | 374 | 60% |

- **断在半句**：先写一篇长文，再按屏幕高度直接切页。有几篇把揭晓词正好放在断点前（「最先让我停下来的，反倒是」）。
- **钩子短句**：「修复思路也很朴素。」「但 MiniMax 讲清楚了。」「有没有进入下一阶段？」
- **点词法**：正文里单独拎出一行，「注意这个词，X」，让读者停一下。

## 8. 论证手法

1. **数字后面立刻跟一句解读**。「这说明」「这组数字意味着什么？」「这是一个信号」。大数字配参照物：「去年全年的1.5倍」。
2. **把比率换成读者能算的账**。「每赚 100 元亏多少」，连着三年递减；「只要产出能提升10%，这笔钱就赚回来了」。
3. **数字联立制造反常**。单独看 A 不稀奇，单独看 B 也说得通，两件事同时发生才反常。
4. **每个技术概念后面立刻跟一个生活类比**。token 漂移像「人名卡壳」，冷门 token 是「冷门住户」。
5. **给事件重新起名、换一把尺子**。「我愿意把 X 称为 Y」「当作 A 看不懂，当作 B 就顺了」。春节免单不当红包大战看，而是当「全民演习」看；机器人公司不当颠覆者看，而是当加持者看。全文围着新名字讲。6 篇这么写。
6. **一个意象从头用到尾**。「尺子」「鸿沟和桥」「一杯奶茶」「养虾」。比「每个概念一个类比」更进一步。
7. **一句口号全文出现三次，当脊柱**。「开源把触达做大，App 把频次做高」。
8. **以前……现在……**。「过去问 X，以后问 Y」是全号最核心的判断句型。
9. **让步式反驳**。先把对方的逻辑完整讲一遍，「要是我不了解……我也会这么想」，再指出「最大的 bug」。
10. **主动降温、写一处翻车**。成熟期至少 20 篇写了局限。早期很多稿子没写，读起来明显更像通稿。
11. **读信号成本**。「没彩排的试驾原片反而会成为负资产，所以敢放出来就是信号」。
12. **指出统计口径漏了什么**。「报告只统计了可追踪的 API 调用」，暗示真实数字更大。
13. **引用自己过去的判断**。「去年 4 月我研究 MCP 时就有个判断，现在看来应验了」。
14. **公开押注**。「我就不装了，我押一波，押错了我也认」。
15. **给读者一个带走的自检问题**。「把特效拿掉以后，我还会担心这个人物吗？」
16. **用真人故事撑抽象定位**。

## 9. 主角怎么进场

- **标题带品牌 → 第一段就出场；标题是判断 → 第 2 到 3 页再出场。** 这是 180 篇合起来看最稳的规律。
- **「刚好」式进入**：成熟期约 25 篇，早期只有约 15 篇。早期更多是「刷到新闻」直接引出主角。
- **借第三方之口**：榜单、外媒、券商、高管原话、友商的态度（「看看友商怎么做：DeepSeek 的论文用了 Qwen」）。
- **品牌打码、缩写**：「dzdp」「某团」「某S开头的AI视频产品」。
- **提前拆掉软广质疑**：「你可能会以为是纯靠营销砸出来的」「一开始我也以为是蹭热度，结果查了一下」。
- **推广变教学**：赛事改写成三种创作问题，招聘改写成「选公司的 5 条标准」。

**反面教材**：
- 形容词和口号多，缺具体测试结果，结论重复，作者自己的场景缺席。
- 「零门槛」话术：「不用学任何 prompt」「完全没有门槛」。出现在 5 篇里，每一篇都是广告味最重的。
- 约 500 字的通稿、格言体、空泛收尾（「值得期待」）。

## 10. 系列化

- **热点连发**：OpenClaw 在 2026-03-09 到 03-13 五天里发了 5 篇，每篇换一个角度（朋友弃用、上门安装生意黄了、部署教程凉了、我装崩了、最强大脑上车）。
- **同一产品分两篇**：先热点种草，隔三周再发深度。
- **跨篇复用自有概念和老熟人**：「认知外包」从论文篇延续到育儿篇；陶哲轩出现在两篇；「前阵子我测过洗车那题」把单篇测试做成了系列。
- **固定栏目**：「冷知识：」只在成熟期出现。

## 11. 语言

| 高频表达 | 覆盖面 | 用法 |
|---|---|---|
| 但 | 成熟期 70/78 篇 | 每页都有转折 |
| 真正 | 成熟期 55 篇、早期约 75% 的篇 | 第一口头禅，全期不变 |
| 最近 / 刷到 | 过半 | 时间锚；早期多用「刷到」 |
| 其实 | 近 6 成 | 纠正预期 |
| 不是……而是 | 约一半 | 对仗判断 |
| 我觉得 / 我认为 | 约一半；「我认为」3 月以后变多 | 判断署名 |
| 信号 | 早期约 10/24 篇 | 早期突出的判断词 |
| 当然 | 成熟期 25 篇，早期少 | 让步降温，后期才成为习惯 |
| 很多人 | 约 1/4 | 立靶子 |
| 有意思 | 约 1/4 | 引出反常细节 |

其他特点：
- 一句一段为主，夹单句成段的节拍词：「确实。」「好家伙。」「为什么呢？」
- 大白话翻译器：「说人话就是」「简单说」「你可以把它理解成」。
- 「写到这里，我想到……」插叙转场，把第二条新闻塞进来当证据。
- 句型：「X 不难，难的是 Y」「A 决定 X，B 决定 Y」「谁能……谁就……」。

## 12. 结尾

| 类型 | 写法 |
|---|---|
| 对仗、比喻金句 | 「能力决定能跑多快，安全决定敢跑多远」；上半场 / 下半场 |
| 首尾呼应 | 回扣标题原词，或者开头出现过的物件 |
| 行动建议、给资料 | 「从一份会议纪要开始」「手册放在附件里」 |
| 主动降调，落到小事 | 「没有什么宏大的时刻」 |
| 反事实 | 「如果当年……当然也可能……只不过……」 |
| 致敬 | 「respect 这几个团队」 |
| 反问、口语调侃 | 「你看懂了吗？」「别传谣好伐？」 |
| 平收 | 早期约 10 篇停在一个开放判断上，或者直接停在截图上 |

几乎不预告下一期（180 篇里只有 1 篇），也没有「关注我」「点赞收藏」式的空喊。

## 13. 迁移到 Krypto说AI

### 最值得学的

1. **荐读体配一个场景开头。** 这是和我们「海外一手内容精读」定位重合度最高的形式。标题用「推荐你去看 X」或「看完 X，我……」（动词开头，人名放后半句，不违反我们的规则）；开头不要复述标题，而是写一个「刷到这篇 / 读到这一句」的时刻。
2. **给事件重新起名、换一把尺子。** 精读海外博主时，把他的观点重新起个名字，全文围着它讲（「这不是自律问题，是一场……」）。
3. **每页最后一句逼人翻页。** 我们的分页脚本只在段落之间切，做不到断半句；可以要求每页最后一段是 20 字以内的钩子短句，在脚本里加一项页末钩子检查。
4. **首页之内给反差**：开头第一段写场景，前 5 段内出现「但 / 却 / 很多人以为」（原号 64% 在前 5 段内转折）。
5. **标题把判断压成一个口语词。正文写完挑一句最狠的当标题，结尾再回扣一次。**
6. **把比率换成读者能算的账**，每个数字接一句「这说明」，每个概念接一个有画面的类比。
7. **主动写一处局限**：「这招在哪种情况下不管用」。
8. **热点连发、跨篇复用概念。** 同一个海外博主或同一个话题连发三篇，每篇换角度；上一篇提出的概念，下一篇直接接着用。
9. **给一个自检问题当收藏点**，顺手做成领取物。

### 不能照搬的

1. **「我」的身份。** 他们是前员工、股东、做产品的团队，我们没有。我们能用的「我」只有「用 Claude / Agent 干活的人」和「每天读海外一手内容的人」。实测类可以用「我」；精读类按 storyteller 口吻，「我」只出现在一个具体的使用场景里，不写查资料的后台过程。
2. **专名开头的标题。** 他们 22% 的标题以专名开头，我们 09-24 复盘里人名或机构开头的点击率只有 4.9% 到 8.2%，数字开头的是 12.3%。句式可以借，开头换成数字或读者处境。
3. **「刚好」式偶遇和「零门槛」话术。** 这是为商业合作服务的，我们用了会像软广。可以借结构（先讲透问题再让主角出场），不借话术。
4. **情绪口语期的标题。** 「笑鼠」「有点子炸裂」「啊？？」是他们几十阅读阶段的写法，后来自己也收掉了。我们可以偶尔用一个情绪词，但不作为主力句式。
5. **没有封面卡。** 他们第一页就是正文；我们的点击率是最大短板，封面大字卡不能省。

### 标题改写示范

| 原标题 | 改写 | 用的句式 |
|---|---|---|
| How to 优雅使用Multi Agent | 开了 10 个 Agent 之后，我反而更慢了 | 第一人称动作 + 反转 |
| How to让你Agent又快又便宜 | Agent 真正贵的地方，不在模型 | 反常识判断（「真正」） |
| CMU 网课AI Agents 教你如何写skills | 强烈推荐你去看 CMU 这节讲 skill 的课 | 荐读体 |
| 额度多花 1 倍的最根本原因，官方讲了 | 冷知识：Claude 额度翻倍消耗，问题不在你 | 栏目前缀 + 反常识 |
| 斯坦福公开课：AI 收入两年爆涨 5 倍 | AI 赚的钱，还没流到应用层...... | 逗号两段式 + 省略号留口 |
| 百万博主Dan Koe：不是没自律，是目标太正常 | 我终于理解，为什么我的自律撑不过两周 | 第一人称顿悟 |

这些改写还要再过一遍我们自己的「标题五条铁律」：不超过 20 字，前 8 字里要有数字或读者处境，不能直接写出答案。
