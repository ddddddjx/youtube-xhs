## 《排第四名的阿福，挺有意思的》（2025-12-25）
- 类型：行业观察 / 产品解读（借 QuestMobile 12 月 AI 应用榜解读蚂蚁阿福）。
- 叙述者身份及作用：看榜单的观察者 +「我体验下来」的用户，身份很薄，主要用来给判断署名。
- 标题拆解：「排第四名的 + 品牌，挺有意思的」。排名数字当定语，品牌放中间，后半句是口语评价「挺有意思」，不给结论，悬念在「为什么第四名值得说」。无标点情绪词。标题 = 正文第 3 段原句「但排第四名的阿福，挺有意思的」。
- 开头：第一句是金句论点「让用户感觉不到AI 的存在」，不是场景；第二段「豆包、DeepSeek…我一点不意外」先给常识，第三段「但排第四名的阿福」转折。靠「意外 vs 不意外」留人。
- 骨架：论点 → 榜单常识 → 转折点名阿福 → 「鸿沟 + 桥」比喻讲用户心理 → 工具价值 + 情绪价值 → 多轮追问功能举例 → 预判质疑「纯靠营销？」→ 数据反驳 → 让步「长期信任最难」→ 收在「起步很扎实」。
- 论证与证据：QM 数据「新上线AI原生应用日活周活第一」、上线三天榜单第二；数字不多，靠比喻「鸿沟前面搭了一座桥」撑全篇。
- 主角进场：第 3 段即出场，借第三方榜单进场。
- 节奏与语言：短段，「所以你看」「当然」让步两次。页末断在「搭了」，下一页「一座桥」——半句断页的典型。
- 结尾：先让步「没有那么好吃下」，再收「阿福的起步很扎实」，降调收尾。
- 最值得学：①「鸿沟—桥」一个比喻贯穿产品价值；②先替读者说出「是不是砸营销」的怀疑，再用数据回。
- 相对手册：补充证据（断半句翻页、主动降温、「当然」让步）；反例：首句不是「时间词+我」，而是一句论点金句。

## 《技术决定走多快，商业模式决定了走多远》（2026-01-15）
- 类型：公司解读（可灵 AI 商业化打法，拼投行报告）。
- 叙述者身份及作用：「我最近在关注」+「翻了些投行的报告」的研究者，作用是把多家报告串成自己的「几个关键点」。
- 标题拆解：「A 决定 X，B 决定 Y」对仗金句，无品牌、无悬念，纯判断；标题 = 结尾最后一句原话（「在AI时代，技术决定了你能走多快…」）。
- 开头：「我最近在关注快手的可灵AI」，第二句直接甩数字「ARR超过2.4亿美元」。靠数字 +「值得学习的商业打法」承诺留人。
- 骨架：数字钩子 → 「三步棋」（C 端破圈 → 技术推生产力/B 端 → 全球化）→ 估值 15 倍 → 抽象成「AI 公司估值新框架（三维度）」→ 对仗收尾。
- 论证与证据：Jefferies、摩根大通、高盛、花旗、摩根士丹利五家轮番背书，一家一个数；数字后接解读「这个比例很有意思，它说明…」「这是全球顶级软件公司的估值水平」。
- 主角进场：第一句即出场。
- 节奏与语言：「第一步棋 / 第二步 / 第三步棋」编号；「传统 SaaS… 但可灵反其道而行之」对照；书面分析体，口语少。「我猜测」给推断留余地。
- 结尾：「技术领先很重要 / 但更重要的是…」→ 标题金句。
- 最值得学：多家机构报告「一家一数一句解读」地串起来，比单一来源更像研究。
- 相对手册：补充证据（标题 = 结尾原句；借第三方框架）；新手法：五家投行轮番背书的「报告拼盘」。

- 类型：实测（阶跃桌面伙伴平替 Claude Cowork）。
- 叙述者身份及作用：想用但用不上 Cowork 的用户，给「平替挑战」一个真实动机。
- 标题拆解：前半问句戳痛点「用不了X？」，后半「Y直接顶上来了」；海外大牌在前当锚，国产主角在后。问号 + 口语「顶上来」。
- 开头：「我承认，我确实很想要，但很难用上」自白 + 转折；「小卷毛CEO给的限制」用昵称调侃。第 2 段立任务「用国产Agent把Cowork复刻出来」。
- 骨架：想要却用不上 → 平替挑战 → 预判「蹭热度」质疑并澄清（2025 年 9 月已邀测）→ 拆三部分（数据分析 case / 导入前端 skill / 全局记忆）→ 下结论「复刻出一大块」→ 隐私、端侧模型 → 邀请读者自己试。
- 论证与证据：截图 + 执行计划；第二个 case 写成手把手教程「第一步…第二步…第三步」，并贴出固定提示原文。
- 主角进场：第 3 段「我用的是阶跃AI的小跃」，很早。
- 节奏与语言：「我把挑战拆成三个部分」先给阅读地图；「你可以把它理解成」大白话。
- 结尾：「随便挑个小任务丢给」它，行动建议。
- 最值得学：①「用不了 A？B 顶上来」的平替框架，借大牌热度又不硬比；②把一个功能写成可照做的步骤教程，天然收藏点。
- 相对手册：新手法（平替挑战框架、步骤教程植入、主动澄清「蹭热度」）；反例：主角第 3 段就出场，不是第 2–3 页。

## 《没有无限预算也能赢，快手估值的第二根柱子》（2026-01-21）
- 类型：公司解读（可灵对快手估值的意义）。
- 叙述者身份及作用：几乎无「我」，只在判断处出现「但我认为」「我认为在资源有限时」，给判断署名。
- 标题拆解：前半反常识「没有无限预算也能赢」，后半比喻概念「第二根柱子」；「柱子」一词正文没有出现（正文说「另一个增长引擎」）。
- 开头：第三人称起笔「快手这家公司，过去…总带着点追赶者的味道」，第二段「可在过去18个月」转折，第三段彭博社故事（OpenAI 预告后快手定目标、6 月上线）。靠「追赶者翻身」的叙事留人。
- 骨架：追赶者印象 → 急行军故事 → 立靶子「大厂砸钱抢风口」→ 我的反驳「节奏和决策准确率」→ 三条战术（聚焦视频 / 独立 P&L / 节奏）→ 同行对比（海螺 MAU）→ 盖坤原话 → 提炼成「可参考框架」三条 → 未来平台 → 收在「这套能力」。

- 主角进场：第一句。
- 节奏与语言：「这个结构很重要 / 因为…」短句 + 解释；金句「可控性几乎等于商业化」。
- 结尾：「这套能力，才是可灵对快手最重要的意义」，判断式收束。
- 最值得学：把公司案例抽成「给读者用的三条框架」（先打穿一个场景 / 隔离组织惯性 / 节奏即护城河），从解读转成方法论。
- 相对手册：补充证据（对照组、立靶子「很多人…」）；反例：标题核心比喻正文没出现，开头三段无「我」。

## 《有点子炸裂！阿里平头哥要独立上市了？》（2026-01-22）
- 类型：热点解读（路透社报道平头哥拟上市）。
- 叙述者身份及作用：刚刷到新闻、顺手查资料的科普者。
- 标题拆解：情绪口语前缀「有点子炸裂」+ 感叹号 + 问句；品牌在中段；问号表示「据报道」的未确认。
- 开头：「刚刷到路透社的消息有点子炸裂」，第二段自问自答「什么，你不知道这家公司？」，假想读者提问来引入科普。
- 骨架：新闻 → 你不知道？我介绍 → 参数对标英伟达 → 查资料列产品线 → 「真正炸裂的地方不在…而在…」→ 自研芯片「三场仗」→ 阿里的场景优势 → 口碑供不应求 → 感慨收尾。
- 论证与证据：芯片参数对标 A800 / H20 / A100，并解释对照对象「本身就具有现实含义」；新闻联播、路透社、三方报告作背书。
- 主角进场：标题 + 第一句。
- 节奏与语言：「谁知道今天，路透社这个百事通称」俏皮；「别人做芯片可能需要先找场景，阿里做芯片是场景天天在逼你交付」对仗。
- 结尾：「必须被认真对待的变量」，判断式，没有让步。
- 最值得学：「真正炸裂的地方，不在于 X，而在于 Y」——先承认标题的情绪，再把它升级成一个更深的判断。
- 相对手册：新手法（「有点子炸裂」情绪前缀 + 感叹号，手册称全号只 1 篇感叹号）；补充（三点结构、对照参照物）；反例：全文无局限、无让步。

- 叙述者身份及作用：使用场景已从内容生产转向协作型任务的用户，给测试一个「我为什么在意稳定交付」的标准。
- 标题拆解：「有点炸裂，」前缀 + 品牌 + 奇观化问句「八个大脑」（正文的 8 个 thinker 并行）。

- 骨架：为什么测 → 预告三线三实验 → 模型简介 → 实验 1 反语规则（8 个分支有跑偏也有「无法回答」→ 收敛）→ 与两个国外模型对比 → 实验 2 脏日志抽取 → 实验 3 Claude Code 接入做 3D 粒子宇宙 → 三线合一的主张 → 对仗收尾。

- 主角进场：第一句。
- 节奏与语言：「下面开测」一句一段做节拍；「这种克制比聪明更重要」呼应全号「靠谱比聪明值钱」母题。
- 结尾：「它不追求每一次都惊艳，它更在意每一次都不掉链子」。
- 最值得学：①开头交代「三条升级线 ↔ 三个实验」一一对应，读者知道要读什么；②把中间跑偏的分支也贴出来，再说收敛能力。
- 相对手册：补充证据（先立判断标准「稳定交付」、写局限、对仗结尾）；新手法：开头给阅读地图。

### 3. 和手册结论冲突的地方

- **品牌开头约一半**：本组品牌或人名开头的只有 3/26（杨丽萍、盖坤、「美团快手百度」且主角放句尾）；14 篇标题完全不写品牌，品牌在标题里多放句尾或被「它 / 他」代替（《没撒钱没请星，但它却…》《股价跌82%，他却…》）。这批更接近我们复盘的「别用品牌开头」。
- **省略号是招牌**：本组 0 篇用省略号。
- **感叹号只有 1 篇**：本组又多 1 篇（平头哥「有点子炸裂！」），且同组问号 3 篇。
- **开头「我」约 8 成、首句「时间词+我」**：本组 4 篇开头三段无「我」（快手、奥运、机器人评价、应用开发），3 篇首句是论点或情绪判断而非时间词（阿福、机器人评价、机器人颠覆）。
- **「标题里的场景一定在正文被单独验证」**：本组 4 篇反例——杨丽萍正文不提；「第二根柱子」正文没出现；「每天那10分钟」正文未验证；「百万预算」而正文说「过千万」。
- **主角第 2–3 页才出场（约 30/78）**：本组第一句或第一段就出场的约 12 篇（多是标题带品牌的热点 / 实测稿）；延后出场的主要是行业判断式标题（机器人评价、应用开发、眼镜、Office）。结论：标题有品牌 → 首段出场；标题是判断 → 延后出场。

### 4. 时间上的变化

本组时间跨度 2025-12-25 到 2026-04-30。
- **2025-12 到 2026-01（7 篇）**：正文页头 OCR 带「16 / 21 / 30 / 55阅读 发布于广东」，是带阅读数的截图，阅读量很低；以公司 / 财报 / 热点解读为主（可灵、快手、平头哥、Kimi），数据靠券商、外媒；标题两极：对仗金句（技术决定…）或情绪口语（有点子炸裂、涨完你的涨你的）。「给大家科普一下」「我简单介绍下」科普腔多。
- **2026-02（9 篇）**：春节营销集中（千问免单、可灵春节、阿里冬奥、河南卫视春晚），页头为「发布于上海 / 广东 / 江苏」+ 时间；品牌稿变多，也出现第一篇常识横评（洗车）和押注稿（咯噔）。
- **2026-03（4 篇）**：每页顶部带「2026.03.xx」日期戳；生活场景起笔明显增多（街头大哥、找店、深夜报错、看直播），口语浓度最高，「龙虾 / 虾」圈内词出现。
- **2026-04（6 篇）**：页头元信息消失；题材转向人物、访谈、大会、论文（盖坤、多邻国、郭彦东、LARYBench、哇唧唧哇），叙事更像故事（纸手机、反事实开头、坐在台下），标题从「品牌 + 情绪」转向「挑战行业共识的判断句」（《整个行业一直在用错误的方式…》《…结果可能都想错了》《现在的应用开发，已经越来越像…》）和「数字 + 反差」（股价跌82%、百万预算）。
- **长度**：各月篇幅差别不大（正文约 3000–9000 字节），看不出明显增减趋势；4 月稿平均略长、书面分析句更多。
