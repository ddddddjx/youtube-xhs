## 《Meta为什么要花这么多钱买Manus？》（2025-12-31）
- 类型：热点吐槽（借 Meta 收购 Manus 的新闻，玩梗式地抬 Qwen）
- 叙述者身份及作用：看新闻的围观者，「我在脑子里盘了几种可能」，身份模糊，作用是当段子手。
- 标题拆解：「为什么」问句，品牌 Meta、Manus 双主体在前，情绪点在「这么多钱」；口语。标题问原因，正文答案是「为了 Qwen」，标题完全没露出真正主角阿里 Qwen。
- 开头：第一句新闻 + 量级参照「能排进Meta历史收购案的前三」；第二段立刻玩笑「小扎这是被电信诈骗了？」靠笑点留人。
- 骨架：新闻 → 玩笑 → 「真相只有一个」→ 引 Manus 创始人推文佐证 → 彭博社旁证 → 虚构「小扎心路历程」→ 扩大到硅谷大佬也爱 Qwen → 调侃收尾。
- 论证与证据：推文截图、彭博社报道、黄仁勋/Airbnb CEO 名人背书；无数字论证，全靠「人设梗」串联。
- 主角 / 品牌怎么进场：阿里 Qwen 以「白月光」进场，第 4 段才出现，全篇逐层升级成主角。
- 节奏与语言：极短，一句一段；网络梗密集（「为了这点醋才包的这顿饺子」「白月光」「皮衣黄」「负重前行」）。
- 结尾：调侃建议「直接在PPT最后加一行鸣谢」。
- 最值得学：用一个情感梗（白月光）把一条收购新闻翻译成人物关系剧；虚构心路历程时明确是「可能是这样的」。
- 相对手册：新手法——把真正主角藏在标题的另一家公司后面，靠梗词反复出场；手册只写了热点吐槽约 2 篇，这篇是纯段子体的完整样本。

## 《你买的 Agent 可能只是一堆提示词》（2026-01-07）
- 类型：行业观察（企业多智能体，借零一万物的 TAB 框架）
- 叙述者身份及作用：和厂商团队「聊了聊」的采访者，后半段转成给管理者出主意的顾问。
- 标题拆解：第二人称「你买的」+ 反常识降格「可能只是一堆提示词」；无品牌，品牌只在文末署名。标题是开头的吐槽靶子，正文核心判断是「能力即服务 / 一把手工程」，两者只在开头相接。
- 开头：「Agent这个词几乎被用烂了」，先吐槽市场乱象，再用「但多数所谓Agent就是个对话框」下判断。
- 骨架：乱象 → 厂商观点（CaaS）→ 过去 SaaS / 现在买能力 → TAB 三要素逐条 → 客户案例（能源巨头物流）→ 我追问落地 → 一把手工程 / FDE → 我的五步路径 → 对仗收尾 + 问题。
- 论证与证据：几乎全是厂商原话转述，只有一个无数字的客户案例。
- 主角 / 品牌怎么进场：第 3 段「前几天我和零一万物团队聊了聊」直接进场，框架全部来自对方。
- 节奏与语言：书面、口号多（「能力软件化」「新纪元」「组织基因」）；「过去…以后…」句式出现多次。
- 结尾：「多智能体要改的是组织基因」＋抛问题给管理者。
- 最值得学：结尾给出可执行的「第一步到第五步」，其中「把验收标准写死」这类一句话能单独收藏。
- 相对手册：补充证据——手册「反面教材」一条（形容词口号多、缺测试结果、作者场景缺席）；另外是「过去买 X，现在买 Y」句式的又一例。

## 《今天看到的很多东西并不梦幻》（2026-01-08）
- 类型：活动见闻（阿里云通义智能硬件展，深圳）
- 叙述者身份及作用：受创业者朋友邀请去看展的人，朋友的邀请聊天截图进正文，用来解释「为什么我会去」。
- 标题拆解：日记式情绪句，无品牌、无主体，「并不梦幻」是反说——正文意思是「未来在兑现、很实在」。标题靠反差留口，不给信息。
- 开头：先写「我一直把CES…当作风向标」，再用「但真正让我觉得…成了」转到阿里展，第二段就是反转。
- 骨架：CES 对比 → 朋友邀请 → 现场第一印象 → 数字（76 品类、200 品牌、1000 款）→ CES=趋势发布会 / 这里=趋势兑现会 → 设问「是什么力量」→ 千问=AI 硬件的 Android → 三个展品例子 → 朋友的产品 → 回到「兑现」。
- 论证与证据：展会规模数字 + 三个产品例子；推动力的判断（千问开源）没有证据，直接断言。
- 主角 / 品牌怎么进场：以设问揭晓「我反复看到一个名字：千问大模型」。
- 节奏与语言：对仗比喻多，口号化（「屠龙之技」「平凡且伟大」「巨人的肩膀」）。
- 结尾：正文停在「站在了千问大模型这个巨人的肩膀上」，之后是展馆图片文字。
- 最值得学：「CES是一场关于未来的趋势发布会」vs「趋势兑现会」这种拿行业标杆当对照的定位句。
- 相对手册：新手法——把私聊邀请截图放进正文当入场理由；补充证据——大会稿「读起来最像通稿」的又一例。

## 《千亿MiniMax相信非共识》（2026-01-09）
- 类型：公司解读（MiniMax 港股上市当日）
- 叙述者身份及作用：「我认识一些在MiniMax工作…的人」，半个圈内人，给「活力」这种软判断背书。
- 标题拆解：品牌前置 + 数字定语「千亿」+ 口语化判断「相信非共识」；无标点。标题就是全文核心判断。
- 开头：「今天，MiniMax在香港上市」＋涨幅市值；第三段转「我脑子里想的，却是几年前AI圈的共识」，反差在第 3 段。
- 骨架：上市数据 → 当年共识（B/G 端）→ 「但MiniMax偏不」→ 孤独的决定 → 认识的人 → Talkie、海螺 → 配售倍数对比 → 长线资金 = 奖励 → 亏损收敛三年数 → 米哈游股东故事 → 让步（做 B 端也可能很大）→ 收尾。
- 论证与证据：国际配售 36.76 倍，拿壁仞、英矽两家同期倍数做参照；亏损写成「每赚100元，要亏出去约3000元」→「千元」→「五百元」，把亏损率翻译成每 100 元的账。
- 主角 / 品牌怎么进场：第一句就进场（上市新闻稿）。
- 节奏与语言：短句单段多（「这是一个孤独的决定」「但MiniMax偏不」），情绪词「偏不」「头也不回」。
- 结尾：让步式，「故事大概率会变得平稳，变得可预测」。
- 最值得学：亏损率换算成「每赚 100 元亏多少」三年递减，数字有画面；配售倍数给同期参照。
- 相对手册：补充证据——「大数字配参照物」「结尾前让步」；新手法——「用反事实收尾」（如果当年选了 B 端会怎样）。

## 《今天，我看到一条新闻时有点小意外》（2026-01-19）
- 类型：公司解读（MiniMax 创始人出席官方座谈会）
- 叙述者身份及作用：看新闻的观察者，「据我了解」给出一点内部信息。
- 标题拆解：纯日记体，时间词 + 我 + 情绪「小意外」，无品牌无事件；标题 = 正文第一句逐字。悬念全靠「什么新闻」。
- 开头：第一句即标题；第二段点事件不点名，「为什么是它」设问留人，第四段才「我先说我的判断」。
- 骨架：设问 → 先给结论（三个标签：年轻、全球化、效率）→ 每个标签「数据 → 悖论 → 反转解释」→ 对照 DeepSeek → 两点原因 → 期待。
- 论证与证据：员工 385 人、平均 29 岁、研发 73.8%；200 国、2.12 亿用户、海外 70%。每组数字后都自提一个反面（「29岁…缺少完整的商业周期经验」「国内市场并不是它的主战场」）再化解。
- 主角 / 品牌怎么进场：第 5 段「MiniMax这次被看见」，先藏再揭。
- 节奏与语言：分析体，「先说年轻」「第二个标签是」编号清楚；「悖论值得聊聊」引出自我反驳。
- 结尾：「我愿意相信它的故事才刚刚开始」。
- 最值得学：每个优点数字后立刻自己提反方（「但这个数字也暴露了…」），再给出解释，显得不是吹。
- 相对手册：补充证据——「标题就是正文第一句」「主动降温」；新手法——「数字 → 自提悖论 → 翻转」的三拍，比手册的结尾让步更早、更密。

## 《OpenEvidence在国内会错位》（2026-01-22）
- 类型：实测（阿里健康 AI 医疗产品「氢离子」，以 OpenEvidence 为对照）
- 叙述者身份及作用：「我有个朋友是医生」，借医生朋友给出评判标准；「我自己也顺手试了试」是次要的使用者。
- 标题拆解：品牌 + 判断（「会错位」），但标题里的品牌是海外对照组，被测主角氢离子完全没进标题。标题判断是正文的一个论点（美国循证语境不适配本地指南），用来给主角让出位置。
- 开头：朋友的一句行业痛点「查到一堆看起来都对的结论」，再把他的判断标准压成一句「能不能把答案变成可核查的证据链」。
- 骨架：医生朋友的痛点与标准 → 新品发布，朋友试用「评价还行」→ 定位（ToP/ToD）→ 海外对照组 → 共同点 / 差别 → 为什么国内医生难用对照组 → 三个亮点 → 检索来源更权威 → 当然：时间成本门槛 → 适用场景 → 我更关注的标准 → 愿景。
- 论证与证据：以产品界面截图为证（51 篇文献、期刊来源），无量化对比。
- 主角 / 品牌怎么进场：第 4 段借「最近阿里健康官宣…」进场，前面先立标准。
- 节奏与语言：克制的专业口吻，「当然」让步，「我会更关注」立标准。
- 结尾：「成为医生桌面上那个随手可用的第二检索系统」。
- 最值得学：先借行内人立一条评判标准，后文三个亮点全都回扣这条标准。
- 相对手册：新手法——标题放海外知名对照品牌 + 否定判断，本土主角藏在正文（和手册「主角藏起来」同向，但更进一步：标题只写对手）；补充证据——「我更关心的是…」立标准。

## 《Step 3.5 Flash登顶OpenRouter，海外炸了》（2026-02-05）
- 类型：行业观察 / 争议解读（阶跃模型隐藏知识类 benchmark 引发的质疑）
- 叙述者身份及作用：吃瓜的旁观者，后段「我突然想明白一件事」转为解读者。
- 标题拆解：逗号两段式，前段产品 + 榜单事实，后段口语情绪「海外炸了」；品牌前置。标题只讲热度，正文核心判断是「Agent 时代评估体系要变」。
- 开头：「最近看到一个挺有意思的事」＋发布两天登顶；第三段解释榜单含义「开发者用钱投票」；第四段「但在海外社区，有人开始质疑了」——转折在第 4 段。
- 骨架：登顶 → 质疑（引三条海外推文 / GitHub）→ 技术员回应（数据 + 理由）→ 我的理解：旧思路 vs Agent 思路 → 产品参数 → 「这个速度意味着什么？」→ 榜单佐证 → 当然有争议 → 反转视角 → 两个反问 → 收尾反问。
- 论证与证据：MMLU-Pro 84.4、HLE 23.1、每 token 激活约 110 亿参数、每秒 350 token；每个参数都跟「意味着什么」。
- 主角 / 品牌怎么进场：第二段即进场，负面事件先行，主角被「质疑—回应」推着出场。
- 节奏与语言：分析体，「不再只看…而是看…」排比；两个「是需要…还是需要…」的选择题。
- 结尾：反问「用旧的标准去衡量新的事物」「到底还有没有意义？」
- 最值得学：把一次公关危机写成「质疑 → 当事人回应 → 我的升维解读」，替主角把缺点改写成路线选择。
- 相对手册：新手法——「争议解读模板」：先大段引用反对声音，再给当事方回应，最后抬高成行业问题；手册解读模板里没有「先放质疑」这一拍。

### 2. 手册里没有的新手法
1. **配角弧线**：同一个真人配角在开头、中段、结尾三次出场，产品带来的变化落在他身上（《AI把短剧门槛打穿后》）。
2. **标题只写对手或旁人**：标题主体是海外对照品牌或收购方，真正主角只在正文（《OpenEvidence在国内会错位》《Meta为什么…买Manus》）。
3. **争议解读模板**：先大段放出反对声音 → 当事方回应 → 升维成行业问题 → 反问收尾（《Step 3.5 Flash》）。
4. **排除法骨架**：先写行业不做的三个理由，再逐个否定现有三种解法，主角是唯一的例外（《为什么行业迟迟没有正面应对AI幻觉》）。
5. **痛点 / 解法镜像编号**：四个梗化痛点小标题，后半用同编号的四个解法一一对应（《AI生图终于开始干点人事了》）。
6. **逆舆论辩护**：品牌负面事件（涨价）里站在平台一边，先认损失，再算账，再拿死掉的对手做对照（《AI视频的低价梦，该醒了》）。
7. **事件推演各方反应**：「我们来猜测一下」X、Y、Z 对这件事可能是什么态度（《Sora关停后》）。
8. **数字联立制造反常**：单独看 A 不稀奇，单独看 B 也可解释，同时发生才反常（《中国AI公司财报》）。
9. **每个优点数字后自提悖论再翻转**：（《今天，我看到一条新闻时有点小意外》）。
10. **把比率换算成「每赚 100 元亏多少」**，三年递减（《千亿MiniMax》）。
11. **同一产品两篇连载**：先热点种草，隔三周再发深度（Loopit：02-10 → 03-02）。

### 4. 时间上的变化
- **2025-12 到 2026-02 上旬（早期，9 篇）**：篇幅短（多篇不到 1000 字），快讯、段子、日记体多；标题是情绪句或日记句（「有点小意外」「并不梦幻」「放大货呀！」「两记重拳」），标题不含判断；口语和网络梗浓（白月光、兄弟们）；出现预告下一期和未完成的初见稿。
- **2026-02 下旬到 03 下旬（中期，6 篇）**：每页页眉印日期戳（「2026.02.26」「2026.03.25」等），版式固定；标题转向「逗号两段 + 判断」（「下一代内容平台，不靠推荐算法」「AI红利，不属于…」）；开头多用饭局、咖啡场景；编号列表和书面分析体增多。
- **2026-03 下旬到 05（后期，11 篇）**：页眉日期消失；篇幅最长（多数 1500 字以上）；标题问句和暴力动词集中出现（踹翻、掀了、打穿、掀翻、洗牌、变天、该醒了、谁最先睡不着、谁在吃下最大红利）；商业主角比例最高，出现明确推荐和操作路径；结构更工整（镜像编号、排除法、框架复核），「我认为」「我觉得」署名判断变多；同时「主动写局限」更稳定（Seedance、GLM-5.1、HappyOyster、智谱都写了）。
- 总体趋势：从「一个刷到新闻的人在吐槽」走向「一个有判断框架的行业评论者」，标题从情绪日记句变成「泛化主体 + 强动词 / 问句」。
