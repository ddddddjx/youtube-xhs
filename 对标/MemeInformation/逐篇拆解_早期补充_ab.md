## 《强烈推荐你去看MIT发表的这篇论文》（2025-12-29）
- 类型：论文或播客推荐（转述 MIT「ChatGPT 和你的大脑」研究，提出「认知债务」）
- 叙述者身份及作用：几乎没有身份，只是「看完论文的人」。「我」只在第一段出现，之后全用「我们」，读者和作者站在同一边，被研究结论一起「点名」。
- 标题拆解：祈使推荐句「强烈推荐你去看 + 权威机构 + 这篇论文」。悬念靠「这篇」不说是哪篇、讲什么；情绪词「强烈」；机构名 MIT 放在中段；无标点；口语。标题只给态度，核心判断（认知债务）不在标题里，要点进来才知道。
- 开头：第一句就复述标题，第二句抛概念钩子：「一个我看完之后，就再也忘不掉的概念」，第三段用「我们都知道……但我们可能不知道」做反差。靠一个新名词留人。
- 骨架：推荐 → 抛概念 → 概念来源（认知外包）→ 实验设计（三组人写论文）→ 结果数字 → 第二重代价（被平均化、作品不属于你）→ 电影《沙丘》台词 → 累积效应 → 「那么，我们该怎么办？」→ 克制使用 → 选择权。
- 论证与证据、数字怎么讲：实验数字直接报（83% 复述不出、只有一半认为作品是自己的），数字之后接「这项代价，是要付出后果的」这类解读。用一句电影台词拔高。
- 主角 / 品牌怎么进场：无商业主角，MIT 是权威背书。
- 节奏与语言特点：一句一段，书面感强，几乎没有口头禅；用第二人称「你会慢慢感觉」制造代入。
- 结尾：「这个选择权，必须牢牢掌握在自己手里」，行动态度式收尾，不回扣标题。
- 最值得学的 1–2 个技巧：用一个「看完就忘不掉」的新概念做开头钩子；「我们都知道……但我们可能不知道」的双句反差。
- 相对手册：新手法——「强烈推荐你去看」推荐体标题（手册八种句式里没有）；开头不是「时间词 + 我 + 具体场景」，而是直接复述标题 + 概念钩子。反例——开头三段几乎没有「我」的具体场景，与手册「首句带时间词」不同。

## 《大模型哪家强，老黄直接摊牌了！》（2026-01-06）
- 类型：论文或播客推荐 / 行业观察（解读黄仁勋 CES 主旨演讲中对 DeepSeek、Kimi 的点名）
- 叙述者身份及作用：看完演讲、做了笔记、翻过 reddit 技术拆解的人。身份很薄，作用是把演讲转述成自己的判断。
- 标题拆解：逗号两段式，前半是网络老梗「XX 哪家强」，后半「老黄直接摊牌了！」。悬念在「摊牌」摊了什么；用昵称「老黄」而非全名；带感叹号（手册 78 篇只有 1 篇带）。标题暗示「老黄给大模型排了名」，正文其实讲的是「DeepSeek、Kimi 为什么被点名」，标题是诱饵式夸张。
- 开头：又是推荐句起笔：「强烈推荐你去看老黄在CES的主旨演讲」，紧跟「看完我才把一件事想透了」。留人靠一个待解释的现象：他为什么反复提中国团队。
- 骨架：推荐 → 疑问（为什么点名）→ 答案一句（刚好踩在他世界观中心）→ 老黄的范式转移（写规则 → 做训练）→ Rubin 数据 → 「最值钱的角色是谁？」→ DeepSeek 做训练侧提效 / Kimi 做使用侧降本 → 行业分裂（热闹商业化 vs 实验室气质）→ 我的判断 → 展望（结尾未写完）。
- 论证与证据、数字怎么讲：「吞吐提升 10 倍、成本砍到 1/10」只报不解；技术名词（mHC、Muon、Int4QAT）一笔带过，没有类比。用对仗句归纳：「一个做训练侧的提效，一个做使用侧的降本」。
- 主角 / 品牌怎么进场：借第三方（老黄）之口抬出 DeepSeek、Kimi，典型「借大佬背书」。
- 节奏与语言特点：自问自答「所以……最值钱的角色是谁？」；「偏要去挖，偏要去验证」三连排比。
- 结尾：最后一句断在「往上」，没有收束（可能是截图缺页，也可能原稿就停在这）。
- 最值得学的 1–2 个技巧：把两家公司的路线压成一组对仗（提效 / 降本）；用「这里面藏着一个很微妙的分裂」引出对照组。
- 相对手册：新手法——「XX 哪家强」老梗 + 感叹号的标题；开头用推荐句。补充证据——「借第三方之口」（手册第 8 节）。反例——技术名词后没有生活类比，与手册「每个概念接一个类比」不符。

## 《强烈推荐去看数学家陶哲轩近期关于AI的访谈》（2026-01-06）
- 类型：论文或播客推荐（转述陶哲轩访谈：AI 可能不会思考）
- 叙述者身份及作用：推荐人，全文基本是转述者，「我」只在开头出现。
- 标题拆解：与 MIT 篇同一模板「强烈推荐去看 + 权威人物 + 访谈」，只写对象不写观点。人名带头衔「数学家」给不熟的读者一个锚。
- 开头：推荐句 → 给名人做「一句话介绍」：「数学界的莫扎特」「相当于数学领域的诺贝尔奖」→ 抛刺耳观点「AI可能根本就不会思考」。留人靠权威 + 反直觉判断。
- 骨架：推荐 → 人物介绍 → 刺耳判断 → 「但并非空穴来风」→ 原理只是矩阵乘法 → 纽结理论例子（AI 是模式识别器）→ 为什么不算推理 → 三个人类思维例子（高维球、1 被开除出质数、反证法）→ 回看 AI → 金句收尾。
- 论证与证据、数字怎么讲：数字少，靠三个有画面的数学小故事撑论点：1000 维的球「几乎为零」、12 的分解「就乱套了」、小孩说「那一百万零一呢？」。每个故事后面立刻落一句「这是人类思维的伟大之处」式判断。
- 主角 / 品牌怎么进场：无商业主角。
- 节奏与语言特点：「第一个 / 第二个 / 第三个」编号；用「你看，」拉读者；借哈代棋局比喻。
- 结尾：「真正有价值的，永远是那个提出问题的」人，对仗式金句。
- 最值得学的 1–2 个技巧：给不熟的权威人物配一个一句话的比喻头衔（「数学界的莫扎特」）；用小孩都懂的例子讲反证法。
- 相对手册：新手法——推荐体标题（同上）；「人物一句话介绍」作为第二段。补充证据——三点结构、每点「例子 → 这说明什么」（手册 5.4）、对仗句收尾（手册第 10 节）。

## 《我眼中的智谱AI（深圳看不到星星）》（2026-01-08）
- 类型：其他（前员工回忆散文，借智谱港股上市日抒情）
- 叙述者身份及作用：智谱前员工、离开北京去了深圳。这是全文唯一的驱动力，情绪线来自「我没能陪到最后」。
- 标题拆解：「我眼中的 + 公司名」+ 括号副题「深圳看不到星星」。括号副题是情绪钩子，与公司毫无关系，制造「这不是财报稿」的反差。无问句、无情绪词。
- 开头：第一句就是副题「深圳看不到星星」单独成段，接着写北京冬夜、CBD 灯光，然后「手机又弹出……智谱IPO的新闻」，「没点开，划掉了」。靠克制的情绪和一个没说出口的身份留人。
- 骨架：深圳夜空 → IPO 推送 → 想吃枣糕 → 第一次买枣糕的回忆 → 赛尔大厦的创业期 → 凌晨听歌的一夜 → 搬到搜狐大厦的困惑 → 离开那天 → 回到深圳 → 看到上市消息 → 释怀 → 替智谱高兴 → 想回五道口买枣糕 → 「谢谢你，智谱」→ 附股价新闻截图。
- 论证与证据、数字怎么讲：几乎不论证。唯一的数字在文末截图（首日涨超 10%、市值 563 亿港元），正文里完全不谈钱。可信度全靠细节：打印机卡纸、厕所的灯坏一盏、排队从店门口排到街角。
- 主角 / 品牌怎么进场：智谱是「我」的一段人生背景，不是被分析的对象；到倒数几段才正面评价公司。
- 节奏与语言特点：散文腔，大量短句和留白（「没想明白。但还是在做」）；有粗口（「这特么」「很牛逼」）；物件（枣糕）贯穿全文。
- 结尾：「谢谢你，智谱。谢谢那两年」，并回到枣糕和五道口。
- 最值得学的 1–2 个技巧：用一个与主题无关的物件（枣糕）当情绪锚，开头、中段、结尾各出现一次；公司大事件只当背景，正文写个人。
- 相对手册：补充证据——手册里「我错过了老东家智谱AI的股票」的前员工身份，这里是更早、更纯抒情的一版，证明「身份越具体情绪线越强」。新手法——括号副题；整篇散文体、结尾用「谢谢你，X」致辞收；新闻截图压在文末而不是正文里。

## 《我终于理解阿里为什么要做千问了》（2026-01-15）
- 类型：公司或财报解读（千问接入淘宝、支付宝等阿里系业务的商业逻辑）
- 叙述者身份及作用：研究过 MCP 的行业观察者。「去年4月，我在研究MCP时，就有个判断」——用自己过去的预判给今天的判断加分。
- 标题拆解：第一人称认知句「我终于理解 + 公司 + 为什么要做 + 产品」。「终于」暗示长期困惑被解开；「为什么」是悬念；品牌放中间。第一句正文就是标题原话。
- 开头：复述标题 → 「过去一年……我听到了太多逻辑不通的故事」→ 列两种走不通的路（会员、广告）→ 「直到今天……我才突然把这件事想明白」。靠先否定别人的答案留人。
- 骨架：困惑（To C AI 怎么赚钱）→ 旧答案被否 → 新事件 → 我的答案（总入口）→ 演示（点奶茶 live 图）→ 三点价值（频率、交叉销售、数据质量）→ 我去年的判断应验 → 旅行场景「折叠进一个对话框」→ 政务服务延伸 → 第三次人机交互革命（Click / Touch / Communicate）→ 只会聊天的 AI 会贬值。
- 论证与证据、数字怎么讲：没有硬数字，用「几十次点击，几十次跳转」对比「一个对话框」；用三次交互革命的历史类比拔高。
- 主角 / 品牌怎么进场：先讲行业困惑两三段，再让千问作为「答案」出场；有产品演示截图。
- 节奏与语言特点：「第一，第二，第三」；「我甚至认为」递进；判断句多。
- 结尾：「能办事的Agent，才更有机会拿到入场券」，对仗判断（只会聊天 vs 能办事）。
- 最值得学的 1–2 个技巧：「我早就判断过……现在应验了」给观点加时间纵深；把一长串操作压成「折叠进一个对话框」一个动词。
- 相对手册：新手法——「我终于理解 X」第一人称认知标题（手册的第一人称句式是动作「我让 / 我拿来」，不是认知「我终于理解 / 我发现」）；「引用自己过去的预判」作为证据。补充证据——标题就是正文第一句（手册 3.2）；「过去……现在」（手册 7.4）。

## 《外媒报道智谱华为合作，就问英伟达慌不慌？》（2026-01-16）
- 类型：行业观察（智谱 + 华为在国产芯片上训出 GLM-Image）
- 叙述者身份及作用：刷到外媒报道的人，也自己试了模型。「我根据公开技术细节推测」——明示是推测，保留余地。
- 标题拆解：两段式，前段「外媒报道 + 两家公司合作」借第三方，后段「就问英伟达慌不慌？」挑衅式反问，把竞争对手拉进标题制造对立。口语「就问」。
- 开头：「最近偶然刷到某知名外媒的一篇报道」，接「标题有点唬人」，「我赶紧把这篇报道看了几遍」。靠转述一个有冲突的外媒标题留人。
- 骨架：刷到报道 → 引爆点（智谱 + 华为）→ 意义（铁律被砸开一条缝）→ 「真正有意思的点」：外溢能力（OpenAI、路透社都提过）→ Google TPU 类比 → 我试了一下 → 现实变量（算力租赁价格、断供）→ 上半场 / 下半场 → 推测芯片型号 → 回答标题「慌不慌」→ 期待。
- 论证与证据、数字怎么讲：数字少，靠多重第三方（外媒、OpenAI 报告、路透社、HuggingFace 榜单第一）叠加可信度；用「中国版的TPU故事」一句类比。
- 主角 / 品牌怎么进场：借外媒之口带出智谱，是「借第三方背书」的极致版：标题第一个词就是「外媒」。
- 节奏与语言特点：情绪化口语（「眼巴巴地指望老黄的卡」「此路已通」）；「上半场 / 下半场」。
- 结尾：「从一种受限的资源，变成了一种普惠的电力」，比喻收尾。
- 最值得学的 1–2 个技巧：在正文里明确回答标题的问题（「所以英伟达慌不慌？」→ 从必需品变成可替代方案）；推测处主动标「我推测」。
- 相对手册：补充证据——借第三方之口（手册第 8 节），上半场 / 下半场（手册第 10 节）。新手法——标题把对手（英伟达）放进来当靶子的挑衅问句。

## 《扣子2.0让prompt没那么重要了》（2026-01-20）
- 类型：实测（教程型：把自己的 vibecoding 经验做成 Skill 上架扣子技能商店）
- 叙述者身份及作用：自己做了一个「前端开发专家 Skill」的创作者。身份是「生产者」而非「用户」，让教程有真实产出。
- 标题拆解：「产品 + 让 + 旧东西 + 没那么重要了」，反常识判断（prompt 不重要了），品牌开头，无标点。「没那么」比「不」更克制。
- 开头：「很多非技术出身的人」容易被「vibecoding撩得心痒」，立靶子；列两条常见路（超长 prompt / 啥都不管），结果是「一眼AI味」的蓝紫色。靠读者熟悉的失败留人。
- 骨架：两条失败路 → 真正缺的是「把隐形标准变成稳定输出」→ 我做了一个 Skill → Skill 和 prompt 的区别 → 四步教程（入口、一句话写清、生成预览、发布）→ 实测（俄罗斯方块）→ 「但我想表达的其实不是……」→ 经验不流动是职场痛苦 → 邀请试用。
- 论证与证据、数字怎么讲：无数字；用对比句解释概念：「prompt是你每次临场发挥」「Skill是把标准固化下来」；类比「可重复启动的按钮」「经验包」。
- 主角 / 品牌怎么进场：扣子在标题里，但正文先讲 vibecoding 的痛点，第 4 段才出现；品牌是「我上架作品的平台」。
- 节奏与语言特点：教程段落密；「蓝紫色」作为一个反复出现的 AI 味符号（开头、第二步、成品各出现一次）。
- 结尾：「欢迎你把自己的经验也做成一个技能丢上去」，行动邀请。
- 最值得学的 1–2 个技巧：用一个具体的视觉符号（蓝紫色）代表「AI 味」，反复回扣；教程写完后用「但我想表达的其实不是……」把工具稿升到一个职场判断。
- 相对手册：补充证据——「很多人以为……其实」纠正预期；「提示词原文照贴」（手册 5.1）。新手法——叙述者是「上架作品的创作者」，教读者把经验做成可分发的东西，读者也被邀请成为创作者；「但我想表达的其实不是X」的转折，把教程拔成观点。

## 《孩子能不能用AI？别把认知外包就行！》（2026-01-22）
- 类型：活动见闻（阿里千问「孩子到底能不能用AI」线下研讨会）
- 叙述者身份及作用：听完研讨会的人，有自己的分类框架（省力型 / 增强型）。身份不具体，主要作用是整理嘉宾观点。
- 标题拆解：问句 + 答句「孩子能不能用AI？别把认知外包就行！」，自问自答，把结论直接写进标题；带感叹号；「认知外包」复用了 MIT 那篇的概念。品牌（千问）不进标题。
- 开头：「我听完阿里千问的那场」研讨会，「脑子里一直绕不开一句话」，再引嘉宾金句「AI已经成为孩子书包里的第四件文具」。靠一个有画面的比喻留人。

- 论证与证据、数字怎么讲：「700万台是什么概念？」自问后给「行业第一」；「那是3000万次真实的人机对话」——把数字还原成行为。演示指令用读者能想象的原话（外卖小哥、樱花大道）。
- 主角 / 品牌怎么进场：先讲个人失败（第 1 屏），再用「如果你最近半年买了辆新车」拉近陌生品牌（火山 = 豆包背后），第 2 屏出场。
- 节奏与语言特点：「我想先说一件有点扎心的事」；「你跟真人说话，也不需要先说一句……」生活类比；口语「妥妥的」。
- 结尾：「当年我在那辆车里停车失败之后」→「现在我觉得，也许不用等那么久了」，回到开头物件。
- 最值得学的 1–2 个技巧：开头的失败指令（停到离入口最近的车位）在正文被原样重测一次、结尾再回到那辆车——一个细节三次出现；标题用八卦词（人脉），正文专门写一段把它翻成技术结论。
- 相对手册：补充证据——首尾呼应开头物件（手册第 10 节）；标题场景在正文单独验证（手册 5.1）；大数字配解释（手册 7.1）；借读者熟悉的产品介绍陌生品牌。新手法——「啊？？……吗？？？」语气词 + 多问号标题（手册：只有 1 篇带感叹号，省略号是招牌，没有多问号的写法）；标题故意用一个带误导性的八卦词，正文收回。

## 《啊？谁还想认真逛超市啊？》（2026-04-24）
- 类型：活动见闻（天猫超市 AI 发布会，李诞站台）
- 叙述者身份及作用：会在货架前纠结的普通消费者，「今天看了一场有点奇怪的发布会」的观众。
- 标题拆解：「啊？」+ 反问「谁还想认真逛超市啊？」，与同日火山稿同一模板（语气词开头 + 问号）。无品牌、无 AI 字样，全靠生活场景。标题的反问正文的回答是「AI 替你把判断做了」。
- 开头：「有一种烦是说不清楚的」→ 两个「比如」：打开购物 APP 看五分钟关掉；洗发水拿起放下。第二人称生活细节，读者代入。
- 骨架：说不清的烦 → 本质是判断成本太高 → 线上购物放大问题 → 传统电商没管「买什么、什么时候买、买多少」→ 奇怪的发布会（李诞讲 AI）→ 李诞第一句话 → AI 家庭购物管家（洗洁精 500ml 例子）→ 主动预判 vs 被动响应 → 李诞第二句话（物流）→ 预判达 → 商家工作台 → 李诞第三句话 → 技术成熟的标志是让你忘记它 → 结尾。
- 论证与证据、数字怎么讲：数字少；用「洗洁精，500ml……这周差不多见底了」一个具体家庭场景代替功能描述；时效曲线「次日达 → 半日达 → 4 小时达 → 预判达」。
- 主角 / 品牌怎么进场：先写两段读者的烦，第 2 屏借「这个画面本身就有点错位」（文科生聊 AI）引出李诞，再由李诞的话带出天猫超市。名人作为三段引语的分节器。
- 节奏与语言特点：「这句话初听像段子，但它说的是真事」；「小哥那一公里你看得见」对「AI跑的那一步」看不见的对仗。
- 结尾：「你甚至不会觉得这有什么了不起」→「但这才是真正了不起的地方」。
- 最值得学的 1–2 个技巧：用名人的三句话当三节的开关，每句话后面接一个具体功能；「技术成熟的标志是让你忘记它的存在」+「你不会每次开灯都想到电」一句判断配一个生活类比。
- 相对手册：补充证据——「先吐槽读者也烦的东西」起手（手册第 4 节第 5 种）；主动降调落到小事（手册第 10 节）。新手法——「啊？」语气词标题（同上）；名人作为「错位」看点（文科生讲 AI）而不是权威背书。

## 《市场上多一匹马，永远比只剩一个选择更安全》（2026-04-28）
- 类型：实测 + 行业观察（阿里 HappyHorse 1.0 视频模型，舆论反转后的评价）
- 叙述者身份及作用：自己试了两天的用户，也替中小创作团队算账的人。
- 标题拆解：比较判断句「多一匹马，永远比只剩一个选择更安全」，「马」双关（产品名「快乐小马」）；无品牌名，只有谐音暗示；「永远」绝对化。标题即全文最后一句。
- 开头：「快乐小马这事，最近有点冰火两重天」→「20天前，它还在匿名登顶」→「20天后，舆论突然转向」。时间对照 + 反转留人。
- 骨架：舆论反转 → 我想聊的不是反转而是「多一个选择」→ 先承认 SD2 强 → 为什么需要更多模型 → 建议自己试 → 试用门槛（千问里能用、66 积分、70 元一个月）→ 长处 → 短板（跳切、站位、背景板、音画同步）→ 不会说追平也不该踩死 → 价格对比（720P 九折、1080P 六五折、会员 0.44 vs 0.72 元每秒）→ 价格锚点为什么关键（按试错算成本）→ 真正的用户是内容公司 → 编辑能力 → 意义：互相施压 → 产业接入 → 市场分化 → 小马的位置 → 「这才是1.0版本」→ 生活类比（外卖打车留两个 App）→ 标题句。
- 论证与证据、数字怎么讲：价格数字全部换算成折扣（「720P大概是九折」「1080P大概是六五折」）和日常参照（「大概两杯咖啡的钱」）；「而是按大量试错算的」把价格差翻成生产逻辑。
- 主角 / 品牌怎么进场：第一句就出现，但立场先设成「为竞争辩护」而非「为产品辩护」；先承认对手（SD2）强，再讲主角的价值。
- 节奏与语言特点：「我并不否认SD2强」「我不会说……但我也不觉得……」双向让步；文末夹活动福利（7 折、0.44 元每秒）。
- 结尾：「市场上多一匹马，永远比只剩一个选择更安全」，回扣标题原句。
- 最值得学的 1–2 个技巧：舆论反转时不站队产品，而是把问题抬成「市场需要多一个选择」，产品只是这个论点的例子；价格数字一律换成折扣和两杯咖啡。
- 相对手册：补充证据——主动写翻车（手册 7.6，本篇写了四处短板）、对比让主角赢一项并承认对手（手册 5.1）、首尾回扣标题（手册 3.2）、大数字配参照物（手册 7.1）。新手法——舆论反转期的「中间立场」写法：不替产品辩护，替「竞争」辩护；标题用产品名的谐音 / 双关（马）而不写品牌。

### 2. 手册里没有的新手法

1. **推荐体标题「强烈推荐你去看 / 去用 + 权威对象」**：MIT、陶哲轩、字节手册、ClawHub。只写对象不写观点，靠「这篇 / 这份 / 这个」的指代制造好奇。早期用于论文、访谈，后期用于工具和资料。
2. **第一人称认知标题「我终于理解 / 我有一种直觉 / 我发现 X 才是 Y 真正的主角」**：阿里千问、双子星、MiniMax ARR。手册的第一人称句式都是动作（我让 / 我拿来），这里是「想通了」的顿悟时刻，适合解读稿。
3. **语气词 + 多问号标题「啊？？原来……吗？？？」「啊？谁还想……啊？」「哇，又看到……」**：火山、超市、哇。都出现在 2026-02 之后，其中两篇是同日（04-24）的活动稿，是一种吃瓜惊讶口吻。
4. **标题用八卦词或双关，正文把它收回**：火山「人脉」→「人脉的底气说到底还是技术」；小马标题「多一匹马」谐音产品名。
5. **「A 像 X，B 像 Y」双比喻标题**：可灵 3.0 像武当太极、Seedance 2.0 像华山快剑。一个比喻同时完成定性和对比。
6. **括号副题做情绪钩子**：《我眼中的智谱AI（深圳看不到星星）》，副题与公司无关，把财经事件写成个人散文。
7. **人物特写骨架**：印奇篇，新闻 → 简历 → 早年 → 回到新闻 → 「这个人才是最大变量」，并解读当事人发的配图。
8. **资料领取式结尾**：字节手册「我问他们要了一份完整的手册」，并说放在附件里。手册的结尾类型没有「给资料」。
9. **引用自己过去的判断当证据**：阿里千问篇「去年4月，我在研究MCP时，就有个判断」→「现在看来，这个判断应验了」。
10. **账号内自有概念 / 老熟人信源的跨篇复用**：「认知外包 / 认知债务」从 MIT 篇延续到孩子篇；陶哲轩在 01-06、04-14 两篇里出现；「双子星」在 02-12、02-14 两篇里出现；「前阵子我测过洗车那题」把单篇测试做成系列。
11. **让读者先答题**：哇篇把题目原文放在第一段，「你一眼看过去，可能下意识就有答案了」，读者先答再看模型答。
12. **金句作副歌**：方言篇「语言是文化最后的容器」在中段和结尾前各出现一次；抒情段插进测评稿。
13. **舆论反转期的中间立场**：小马篇不替产品辩护，而是替「市场多一个选择」辩护，产品变成论点的例子；先承认对手强，再写自家四处短板。
14. **读者先猜、名人当分节器**：超市篇用李诞的三句话切分三节，名人的看点是「错位」（文科生讲 AI），不是权威。
15. **「X 本身不是新闻，真正罕见的是 Y」**：大公司篇，先承认表面事实，再指向更深的看点；顺手解释数据源（OpenRouter）为什么可信。
16. **品牌公益稿写法**：尊重篇完全不涉及 AI，用「具体的人 + 精确到角的数字 + 一个抽象价值词」，并主动回应「作秀」质疑。

### 3. 和手册结论冲突的地方

1. **开头不一定是「时间词 + 我 + 具体场景」**。手册说「没有一篇用大背景起句」。本组至少 3 篇用宏观判断或背景起笔：千问 3.5「真正能决定一个时代胜负的模型」、方言「中国有大量的方言内容没有被好好存档」、大公司「最近AI行业有个现象挺有意思」。另有 3 篇用「强烈推荐你去看」起笔。开头三段出现具体的「我」的场景的，本组约 15 / 26，低于手册的约 8 成。
2. **主动降温 / 让步不普遍**。手册「当然」出现在 25 / 78 篇；本组只有 4 / 26。《我们要面对的……》全篇没有让步，以「没人能躲得过去」高压收尾，数字不注出处；《千问 3.5》《杨丽萍》《双子星》都没有写任何局限。
3. **「刚好」式进入不是主流**。本组只有 5 篇用「刚好 / 正好」。更常见的进入方式是「刷到新闻」直接引出主角，或借嘉宾 / 名人 / 外媒之口。
4. **感叹号和问号不克制**。手册说 78 篇只有 1 篇带感叹号、省略号是招牌；本组 2 篇带感叹号、5 篇带问号（其中 2 篇多问号），没有一篇用省略号。
5. **「每个概念接一个类比」不稳定**。老黄篇的 mHC、Muon、Int4QAT，千问 3.5 的 397B / 17B MoE、门控注意力，都是只报名词和数字不做类比。
6. **身份不一定具体**。手册说「几乎每篇都有具体身份的我」。本组至少 8 篇的「我」只是「看到 / 刷到的人」，或几乎不出现（千问 3.5、大公司、学术圈、ClawHub、陶哲轩、MIT、杨丽萍、印奇）。MiniMax 篇也没用手册提到的「小股东」身份。

### 4. 时间上的变化

- **2025-12 到 2026-01（9 篇）：早期「推荐 + 转述」期。** 页面顶部能看到阅读数（17、18、41、132、133 阅读），账号还很小。标题多「强烈推荐你去看」和第一人称认知句（我终于理解、我眼中的）；正文多是转述一篇论文 / 演讲 / 访谈 / 外媒报道，叙述者是「看完的人」；开头多复述标题；「我」的具体场景少。阅读最高的两篇（智谱 132、印奇 133）一篇是前员工散文、一篇是人物特写，都是有「人」的稿子（仅两个数据点，不能下结论）。

- **2026-04（7 篇）：场景化与语气词期。** 开头明显更像手册描述的样子：个人失败（车机停车）、生活烦恼（货架前纠结）、舆论反转（20 天前 / 20 天后）；首尾呼应和回扣标题更常见；主动写短板（小马四处短板）；标题出现「啊？」语气词和多问号；抒情段、副歌金句出现（方言）。最长的一篇（方言，约 2500 字）也在这一段。
- **总的走向**：从「我推荐你看 X」（转述别人）走向「我遇到了 X」（自己的场景）；从通稿式品牌稿走向「先讲读者的烦，再让品牌出场」；标题从说明性（推荐体、我终于理解）走向情绪化口语（啊？、哇、双关）。手册总结的「时间词 + 我 + 具体场景 → 反差 → 主角第 2 到 3 页出场 → 写一处翻车 → 回扣」这套配方，在本组 2026-04 的稿子里最完整，在 2026-01 以前的稿子里基本还没成形。
