# Krypto说AI · 文风蒸馏手册

> 给后续写作 agent / 编辑的 system 规则。每条规则至少能从 `对标/` 里 1 个样本反推。  
> 账号定位：AI 科技解读 · 把英文圈或硬核信源讲成人话（youtube-xhs → 小红书两件套）。  
> 蒸馏日期：2026-10-20（Asia/Hong_Kong）  
> 样本范围：`对标/` 下 16 个子目录；精读清单见附录 H。

## A. 总论：什么叫「竞品级叙事感 + 真人感」

编辑打开成稿，用下面 8 条做是非判断。**全部满足才算过线**；缺一条就退回改，不要用「加几个我觉得」补洞。

| # | 判断标准 | 过线长什么样 | 不过线长什么样 | 样本依据 |
|---|---|---|---|---|
| 1 | **一篇只有一个来源、一个人、一件事** | Jen Abel 一期播客 / Karpathy 一条推 / 一份 Anthropic 报告 | 「我对行业的三到五个判断」拼盘 | 西元Tech拆解 §五；Kai科技说三篇 |
| 2 | **判断对着世界或读者处境，不对着「这篇文章」打分** | 「海底捞肯定会提供订餐 Agent」「新人只招 9%，岗位在重新定价」 | 「整篇我就认这一条」「这条我不同意」 | 小盖口吻拆解 §25；未署名_JackClark奇点稿拆解 |
| 3 | **具体场景（或主角处境）出现在抽象判断之前** | 凌晨三点半打不到车 → 再讲预约功能；1978 紧张到想吐 → 再讲神话 | 抽象判断接抽象判断；金句飘着 | 华一说AI/peterdeng；玉伯乔布斯稿；小盖 §29 |
| 4 | **「我」只做三件事：听了/试了/看完了；一两处感受；结尾一句自己的话** | 华一全文「我」3 次；西元「太颠覆了」「这话太重了」 | 模板凑齐：stance + 3 个我觉得 + 2 个假设 + 回指 + 押注 + 局限 | 华一说AI拆解「六条差距」；西元Tech拆解 §五.2 |
| 5 | **读者被点名成身份，不是情绪** | 「做 B2B / 创业 / GTM 的你」「正在找工作的朋友」 | 「怕被 AI 淘汰的人」 | 西元Tech拆解；Echo note拆解 §一.4；小盖 Anthropic 稿 |
| 6 | **一个意思允许说两到三遍：口语版 → 展开版 → 加粗/大白话收束** | 「它只是一套记账方式」→ CFO 视角 →「财务抽象，不是操作地图」 | 每句必须带新事实 → 虚词被挤掉 → 电报腔 | 西元Tech/Jen_Abel；西元Tech拆解 §三.1 |
| 7 | **主动写一处具体局限或翻车，且说出卡在哪** | 「复杂物理接触仍然很难模拟」「这些结果还局限在特定任务」 | 「当然也有局限」空姿态；或零局限通稿 | 小盖自然意志稿；MemeInformation手册 §8.10；追光 part4「很模糊，只是开始」 |
| 8 | **读完能带走一样东西：一个数字、一招、一张自检、一个时间戳清单** | 赢率 25%–35%；八招表；演示前准备会 15 分钟 | 只有态度没有物件 | 西元 Jen；玉伯末尾「值得记住的」；Echo 分人群带走 |

**一句话定义（给 agent）：**  
竞品级 = 读者停得住、记得住、能转述给同事；真人感 = 像受过高等教育、有 AI/科技经验的人在跟朋友复述一件真事，而不是在填写作槽位。华一拆解的根因写得很清楚：往清单上加「至少」会叠出 AI 味；竞品只是把真人讲的真事用顺的中文转述一遍，最后自己说一句。

**与 qualia 写作要求的对齐（`对标/写作要求_qualia/原文.md`）：**  
讲清楚别压缩；说具体说准确；不表演深刻；不预设读者肤浅；不表演情绪；中文要像中文（禁单字动词腔）；用自然段写。本手册所有母版默认服从 qualia；与竞品样本冲突时，**保真实场景与具体局限，砍表演句**。

## B. 可复用叙事母版（5 套）

每套：适用题材 → 骨架（4–7 步）→ 示例开篇 2 句 → 示例结尾。开篇/结尾为示范句式，成稿须换成当篇素材事实，禁止原文照搬。

### 母版 1 · 转述荐读（华一 / Echo 主模）

**适用：** 访谈、播客、人物长文、英文长文精读；原文故事多、细节真。  
**样本：** `华一说AI/peterdeng_文字稿.md`；`Echo note回响阅览室/拆解.md` 四篇骨架。

**骨架（6 步）：**
1. 荐读表态 + 点名读者身份（一句，直白可土）
2. 这人是谁 + 一个反常识细节/数字（履历压进半句可搜标签）
3. 「最让我改观/停下来的一件事是：……」（编辑声音框，全文论点首页亮出）
4. 4–6 个小标题 = **一件事或一种感受**（不是对仗金句）；每节：场景 → 他说 → 半句编者提炼
5. 段内过渡带着走：「所以在这期里」「聊到这里」「只看这句话容易理解成……但还有一层」
6. 结尾：「以前我以为……现在觉得……」+ 分 1–2 类读者各带走一句；「我」认同最多一句

**示例开篇：**  
「非常推荐把这期 Peter Deng 访谈读完。正在做产品、带团队，或在考虑下一份工作的人，都能从他的经历里拿走几条能用的尺子。」  
「他是 Facebook 早期第四名产品经理——五点飞机、凌晨三点半打不到车，夜里睡不踏实，才是他们做预约用车的真正起点。」

**示例结尾：**  
「以前我以为好产品是功能堆出来的，现在觉得更像把用户夜里那点心神不宁拆开。如果你在带团队，记住『六个月还在手把手教，先查选人』；如果你在找下一段工作，把『还能不能学到东西』和薪资摆在同一张桌上权衡。」

**适合 Krypto：** 默认主模。youtube / 播客 / 论文访谈优先走这条。  
**不适合照搬：** Echo 末页卖订阅、站外领取；华标题「简直夯爆了」可学直白，但账号少用极限词堆叠。

### 母版 2 · 颠覆常识精读（西元主模）

**适用：** 有来头的人抛出一个反常识数字/区分；读者有明确职业身份。  
**样本：** `西元Tech/Jen_Abel_ToB销售.md`（7718 赞）；`西元Tech/Mark_Pincus_烫知识.md`。

**骨架（7 步）：**
1. 「最近听了一期……太颠覆了。」（感受在门口）
2. 人是谁 + 一句人话比喻（人类学家 / 恋爱类比）
3. 点名读者：「不论你是做 B2B / 创业 / GTM……」
4. 每节一个点：抛观点 → 说两到三遍 → 一个例子 → 节尾一句大白话
5. 「你」的处境整段出现（主语是你，不是作者）
6. 转述词当节奏：「Jen 说」「Mark 的意思是」（每千字 3–6 处）
7. 结尾一句温和但沉的判断；可给一个自测题带走

**示例开篇：**  
「最近听了一期 Jen Abel 讲企业销售的播客，太颠覆了。」  
「不论你是做 B2B 产品、创业，还是负责 GTM，这期里有一组数字会直接打翻你原来的赢率直觉。」

**示例结尾：**  
「听完整期，最大的感受是：真正卖得好的人，做的是产品经理的事——找 champion、识别 blocker、管预期。慢下来，才能跑得快。」

**适合 Krypto：** 海外播客里「反常识数字 + 对你意味着什么」类；标题可走「关于 X，我听过最颠覆的一期」。  
**不适合：** 纯工具配置、无读者身份的评论员腔（同目录 Peter 稿 196 赞是反例：虚词低、「你」为 0）。

### 母版 3 · 一手动作链 / 招式实测（小盖第二批 + Kai）

**适用：** 自己真跑过、真配过、真翻过车；或「一招 + 昨天干的事」。  
**样本：** `小盖/口吻拆解.md` 第二批 Jev/Kimi；`Kai科技说/Karpathy_不返工.md`；`Kai科技说/DeepSeek_Harness_教程.md`；Meme 成熟期实测（如电脑忘在公司）。

**骨架（6 步）：**
1. 第一句 = 判断或意图（不是「今天刷到」）
2. 第二句 = 带专名/数字的事实；信源半句带过
3. 按「我做了什么」时间顺序，或编号 1…N（每个编号开头就是判断句）
4. 新概念先放进已知清单当「第 N+1 个」；名字放在解释后面
5. 一组例子用到底；每篇一次「换一群读者再讲一遍」（程序员伪代码 / 非技术场景）
6. 结尾往下收：「还行还行。」/ 先降温再一句温和判断；不回扣升华

**示例开篇：**  
「越来越觉得，只靠『再改一版』已经救不了 AI 输出。」  
「这几天试了 Karpathy 推上的几个思路，才明白问题常常不在模型，而在你要它交出来的形式。」

**示例结尾：**  
「以后再觉得 AI 输出不好用，别只会说『再改改』——直接让它换一种你要的形式。」

**适合 Krypto：** agent 怎么配、提示词、工具上手；收藏导向用编号知识体（Kai DSH 藏>赞）。  
**不适合照搬：** 小盖的银杏/山西/孩子经历（没有就不借）；Kai STEPX 品牌感叹号稿（无读者、不火）。

### 母版 4 · 概念翻转解读（小盖讲课腔 + JackClark 对照）

**适用：** 论文、技术报告、公司动作、硬概念；要把「事不关己」拧成「你的活会被重新定价」。  
**样本：** `小盖/自然意志稿_文字稿.md`；`小盖` 字节 Seed 截图拆解；`未署名_JackClark奇点稿/拆解.md`；追光「现象先行」。

**骨架（7 步）：**
1. 门口一句带脸的态度（骂一种现象 / 「我天，带了个好头」）——情绪归自己，不替读者预设焦虑
2. 一个已知锚用到底（GPT-3 / 考试 / 造神 IPO）
3. 品类里还有谁 → 只挑 1–2 件不一样的事从零讲清
4. 「读者直觉 → 翻过来」：「我们很自然会觉得 A 更强，对吧？真机上可能完全不同。」
5. 用动作/岗位/钱当证据，不堆只有圈内懂的跑分
6. 自己泼冷水 2–4 次，每次说出具体技术/组织难点
7. 结尾回到锚 + 普通人该守住什么（定方向、拍板、对结果负责）

**示例开篇：**  
「你可以不信『奇点』这个词——但有的实验室已经按这个前提在调招聘和预算。」  
「初级技术岗新人占比从 27% 掉到 9%，这种数每个打工人都有体感；跑分只有圈内有感觉。」

**示例结尾：**  
「争论定义没那么要紧。更要紧的是：熟练手艺贬值之后，你还能不能快速定方向、敢拍板、为结果负责。」

**适合 Krypto：** 英文报告、安全对齐、就业/Agent 工时、具身/模型论文的「人话版」。  
**不适合：** 无锚点的空评论；软广话术「零门槛」；极限词堆「最耐人寻味」。

### 母版 5 · 时间线 × 分类双骨架（玉伯 / 追光信息型）

**适用：** 人物方法论、发现史、多招数清单且要收藏。  
**样本：** `玉伯/乔布斯讲故事_原文.md` + 拆解；`追光_3D科普/拆解.md`（现象→年份实验链→落到人）。

**骨架（5 步）：**
1. 开头 = 主角狼狈/反差处境（不是作者判断）
2. 小节同时推进：时间（或发现顺序）+ 手法/实验名
3. 每节：一个摸得着的物 + 可选一个反面人物（反面用同一组人跟到底）
4. 专名首次出现后 20 字内给人话注（「12 磅约合 5.4 公斤，一个人拎得动」）
5. 结尾领取物：值得记住的表 / 原片时间戳 / 延伸阅读带一句理由；先降调再升

**示例开篇：**  
「1978 年，地方电视台开录前，他紧张到想吐。」  
「后来被讲成神话的那个人，起点就是监视器里那个想吐的自己。」

**示例结尾：**  
「很模糊，只是开始。可这个开关，来自一颗绿藻。——值得记住的八行清单见末页。」

**适合 Krypto：** 长 YouTube 精读要「收藏清单」时；图下正文.txt 的领取物结构直接抄玉伯三段。  
**注意：** 玉伯全文无「我」，靠本人名气；Krypto 粉丝少，仍要首页一句、结尾一句「我」。篇幅压到小红书 1300–2200 字量级，只留 3–5 节。

## C. 句式与节奏清单

### C1. 要

| 要 | 做法 | 样本 |
|---|---|---|
| 虚词撑口语 | 的了就是其实这个那个啊呢吧；成稿虚词占比尽量 ≥30%（讲课腔解读可略低，但须有场景/泼冷水补偿） | 西元 Jen 34%、Mark 36% vs 电报稿 28% |
| 多字自然动词 | 「带来安全感」「帮对方理清思路」「把价值主张送到该听的人那里」 | 华一全文；西元长句 |
| 「你」的处境 | 每节至少一段主语是「你」；reader 写成职业身份 | Mark 每千字 31 个「你」 |
| 转述词当节奏 | 「他说 / Jen 说 / 按作者的说法」每千字 3–6 | 西元；玉伯 18–20 处挂作者 |
| 短段呼吸 | 20 字内短段可到 25%–30%；单句段仅三种：带态度的判断、说话人动作、给上文起名——且前一段须是具体场景 | 西元拆解；小盖 §21 |
| 数字带参照 / 立刻解读 | 「0.5 毫秒对人眼 10 毫秒」「这说明……」 | 追光；Meme手册 §8 |
| 一个锚/意象用到底 | GPT-3、考试、造神 IPO、蓝光、照片 | 小盖 Natura；追光；小盖 Muse |
| 概念名放解释后 | 先讲完再「这就是 Machine Native / 生态」 | 小盖 Jev §15 |
| 正在想的毛边（少而真） | 「好像……真的来了。真的来了。」「现在不敢下结论。」——有则用用户原话，无则不编 | 小盖 Personal Agent |
| 页末钩子 | 每页最后一句 ≤22 字，逼翻页；或断在半句 | Meme手册 §7 |

### C2. 不要

| 不要 | 替换 | 样本反推 |
|---|---|---|
| 单字动词谓语：「到」「立」「强」「给了口径」 | 改成完整动词短语 | 西元Tech拆解 §二对照表 |
| 「不是 X 是 Y / 能 X 不能 Y」对仗堆砌 | 小标题改成「一件事」；全篇对仗 ≤1–2，且前有场景 | 华一拆解差距 2 |
| 「真正的问题是 / 本质上 / 说到底 / 值得注意的是」表演深刻 | 删引导语，直接写普通具体句 | qualia §三 |
| 「很多人以为……其实……」虚构误解 | 仅当误解真实存在并点明是谁；否则直接说正确内容 | qualia §四；小盖「读者直觉」须是推理不是情绪操弄 |
| 每句新事实、不许重复 | 允许口语→展开→收束说三遍 | 西元 §三.1 |
| 首屏锚点堆满（一句 3+ 专名） | 每句最多一个专名或数字；前 200 字最多四个锚 | 西元拆解待议 |
| 英文专名 / 千字 >25、数字 / 千字 >8（解读/自述） | 专名换「他/这家公司/这个模型」；首次加注 | 李录爆款英文 17/千 vs Wang 63/千 |
| 「零门槛 / 完全不用学 prompt」 | 写真实步骤与会翻车处 | Meme手册 §9 反面 |
| 预告下一期、关注话术空喊 | 回指已发稿；结尾停在判断或领取物 | Meme §12；小盖规则 |
| 假设场景冒充经历库真事 | 「假设我」日常推演可有（带时间地点），标注为推演；真日程须用户提供 | 小盖 §26 vs 华一「细节是原文真有的」 |

### C3. 替换表（电报腔 → 人话）

| 电报腔 | 人话 |
|---|---|
| Codex 工作里天天用，代码强。 | 写代码这件事，日常我更常把它交给 Codex。 |
| 钱有多大，Zuckerberg 给了口径：…… | 钱要砸到什么量级，他后来给过一个算法：…… |
| 能力顶级，最核心任务给 Claude。 | 最难、最不能翻车的那几步，才轮到 Claude。 |
| Meta 先押一千多亿，Muse 却连影都没有。 | Meta 这边已经按千亿级在铺算力；Muse 那条产品线，外界却几乎还看不见成品。 |
| 三个模型三张桌子，哪个榜单也排不出这个分工。 | 分工不是榜单能排出来的：有的模型适合日常改稿，有的适合最后把关。 |

## D. 标题与封面文案公式

### D1. 标题公式（可 A/B）

| 公式 | 样例（竞品原题或结构） | 来源 | Krypto 用法 |
|---|---|---|---|
| 情绪荐读 + 后半人名/信源 | 「强烈推荐去看数学家陶哲轩近期关于AI的访谈」 | Meme 荐读期；Echo | 标题情绪，封面大字放可搜判断 |
| 平常话 + 句号 | 「我已经蹬完了 5 亿 Space Bunny Token。」「头一回这么深刻的理解了 RSI 的价值。」 | 小盖 | 实测/动作稿首选 |
| 对比句 + 句号 | 「Kimi 做 FDE 的路子，和 OpenAI 完全不一样。」 | 小盖 | 素材有两边时必出一条候选 |
| 逗号两段判断 | 「AI短剧，故事比画面更重要」 | Meme 成熟期 | 结论型解读 |
| 反常识 / 「真正的门槛」 | 「AI视频真正的门槛：听话」 | Meme | 判断压成口语词 |
| 认知差 | 「看来很多人没看懂字节昨天的决定。」 | 小盖字节 Seed | 新闻动作稿 |
| 颠覆数字型 | 「关于 ToB 销售，我听到过最颠覆的一期」 | 西元 | 播客精读 |
| 身份标签 + 人名 + 轻评价 | 「中国巴菲特李录对 AI 的理解，有点意思。」 | 小盖 | 人物稿；可搜标签优先于长履历 |

**禁忌（样本 + 账号定位）：**
- 前 6–8 字没有数字、读者处境或可搜专名（纯情绪「很少见到这么真诚的分享」Echo 可用，Krypto 搜索弱，慎做主力）
- 专名硬开头占比过高（Meme 22% 专名开头；Krypto 自有复盘里人名机构开头点击偏弱——以账号数据为准）
- 答案在标题里说完；超过约 20 字无呼吸
- 「笑鼠 / 有点子炸裂 / 啊？？」情绪口语期写法（Meme 后来自己收掉）
- 标题场景正文不兑现（Meme 反面教材）

### D2. 封面 / 首页大字

- **标题管情绪与点击，大字管信息与反常识判断**（Echo 拆解 §三；华一/西元首页人像或播客截图）。
- 首图优先：播客现场人脸、打印出来的报告照片、关键数据表红框——**物件与真人信号 > 空泛插画**（小盖 Anthropic 打印纸）。
- 图出现前先写「大家看右上角 / 最后一行」（小盖 §8）。

## E. 素材 → 成稿 Checklist（编辑工序）

用户丢来 YouTube / X / 新闻 / PDF 后，**按序执行**；写稿前缺日程与判断就停，先问用户（小盖第四批结论：规则生成不了判断与日程）。

1. **定母版：** 故事多 → 母版1；反常识数字+职业读者 → 母版2；自己跑过 → 母版3；硬概念/公司动作 → 母版4；多招收藏 → 母版5。一篇只用一套主骨架。
2. **一句话主线：** 「他讲了什么 → 对你意味着什么」；禁止「我的 3–5 个行业判断」当骨架（西元 §五；own 判断条数降至 1–2）。
3. **写 front matter：** `reader:` 一个职业身份；`source:` 一个；`mode:` retell / 实测 / 解读。
4. **抽 3–7 个真细节：** 必须原文或用户经历库有的；整齐假数字宁可删（华一差距1）。
5. **列小标题：** 每条 = 一件事或一个反常识判断；不是「能X不能Y」。
6. **写首页 200 字：** 我（听/试/看）+ 时间锚 + 画面或数字 + 转折；锚点 ≤4；第三段可放「最让我改观的是」。
7. **中段：** 每点「例子 → 这说明什么 → 放到你的工作」；转述词节奏；一处具体局限。
8. **结尾：** 改观框或降温判断 + 分人群带走 / 自检 / 领取物；不预告下一期。
9. **标题三条候选：** 至少一条对比或认知差；写完正文后可倒选「最狠的一句」当标题（Meme §4.2），再回扣结尾。
10. **qualia 过一遍：** 删表演深刻、删单字动词、段内因果写全、术语首次人话注。
11. **流畅度速查：** 虚词；「你」；英文/数字密度；有无场景在判断前；有无具体局限。
12. **图与图下：** 证据图红框；图下正文 = 关注理由一句 + 领取物（要点/时间戳/提示词），学玉伯与 Morry 末页唯一 CTA。

## G. 与竞品的差异化边界

**学叙事，不学人设照搬。**

| 学 | 不学 |
|---|---|
| 华一的转述分寸、「我」退后、小标题=事 | 假装有 Peter 级履历 |
| 西元的「你」处境、说三遍、颠覆数字 | 把读者写成「怕被淘汰」情绪人设 |
| Echo 的改观框、分人群带走、标题/大字分工 | 年费订阅与站外阅览室 |
| 小盖的编号判断句、已知锚未知、读者直觉翻转、具体泼冷水 | 银杏/孩子/山西；软广不标注；极限词「99%」 |
| Kai 的「一招+昨天的事」、教程一行一步 | 无读者的品牌软文 |
| Meme 的荐读+场景、页末钩子、局限标配、热点连发 | 前员工/股东身份；「刚好偶遇」软广；情绪口语标题主力 |
| 玉伯的双骨架、专名注、领取物表 | 全文零「我」；文末才露 AI 生成（发布须按平台规则披露） |
| 追光的现象先行、数字参照、先降调再升 | 未核实的「诺奖」事实；3D 片本身不是 Krypto 主产品形态 |
| TomCC 的「先处境再知识、锚词重定义」 | 除非做视频栏目，否则不搬宣纸水墨全套 |
| qualia 反表演 | 为像人而故意写糙 |
| Jessi/Roland/Morry 的定位锚、站队、视觉母版 | 整本增长课当正文发 |

**Krypto 独特位置（写进每篇自我检查）：**  
英文圈/硬核信源 → 人话；「我」= 每天读一手、用 Agent 干活的人，不是前大厂股东；判断少而硬；领取物是提示词/自检/时间戳，不是课程售卖。

**同质化红线：** 标题结构、封面模板、开头三句与对标账号撞车时，改第一句立场或证据顺序，保留母版骨架即可。
