# Krypto说AI · 发帖前写作 Checklist（一页）

> 配套：`Krypto说AI_文风蒸馏手册.md`。全部勾上再发。

## 选题与母版
- [ ] 一篇只有 **一个来源 / 一个人 / 一件事**（不是行业判断拼盘）
- [ ] 已选母版：□转述荐读 □颠覆精读 □动作实测 □概念翻转 □双骨架清单
- [ ] `reader:` 写成 **职业身份**（如「带团队的 PM」），不是情绪标签

## 首页 200 字
- [ ] 有「我听了/试了/看完了」+ **时间锚** + **画面或数字** + **转折**
- [ ] 前 200 字锚点（专名+数字）**≤4**；一句里不堆 3 个专名
- [ ] 可选：第三句「最让我改观/停下来的是：……」
- [ ] 已点名读者：「如果你正在……」

## 中段
- [ ] 小标题是 **一件事/一种感受**，不是「不是X是Y」对仗
- [ ] 每点：**例子 → 这说明什么 → 放到你的工作**
- [ ] 判断前有 **具体场景**（原文细节或用户日程；假整齐数字已删）
- [ ] 「你」的处境至少一段；转述词「他说」等作节奏（约 3–6/千字）
- [ ] **具体局限/翻车一处**（说出卡在哪，不是「当然也有局限」）
- [ ] 同一组例子/锚词用到底；概念名放在解释后面

## 语言（qualia + 西元）
- [ ] 无单字动词谓语（到/立/强/给口径…）→ 已改多字动词
- [ ] 无「本质上/真正的问题是/说到底/值得注意的是」表演句
- [ ] 虚词够口语；不在电报腔（名词+数字硬连）
- [ ] 专名首次有人话注；英文密度未爆（解读稿宜 ≤25 英文词/千字）

## 标题 / 封面
- [ ] 标题候选 ≥3；有两边时含 **对比句**；或含认知差/颠覆数字
- [ ] 标题场景在正文有兑现；结尾可回扣标题词
- [ ] 封面大字 = 反常识判断或可搜信息；首图 = 人脸/物件/红框证据

## 结尾与领取物
- [ ] 「以前以为…现在觉得…」或降温判断；**不预告下一期、不空喊关注**
- [ ] 分人群带走 / 自检问题 / 表格式领取物（提示词·时间戳·要点）有其一
- [ ] 末页 **唯一 CTA**；图下关注理由一句

## 红线
- [ ] 未借用竞品个人经历；未编经历库没有的日程
- [ ] 未整段抄增长 SOP；商单若有则按平台标注
- [ ] 与对标账号标题/开头未明显撞车（骨架可同，第一句立场须不同）
