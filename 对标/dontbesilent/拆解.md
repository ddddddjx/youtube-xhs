# dontbesilent《标准写文案五步流程》（@dbs_old_tweets 转发，原出处 2025-07-09；用户 11-21 发来截图）

原文截图：`五步流程_1.png` `五步流程_2.png`。例子是「你学习不好不是因为智商低，而是心理能量不足」。

五步：
1. 共情痛点：一个读者自己身上的场景（坐在书桌前一小时还在第一页）
2. 提炼冲突：一组核心冲突 + 一个比喻（智力硬件 vs 心理电源）
3. 提出框架：导致问题的三个原因（三大「漏电元凶」）
4. 注入共鸣：把核心比喻再强化一遍（后台流氓软件、劣质充电器）
5. 给出解法：解法一一对应第 3 步的三个原因

## 用在我们的稿子上（11-21 Brian Armstrong 稿第一次用）
- 第 1 步用「我」的真场景起笔，同时是读者的处境（被 agent 长回复淹没），符合 meme-v2「第一句一个人站在具体时刻里」
- 第 2 步的比喻用一个读者熟悉的锚用到底（老板桌：下属越能干桌子越满）
- 第 3 步三个原因编号写；第 4 步把播客主角的做法当成比喻的展开（桌上只放要签字的文件 / 幕僚长 / 每晚更新的员工手册）
- 第 5 步「我自己的做法」一一对应三个原因，做成一张对照卡，领取物放图下正文

不学：「这不是懒，而是……」「不是 X 而是 Y」句式、「元凶」这类夸张词、原文括号里那句「搞流量就不能说实话」的态度。
