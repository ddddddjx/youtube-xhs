# 《追光：3 分钟看懂 2026 诺贝尔生理学或医学奖》拆解

素材：用户 10-11 上传的三段（part1、part3 各 45 秒，part4 42 秒，1920×1080，60fps，part2 缺）。参考帧在 `参考帧/`（每 1 秒一帧的拼图 + 13 张单帧）。
主题：光遗传学（用光开关指定神经元）。片中「2026 年诺贝尔奖」这条我们没核实，学它的做法时别照搬这个事实。

## 一句话

**一个镜头不断地推进、穿透、拉出，把一条「发现链」讲完：现象 → 源头生物 → 按年份排的几个关键实验（每个实验一个人名、一个数字、一个画面）→ 应用到人。** 画面是有景深和辉光的 3D 微观世界，信息层像科学纪录片的 HUD，字幕跟着旁白逐字出现、关键词点金色。

## 让它显得「高级」的做法（前 12 条看 part1、part3；第 13～16 条看 part4）

**叙事**
1. **现象先行，身份后置**：前 15 秒只有一只转圈的小鼠，第 15 秒才说「诺贝尔奖」，第 17 秒才出片名。
2. **一条发现链**：每一步都是「年份 + 人名 + 一个发现 + 一个数字」，按时间往前走，观众感觉在看一个故事，而不是知识点清单。
3. **数字带参照物**：0.5 毫秒对人眼 10 毫秒；57 秒对 33 秒；35% 的时间僵住。
4. **一个母题贯穿**：蓝光（470nm）从第一帧到最后一帧，是开关、是片名、是治疗手段；源头绿藻在结尾又出现一次。
5. **讲到人收尾**：从小鼠、细胞一路走到一个 58 岁的失明男人；他出场时画面里只有暗处桌上一只杯子（part3 到这里截止，结尾没看到）。

**镜头**
6. **一镜到底**：两段共 90 秒里没有一个硬切（实测场景切换检测 0 次）。转场全靠镜头穿过物体：贴着光纤推进头部 → 进神经网络；从细胞拉远到藻群；从大脑拉远到地球。
7. **讲到哪推到哪**：说「眼点」就推到眼点，说「视网膜」就切开眼球。

**画面**
8. **3D 微观质感**：深海军蓝 / 墨绿底，景深虚化的前景颗粒（散景），辉光，丁达尔光柱，半透明果冻材质（细胞、小鼠身体），点云 + 连线做器官（像星座）。主角模型是低细节、圆润的玩具感（白色小鼠、粉耳朵），不追写实。
9. **场景冷暖分区**：脑内、微观用冷蓝 / 墨绿；「安全的盒子」用暖木色；人的日常用暗暖色。

**信息层**
10. **纪录片式 HUD**：年份用大号衬线数字（1991、2007），竖线后接「人名 · 发现」；物体标签 = 中文名 + 英文小型大写 + 一行说明，带一根细引线；比例尺（10 µm）；胶囊芯片（「蓝光 470 nm」）；iOS 式开关；现场画的小折线图、方波、流程图；出处小字（作者 · 期刊 · 年份）；右下角「示意」水印。
11. **字幕**：底部居中，米白色宋体，跟旁白逐字出现，每句一个关键词点成金色；一屏一句，句子 12～20 字。

**声音**
12. 旁白 + 低音量氛围音乐 + 状态变化处的短促音效（开关一拨一下「咔」，约每 1.7 秒一次，频谱图上是清楚的竖线）。旁白是否存在没法在云端转写确认（无语音模型），但字幕逐字出现的节奏符合旁白驱动。

**结尾（part4）**
13. **主观视角兑现**：讲完机制，画面变成他眼里的世界（琥珀色点阵的杯子），结果用清单一条条累加，每条一个数。
14. **同一个物从示意变成真实**：点阵杯子 → 暖光木桌上真实的杯子，大字「光，回来了」，全片唯一的暖色大字，是情绪高点。
15. **先降调再升**：「很模糊，只是开始」——不夸大，反而更可信；然后回到源头讲一句道理（「始于一个『没用』的问题」）。
16. **结尾问观众 + 片尾卡**：「如果大脑也能装一个光控开关，你最想关掉什么？」，开关图标回扣开头；片尾写明「全片代码实时渲染 · 蛋白原子坐标来自 PDB 6EID」和参考文献，确认原片也是代码渲染的。

## 和我们已有做法的关系

- 和 Tom CC 的 Vibe 知识（`对标/TomCC_Vibe知识/`）比：那边是纯音乐 + 宣纸水墨 + 一个锚词砸在重拍上，情绪型；这边是旁白 + 3D 微观 + 发现链，信息型，更像小型纪录片。
- 和 huashu-art-motion 比：它是 2D canvas，最接近的是 y1 Kurzgesagt（尺度穿越）和 t1 3Blue1Brown（变形）；但这支片子的深蓝辉光会被 huashu 的蓝紫门禁判红灯，这种风格交付时要用 `--allow-blue-purple` 写理由，或者不跑那道门。
- 手写版提示词在 `提示词.md`；做成 skill 的版本是 `/science-film`（`skills/science-film/`），带引擎、检查脚本和渲染。
