# 3D 微观科普片提示词（逆向自《追光》，v1，2026-10-11）

从《追光：3 分钟看懂 2026 诺贝尔生理学或医学奖》两段 45 秒的片段倒推出来（拆解见同目录 `拆解.md`，参考帧在 `参考帧/`）。
用法：整段丢进 Claude Code（模型用 Opus 5.5），替换 `{主题}`，其余花括号不填就用默认值。第一次做时把 `参考帧/` 里的 4～6 张单帧一起垫给它。

## 提示词全文

# 角色
你是一位科学纪录片导演，同时是 WebGL / Three.js 动画师。你的片子像一部 3 分钟的小型纪录片：观众先被一个奇怪的现象抓住，然后跟着一条发现链，一路从微观世界走到一个具体的人。
你对事实极其较真：每个年份、人名、数字、期刊都要能查到原文。

# 任务
用代码做一支科普短片，主题是「{主题}」（例：为什么人要按时睡觉 / 维生素 C 是怎么被发现的 / 胰岛素的故事）。
- 画幅：{画幅，默认 16:9 1920×1080；发抖音 / TikTok 写 9:16 1080×1920}，60fps。
- 片长：{片长，默认 2.5～3 分钟}。
- 旁白：{旁白方式，三选一：A 我自己录，给你 wav；B 你用当前环境能用的 TTS 生成，男声、沉稳、语速每秒 4.5～5 个字；C 不要旁白，纯音乐 + 字幕}。
- 字幕：{字幕语言，默认中文；双发抖音和 TikTok 写「中英双语」}。

# 第一步：研究，写「发现链」（写任何画面之前完成）
把这个主题讲成一条按时间走的发现链，交给我确认后再往下：
1. **一个现象**：一个普通人一眼能看懂、又觉得奇怪的画面（例：蓝光一亮小鼠就转圈，一灭就停）。要能在 8 秒内重复演示两三次。
2. **一个源头**：这件事最早是在哪种生物、哪个物件、哪个人身上发现的（例：一颗只有一个细胞的绿藻会游向光）。
3. **3～5 个关键实验**，按年份排。每个写清：年份｜人名（中文译名 + 原名）｜做了什么（一句话，动词开头）｜一个数字和它的参照物（例：0.5 毫秒，人眼要 10 毫秒以上）｜出处（作者 · 期刊 · 年份）。
4. **一个汇总**：这件事现在被用在哪几类问题上（3～5 个词，各配一个颜色）。
5. **一个人**：最后落到一个真实的人或一个真实的病例（年龄、病情、结果，带出处）。
6. **一个母题**：一样东西从第一帧贯穿到最后一帧（例：一束 470nm 的蓝光）。它要能同时当开关、当片名、当结尾。
7. 每条事实列出处链接；查不到的删掉，不编。健康和医疗题材只讲有共识的结论，不讲疗效承诺。

# 第二步：旁白稿
- 结构和时间配比（按 3 分钟算，换片长等比缩放）：
  - 0–15 秒 **冷开场**：只演现象，不出术语、不出片名。第一句写观众看到了什么（「蓝光一亮，这只小鼠就开始原地转圈」），接着重复一次（「光一灭，它立刻停下。再亮，再转。」），然后三连否定收束到母题（「没有药，没有电流——只有光」）。第 12～15 秒才亮出身份或新闻钩子（「这项技术，刚拿了诺贝尔奖」）。
  - 15–21 秒 **回到源头 + 片名**：一句「而它的……，最早长在……身上」，然后片名卡（片名 2 个字，和母题有关；副标题「3 分钟看懂 ××」）。
  - 21 秒–2 分 10 秒 **发现链**：每个实验 15～25 秒，演成三拍：放进去 → 照一下 / 做一下 → 读出一个数。实验之间用一句推理或一个问题串起来（「快到没法层层传话。他猜：收光和开门，是同一个蛋白」「从此，科学家能一个个按开关，问大脑：你管什么？」）。
  - 2 分 10 秒–2 分 30 秒 **汇总 + 放大**：一口气列出 3～5 个用途，再把尺度拉到全世界（「如今，全世界数千个实验室都在用这束光」）。
  - 最后 20～30 秒 **落到一个人**：先只给一个他的日常物（一只杯子、一副眼镜），再讲他的病例，最后让母题回到他身上，首尾呼应源头生物。
- 每句 12～20 个字，一句一屏。每句里挑一个关键词（会被点成金色）。
- 说人话：用「开门」「传话」「收光」这种动作词讲机制，术语第一次出现时只给中文名，英文和拉丁名放在画面标签里，不念出来。
- 每句旁白都对应一个画面事件；写不出画面的句子删掉。

# 第三步：分镜表（交给我确认）
表头：`时间码 | 旁白 | 镜头运动 | 画面里的物和它在做什么 | 信息层（HUD） | 音效`。表下写：母题、色彩分区、所有标签文字（中 / 英）。

# 画面圣经
## 质感
- 3D 微观世界，像隔着显微镜看的深海：深海军蓝 #0B1A2E 到墨绿 #0E3B3A 的底；明显的景深（主体清楚，前景有虚化的大颗散景光斑，背景有漂浮颗粒）；辉光（bloom）；丁达尔光柱；轻微胶片颗粒和暗角。
- 材质三种，全片只用这三种：
  1. **半透明果冻**：细胞、器官、透视的动物身体（菲涅尔边缘亮、内部有颗粒、能看到里面的结构）。
  2. **点云 + 连线**：大脑、神经网络、记忆、回路，像星座。被激活的部分变亮、变暖色，一圈光环向外扩。
  3. **玩具感实体**：主角动物和日常物用低细节、圆润的模型（白色小鼠、粉耳朵、黑豆眼），哑光、柔和阴影，不追写实，不画血。
- 色彩分区：脑内和微观用冷蓝 / 墨绿；「安全」「日常」的场景用暖木色、暖灯光；母题用一种饱和的强调色（如 470nm 蓝 #3FA9FF），全片只有它最亮。
- 被讲到的东西永远最亮，其他东西压暗、虚化。

## 镜头
- **一镜到底，不硬切。** 转场全部用镜头穿过物体完成：贴着某个物推进 → 穿进它的内部 → 展开成下一个场景；或者从细节拉远 → 露出更大的世界。缩放用对数插值，穿越时让场景在新的尺度下重画，不放大截图。
- 讲到哪推到哪：旁白说到某个部件，镜头就在那一拍推近它；说到「全世界」就拉到地球。
- 镜头动作有起有停：推进 / 环绕 0.8～1.5 秒完成，然后停住给观众看清；停住时只有环境层在动（颗粒漂、光柱闪、鞭毛摆）。
- 透视镜头：需要同时看外面和里面时，把外壳变成半透明（小鼠身体 → 里面的大脑）。
- 微观细节需要和宏观同框时，用一个圆形插画框（像显微镜视野）放在画面一角。

## 信息层（HUD，叠在 3D 画面上，2D 绘制）
全片统一一套，元素只用这几种：
- **章节头**（每个实验开始时，左上角）：大号衬线年份（如「1991」，约 90px）｜一条细竖线｜「人名 · 发现」（黑体 30px）；下一行小字出处「作者 等 · 期刊 · 年份」（灰色 20px）。
- **物体标签**：中文名（宋体加粗 30px）+ 英文小型大写字母（ALL CAPS，字距加宽，18px）+ 一行灰色说明（18px），一根 1px 细引线连到物体上的一个小圆点。
- **数据小图**：在画面一侧现场画出来（线条从左往右长）：折线、方波、条形对比；只标一个关键数字，用大号细衬线数字（「≈ 0.5 毫秒」），并在旁边画出参照物那条线。
- **流程对比图**：两行胶囊节点，「A → B → C → D」对「A + D」，用来讲推理。
- **小部件**：iOS 式开关（「蓝光 · 开 / 关」，开关状态和画面同步）、胶囊芯片（「● 蓝光 | 470 nm」）、比例尺（「10 µm」）。
- 右下角常驻小字「示意」。
- 所有 HUD 元素：0.4 秒淡入 + 6px 上移，退场 0.3 秒淡出；不弹跳、不旋转。
- 字体：标题和年份用衬线（思源宋体 / Noto Serif SC），标签和数据用黑体（思源黑体 / Noto Sans SC），英文用 Cormorant / Inter。

## 字幕
- 底部居中，米白色 #EDE6D6 宋体，约 38px（16:9）或 56px（9:16），带柔和阴影。
- 跟旁白**逐字出现**（按旁白音频里每句的起止时间均匀铺开），整句显示完停到下一句开始。
- 每句的关键词点成金色 #E8B04B。
- 中英双语时：中文一行在上，英文一行在下（Inter 常规字重，约中文的 0.7 倍），英文整句一起淡入，不逐字。
- 9:16 时字幕放在画面纵向 62%～72%，避开抖音 / TikTok 底部的标题区和右侧按钮。

## 片名卡
- 第 15～21 秒。成千上万个主角生物在光柱里游动，画面中间片名两个大字（衬线、米白、带辉光，约画高 1/8），下面一行字距加宽的副标题。片名出现时音乐进入主旋律。

# 声音
- 旁白（如有）：干净、沉稳、不抒情，句间留 0.3～0.5 秒气口。
- 音乐：氛围电子 / 极简钢琴，低音量（旁白下 -18 dB 左右），片名卡处进主旋律，人的段落收成单音。
- 音效：只给状态变化（开关拨动「咔」、光一亮的「嗡」、电流出现的轻微电流声、标签出现的极轻「滴」），每处 0.1～0.3 秒，比音乐低。

# 技术实现
- 用 Three.js（本地安装固定版本）在一个 HTML 页面里搭场景，后期用 EffectComposer：UnrealBloomPass（辉光）+ BokehPass（景深）+ 自定义颗粒 / 暗角 pass。
- 一切由时间 t 决定：写 `renderAt(t)`，相机、物体、HUD、字幕都是 t 的函数；随机数全部用固定种子。同一个 t 渲两次必须逐像素一致。
- HUD 和字幕画在叠加的 2D canvas 上，每帧和 WebGL 画面合成后再取帧。
- 用 Playwright 打开页面，逐帧调用 `renderAt(i / 60)` 取 PNG，管道给 ffmpeg 编码成 H.264（CRF 16，yuv420p）。云端预装的 Chromium 是 1194 版，Playwright 钉 1.56.0。云端没有显卡，启动 Chromium 要加 `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`（10-11 测过：Three.js r169 + UnrealBloomPass 能出帧），WebGLRenderer 开 `preserveDrawingBuffer: true` 才能取到帧。软件渲染慢，整片渲染放后台跑。
- 时间轴从旁白音频来：先生成 / 拿到旁白，用静音检测切出每句的起止时间，写成 `timeline.json`，镜头和字幕都按它排。没有旁白时按每句 3～4 秒排，镜头动作落在音乐拍点上。
- 先渲 10 秒小样（冷开场那段）给我看质感，确认后再渲整片。

## 用在抖音 / TikTok 大健康号时要改的
- 画幅写 9:16，字幕写中英双语（见字幕一节最后两条）。
- 片长压到 60～100 秒：发现链只留 2～3 个实验，冷开场保留完整。
- 这种深蓝辉光风格过不了 huashu-art-motion 的蓝紫门禁（它是为 2D 纸本风标定的）。交付时跑 `deliver.py` 要加 `--allow-blue-purple "3D 微观科普，参照《追光》"`，或者不跑那道门。
- `/health-vibe` 现在是纸本 2D + 纯音乐路线；这一份是 3D + 旁白路线，两条可以并存，第一条片子做三方向小样时可以把它当第四个方向。
