## 一、这是什么

一门 2015 年 MIT 寒假小课（IAP，讲师 Kevin Desmond，8 讲 + 3 份作业），被一个 AI 流程改写成了中英双语的在线教材（mdBook 站，英文在根目录，中文在 `/zh/`）。

| 部分 | 内容 | 体量（中文 md） |
|---|---|---|
| L1–L8 讲座 | 导论 / PokerTracker 数据复盘 / 底池赔率 / 翻前范围与 SK 模型 / 锦标赛 ICM / 扑克经济学 / 博弈论 CFR / 决策 | 每章 13–35 KB |
| Case 1–3 | 原课作业 + 解答 | 每份 6–9 KB |
| 术语表 | 由 `terms.zh.yaml` 生成，按拼音分组；正文里的术语悬浮出 Wikipedia 式小卡片 | 28 KB |

客座讲者阵容是这门课的「来头」：Bill Chen（SIG，《The Mathematics of Poker》作者）、Aaron Brown（AQR 风险官，扑克经济学）、Matt Hawrilenko（职业牌手）、Will Ma。L7 讲的是阿尔伯塔 Cepheus 怎么用 CFR「解掉」单挑限注德州，900 CPU-年，可剥削性低于千分之一大盲，这是 Libratus / Pluribus 之前的那一代扑克 AI。

## 二、内容本身怎么写的

读了 L1、L7、Case 2 全文，其余看结构：

1. **按原课结构如实重组**：README 写明「删去过渡语与重复表达，保留全部知识点」，不加课外内容。每章开头一段说本章讲什么，结尾「要点小结」。
2. **教科书腔，不是讲课腔**：主语是概念，几乎没有「我」和「你」，Kevin 的口头禅、玩笑全部剥掉。好处是密度高；代价是读起来像译好的讲义，不像在听课。
3. **把视频里板书写了、课件没写的东西补回来**，并且标出来：L1「讲师还在板书中把这两条轴对应到 PokerTracker 的两个指标上（课件与讲稿均未写出）」。这是流程第 3 步「逐讲看视频补漏」的产物。
4. **例子保留到能算**：L7 的 Rose / Colin 黑桃诈唬小游戏、后悔匹配的 5 步数值演示、河牌节点数 1755 × 9³ × 2352 的推算都完整留着，公式用 MathJax。
5. **作业保留原场景**：Case 2 是「2014-06-07 WSOP 20 号赛事 Shootout，你 78,000 对他 12,000」，连题目里老头的原话都翻了。

## 三、做法：一个可复用的「课程 → 教材」agent 流程

gist 写的流程（意译）：

1. **抽素材**：yt-dlp 下视频、poppler 抽课件文字、清洗字幕；只用开放获取的阅读材料，付费墙的记为缺失跳过。
2. **一讲一个子 agent 并行写章节**：保持原顺序，定义 / 公式 / 定理 / 例子全留，不引入课外内容；阅读材料只在加深本讲时并入，篇幅涨幅控制在 1.5 倍内。
3. **一讲一个子 agent 看视频核对**：找屏幕上出现、但课件和字幕里没有的知识点补进去；有版权的画面改写，不截图。
4. **双语各写各的**：中文从原始素材写，英文版只当结构参考；两边交叉对错，改一处两边都改。术语表 yaml → 附录 + 悬浮卡。
5. **部署**：GitHub Actions 每次 push 重建两本书发到 Pages；首页必须注明由这个 skill 生成并给链接。

验证原则里最值得抄的三条：

- **源码层面的检查（能 build、链接有效）不证明渲染没问题**，每次 push 前用无头浏览器把每一页跑一遍，看公式排没排版、有没有裸 LaTeX、图加没加载、控制台干不干净，桌面和手机都截图；push 后对线上再跑一遍。仓库里 `tools/render-check/check.js` 就是这个。
- **插图对不对靠看图，不靠写稿 agent 自己说**。
- **出现新的翻车方式，改模板或生成规则，从源头修**，不是只修这一页。

已知坑：字幕里符号、数字、人名错得多，以课件和画面为准，并在正文里注明更正；Markdown 会在 MathJax 之前把 LaTeX 弄坏，要专门做公式保护（仓库里的 `escape_math.py`，每页顶上的 `<!-- escape-math: v1 -->` 就是标记）；并行子 agent 各写各的文件、临时文件前缀不同，commit 只由主 agent 做。

## 四、跟我们的号有什么关系

1. **它本身就是主线选题的素材**（「AI agent 怎么配 / 工作里怎么用」）：一个人用 Claude Code 一类的 agent 把一门 MIT 课变成双语教材，流程公开、仓库公开、有页面可以截图。按 `账号/爆文方法论.md` 的选题门槛看：有来头（MIT + Bill Chen），有可搜词（MIT 公开课 / 扑克 / 博弈论 / AI 自学），有截图证据。缺的是「有来头的人怎么看 AI」里那个人：作者 YoungY620 不是名人，所以不能写成人物稿，只能走 `/own-xhs` 自述，主角是用户自己怎么看「AI 把课变成书」这件事。
2. **它的验证原则跟我们的出图流程是同一个问题**：我们靠 meme_check 和截图自查，它靠无头浏览器逐页渲染、「出新错就改规则源头」。前者我们已经在做；后者跟 10-07 / 10-14 我们反复加规则又回退的经历正好可以对照。这条只记进待议，10-21 前不动规则。
3. **领取物天然现成**：一份「把任意公开课变成自己教材」的 agent 提示词 / skill 骨架（五步 + 三条验证原则），符合「领取物优先给提示词 / skills / agent 配置」。
4. **不能直接拿的**：内容是 CC BY-NC-SA，引用要署名、不能商用；扑克 / 德州在小红书有赌博相关的审核风险，标题和首图不要出现「德州扑克」「赢钱」「ROI」，要讲就讲「博弈论」「MIT 公开课」「AI 怎么学会诈唬」。
