# 对标库索引：写稿前先查这张表

用户在对话里发来的竞对截图、文章、视频文字稿都存在这个目录（用户 10-17 定，不进 Notion）。每个号一个文件夹：截图原图和用户贴来的原文原样存，Claude 写 `拆解.md`。**只学结构和口吻，不复述、不改写它们的内容和案例**（CLAUDE.md 内容边界）。

写 meme / own 稿之前，按「这篇是什么文体、什么题材」在下面的表里挑一篇对标先读，再读 `账号/范本/` 里自己的一篇。拆解里每批末尾的「对我们能用的 / 等用户定」是候选规则，用户点头前只当写稿参考，不进 SKILL。

## 四、新对标怎么进来

1. 建 `对标/<号名>/`，截图按 `截图/<日期>_<稿名>/01.png…` 存，原文转成 `<稿名>_文字稿.md`（开头写来源、日期、截图时的赞藏评）。
2. 写 `拆解.md`（或追加一批）：好在哪、学哪几样、他做了我们禁的、对我们能用的（等用户定）。
3. 在本页第一、二节加一行，CLAUDE.md 摘要记一行「10-xx 对标 X：学了 Y」。
4. 用户点头的才改 SKILL；10-18 回看定的规矩：输出规则只撤不加，每条新规则绑 3 篇稿再定去留。
