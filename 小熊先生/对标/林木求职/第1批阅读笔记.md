# 林木求职 batch1 蒸馏笔记

范围：batch1/ 下 46 个 .txt 全部读完，其中 45 篇口播转写稿 + 1 篇笔记文案（32_ 无「_原文」那份，只有标题、简介和话题标签）。
引用格式：「文件前缀 时间码」。id 文件用前 8 位，如「640b1749 00:18」。转写错字原样保留（谈心=谈薪，主持稿/主次稿/主色=逐字稿，web coding=vibe coding，密码/面板=面麻）。

**先说一个分期**：这批其实是两个时期的林木。
- **旧期（13 篇 id 命名，2023 年 3—5 月）**：1—2 分钟，短、狠、金句收尾，带团队 / 晋升 / 简历 / 行业知识，**0 篇引流**。
- **新期（32 篇编号 01—50）**：2—4 分钟，几乎全是面试，统一「面试官视角」，**25 篇用固定话术结尾卖「高阶问题逐字稿」**，另有 32_ 整篇在讲自家服务。
两期的拆解骨架一样，口吻新期更稳、旧期更毒舌。下面统计如果不特别说明，都是 45 篇合计。

## A. 开头

**总体规律**：第一句几乎从不寒暄、不自我介绍；45 篇里 0 篇以「大家好」起。最慢的也在第 3 句进入正题（连麦稿除外）。前 3 句的常见组合是「抛问题 → 否定多数人 → 预告几点」。

| 开头类型 | 次数 | 例子 |
|---|---|---|
| 1. 直接抛听众的问题（怎么/如何/为什么/什么） | 20 | 「面试中怎么体现自己的产品规划能力？」（01 00:00）；「B端产品和C端产品有什么区别？」（641058d2 00:00）；「面试被问到现在你有哪些offer，应该怎么回答？」（50 00:00） |

**第 2—3 句的三种固定动作**（比第一句更值得学）：
1. **否定多数人**：「多数人回答这个问题的时候，他的问题在于…」（01 00:00）；「如果你只会说面向的用户和商业模式不一样，一张嘴就是一个低段位的选手」（641058d2 00:00）。约 14 篇。
2. **反常识翻转**：「中国的职场是不欢迎gap的…甚至…gap 1年对你的影响也不大」（06 00:00）；「能力越强越聪明…越拿到结果的人特别容易犯」（39 00:00）；40 先说「从外部视角…实际上不应该做」再翻（40 00:17）。约 6 篇。
3. **预告数量**：「核心三个」「我总结过三句口诀」（14 00:00）、「核心看三个点」（49 00:00）、「这里面的三个非常核心的逻辑」（64469493 00:00）。约 25 篇在 30 秒内报出「几点」，其中「三」占绝大多数。

**进入正题速度**：非连麦稿平均在 00:15—00:25 进入第一点；最快 641058d2 在 00:10 就是「第一」。

## B. 拆解问题的方式

拿到一个问题，他的第一步几乎总是**先改写问题本身**：把「怎么答」改成「面试官为什么问、想判断什么」，再按下面几种骨架展开。一篇常叠两种。

**1. 分级 / 段位尺（5 篇：08、11、41、45、641058d2）**
骨架：① 说多数人在第一级，描述这一级的答法；② 第二级多做了什么，但还差在哪；③ 第三级是体系，展开 4—6 步；④ 告诉你面试够用到第几级。
- 「实际上AI和工作的结合是分级别的，最低的级别」（08 00:00）
- 「最初的级别我把它称之为叫感知型评测，这是多数同学现在停留的层级」（11 00:24）
- 「当前的面试完全不需要让自己掌握到第三种，第二种真的绰绰有余」（08 01:41）

**2. 先列错法，再一一对应给解法（8 篇：18/46、23、38、39、15、640b1749、640dc2b9）**
骨架：① 「我们很多人经常犯的错误」列 3—4 条，每条配一个具体动作；② 「那应该怎么办呢？你抓住几个重点」；③ 解法和错法常是镜像（23 三个问题 → 三个解法一一对应）。
- 「第一个讲的内容答非所问…第二个…揉在一起…第三个…黑话特别多」（23 00:00—00:32）
- 「这个时候这个offer 80%就没有了」（18 00:28）

**3. 链条 / 层层倒推（4 篇：01、20、6467、44）**
骨架：把一个能力放进因果链，往前追一步、往后走一步。01 是「需求 ← 产品目标 ← 业务规划 ← 策略 ← 目标 ← 战略 ← 机会点与竞争」。
- 「第二个关键点就是你往前走一步，战略怎么定呢？」（01 01:09）
- 「岗位一定来自于业务…有岗位才会有相应的能力要求」（20 00:35）
- 6467 宏观→中观→微观→结论，是漏斗版：「宏观看市场…中观看竞争…微观看用户需求」（646782fd 00:00）

**4. 二分对比两类人 / 两种东西（7 篇：02、22、19、646b、641058d2、640c、14）**
骨架：① 给两类起名字；② 各自定义一句；③ 列「为什么面试官喜欢 A」的 3 个特质；④ 落到「哪怕你是 B，表达上也要像 A」。
- 「所有的转行动机本质上只分两种，一种叫内驱，一种叫逃避」（02 00:23）
- 「工作时候的语言体系多数人是执行体系，但面试的时候…是决策体系」（22 00:26）
- 「一个是纯风控出身，一个是风控加业务出身」（19 01:52）

**5. 分情况 / 按对象分档（7 篇：02 后半、06、17、18、41、43、641b9979）**
骨架：先给分档标准（时间、公司类型、职级、概率、职业阶段），每档一句结论 + 一个条件。
- 06：「三个月左右…七八个月…一年左右…一年半以上」（06 00:19）
- 02：大厂要热情、创业公司要认同、央国企要求稳（02 01:49—02:51）
- 43：「第一种百分百过的…第二种…80%也能过…第三种就是60%到70%」（43 00:19—01:35）
- 18：offer 定位分「练手的 / 抬价的 / 特别想去的」（18 02:44）

**6. 决策三要素（选择题专用，3 篇：49、03、18）**
骨架：「我觉得这个事儿其实是给大家有标准答案的。核心看三个点」，三个要素都是可自查的问题（找得够不够充分、调整到位没有、存款撑多久），最后「三个要素考虑清楚之后，你就知道要不要接了」。
- 「第一个点一定是看你找的充分程度」（49 00:09）
- 「你上一次面试满分100分，给自己打几分？」（03 02:09）

**7. 讲故事 / 讲项目的维度清单（7 篇：14、16、36、47、30、6419、6414）**
骨架：给一套可直接套的维度（背景→解法→结果→复盘；context/purpose/方法/result/复盘；5 页 PPT），**每个维度都写「很多人这么讲 / 面试官想听的是」两句**。
- 「第二个维度叫purpose目标…面试官想听的是什么？更想听你定目标的逻辑」（47 00:45）
- 「先讲背景，先把压力和难度塑造出来」（16 00:53）

**8. 连麦诊断式追问（3 篇：03、09、645e）**
骨架：不先给建议，连问 3—4 个事实（怎么看出来的 / 上次怎么离开的 / 假设身体没问题会走吗 / 最大挑战是什么），从回答里找出一个模式再下判断。
- 「那假设身体没问题的话，会离开吗？」（09 01:23）
- 「我就问一个问题，多少已读？多少未读？」（03 01:30）

## C. 叙事和论证推进

**段间衔接**：几乎全靠序数词 + 自问自答，不用过渡句。高频连接：「第一个/首先」（第一个 35 次/24 篇，首先 33 次）、「那为什么…？」「那怎么…呢？」「什么意思？」「所以」（132 次/37 篇，是最强的段尾词）。全部 45 篇共 329 个问号，平均每篇 7 个，大部分是自己问自己。
- 「什么意思？我之前在短视频里面有次讲过」（14 00:15）
- 「那状态怎么改？第一，一定要声音大」（14 02:16）

**例子写具体的三种手法**：
1. **动作 + 原话**：14 的下属故事有完整动作链——「有次我去看了他的面试，发现他特别会引导候选人」（14 00:15）；19 还原后台对话——「我会先问他，你觉得谁咋样？」（19 00:30）。
2. **小数字锚**：时长、频率、比例，不追求权威出处。「每周推进一轮…或者两周推进三轮」（18 03:17）；「调研一家公司我只花30分钟」（28 02:23）；「过去…是几个小时，…现在…几个小时，这个叫效率低」（23 01:26）。
3. **生活化类比**：「早晨你要去地铁站，共享单车一定是最优解」（36 01:28）；「我上大学的时候玩…魔兽争霸，最后达到了WCG」（643cf368 00:19）。

**论证节奏**：每一点 = 定义一句 → 「举个例子」→ 「所以」一句收。「举个例子」19 次、「比如说」76 次/32 篇，几乎每段都有一个例子，抽象句很少连续超过两句。

## D. 口吻

**句子**：口播长句为主，逗号串联，一句里常塞「首先…其次…」；但关键判断会单独压成短句（「结论先行。」14 01:09；「管住你的手。」640b1749 00:49）。旧期句子更短、更多祈使句。

**高频词估计（45 篇合计，grep 计数）**：
- 「我们」151、「所以」132、「面试官」105、「一定」91（36 篇）、「非常」82、「比如说」76、「其实」69、「同学」69、「核心」61、「特别」60、「大家」54、「关键」41、「基本上」30、「认知」27、「复盘」23、「你看」20、「举个例子」19、「实际上」16、「OK」17、「对不对」13、「本质上」10、「决策逻辑」11、「最优解」7、「我反复（说/讲）」6、「巴拉巴拉」4、「我告诉大家/你」6。
- **没有**「说白了」（0 次）；「对吧」只 4 次，他用「对不对」。
- 口头禅组合：「核心 + 一定」是他的确信标记；「其实 + 本质上 + 实际上」是翻面标记；「OK」用在自问自答的转身处（「OK不需要」15 00:58）；「No,」用来否定常见说法（19 02:24、47 01:44）。

**语气**：笃定为主，轻度毒舌，偶尔居高临下（主要在旧期和连麦）。不安抚式亲切，是「过来人 + 面试官」的直给。
**称呼听众**：「同学 / 同学们」（69 次，最主要）、「大家」、「你」；自称「我」（个人经历）和「我们」（指团队/陪跑，也指「我们求职者」，两种混用）。
**下判断的方式**：① 「一定 / 绝对 / 基本上」+ 结论；② 「我告诉大家，这个只能体现出…」；③ 给数字档位（80%、60%—70%）；④ 「这个叫…，不叫…」重新命名（「这个不叫意向，叫反向给面试官画饼」19 02:24）。

## H. 情绪处理

**套路：先命名情绪 → 去个人化 → 给可控的动作 → 留一句硬话。**
1. **命名 + 说「不是个例」**：「我告诉大家，这个真的不是个例，我们陪跑的同学绝大多数都有」（28 00:00）；「我能理解你gap了三个多月…现在心情很内耗」（03 01:30）。
2. **把锅从人身上挪到结构上**：「非常多未读跟你投不投得出去没关系，不是你的问题」（03 01:30）；「如果你也没有拿到offer，也不用那么气馁」（20 00:00）；「多数人整体发挥都还可以，挂都不知道为啥挂」（19 00:20）。
3. **给小而可执行的 SOP**：「面完一家花十分钟记一下…记完立刻关文档」（28 02:23）；「我的求职时间就是早上十点到晚上六点」（28 03:00）。
4. **最后一句硬话，不纯哄**：「脸上一定是写满了苦大仇深，面试官是不敢要的」（28 03:00）；「发现不了问题也代表着市场给你了一个新的定位」（49 00:42）；「每一次离职坦白讲都是不够理性的」（09 02:35）。
5. **刺激型（旧期）**：直接制造焦虑——「踩中一条让你天天焦虑」（640b1749 00:00）、「我只知道不参与就会被淘汰」（6411c615 01:10）、「今天这个梦该碎了」（641880a7 00:55）。新期明显收敛，改为「先说结论，三四个月之内基本上对任何人都没有影响」（06 00:19）这种分档降焦虑。

## I. 招牌动作

1. **「多数人这么答」现场降级**：先把普通答法完整说一遍（常带「巴拉巴拉」），再一句话判它只值几分。
   「说实话在SPA这个层面整理的再好，那其实就是一个及格分，60分」（36 00:18）；「很多人会回答，当时我们做了一个活动项目…巴拉巴拉」（14 00:57）。
2. **当场改写示范句**：给出可以直接背的「改完版本」，前后对照。
   「我做过最有价值的一个项目是一次活动转化率的优化」（14 01:09）；「上一段离开主要是因为岗位的实际内容和我的长期方向有偏差」（15 01:23）。
3. **替面试官说潜台词**：把面试官脑子里的怀疑一条条念出来，让听众自己意识到答案的风险。
   「是不是业务不太稳定，是不是有可能你在原团队待不下去了？」（15 00:00）；「如果我竞争不过，那我给你offer也特别容易割」（50 00:00）。
4. **给问题标「真实目的 + 概率」**：「这是最核心的原因。基本上占70%以上」（50 00:00）；「只要面试官和面试者角色翻转了，80%也能过」（43 01:15）。
5. **后台场景还原**：讲公司内部真实流程，听众像在旁听评审会。
   「基本上我面完一个人就会喊一面的面试官」（19 00:30）；「他会问你如果发了offer你什么时候能入职？」（43 02:10）。
6. **自造概念 + 命名**：把现象命名成两三个字，方便传播和回指。内驱/逃避（02）、执行体系/决策体系（22）、组合优势（19）、感知型评测（11）、面麻了三层（28）、三个杠杆（641b）、「看着下属犯错」（640b1749 00:49）。
7. **反向画像 / 不该问的问题**：「当场问面试官，薪资能涨多少，问社保能不能交满」（38 02:03）；「我认识你们部门那个谁对不对？」（38 02:03）。
8. **俗语反转式毒舌**：「面试官问的是牛头，你对的是马嘴」（23 00:00）；「千年的狐狸…玩聊斋」（19 02:24）；「让你觉得你是在跟他对话，而不是在念经」（28 01:55）。

## J. 不该学的

**1. 引流售卖**
- 25 篇结尾卖资料，7 篇一字不差复用「越是高级的同学…高阶问题逐字稿」，其中 03（gap 连麦）、06（gap 时长）跟「高阶问题」毫无关系，是硬接。
- 32_ 整篇是给自家陪跑做定位：「但我们自己的服务还是会更偏体系化一些」（32 00:00）；配套笔记文案带 #求职陪跑 #求职机构。
- 03 连麦里学员说「我也是昨天我就下单了老师的课」（03 02:09），属于软广植入。
- 30 「很多同学拿到过SSP offer」（30 01:01）为资料背书。
- 17 通篇夸小红书招聘（「他是第一个」17 02:37），09 替小红书搜索团队说好话（09 03:23），立场存疑。

**2. 无出处数字**
- 「这个offer 80%就没有了」（18 00:28）；薪资红线 20% / 30%（18 01:39）。
- 「基本上占70%以上」（50 00:00）；「百分百过」「80%也能过」「60%到70%」（43）。
- 「70%以上的提拔…是组织在快速扩张的时候」（64469493 00:19）。
- 「2000年…注意力还有12秒，到了2013年只剩下了8秒」（641058d2 01:07），是流传已久、出处被质疑的说法。
- 便利店「日本和韩国平均2000人左右…中国每6万人才有一家」「人均GDP8000美金」（646782fd 01:04）。
- 学员结果：「gap了十个月…薪资还涨了50%」（06 00:57）、「接近100万的offer」（06 03:15）、「五年…P6到P9…涨了300万」（641b9979 00:00），都是单例无法核实。

**3. 诚信风险建议**
- 「哪怕你本身确实有逃避的成分…一定要体现自己是内驱的」（02 01:49）——教人包装动机。
- 「面试本身需要表演」（28 00:43）。
- 50 反对伪造 offer，但理由是「HR…需要你展示其他offer的截图」（50 01:18），是怕被查不是讲诚信；同篇还建议「让其他家的offer把你抬」（50 00:51）。
- 15「适度的真诚」整体可取（只讲事实、不撒谎），可以学，但要保留「没有撒谎」那句前提。

**4. 偏见 / 冒犯**
- 「反而是农村出身的孩子更加容易玻璃心」（646b4bb1 00:00）——出身刻板印象。
- 「人和人的差异比人和动物的差异还要大」（640b1749 01:16）。
- 连麦里对女学员下性格结论：「整体是一个这样的姑娘」「偏感性」（09 02:47）。
- 「这种行为简直愚蠢的可怕」（641880a7 00:00）。
- 「大家别惦记怎么送外卖比较快了，赶紧all in」（6411c615 01:10）——制造焦虑。

## 附：对「小熊先生」可直接迁移的几条（只学结构）

- 四大 / 审计面试题完全可以套「分级尺」（如「你怎么理解审计」分感知级、流程级、风险导向级）和「5 维度 × 你以为 / 面试官想听」。
- 「替面试官说潜台词」对 Big4 的 behavioral 题（离职原因、为什么四大、加班）很好用，但要换成读者能核实的场景，不能编后台对话。
- 他的可信度大头是「我当面试官」。小熊先生没有这层身份时，不要模仿「我面过几百个人」，改用自己真实经历 + 能查到的公开信息。
- 不学：结尾引流模板、无出处百分比、「哪怕是逃避也要说成内驱」这类包装建议。
