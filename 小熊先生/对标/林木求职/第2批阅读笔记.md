**第一句的属性**：问题（①⑤⑦⑩合计约 21）≈ 判断（②及①的第二句）> 场景（④⑧）> 身份（⑥）。问题开头的那一类，**第二句一定是判断**，从不悬着。

**前 3 句的通用三拍**（约 35 篇能套上）：
1. 问题 / 处境；
2. 一句定性（「最核心的原因是」「本质是」「是个伪命题」）；
3. 预告结构 + 价值承诺：「今天就说三条……听了学会照做就改变」（64a57ecf 00:00）、「如果你能把今天的视频完全理解清楚，那行业调研不在话下」（65b0fdb3 00:08）、「你完全可以照着这个去抄作业」（64ede490 00:00）。

## B. 拆解问题的方式

几乎每篇都编号（「第一」在 41 篇出现，共 68 次）。拆法按出现次数：

1. **平铺清单（N 条建议 / N 个道理）**，约 16 篇。64a57ecf、64a81c38、64fef245、65687a58、65523a3e、658969ef 等。骨架：总判断 → 第 1 条（一句命名 + 一句为什么 + 一个例子）→ 第 2 条 → … → 末条停在金句。弱点：条与条之间无逻辑关系，最像鸡汤。

2. **流程 / 步骤拆（按做事顺序）**，约 12 篇。5 页 PPT（结果→原因→认知→策略→资源）、复盘四步（回顾目标→评估结果→分析原因→形成做法）、简历三步、产品规划三步、周报三部分、159 稿评审、Keep 商业画布九格。骨架：第一步是什么 → 这一步自问哪几个问题 → 一个贯穿全篇的例子在这一步怎么填。最好的一篇是 6522a397：一个「新增广告位」例子从第一步用到第三步（00:26、01:00、01:19）。

3. **按层级 / 段位拆**，约 7 篇。年薪 30w/50w/100w 汇报（64b94eb4）、负责人 3 决策 vs PM 3 决策（655b5310）、信息层 / 共识层 / 非共识层（65bf8dce）、宏观 / 中观 / 微观（65141c70）、空窗期 3 个月 / 6 个月 / 1 年（65858cbd）。骨架：最低段位的人怎么做（带贬低）→ 中段 → 高段（要「认知、机会、资源」）。读者自动对号入座。

4. **按角色 / 关系拆**，约 5 篇。新公司三种关系：老板 / 协同部门 / 同部门同事（654cc524 00:21–01:49）；立人设按上游 / 输出 / 下游 / 平级（6565eb62）；B 站改版按用户 / up 主 / 内容 / 商业化（64a6d803）；B 端「决策者和使用者分离」（650841c4 00:00）。

5. **按原因分情况给对策**，约 4 篇。PM 与研发吵架的 5 个原因，每个原因对应一个「找谁」（655f3418）；老板瞎指挥：先判断「改不改」，再分「给了信息建议他还坚持」的情况（6582cf99）。骨架：「X 能发生就这么 N 个原因」→ 原因 1 → 你该检查自己哪里 → 不是你的问题就找谁。

6. **按提问者意图拆（面试题专用）**，约 3 篇。数据造假题：「一定要看这个问题背后面试官想问什么」→ 价值观测试 / 服从性测试两种意图 → 两种都指向同一答案（6578585f 00:35–00:59）。产品思维题：价值 / 目标 / 方案三问，「难回答的都在追问」（64fad03a 00:34）。项目题：CPWRR 五维（64c79e05）。

7. **两类人对比**，约 4 篇。工具人「执行思维」vs 负责人「决策思维」（6530e1bb 00:00）；排队队尾的人 vs 排在前面的人（65965062）；会看老板的人 vs 不愿意的人（6582cf99）；B 端 PM vs C 端 PM。

8. **时间阶段拆**，约 4 篇。招聘软件：免费期讨好候选人 → 上市后制造错配（65707345）；国企看大厂人：刚去是救世主 → 慢慢是异类 → 最后老人好用（659402e1）；试用期按「第一周 / 第一次发工资前」检查（659fcf0b）。

9. **公式链拆（指标类）**，1 篇但值得学：LTV = LT × ARPU → LT 受留存 → LTV > CAC → ROI = LTV/CAC → ROI 也不是越大越好（65113232）。每引出一个新指标就自问一句「又出现两个新的指标，它们分别代表什么呢？」（00:53）。

**通用动作**：几乎每一层都用「X 是什么？怎么做？为什么？」自问自答推进（全集约 400 个问句子句，≈6.6 个/篇）。

## C. 叙事和论证推进

**段间衔接**：靠自问句，而不是连接词。最常用的过门句：

- 「什么意思？」（16 次，15 篇）：抛出一个抽象词后立刻接这句，下一句给例子。
- 「为什么这么说？」（「为什么」56 次）
- 「那这个时候你怎么办？」把读者推回决策位。
- 段末小结「这是第一个」「这是第二个」（6540e4f2 02:41）。

**例子来源占比**（按出现过的篇数，可重叠）：

## D. 口吻

**句长**：口播短句为主，一句 10 到 25 字，靠逗号连成长串；判断句极短（「不可能的。」「没有对错，只有回读。」，「回读」应为「取舍」的转写错）。

**高频词估计**（61 篇总计 / 出现篇数）：
- 所以 99 / 38；非常 78 / 38；一定 68 / 33；比如说 66 / 28；为什么 56 / 31；其实 47 / 23；同学 35 / 18；给你 32 / 25；直接 29 / 21；核心 26 / 18；是不是 25 / 12；真的 25 / 15；对不对 22 / 15；你看 21 / 17；我觉得 20 / 12；基本上 19 / 13；本质 18 / 13；实际上 17 / 13；什么意思 16 / 15；最重要 15 / 12；大概率 12 / 9；举个例子 12 / 11；牛逼 11 / 6；对吧 5；OK 6。
- 「说白了」只出现 1 次，「底层」3 次：他不是靠「本质上说白了」那套，而是靠「**对不对 / 是不是 / 你看**」拉听众点头，靠「**一定 / 非常 / 直接**」加分量。
- 「你」719 次，「我们」109 次：几乎全程第二人称对着读者讲。

**称呼听众**：「你」为主；群体叫「同学」「同学们」「打工人」「产品人」；面向咨询者时直接「这个同学」。**自称**：「我」，偶尔「我们实干圈」；身份词靠「我在字节」「我面试产品的时候」「我之前带过一个下属」带出，不说头衔。

**语气**：笃定 + 轻毒舌 + 带一点居高临下的教练感。对浅答案直接贬：「一张嘴就是一个低段位的选手」（650841c4 00:00）；对读者妄念直接怼：「你说你想直接去自己去腾讯，那不是搞笑吗？」（6571a9db 00:00）；但对读者的处境不骂，骂的是公司、平台、老板、培训师。

**怎么下判断**：
- 「不是 A，而是 B」句式（「不是」86 次，「而是」15 次），常放在开头。
- 「本质是 / 本质上」给定义；
- 「我再说一遍」「这个我说三遍」重复强调（64d39a54 00:29、654b834f 02:21）；
- 用「大概率」给概率判断，比说「一定」显得有分寸，但他两者都高频。

## H. 情绪处理

1. **先认同处境，再降预期**：「这点我能理解」后接「凭运气凭时机赚来的钱……很容易凭你的认知还回去」（65003bd5 01:17）。
2. **「普通人」叙事**：「我们要认清自己真的就是一个普通人」（65003bd5 01:53）；「只要你没有下牌桌……这才是普通人风险最小，收益最大的事情」（65003bd5 00:37）。既刺激（你不特殊）也安抚（稳住就赢）。
3. **把问题外归因**：工作难找是「招聘软件一定要背锅」（65707345 00:00）；被骂是遇到「垃圾领导」；阿里出来的人被黑是因为「这三种特质」。读者情绪有出口。

## I. 招牌动作

1. **标题即首句 + 第二句给答案**：不铺垫，问句念完立刻定性。例：「为什么今年很多人面试都是一轮游？最核心的原因就是自己的项目。」（64c79e05 00:00）
2. **「我是在教你 X 吗？我是在教你 Y」：升维反转**，把一个技巧题抬成业务能力题，首尾各说一次。例：6522a397 00:01 与 01:37。
3. **按薪资段位分层讲同一件事**：30w 的人讲做了什么、50w 讲原因、100w 讲认知和资源（64b94eb4）。读者自动定位、自带焦虑和向往。
4. **给出可直接念的话术 / 对白演示**：谈薪、接 HR 电话、项目面试都用一人分饰两角演出来；空窗期给三档原话。例：「方便耽误您两分钟的时间吗？想了解一下具体的岗位情况」（65375ba8 00:00）。
5. **面试官追问链**：先说「常见问题平平无奇，难回答的都在追问」，再演三层追问（64fad03a 00:34–01:30）。
6. **一个例子贯穿所有步骤**：广告位例子从「回顾目标」用到「分析原因」（6522a397）；Keep 从商业画布九格一路用到行业调研 STP。
7. **短名词化方法**：自造或借用短口令，便于记忆和截图——「CPWRR 模型」「159 稿评审」「给信息给建议，别拧巴」「摘低垂的果实」「保下限 / 博上限」「纺锤策略」。
8. **贬低浅答案定基准**：「如果……你只会说他们面向的用户和商业模式不一样，一张嘴就是一个低段位的选手」（650841c4 00:00），先立一个低线，读者想站到高线那边。

## 给小熊先生的可迁移要点（小结）

- 照搬：标题即首句、第二句给诊断、「X 是什么？怎么做？」自问推进、一个例子贯穿、段位分层、面试官追问链、话术演示。
- 换内容：把「字节双月会」换成四大 / 审计里真实的流程节点（如项目组 review、背调、PA 打分），可信度来自流程细节，不靠头衔和年薪数字。
- 避开：引流手册话术、虚报薪资 / 隐瞒履历类建议（四大背调严，读者照做会出事）、无出处数字、点名攻击公司。
