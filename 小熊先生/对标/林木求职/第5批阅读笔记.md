# 林木求职 batch5 拆解笔记（45 篇全读）

素材：`scratchpad/batch5/` 下 45 篇口播转写稿，时长多在 1—4 分钟，最长一篇约 5 分钟（67728693）。引文标文件 id 前 8 位 + 时间码。转写错字照原样引（如「主字稿」=逐字稿，「铃木」=林木，「自己」常是「字节」，「埃批」=IP）。

一句话画像：**一个自称「前字节产品负责人、7 年面试官、求职陪跑公司创始人」的人，用「面试官 / 招人方真正在想什么 → 所以你该这么答」的结构，把每个问题拆成 2—5 个编号要点，口吻笃定、偏说教，结尾一半在卖课。**

---

## A. 开头：前 3 句怎么起

整体规律：第一句几乎都是**把标题问题原样念一遍或换个说法**，第二句立刻给「核心判断」或「X 个点」，正题在 10—20 秒内开始。几乎没有寒暄、没有「大家好」。

| 开头类型 | 次数 | 例子 |
|---|---|---|
| ① 直接抛问题（多是复述标题） | 26 | 「一面能过，但是二面为什么过不了？」（6729a89c 00:00）；「年终汇报怎么做？」（674d942f 00:00）；「试用期做什么事情才能够更顺利的通过？」（6752e251 00:00） |
| ② 判断 / 反常识断言 | 10 | 「面试官其实特别喜欢问一些自己也回答不上来的问题」（672a01c7 00:00）；「其实每一次面试都是在浪费机会」（6751927c 00:00）；「大多数求职配套的公司，其实都撑不过半年」（675c21df 00:00）；「找工作根本不是什么要看长期主义或者短期主义」（67616021 00:00） |
| ③ 场景 / 观察 / 学员私信 | 3 | 「这是一个同学给我发的信息」（678a3d7a 00:00）；「我发现很多人今年在找工作的时候有一个心态」（6788f080 00:00）；「很多人都会担心自己35岁或者40岁的时候」（6793796b 00:00） |
| ④ 自述 / 身份 / 宣告 | 4 | 「给大家做一个求职陪跑的年终总结」（67922b37 00:00）；「预测一下明年的金三银4到底整个行情是怎么样的」（67937968 00:00）；「今天也跟大家说一说创业几年来」（6790dcaa 00:00） |
| ⑤ 选择题互动 | 1 | 「这三个候选人如果你是面试官，你会选哪个？」+「给大家3秒钟的时间」（67445a73 00:00/00:18） |
| ⑥ 条件句 + 数字清单 | 1 | 「如果年底想要拿offer的话，有三个特别重要的点」（6731e899 00:00） |

**前三句的标准组合（出现最多）：问题 → 一句定性判断 → 身份背书或「X 个点」。**
- 「二面面试官很关注一个点……我自己做过七年的面试官非常清楚这一点。」（6729a89c 00:00）：问题→判断→身份，10 秒内三步走完。
- 「面试中怎么体现自己的专业感？首先我们要理解，面试本质上是一个沟通。」（6733631c 00:00）：问题→「本质上」定性。
- 「普通人要转AI领域要做哪些准备？四个点。」（673c1e07 00:00）：问题之后直接报数，最短的写法。

**问题之后常接一句「为什么这个问题重要 / 常见」**，给观众一个「这事和我有关」的理由：「为什么说这个问题很常见？因为……被称之为基本功」（6756d8e0 00:00）；「你可以看到非常多的GD里面都会有一个关键词」（673c79b6 00:00）。

**可模仿的开头公式**：「[读者的原话问题]？[面试官/老板其实看的是 X，一句话]。我做了 N 年面试官，[一句身份]。今天说 N 个点。」

## B. 拆解问题的方式

几乎每篇都编号（「第一个……第二个……第三个」三个词分别出现在 27、26、27 篇里），数字以 3 为主，其次是 2、4、5。编号只是外壳，里面真正的拆法有下面几种（一篇可能叠两种）：

### B1. 先讲「招人方 / 面试官 / 老板的意图」，再推出怎么答（10 篇）
最招牌的拆法。骨架：
1. 这道题 / 这件事，对方背后真正想看什么（1—2 个东西）；
2. 所以你回答要覆盖哪 N 点；
3. 举一个例子按这 N 点走一遍。

例：
- 「实际上在问价值这个问题的时候，背后他想了解的其实两个东西」（67485624 00:00），后面接四步回答：谁的问题→不解决会怎样→指标变化→格局影响。
- 「老板们搞年终总结，实际上是为了人才盘点」（674d942f 00:09），后面推出 5 页纸。
- 「一面的面试官是谁？一般情况下都是这个岗位的直属leader」（67373af7 00:00），后面列直属 leader 会问的问题清单。
- 「年底找工作……更多的来自于原有业务的替换」（677e60b4 00:00），先讲招人方的需求，再讲求职方的四条注意。

同类：672a01c7、673c79b6、6731e899、67503ec5、678651ab、678a3d57。

### B2. 对比两类人 / 两端（8 篇）
骨架：A 类人这么做（反例，带具体表现）→ B 类人这么做（正例，带指标）→「你说面试官选谁」。
- 「凭感觉是什么？就是你问他做什么，他能答得上来，但问他为怎么做……」（6729a89c 00:10）
- 「好的人你跟他聊……三句两句就能够说明白」/「不好的人……我问东他回答西」（6749a725 00:00/00:24）
- 「年薪20万的人主要考察的是他的落地和执行的能力」vs「年薪100万……带领业务有突破」（6784f824 00:00/00:25）
- 6732dc25 五个维度里每一维都是「这个大家都会讲」vs「面试官最想听到的是……」的对比。

同类：67503ec5（年底 vs 年后）、677e60b4、67591506（新媒体 vs 平台内容运营）、677d09d8（误区 vs 正解）。

### B3. 分情况 / 按场景给不同答案（6 篇）
骨架：先说「没有统一答案，要看情况」→ 列 2—3 种情况 → 每种情况对应一个处理。
- 「一定是见人下菜碟，见岗下菜碟的」（67445a73 00:18）：应届看潜力选 A，脏活累活选 B，特长匹配选 C。
- 「其实这个问题有几种可能性。第一种可能性，本来你做的项目就是很浅」（6749b39a 00:00）：本来浅 / 做得浅 / 讲不清。
- 「原因基本上分为两类，一类是主观原因」（6787a0f0 00:18）：意愿问题 → 利益；客观问题 → 时间 / 能力，各配一个解法。
- 「你其实要把你所有的工作分为两类。第一类叫例行的事情」（67597eaa 00:00）。

同类：6728b23b（转行先分两类人）、674c3c51（花钱找工作三类）。

### B4. 层级 / 递进（5 篇）
骨架：第一层（最普通）→ 第二层 → 第三层（最好的），每层说「这层的人是什么样、对方怎么对你」。
- 「第一个层级叫只聊工作不聊其他」→「除了工作，你跟老板还会聊你的成长」→「你在老板的未来规划里」（674ef2ed 01:02/01:28/01:59）
- 676e94cb：基础三点 → 工作思路四步 → 体系化两件 → 支撑平台三个，四层越讲越高。
- 「第四点我们还要再上升一层看一看」（67485624 01:36）：最后一点刻意拔高。

同类：676016e7（理指标→捋模式→找 key person，每一步建立在上一步上）、6756d8e0（先定标准再讲步骤）。

### B5. 误区 → 正解（5 篇）
骨架：大多数人会这么答 →「大错特错」→ 正确的逻辑是 → 再追问一层。
- 「他会觉得提升的幅度越高……我告诉大家大错特错」（677d09d8 00:16）
- 「很多人会觉得有一个误区……底气就是只给你好活」（674ef2ed 00:08）
- 「很多人会觉得我不就应该基于GD去分析需求……这个方法不也是你讲的吗？」（677fb46f 00:00）：连自己讲过的方法也拿来纠偏。

同类：67616021（长期主义 / 短期主义都错）、6732dc25。

### B6. 按角色拆（3 篇）
- 「对你的上级……其次最有帮助的关系一定是你的横向部门……第三个关系其实是部门的同级别的同事」（6752e251 00:00—01:27）
- 674c3c51：求职中介 / 课程 / 陪跑，陪跑再拆个人 IP / 机构全职 / 机构兼职。

### B7. 漏斗 / 数据诊断（1 篇，但很有辨识度）
- 「我们可以把整个求职看成一个漏斗……最上层实际上是你的打招呼的数量」（676bead4 00:37）。每层给一个阈值，再拿一位学员的 100→5→2→0 数据跑一遍。

### B8. 供需框架（1—2 篇）
- 「第一是需求侧……其次是供给侧」（67937968 00:00），预测类内容专用。

**另一个通用小动作**：先下定义再拆。「先定义什么是长期主义和短期主义」（67616021 00:00）；「首先我们先定义一下到底什么是数据能力」（6776790b 00:16）；「先说什么是嫡系」（674ef2ed 00:08）。

## C. 叙事和论证推进

### 段与段怎么接
几乎全靠**口头路标**，不靠情节：
- 序号：「第一个……第二个……第三个」（每篇平均 3 次以上）、「一个一个说」（6756d8e0 00:37）、「最后一页可以说说自己的成长」（674d942f 02:22）。
- 自问自答过门：「那怎么做呢？」「原因是什么？」「什么意思呢？」（「那怎么」12 篇，「什么意思」7 篇，「原因是什么」7 篇）。
- 先定标准再转方法：「我们先定清楚标准，然后再说一说怎么设计最好的活动？」（6756d8e0 01:34）
- 回指旧视频 / 直播：「我过去的视频也跟大家说过」（6731e899 01:20）；「这就是我经常在直播里讲到的面试官思维」（67373af7 00:49）。
- 收拢句：「所以这三个问题其实是……最核心的思考逻辑」（673c79b6 01:04），每个大块讲完都会有一个「所以」把它收一下。

### 例子来源（45 篇里出现过例子的计数，可重叠）
| 来源 | 篇数 | 典型 |
|---|---|---|
| 假设场景 / 泛化例子（「比如说你做增长……」） | ~18 | 「你就是发了优惠券，并且是一个通用的新手礼包」（6749b39a 00:47） |
| 公司 / 行业案例 | ~8 | 美团 vs 抖音、滴滴做外卖（672a01c7 01:19）；双十一、春节红包（6756d8e0 02:32）；WXG「屎上雕花」（67937968 00:56） |
| 学员案例 | ~7 | 制造业项目管理→供应链数字化 PM（6728b23b 01:09）；7 年经验 100 投 5 面（676bead4 01:49）；gap 一年大龄女生（6788f080 00:38） |
| 自己的经历 | ~4 | 字节第一次双周会「结果非常尴尬」（6752e251 01:40）；父母 98 年下岗（6793796b 00:00）；2015 创业融资（6793796b 01:29） |
| 面试过的候选人 | 2 | 度小满收银台做三年（675c21d7 00:58）；美团门票异常数据（6776790b 02:08） |

假设场景占大头，真案例偏少。**真案例反而是最好的段落**，值得学的是它们的写法。

### 例子怎么写具体
- **数字**：「100份投递，五个面试，两个二面，没有三面和offer」（676bead4 01:49）；「转化率低于40%、30%」（676bead4 00:58）。
- **指标名点名**：「从客单价、转化率、用户量、续费率这些指标里面定位」（6749a725 00:24）。读者听到的是一串真行话，可信度就来了。
- **具体动作，有前后对照**：「从过去的激励这种分享的结果变成激励分享的动作」（6749b39a 01:16）：同一个项目，浅版本是什么，深版本是什么。
- **心理活动 / 现场感**：「心高气傲对不对？……单凭自己的理解写了几条内容，结果非常尴尬」（6752e251 01:40）；「我的印象就是父亲不断抽烟的背影」（6793796b 01:00）。
- **反例演一遍**：「他巴拉巴拉十分钟项目的背景……我问你个问题，如果你是面试官，你能听进去吗？」（6733631c 00:26）
- **对话体代答**：「整个AI市场我比较关注的是AI社交。因为什么什么原因」（672a01c7 00:53），直接给出可以照抄的回答句式。

## D. 口吻

### 句子
口播长句多、靠逗号串，但信息单位很短：一个分句一个意思。高频结构是「X 是什么？就是 Y」和「为什么？因为 Z」，自问自答的节奏很密。

### 高频词（45 篇统计：出现次数 / 出现篇数）
- 一定 133 / 36：最强标志，判断几乎都带「一定」
- 非常 107 / 35（「非常非常」5 篇）
- 其实 93 / 30
- 为什么 69 / 32
- 核心 65 / 36、最核心 25 / 21
- 关键 55 / 23
- 我觉得 36 / 22
- 举个例子 35 / 21
- 实际上 31 / 19
- 本身 25 / 16
- 对吧 16 / 10、对不对 16 / 15：句尾拉听众点头
- OK 16 / 10：转场用，「OK我们找一个电商领域的增长产品」
- 你看 15 / 11（「所以你看」5 篇）
- 本质上 12 / 10
- 大概率 10 / 8
- 很简单 7 / 7、完全不一样 7 / 6
- 「说白了」0 次。他不用这个词，用「本质上」「实际上」代替

### 语气
笃定、说教、略居高临下，偶尔毒舌，不撒娇也不卖惨。判断几乎不留余地（「一定」「大错特错」「完全不会」）。毒舌对着读者的错误认知和同行：
- 「当你来问这个问题的时候，就证明你已经不是嫡系了」（674ef2ed 00:46）
- 「能说出这种话的人我告诉大家，其实都是没有干部管理的」（674ef2ed 00:08）
- 「怎么样屎上雕花，外面的人机会就更少」（67937968 00:56）

### 称呼和自称
- 称听众：「大家」（29 篇）、「同学」（26 篇；把观众默认成学员）、「你」（大量，直接对话）。
- 自称：「我」+「我们」混用。「我」是面试官 / leader 身份，「我们」是陪跑公司（「我们自己配保了」「我们带过很多个同学」）。

### 怎么下判断
- 「X 本质上就是 Y」：「招聘本质上就是招匹配度高的人」（6728b23b 01:31）
- 「X 都是 Y」式口诀：「意愿问题本质上都是利益问题」（6787a0f0 00:18）
- 「这个问题其实是有标准答案的」（676016e7 00:00、6752e251 00:00）；「标准答案又来了」（677d09d8 00:00）
- 「我告诉大家大错特错」（677d09d8 00:16）

### 10 句代表原句
1. 「招聘本质上就是招匹配度高的人。」（6728b23b 01:31）
2. 「意愿问题都是利益问题。」（6787a0f0 00:18）
3. 「你看大的不好回答，我们就收敛到我们了解的那些地方。」（672a01c7 00:53）

## E. 可信度来源

1. **身份声明（反复用）**：「七年的面试官」5 篇，「字节的产品负责人」4 篇，「工作了13年」（6776790b 00:16），「从21年开始做的」（675c21df 00:00）。用法是**一句带过，不展开**：「我自己做过七年的面试官非常清楚这一点」（6729a89c 00:00）。
2. **面试官 / 招人方视角**：「面试官思维」4 篇，「从面试官……的视角」3 篇。本质是换位：「你站在他的角度来讲，他想招一个什么样的人？」（67373af7 00:00）
3. **管理者 / 内部视角**：「今天我们从一个leader的视角给大家解读一下」（674ef2ed 00:00）；「我过去自己带团队的时候，让每一个新加入的核心的同学也都是按照这套动作」（676016e7 00:00）。
4. **规模数字（大多无出处）**：「大概有两千多名全程的求职陪跑」（67922b37 00:00）；「每个月几百个配的同学」（6751927c 00:13）；「几百名兼职合作的老师」（67728693 03:56）。
5. **具体行话和指标**：客单价 / 转化率 / LTV / AB test / 埋点 / 指标体系，一个接一个地报出来，内行感比身份声明更强。
6. **真实细节 / 自曝糗事**：「我去参加第一次双周会的时候……结果非常尴尬」（6752e251 01:40）；「拿到过大几百万融资……没有想到一年就干不下去了」（6793796b 01:29）。
7. **反常识 + 自我设限**（显得不忽悠）：「你过去明明是很小的公司，他说我一定能让你进大厂，你觉得可能吗？我做了那么久，我是没有办法承诺的」（674c3c51 03:14）；「不是所有人都适合AI产品经理的」（67728693 04:42）。
8. **结果截图 / 日程展示**：「大家可以看一下我每天的面试安排，基本上每天面2到3个老师」（675c21df 01:29）；「最后再给大家看一看我们最近拿到的offer的截图」（675c21df 01:29）。

**指令 / 建议型（9）**：建议表达能力不行的人，反复观看；面试表达能力不行的，建议反复观看；一定要在职场建立自己的人设；年底要拿offer，注意这3点；0基础转行必看：项目经历如何讲出价值；压力面试不卑不亢，才能赢得尊重；面试前，逼自己重新准备一遍项目经历；年轻人越早明白越好：领导是怎么挑选嫡系的；面试前，先停止否定现在的你，找到主线

**身份 / 数字 / 方法型（7）**：走上管理岗才发现：年终述职汇报 就看5页纸；克服「汇报羞耻」：把汇报当作SOP去执行；当前就业行情，我是怎么设计求职陪跑产品的；运营「懂业务」之，搭建自己的用户运营体系；求职博主坦白局：比暴富更拥挤的赛道—暴雷；给我的精神股东们，预测下25年的就业市场；25金三银四，只有3波找工作机会

标题规律：
- **「场景，+ 判断 / 问题」逗号二段式**最多（约 25 个）：前半句是场景（年底找工作 / 面试前 / 大厂一面过不了），后半句是判断。
- **用引号给一个概念贴标签**：「长期主义」「评价」「答对了」「汇报羞耻」「可迁移」「沟通协调」，共 9 个。
- **数字** 9 个（3 点、1 点、5 页纸、100 份、100%、3 波、10 年、25、0 基础），基本是小数字。
- **否定纠偏句式**：「真不是你简历的问题」「不是你能力不行」「你不是怕……你只是……」「并不是……才有」，替读者开脱、同时把锅换个地方放。
- 同一标题会复用：「建议表达能力不行的人，反复观看」和「面试表达能力不行的，建议反复观看」两篇内容不同、标题几乎一样。

## H. 情绪处理

先「刺」一下，再给方法，最后才安抚。他基本不哄人，安抚的方式是**把问题从「你不行」换成「你方法不对 / 你心态不对 / 你准备不够」**，读者因此觉得有办法可想。

- **先刺**：「以大多数人他的面试准备程度，其实每一次面试都是在浪费机会」（6751927c 00:00）；「最简单的说，当你来问这个问题的时候，就证明你已经不是嫡系了」（674ef2ed 00:46）。
- **去个人化（不是你能力差）**：标题「找不到工作不是你能力不行」（677fb46f）；「他分不清楚面试官给他的评价……和自己的关系」（678a3d7a 00:40）；「有些面试官他就是那种风格，或者他评价的也根本不客观」（678a3d7a 00:40）。
- **重新定义处境**：「把面试当做提升自己了解市场行情的机会」（678a3d7a 00:40）；「正因为这种贱人下菜碟……才给了我们不同特点的人他的差异化的优势」（67445a73 01:28）：把劣势翻成优势。
- **长周期 + 数据给预期**：「三个月左右的时间才是一个合理的预期」（67728693 00:46）；「大多数人拿不到offer的原因，最核心的是因为坚持的不够久」（67922b37 01:19）。用「这很正常」来降焦虑。
- **个人史安抚（仅 1 篇，但最动人）**：父母 98 年下岗、「父亲不断抽烟的背影」→自己 2012 年入互联网、2015 年创业失败→「不确定性不一定就是糟糕的」（6793796b 01:00—01:48）。
- **行情恐吓 + 给出路**（预测类）：「今年的3 4月份求职惨烈程度比去年还要更高」（67937968 01:45）→ 立刻接「不触及底线，你要谨慎离职」。
- **心态失衡的诊断**：「不自觉的就把自己会放到面试中比面试官更低的位置，就像白菜一样」（6788f080 00:38）。具体比喻加一个可以照做的处理：「你只要准备好一个合理的解释就可以了」。

## I. 招牌动作（7 个）

1. **「对方真正想看的是……」反转**：任何问题先翻到出题人那边，讲他的动机，再给答法。例：「其实不是要讨方案……我想听的是什么呢？你对这个行业和业务的理解」（672a01c7 00:19）；「老板们搞年终总结，实际上是为了人才盘点」（674d942f 00:09）。
2. **「大家都会讲 X，但面试官想听的是 X 背后的逻辑」**：把一个常识动作再往下挖一层「为什么」。6732dc25 五个维度全用这一招：「你看这个角度听起来每个人都会讲，但问题是面试官最想听到的是……」（00:41）；「他想听到的是你为什么用这种方法，而不是其他方法」（01:56）。
3. **代写一句可照抄的回答**：直接给出面试时的原话骨架。「你可以说整个AI市场我比较关注的是AI社交」（672a01c7 00:53）；「如果后续有机会合作，有更详实的数据，那策略肯定也会更准确」（678a3d57 02:56）。
4. **把业务方法论搬到求职上**：漏斗、转化率、复盘、SOP、标杆分析、供需侧，全部拿来分析找工作这件事。「我们是把做业务的思路和找工作这件事情结合起来」（676bead4 00:00）；「把汇报当作SOP去执行」（67597eaa 标题）。
5. **浅 / 深同题对照**：同一个项目给出浅版和深版两种做法，读者马上看懂差在哪。「如果你只是做了一个分享有礼的功能，那简不简单？非常简单。但是如果你做的深一些……」（6749b39a 01:16）。
6. **见人下菜碟 / 没有统一标准**：先宣布「没有标准答案」，再按岗位、阶段、职级给不同答案；年薪 20 万 vs 100 万、应届 vs 社招。「他不是一概而论的」（67445a73 00:59）。
7. **一句口诀定性**：在拆完之后压成一句可记的话。「意愿问题都是利益问题」（6787a0f0 00:18）；「高涨幅来自于……上一段经历的变现」（67922b37 00:26）；「先有根再发散」（677fb46f 01:03）。
8. **白嫖识别 / 反套路**：教读者识别面试官的坏心思，站在读者一边。「他一上来就问你这个问题大概率是白嫖」（678a3d57 00:00）。

- 「谁触碰到我的核心利益，那我就需要让他知道我不是那么好惹」（672b5137 01:10）：职场对抗话术，对 0—3 年新人有风险。

- 「面试官没问你为什么gap……你反复自己提，反而会让面试官慎重的去想」（6788f080 00:00）：本身合理，但要和「被问到要如实答」配套讲，不然像教人隐瞒。

**表达上的坏习惯**
- 「一定」133 次，几乎每个判断都绝对化。
