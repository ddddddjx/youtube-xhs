# 段落改写与验证复核

## 一、三组段落改写

附件里没有小熊已发布文章的正文，所以**三组「旧版」段落都是依据旧规则模拟写出的，不是已有文章**。模拟时严格按旧规则：首页不下总判断、问读者两点、机制腔词替换、「你可能会说」「如果你问我」各一次、「我」主语不超过 6 句。新版段落取自验证稿。

### 第一组：开头

**旧版（依据旧规则模拟）**

> 你在准备四大审计的面试，刷到一道题：「询证函发出去两周没回，你怎么办？」心里大概有个答案，说出口又总觉得差点什么。
>
> 你对函证熟到哪一步，是只知道名字，还是知道每一步在干什么？手上有没有一段能让面试官信的经历？这两件事不同，答法也不同。

**新版**

> 面试官问：「你发出去的应收账款询证函，两周了还没回，你怎么办？」
>
> 这道题考的是审计里的一项基础程序。寄函、跟函、登记回函，常有新人和实习生参与，具体分工各所、各项目不同。面试官想确认两件事：你知道函证为什么可靠，也知道回函不来的时候，证据要从哪里补。

**改善了什么**

- 信息到达更早：读者第二段就知道这道题在确认什么，第四段开始拿到答法。旧版两段都在描述处境和反问，第一屏没有信息。
- 和林木技法 1、10 一致：开口摆原问题，马上翻译成考点。
- 事实边界：「常有新人参与」是行业常见说法，紧跟「各所不同」，没有写成确定事实，也没有用「我带过的实习生」之类的经历撑场。

### 第二组：专业解释

**旧版（依据旧规则模拟）**

> 你可能会说：我又没做过审计，回函没来该干嘛，我怎么会知道。
>
> 招人一方担心的，是新人卡住以后就停在原地，等别人来推。所以这道题要答出两样：你会找什么东西补上，你会去问谁。

**新版**

> 第三步，做替代程序。应用指南第 18 段给了例子：应收账款，检查期后收款、货运单据和临近期末的销售；应付账款，检查期后付款、和供应商的往来函件，以及货物收讫凭证等记录。期后收款最好理解：客户在资产负债表日之后真的把这笔钱付了，就能支持这笔应收确实存在。

**改善了什么**

- 专业性从姿态变成内容：旧版说「招人一方担心」，读者读完仍不知道该找什么；新版给出准则里列明的程序、出处段落和一句原理。
- 术语回到正文：「替代程序」「期后收款」是读者入职后要用的词，旧规则的替换表会把「证据」改成「拿得出手的事」，新版保留并解释。
- 去掉表演：旧版的「你可能会说」是为满足配额虚构的反驳。

### 第三组：建议

**旧版（依据旧规则模拟）**

> 如果你问我，我会把时间花在讲清一件小事上，代价是少讲几个程序名，前提是你真的做过。还没有任何审计实习的同学，这条不适用。

**新版**

> 这些判断由项目上的注册会计师来做，新人不用、也不该自己拍板。所以回答最后可以补一句：替代程序做完，把未回函清单、跟进记录和替代程序结果整理好交给 senior，有异常的单独标出来。我觉得这一句比多背几个程序名更有用，它说明你清楚自己在项目里的位置，也知道异常该往哪里报。

**改善了什么**

- 判断有依据：前一段引用了应用指南第 19、20 段（回函数量异常、积极式回函必要的两种情况），作者的偏好建立在这个事实上。
- 建议能直接用：给出一句能加进回答的话，比「讲清一件小事」具体。
- 「我」出现在真正下判断的地方，没有用「如果你问我」包装。
- 适用条件放在别处具体写（没做过函证的人怎么说、投税务咨询岗怎么调整），没有用一句「这条不适用」草草带过。

## 二、验证稿复核

验证稿：`04_验证稿_函证没回函.md`。选题理由：

- 读者和决定：投四大或本土所审计岗的在校生、审计实习生；决定是这道题怎么答、实习里遇到时怎么做。
- 素材支撑：中注协官网公开的《1312号——函证》准则文本和 2023 年修订的应用指南原文，可以逐段核对；银行函证时限有财政部文件。
- 不与已发内容重复：后台 505 个标题里没有函证题。和 9 月的《审计面试遇到异常数据》《审计面试遇到数据造假》比，决定和原因都不同。
- 题材类型：B 类（面试实操），对应数据里收藏率高的方向，同时落在主场。

### 2.1 第一稿到定稿的修改

| 位置 | 第一稿 | 定稿 | 原因 |
|---|---|---|---|
| 第二段 | 审计里最基础的一项程序 | 审计里的一项基础程序 | 「最基础」没有依据，也是极限表述 |
| 第三段 | 可靠性落在「直接」「书面」两点 | 引用准则第三条的三条一般原则 | 用原文代替概括，专业信息更完整 |
| 新人一节开头 | 很多回答停在替代程序 | 答到替代程序，还差一句 | 「很多回答」是没有出处的概括 |
| 串成一段话之后 | 面试官很容易听出哪些是背的 | 追问一深，背出来的流程很难接住细节 | 原句是对面试官能力的断言，改成可理解的原因 |
| 末节 | 这道题出现的机会小 | 函证和日常工作关系不大 | 「出现机会小」没有数据，改成理由 |

### 2.2 对照新规则

| 检查项 | 结果 |
|---|---|
| 一个读者、一个决定 | 审计岗面试者；这道题怎么答 |
| 信息增量 | 准则定义和可靠性原则、三步程序及出处、替代程序例子、两种替代程序不够的情况、三道追问、银行函证时限 |
| 判断后有原因和条件 | 每个做法都有出处；没做过函证、投税务咨询岗、面试官考沟通三种情况分别写了怎么调整 |
| 专业解释接得上 | 岗位要做什么（发函、跟进、替代程序）→ 招人方确认什么（知道证据从哪补、知道异常往哪报）→ 读者怎么说（串成的一段话） |
| 事实可追溯 | 来源清单列出准则条号、应用指南段落号、文件文号；C 级说法已标注 |
| 术语解释一次 | 函证、替代程序、积极式询证函、不符事项 |
| 标题兑现 | 标题问「怎么答」，正文第四段开始答 |
| 先否定再纠正 | 0 处（脚本提示 0 条，人工复读确认） |
| 固定引导句 | 没有「你可能会说」「如果你问我」 |
| 「我」 | 一处，「我觉得这一句比多背几个程序名更有用」，是判断，不是经历 |
| 私信邀请 | 未放。B 类可选，本篇读者需要的是答法，放邀请会打断 |
| 平台字段 | 短标题 16 字；总结 236 字；备选标题 4 个 |
