## 00｜分析

### 参考图的设计语言
- **风格**：日系手绘线稿 + 平涂，扁平无透视，像一页手账。关键是「同一套线稿语言统一四种内容」，不是那个女孩
- **构图**：横向等宽 4 格 + 中间主角破格；格子底边对齐在一条横向「管道」上，管道就是叙事线（系统被串起来）
- **字体**：只有一种，粗黑体中文标签，居中放在格子下方；图里的「文字」全是灰色占位条，信息层级靠粗细和位置，不靠字号堆
- **颜色**：暖米白底 + 黑色墨线 + 一个高饱和强调色（荧光草绿）+ 两三档灰绿 / 灰 + 极少量腮红粉。强调色占比约 10%，只出现在要看的地方
- **留白**：格与格之间、格内都很松，单格信息 3–6 个元素
- **图形**：1.5–2px 黑色手绘描边，小圆角（约 8px）白卡；卡片四角有强调色取景框角标；流程图用圆角矩形 + 圆点 + 菱形 + 细箭头 + 虚线；漫画式放射短线表示「亮了」
- **插画/图片**：全部是插画，没有摄影和产品图；人物就是 IP，在各格里换姿势换场景（封面里探头、插画里趴着看电脑）
- **材质光影**：无阴影、无渐变、无发光，纸感底色，平面

### 头像里已有的个人识别
- **主色**：纯黄 `#FFE600`（头像底色）+ 黑。黄黑是警示牌配色，最高对比，缩略图里第一眼就能认
- **IP**：爱因斯坦吐舌头 → 已经被做成漫画 IP「K 老师」：聪明、嘴欠、不端着
- **插画风格**：头像是半写实厚涂；但账号里 K 老师已经是白底粗黑线的漫画造型
- **字体气质**：账号定了黑体，直接、不文艺
- **品牌气质**：顶尖理解 + 稍微毒舌 + 有点搞笑。「懂行但不装」

### 融合原则
1. 参考图借 **方法**：手绘线稿统一所有图、米白纸底、单一强调色、取景框角标、管道式串联、松的留白
2. 头像给 **身份**：草绿换成头像黄，女孩换成 K 老师，气质从治愈换成「懂行的坏笑」
3. 头像的厚涂写实只留在头像本身，配图里的 K 老师一律是线稿版
4. 黄色在米白底上做细线和文字会看不清，所以黄只做 **面**（底块、高亮、色条），线和字永远是黑

## 01｜核心视觉风格
**手绘线稿 · 米白纸底 · 黄黑高对比 · 单一强调 · 松留白 · K 老师坏笑 · 扁平无阴影 · 像一页聪明人的手账**

## 02｜颜色系统

| 角色 | 色值 | 用途 | 比例 |
|---|---|---|---|
| 背景 | 米白 `#F7F5EF` | 全图底色（纯白 `#FFFFFF` 只用于卡片内部） | 60–70% |
| 文字 / 墨线 | 墨黑 `#1A1A1A` | 标题、正文、所有描边、箭头 | 15–20% |
| 主色 / 强调 | 头像黄 `#FFE600` | 关键词荧光笔底、重点色块、数据里的「主角」系列、角标 | 8–12% |
| 辅助灰 | 深灰 `#5C5C5C` / 中灰 `#BDBDBD` / 浅灰 `#E6E4DE` | 次要文字、非重点数据、占位、分隔 | 5–10% |
| 警示 | 红 `#FF5A5A` | 只用于证据截图红框、负值、「错误示范」叉 | <2% |
| 点缀 | 腮红 `#F4B6B0` | 只用于 K 老师脸颊 | 极少 |

规则：一张图只有一个黄色焦点区；黄上的字用墨黑，不用白；不加第二个彩色强调色。

## 03｜字体系统
- **中文**：思源黑体 / Noto Sans CJK SC（Mac 上 PingFang SC 等效）。不用宋体、手写体、圆体、艺术字（用户 10-03）
- **英文**：Inter（无则同用思源黑体自带西文）。专有名词保留原拼写，不全大写
- **数字**：Inter / DIN 风格等宽数字，数据卡里的大数字用 Black 字重
- 层级（1080×1440 画布）：

| 层级 | 字号 | 字重 | 规则 |
|---|---|---|---|
| 封面大标题 | 110–150px | Heavy / Black | ≤2 行，每行 ≤10 字；关键 2–4 字加黄色荧光笔底 |
| 页标题 | 64–80px | Bold | 1 行为主 |
| 副标题 / 引子 | 40–52px | Bold | 可放黄底小条 |
| 正文 | 34–40px | Regular / Medium | 行高 1.6，每行 ≤18 字 |
| 标注 / 来源 | 24–28px | Regular，深灰 | 来源写全名 |

- 一张图最多 3 级字号；强调只用「加粗 + 黄底」，不用斜体、描边字、渐变字

## 04｜版式系统
- **画布**：小红书 3:4，1080×1440
- **Grid**：12 栏，左右边距 72px，栏间距 24px，8px 基线；常用拆法 12（通栏）/ 6+6 / 4+4+4 / 8+4
- **对齐**：正文左对齐；封面标题和单个大数字可居中；同一张图不混用两种对齐
- **留白**：外边距 ≥72px，模块间距 ≥48px，内容总面积 ≤65%
- **信息密度**：一张图一个结论；信息图 ≤6 个节点，数据图 ≤1 张主图表
- **视觉重心**：上 1/3 放标题，焦点（黄块或 K 老师）落在上 2/3
- **常用构图**：① 大字 + 角落 K 老师（封面）② 横向管道串 3–5 格（流程 / 系统）③ 左右对比两栏（before / after，我 vs 他）④ 中心大数字 + 下方小注（数据卡）⑤ 上图下文（截图证据页）

## 05｜图形系统
- **线条**：墨黑 3px（1080 宽下），手绘略抖但不潦草；虚线 3px、段长 12px 表示「可选 / 推测」
- **圆角**：卡片 16px，标签胶囊 999px，按钮式块 12px；同一张图只用一种卡片圆角
- **卡片**：白底 `#FFFFFF` + 3px 墨线描边，无阴影；重点卡片四角加黄色取景框角标（L 形，线宽 8px、边长 40px）
- **标签**：胶囊形，黄底黑字或浅灰底深灰字，字号 26–30px Bold
- **箭头**：墨黑实线 + 实心三角头；连接多个模块时用「管道」：粗 20–24px 的黄色圆角带 + 黑描边 + 黑色卡扣，代表流程 / 串起来
- **图标**：线性图标，3px 黑线、圆端，放在 72–96px 的黄圆底里；一套图标线宽一致
- **边框**：整图不加外框
- **辅助图形**：漫画放射短线（「亮了 / 重点」）、手绘下划线、手绘圈、小叉小勾；每张图 ≤2 处

## 06｜图片与插画系统
- **K 老师（IP）**：线稿版爱因斯坦小人——灰色炸毛、灰胡子、吐舌头、黑外套、黄领带、脸颊一点腮红；3px 墨线 + 平涂。表情只用：坏笑吐舌、挑眉、无语、指着讲。每张图最多出现一次，占画面 15–35%；不是每张都要有（数据图、证据页可以没有）。形象来自 `characters.py`，新姿势在那里加
- **头像本身**：厚涂写实版只用于头像，不进配图
- **插画**：场景用同一套线稿 + 平涂，配色只用灰阶 + 黄；比喻角色（机器人 = AI / Agent）同样线稿
- **摄影**：原则上不用；必须用时去饱和到灰阶，放进白卡片里，加 3px 墨线框
- **产品图 / Logo**：放白卡片内，保持原色但缩小（≤卡片 40%），不加特效
- **UI 截图 / 原文截图**：原样不改色，放白卡片里，圆角 16px + 墨线框；要看的地方用红 `#FF5A5A` 框或黄色荧光笔底标出，每张 ≤2 处；下方 24px 深灰小字写来源

## 07｜数据可视化系统
- 先准：数值、单位、时间、来源写清楚；纵轴从 0 开始（柱状图强制）；不用 3D、不做透视
- **配色**：要读者看的那个系列用黄 `#FFE600`（带 3px 黑描边），其他系列用中灰 / 浅灰；最多 1 黄 + 2 灰；负值或「坏」用红
- **柱状图**：柱宽 = 间距的 1.5 倍，直角或顶部 4px 小圆角；数值标在柱顶，不靠读者看刻度
- **折线图**：线宽 4px，数据点为白心黑边圆点；只给关键点标数值；主线黄（黑描边）或墨黑，对照线中灰
- **饼图**：只在 ≤4 个分类、表达占比时用，优先做成环形；主角扇区黄，其余灰；百分比直接写在旁边
- **数字卡**：大数字 120–180px Black 墨黑，下面一行 28px 说明 + 参照物（「相当于……」）；只给一个数字加黄底
- **网格线**：只留浅灰横线 1px，去掉纵线和边框；图例尽量改成直接标在线 / 柱旁
- **来源**：图下左侧 24px 深灰「来源：xxx，yyyy-mm」

## 08｜四类配图规则
- **文章封面**：米白底 + 1–2 行超大黑体标题（关键词黄底）+ K 老师角落出镜（坏笑或无语）+ 可选一个与题目有关的道具；缩到 300px 宽标题仍能读清；不放栏目期数、不放 headline 以外的小字
- **信息图**：一个结论做标题，下面用管道或卡片网格串 3–6 个节点；节点 = 白卡 + 图标 + 一句话；只有终点或关键节点用黄；K 老师可选，放在边角指着重点
- **数据图**：一张图只讲一件事；标题直接写结论（「X 一年翻了 3 倍」而不是「X 增长情况」）；按 07 执行；K 老师默认不出现，最多一个小头像在角落做表情
- **插画**：叙事场景（K 老师 + 机器人 / 道具），手绘线稿 + 平涂，灰阶为主、黄只点一处（领带 + 一个关键物件）；背景简化成一两条地平线或几笔环境，不画满

## 09｜固定不变 / 可以变化 / 禁止出现
**固定不变**：黄 `#FFE600` + 墨黑 + 米白三色骨架；黑体；3px 手绘墨线；无阴影无渐变；K 老师造型（灰炸毛、吐舌、黑外套黄领带）；3:4 画布和 72px 边距；一张图一个黄色焦点

**可以变化**：构图（五种常用里选）；K 老师的姿势表情和道具；卡片数量和排布；灰阶深浅；是否出现 K 老师；管道 / 箭头 / 网格哪种连接方式

**禁止出现**：第二个彩色强调色（蓝、紫、绿等）；渐变、玻璃拟态、发光、投影、3D；宋体、手写字体、艺术字；黄底白字或米白底黄字黄线；赛博朋克 / 霓虹 / 「AI 科技蓝」机器人；写实照片当主视觉；厚涂写实 K 老师；表情包堆叠、emoji 当图标；极限词、二维码、站外链接、栏目期数；高尔夫和 F1 元素（用户 10-04）；直接复刻参考图的草帽女孩、绿色管道配色

## 给 AI 生图直接用的 Prompt

### 中文版
```
小红书配图，3:4 竖版 1080×1440。风格：日系手绘线稿 + 扁平平涂，像一页聪明人的手账，无阴影、无渐变、无 3D、无发光。
背景：暖米白纸色 #F7F5EF，大量留白，内容不超过画面 65%，四周至少 72px 边距。
颜色：只用墨黑 #1A1A1A、头像黄 #FFE600、灰阶（#5C5C5C / #BDBDBD / #E6E4DE）。黄色只做色块和荧光笔底，不做细线和文字；全图只有一个黄色焦点。不要任何其他彩色。
线条：3px 墨黑手绘描边，略抖但干净；卡片为白底 + 黑描边 + 16px 圆角，重点卡片四角有黄色 L 形取景框角标；箭头为黑色实线三角头；多个模块用一条带黑描边的黄色圆角「管道」串起来。
字体：粗黑体中文（思源黑体 Heavy/Bold），标题关键词加黄色荧光笔底；不要宋体、手写体、艺术字。
IP 人物「K 老师」：线稿版卡通爱因斯坦——灰色炸毛、灰胡子、吐舌头坏笑、黑外套、黄领带、脸颊一点粉；与画面同样的线稿平涂画法，占画面 15–35%，只出现一次。
气质：懂行、有点毒舌、带点搞笑，不可爱、不治愈、不科技蓝。
```

- 封面：`1–2 行超大黑体标题占上 1/3，关键词黄底；K 老师在右下角探头坏笑；300px 缩略图下仍可读。`
