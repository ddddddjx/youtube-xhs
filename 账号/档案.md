## 四轮访谈（每轮 2 到 3 个问题，答完再问下一轮）

### 第一轮 你是谁（收集过来人信任）
1. 你的职业 / 专业背景？现在每天的工作里 AI 占多大比例？
2. 用 Claude / Agent 干活多久了？日常高频用的是哪几个？
3. 有没有一次「从踩坑到开窍」的真实经历？（哪天、在做什么、卡在哪、后来怎么通的）
答（2026-09-30）：
1. Tech 行业产品经理，CMU 毕业。每天工作里 AI 占比「100% 以上」（原话）。
2. 用 Claude / Agent 干活 2 年，Claude、Codex、Grok 都用。
3. 印象最深的一次：Claude 的 managed agent team 刚出的时候，第一次配置了自己的 agent team：一个接 data query 的 MCP，一个搭前端，一个做数据分析，几个 agent 之间互相同步进度。背景记不清具体月份了。用户的观察：现在工作里不同 role 之间的界限越来越模糊。→ 经历库 #2、观点库 #7。

### 第二轮 你服务谁（收集信息差焦虑）
4. 目标读者一句话，越窄越好。
5. 这群人最大的焦虑是什么？怕错过什么、怕不会什么？
6. 看完你的笔记，他们最想立刻能做到什么？
答（2026-09-30）：
4. 对 AI 和自我成长刚感兴趣的人（用户原话）。两群观众都在这个范围里：技术男性偏「AI」，成长女性偏「自我成长」，选题在两边轮换，但每篇都要同时碰到「AI」和「我自己怎么办」。
5. 焦虑两层：怕被 AI 淘汰；自我成长的 FOMO、peer pressure。→ 选题要落到「别人已经在这么用了，你还没」和「这一步今天就能做」。
6. 用户答的是账号目标：看完先关注。读者侧的动机（Claude 替填，待确认）：拿走一个今天就能试的动作或模板，并且知道下次再来这里还能拿到。转关注靠这个，不靠喊。

### 第三轮 你做什么（收集高收藏形态）
7. 想聚焦哪些场景？（AI + 写作？AI + 编程？AI + 起号？）
8. 能给读者什么赠品？（模板、清单、提示词、自查表）
9. 偏好哪种形态？（知识卡、长文精读、漫画、视频）
答（2026-09-30）：
7. 三条线：AI agent 怎么配（自己工作里的一手体感）／ 海外一手内容解读（现有主线）／ AI 新创意（新工具、新玩法）。
8. 赠品现成有：提示词、skills、agent 配置。每篇的领取物优先从这三样里出，比「自查表」硬。
9. 知识卡、长文精读为主，漫画和视频保留。

### 第四轮 你怎么做（收集差异化）
10. 独家信息源？（英文一手、内测、付费社群、深度用户）
11. 人设语气？（过来人 / 极客 / 毒舌 / 温柔 / 搞笑）
12. 每周几篇？
答（2026-09-30）：
10. 都有：英文一手、内测资格、付费社群、自己工作里的一手体感。稿子里可以写「我在内测里看到」「我工作里试过」，但具体是哪家内测、哪个社群，写之前先确认能不能说。
11. AI 专家为主，稍微毒舌，带点搞笑。毒舌对着现象和自己，不对着具体的人；搞笑靠事实错位，不加「哈哈」。
12. 每天至少一篇。
