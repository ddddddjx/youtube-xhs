# 范本：写稿前先读

范本分两类，作用不同，写稿前各读一篇：

| 类 | 放哪 | 学什么 | 不学什么 |
|---|---|---|---|
| **自己的**（Krypto说AI 表现最好的稿子） | 本目录，`<日期>_<短标题>/` | 语气、「我」怎么出现、判断怎么下 | |
| **对标的**（MemeInformation） | 见下面的索引，原文在 `对标/MemeInformation/文字稿/` | 结构：开头场景、首页反差、三点拆法、页末钩子、结尾回扣 | 不复述、不改写它的内容和具体案例；「刚好」式品牌植入、专名开头的标题不学（手册第 13 节） |

最多留 5 篇自己的，新的进旧的出。每篇目录里放 正文.txt、draft.md（有的话）和一行数据（日期、点击率、收藏、涨粉）。
